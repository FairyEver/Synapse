# 8.0 执行计划

## 当前分支

- 分支：`第四步A`
- 起点：从 `第三步` 新建。
- 初始状态：`git status --short --branch` 显示工作区干净。

## 假设

- 本阶段项目粒度沿用现有仓库配置的 `repository.uuid` 作为 `projectId`。
- Renderer 只传 `projectId`、`sessionKey` 和消息内容；工作目录由 main process 从配置中解析，不信任 renderer 传入本地路径。
- 本阶段只支持本地 renderer reply target，不实现 Bridge、飞书、Cron、Relay 或 side-channel send。
