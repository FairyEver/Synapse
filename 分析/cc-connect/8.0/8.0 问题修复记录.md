# 8.0 问题修复记录

## 1. 首轮 typecheck 失败

- 命令：`pnpm desktop:typecheck`
- 结果：失败。
- 原因：
  - `agentIpcModule` 作为 `IpcModule` 声明后，handler 泛型没有从 zod schema 自动缩窄，`request` 被推断为 `unknown`。
  - `ReplyOutboxService` 需要 `OutboxPayloadV1`，但 data-repo barrel 未导出该类型。
- 修复：
  - 给 Agent IPC handler request 参数补显式 `z.infer<typeof schema>` 类型。
  - 从 `desktop/electron/runtime/data-repo/index.ts` 导出 `OutboxPayloadV1`。
  - 从 `desktop/electron/runtime/data-repo/schemas/index.ts` 补导出 `OutboxPayloadV1`。
- 复测：`pnpm desktop:typecheck` 通过。

## 2. Agent IPC 测试桩泛型类型失败

- 命令：`pnpm desktop:typecheck`
- 结果：失败。
- 原因：`electron/modules/agent/__tests__/ipc.test.ts` 中 `ctx.resolve` 测试桩返回值过窄，不满足 `IpcHandlerContext.resolve<T>()` 泛型签名。
- 修复：给测试中的 `ProjectContainer`、`ProjectContainerRegistry.open`、`IpcHandlerContext.resolve` 补明确类型，避免用不完整对象隐式匹配泛型服务注册表。
- 复测：`pnpm desktop:typecheck` 通过。

## 3. Renderer Chat 无项目状态残留

- 发现方式：源码收尾检查。
- 结果：无 active project 时，`useAgentChat` 会返回但不清空上一项目的 sessions/timeline/providers。
- 修复：在 `projectId` 为空时清空 Chat 状态，并将 session key 复位为本地默认值。
- 复测：`pnpm desktop:typecheck`、`pnpm desktop:test` 通过。
