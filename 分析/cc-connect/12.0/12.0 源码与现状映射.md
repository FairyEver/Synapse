## 2. CC Connect 关键行为

### Cron 数据与调度

- `core/cron.go:22-40` 的 `CronJob` 字段包括 `id/project/session_key/cron_expr/prompt/exec/work_dir/description/enabled/silent/mute/session_mode/mode/timeout_mins/created_at/last_run/last_error`。
- `prompt` 与 `exec` 互斥；`IsShellJob()` 只看 `Exec != ""`。
- `ExecutionTimeout()`：`timeout_mins` 缺省为 30 分钟；`0` 表示无限等待；负数非法。
- `session_mode` 合法值是空值/`reuse`/`new_per_run`/`new-per-run`，空值和 `reuse` 等价。
- Scheduler 用 robfig cron；`scheduleJob` 的 callback 只捕获 `jobID`，执行前重新 `store.Get(jobID)` 并再次检查 `Enabled`。
- disable/delete/update cron_expr 会移除旧 entry；`NextRun` 从 cron entry 读取。
- `MarkRun` 更新 `LastRun` 和 `LastError`。Synapse 需要额外记录 `lastStatus/runCount/nextRunAt`。

### Cron 执行与 Feishu 主动回传

- `Engine.ExecuteCronJob` 从 `sessionKey` 前缀推断平台；多工作区旧实现还会剥离 workspace 前缀。
- 平台必须实现 `ReplyContextReconstructor`，否则 Cron/Heartbeat 无法主动回传。
- `silent` 只抑制开始通知；`mute` 包装 `mutePlatform`，开始通知和 Agent/exec 结果都不发。
- prompt job 构造 synthetic `Message`：`UserID/UserName=cron`、`Content=job.Prompt`、`ModeOverride=job.Mode`。
- `reuse` 用当前 active session；`new_per_run` 创建 `NewSideSession`，interactive key 包含 side session id，不覆盖 active session。
- `job.WorkDir` 优先切换 workspace agent/session；其次按 multi-workspace binding 解析；否则用全局 agent。
- shell job 走 `sh -c`，设置 cwd，按 timeout 运行，stdout/stderr 合并，输出截断到 3000 字符后回传。

### `/cron` 命令

- `core/engine.go:9426-9657` 支持 `/cron add/addexec/list/delete/del/rm/remove/enable/disable/mute/unmute/setup`。
- `/cron add` 取前 5 段 cron，余下为 prompt，绑定当前 `msg.SessionKey`。
- `/cron addexec` 要求 admin；同样取前 5 段 cron，余下为 shell command。
- list 展示 enabled/mute、cron human/expr、next run、last run/error。

### Side-channel Cron Add

- `core/api.go:223-309` 的本地 API `POST /cron/add` 复用本地 token/API；请求支持 `project/session_key/cron_expr/prompt/exec/work_dir/description/silent/session_mode/mode/timeout_mins`。
- 未传 project 时，只有单项目才自动推断；未传 session_key 时，只有当前项目唯一 active session 才自动推断。

### Heartbeat

- `core/heartbeat.go` 的配置包括 `enabled/interval_mins/only_when_idle/session_key/prompt/silent/timeout_mins`。
- `Pause/Resume/SetInterval/TriggerNow` 可管理运行态；状态记录 `runCount/errorCount/skippedBusy/lastRun/lastError`。
- `execute` 读取配置 prompt；空 prompt 时读 `HEARTBEAT.md`，再 fallback 默认 prompt。
- `Engine.ExecuteHeartbeat` 构造 synthetic `Message`，`UserID/UserName=heartbeat`，复用 active session，主动回传走和 Cron 相同的 `ReconstructReplyCtx`。

### Feishu reply context

- CC Connect Feishu `makeSessionKey`：thread isolation 群聊为 `feishu:<chatID>:root:<rootID>`；share channel 为 `feishu:<chatID>`；默认为 `feishu:<chatID>:<userID>`。
- `ReconstructReplyCtx` 从 sessionKey 还原 chatID；`root:`/`thread:` tail 会恢复 root message id。
- `Send`/`Reply` 在有 messageID 时用 reply API，否则 create message 到 chat。

## 3. Synapse 当前可复用能力

- `AgentMessage` 已有 `projectId/sessionKey/channelKey/platform/replyCtx/modeOverride/workspaceKey/workspacePath`。
- `AgentRuntimeService` 已按 `projectId + workspaceKey + sessionKey` 隔离 live session、queue、pending permission、history；`CC_SESSION_KEY` 仍由 side-channel env 使用原始 `sessionKey`。
- Feishu normalizer 已生成 `sessionKey`、`channelKey`、`replyCtx`；`reconstructFeishuReplyContext` 可从 sessionKey 重建基础主动回传上下文。
- `FeishuReplyService` 可从 `ReplyTarget` 主动发送文本、权限卡片、side-channel 附件；connector 未运行时会报 `Feishu connector "... " is not running`。
- `WorkspaceBindingRepository` 已实现 project/shared binding、project 优先、shared fallback。
- `SideChannelService` 已通过 `NetworkServiceRegistry` 提供 `POST /send` 和 token 鉴权，并给 Agent 注入 `CC_PROJECT`、`CC_SESSION_KEY`、`SYNAPSE_SIDE_CHANNEL_URL/TOKEN`。
- `ControlledProcessRunner` 已封装 `PermissionGuard.check()`、`AuditSink.record()`、timeout、stdout/stderr buffer。
- `connectors` IPC、preload、settings Feishu panel 已存在，可扩展 Feishu 自动化区域。

## 4. 当前缺口

- 缺 `scheduled.jobs` 与 `scheduled.heartbeat` schema、repository、状态字段。
- 缺 5 段 cron parser、nextRunAt 计算、持久化恢复和 timeout 调度服务。
- `AgentRuntimeService.send(...)` 总是使用 active conversation，缺 `new_per_run` side session 入口。
- Feishu connector 缺 `/cron` 与 `/heartbeat` 命令拦截。
- Side-channel 只有 `/send`，缺 `/cron/add` endpoint 和 `SYNAPSE_CRON_ADD_URL` env。
- Shell exec cron 尚未通过受控 runner 串起 cwd 优先级、timeout、输出截断和 Feishu 主动回传。
- 缺 Heartbeat 配置、pause/resume/run now 与 UI/IPC。
- 设置页缺 Feishu 定时任务管理 UI。
