# 12.0 问题修复记录

## 1. Side-channel 新类型未导出

- 现象：`pnpm desktop:typecheck` 报 `SideChannelCronAddContext`、`SideChannelCronAddResult` 未从 `../side-channel` 导出。
- 原因：新增类型只写入 `side-channel/types.ts`，遗漏 barrel export。
- 修复：在 `desktop/electron/services/side-channel/index.ts` 导出 `SideChannelCronAddContext`、`SideChannelCronAddHandler`、`SideChannelCronAddRequest`、`SideChannelCronAddResult`。
- 复测：`pnpm desktop:typecheck` 通过。

## 2. IPC codegen 校验初次失败

- 现象：`pnpm desktop:check:ipc-codegen` 初次失败，提示 `electron/generated/ipc-channels.generated.ts` differs from committed file。
- 原因：新增 connectors IPC 方法后生成文件已更新，但该脚本通过 `git diff --quiet` 检查生成文件相对 index 的差异。
- 修复：执行 `pnpm desktop:generate:ipc` 更新生成文件，并暂存 `desktop/electron/generated/ipc-channels.generated.ts` 后复跑校验。
- 复测：`pnpm desktop:check:ipc-codegen` 通过。
