# 12.0 执行计划

## 1. 成功标准

1. Feishu `/cron` 可创建、列出、删除、启用、禁用、mute/unmute prompt/exec job。
2. Cron prompt job 到点后构造 synthetic `AgentMessage` 进入 AgentRuntime，并主动回到原 Feishu session。
3. Cron exec job 到点后使用 `ControlledProcessRunner` 执行 shell，受 PermissionGuard/AuditSink 约束，并主动回传结果。
4. `silent` 只抑制开始消息，`mute` 抑制所有回传但仍记录状态。
5. `sessionMode=reuse` 复用 active session；`new_per_run` 创建 side session，不覆盖 active conversation。
6. Side-channel 增加 `/cron/add`，Agent env 包含 cron add URL/token/session 信息。
7. Heartbeat 可配置、暂停、恢复、run now，并走 AgentRuntime/Feishu 主动回传。
8. 设置页 Feishu 区域可查看和管理定时任务与 Heartbeat。
9. 必须命令全部通过并写入测试记录。

## 2. 实现顺序

### 步骤 A：数据模型与 repository

- 新增 `scheduled.jobs` schema 和 `ScheduledJobRepository`。
- 新增 `scheduled.heartbeat` schema 和 `HeartbeatRepository`。
- repository 层验证 prompt/exec 互斥、cron 合法、`timeoutMins=0` 合法、不可变字段不被覆盖。

验证：repository 单测。

### 步骤 B：cron parser 与 SchedulerService

- 实现 5 段 cron parser：`minute hour day month weekday`。
- 支持 `*`、`*/n`、单值、范围、范围步进、逗号列表。
- 计算 `nextRunAt`，本机时区。
- SchedulerService 启动恢复 enabled job，add/update/delete/enable/disable/run now 都重新读取 repository。
- timer callback 只捕获 jobId。

验证：scheduler 单测。

### 步骤 C：AgentRuntime side session

- 新增 `sendNewSession(...)` 或等价入口。
- 新入口创建 inactive side conversation，`resumePolicy=fresh`，state key 带 side conversation id。
- 不改变原 active conversation，不改变 `CC_SESSION_KEY`。

验证：AgentRuntime 单测。

### 步骤 D：CronExecutionService

- 构造 Feishu `ReplyTarget`，优先 job.replyCtx，缺失时用 sessionKey 重建。
- 执行前检查 Feishu connector 是否 running；缺失则 job failed。
- prompt job 构造 synthetic `AgentMessage`，按 sessionMode 调用 AgentRuntime。
- exec job 解析 cwd 优先级：`workDir -> workspacePath -> binding -> project workspacePath`，并用 `ControlledProcessRunner` 运行。
- 写回 `lastRunAt/lastError/lastStatus/runCount`。

验证：主动回传、prompt、exec 单测。

### 步骤 E：Feishu 命令与 Side-channel

- FeishuConnectorService 在进入 AgentRuntime 前拦截 `/cron` 和 `/heartbeat`。
- `/cron add` 支持 quoted/unquoted cron expr。
- `/cron addexec` 复用 Feishu admin，并在创建时做 shell.exec permission/audit 检查。
- SideChannelService 新增 `/cron/add`，复用 token 鉴权，返回 job id 和 nextRunAt。
- Agent env 新增 `SYNAPSE_SIDE_CHANNEL_BASE_URL`、`SYNAPSE_CRON_ADD_URL`。

验证：Feishu command 和 side-channel 单测。

### 步骤 F：Heartbeat

- HeartbeatService 使用独立 repository 和 timer。
- 支持 enable/update/pause/resume/run now。
- 执行 synthetic heartbeat message，`userId/userName=heartbeat`。
- 复用 Cron 的 workspace/reply target/silent/mute/status 逻辑。

验证：Heartbeat 单测。

### 步骤 G：IPC 与 UI

- connectors IPC/preload 增加 Feishu automation 方法。
- 设置页 Feishu panel 增加 `定时任务` 和 `Heartbeat` 区域。
- 只用现有 shadcn/Radix 组件和 Tailwind token；不新增自定义颜色、CSS module 或卡片套卡片。

验证：IPC codegen、typecheck。

### 步骤 H：验证与记录

- 运行：
  - `pnpm desktop:typecheck`
  - `pnpm desktop:test`
  - `pnpm desktop:check:hard-constraints`
  - `pnpm desktop:check:ipc-codegen`
- 每次失败先记录到 `12.0 问题修复记录.md`，再修复并复测。
