# 12.0 最终报告

## 1. 已实现能力

- 新增 `scheduled.jobs` 与 `scheduled.heartbeat` 持久化模型，覆盖 CC Connect Cron/Heartbeat 的核心字段：cron、prompt/exec、workDir、silent/mute、sessionMode、timeout、lastRun、lastError、nextRun、runCount。
- 新增 5 段 cron parser 与 `SchedulerService`，支持启动恢复、add/update/delete/enable/disable/mute/run now，timer callback 只捕获 jobId，执行前重新读取最新 job。
- 新增 `CronExecutionService`，prompt job 进入 AgentRuntime；exec job 使用 `ControlledProcessRunner`，受 PermissionGuard/AuditSink 约束，支持 cwd 优先级、timeout、输出截断和 Feishu 主动回传。
- 补齐 AgentRuntime `sendNewSession(...)`，`sessionMode=new_per_run` 创建 inactive side conversation，`resumePolicy=fresh`，不覆盖当前 active session；`CC_SESSION_KEY` 仍使用原 Feishu sessionKey。
- Feishu connector 新增 `/cron` 命令：help/add/addexec/list/delete/del/rm/remove/enable/disable/mute/unmute/run；`addexec` 复用 Feishu admin 权限。
- Side-channel 新增 `/cron/add`，复用 token 鉴权，Agent env 增加 `SYNAPSE_SIDE_CHANNEL_BASE_URL` 和 `SYNAPSE_CRON_ADD_URL`。
- 新增 `HeartbeatService`，支持配置、pause/resume/run now，执行 synthetic heartbeat message，并复用 Cron 的 reply target、workspace、silent/mute 与状态记录链路。
- 设置页 Feishu 区域新增 `定时任务` 和 `Heartbeat` 管理入口，使用现有 shadcn/Radix/Tailwind token。

## 2. CC Connect 对齐点

- `timeoutMins`：未设置默认 30 分钟，`0` 表示不设置 timeout。
- `prompt` 与 `exec` 互斥；`kind=prompt` 必须有 prompt，`kind=exec` 必须有 exec。
- `silent` 只抑制开始消息；`mute` 抑制主动回传与 Agent 事件派发，但仍执行并记录状态。
- `reuse` 复用当前 `sessionKey + workspaceKey` active conversation；`new_per_run` 使用 side session。
- exec cwd 优先级：`workDir -> workspacePath -> workspace binding -> project workspacePath`。
- Feishu 主动回传优先使用保存的 `replyCtx`；缺失时按 `sessionKey` 重建基础 chat 上下文。

## 3. 差异与原因

- Cron timezone 使用本机时区；未引入额外 cron 依赖，避免增加依赖面。
- Feishu thread/root 的完整主动回传依赖创建 job 时保存的 `replyCtx`。如果只从裸 sessionKey 重建，只能恢复基础 chat；这是当前 Synapse Feishu sessionKey 信息量的边界。
- Heartbeat 未实现 CC Connect 的 `only_when_idle` 和 `HEARTBEAT.md` 读取 fallback，本阶段按任务书最低要求实现 Feishu session 配置、pause/resume/run now 与 AgentRuntime 执行。
- 桌面 UI 是最小可用管理入口，不包含复杂 cron builder。

## 4. Feishu-only 边界

- 数据模型保留 `platform/connectorId`，但 schema 校验、命令、IPC、side-channel handler、UI 均只支持 `platform="feishu"`。
- 未实现 Lark、微信、Telegram、Slack、Discord、Webhook、Relay 或多平台 UI。
