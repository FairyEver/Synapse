# 10.0 最终报告

## 交付内容

- 新增 `ConnectorRepository`，基于 DataRepository `connectors` namespace 管理 Feishu connector metadata、status、allowlist、sessionKeyPolicy、dedupe、reconnect。
- 新增 Feishu setup service：对齐 CC Connect app registration begin/poll/save；`appSecret` 只写 encrypted `secrets` namespace，IPC/renderer/audit 不返回明文。
- 新增 Feishu runtime：使用官方 `@larksuiteoapi/node-sdk` `WSClient` 接收飞书消息和卡片动作；支持启动、停止、状态查询、reconnect/degraded/error 状态更新。
- 新增 Feishu message normalizer：文本 JSON 解析、mention stripping、旧消息过滤、message_id 去重、群聊 @ bot 过滤、allowlist、session key policy、reply context。
- 新增 Feishu reply service：复用 ReplyTarget/SideChannel dispatcher，支持文本 reply/create、图片上传发送、文件上传发送、permission request 卡片。
- 新增 connectors IPC、preload bridge、renderer 类型和设置页“连接器/飞书”面板。
- 新增单测覆盖 ConnectorRepository、setup、message normalizer、reply service、runtime message/card action、IPC。

## 未纳入范围

- 未实现 Lark、微信、Cron、Relay、多工作区。
- 未实现 CC Connect 的 `perm:allow_all`，因为当前 AgentRuntime permission response 只支持 `allow` / `deny`。
- 入站图片/文件已作为 attachment metadata 进入 AgentMessage；下载用户发送资源和富媒体深解析留给后续阶段。
