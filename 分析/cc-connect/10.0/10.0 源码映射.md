## 已读规则与阶段结论

- `AGENTS.md`：新增业务模块应复用现有 Electron runtime、DataRepository、PermissionGuard、AuditSink、ProjectContainer、ReplyTarget/Outbox；不得裸用 `ipcMain.handle/on`、`webContents.send`、`http.createServer`，不得在 renderer 直接接触 privileged capability。
- `.claude/rules/design.md`：UI 必须沿用 `radix-nova`、Radix、shadcn/ui、Tailwind token，不新增视觉体系。
- `.claude/rules/ui-rules.md`：Tailwind 只承担布局、间距、尺寸和 token 引用；界面文案必须克制，不写实现说明。
- `1.2`：Feishu 接入分为扫码配置和运行时 WS 长连接；二维码内容是 `verification_uri_complete`，本机通过 `device_code` 轮询 app registration，不需要公网 IP。
- `3.1` / `3.2`：Feishu 必须在 AgentRuntime、治理、ReplyTarget/Outbox、Bridge/side-channel 之后接入，且不能绕过 AgentRuntime。
- `8.0`：已提供本地 Agent IPC、Renderer Chat、持久化 AuditSink、ReplyTarget/Outbox 基础层。
- `9.0`：已提供 BridgeAdapterService、side-channel `/send`、ReplyTarget 记忆、session env 注入与 localhost 网络边界。

## 官方 SDK 结论

- 官方仓库：`https://github.com/larksuite/node-sdk`。
- 官方 README 说明 `@larksuiteoapi/node-sdk` 支持 `Client`、`EventDispatcher`、`WSClient`；长连接模式无需公网 IP，SDK `1.24.0` 起可用。
- README 同时提供 `registerApp` app registration helper，但本阶段为对齐 CC Connect 且保证 setup cache 安全，先按 CC Connect form API 实现 begin/poll/save。
