# 5.0 问题修复记录

## 已修复问题

### 1. AgentRuntime service 引入未导出的 history entry 类型

现象：

- `pnpm desktop:typecheck` 首轮失败。
- 报错：`"../../runtime/data-repo" has no exported member named 'ConversationHistoryEntryV1'`。

原因：

- `ConversationHistoryEntryV1` 在 schema 文件内存在，但没有从 `desktop/electron/runtime/data-repo/index.ts` 导出。
- AgentRuntime service 只需要 history entry 的 role/content/timestamp 类型，不需要扩大 data-repo 公共导出面。

修复：

- 将 `historyEntry()` 的类型改成 `ConversationEntryV1["history"][number]`。
- 保持 `data-repo` 入口不变，避免为了单个服务扩大公共 API。

复测：

```bash
pnpm desktop:typecheck
```

结果：通过。
