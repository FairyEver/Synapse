# 5.0 执行计划

## 目标

执行 CC Connect 迁移计划的“第一步：本机 AgentRuntime MVP”，只验证本机 `prompt -> Codex CLI -> JSONL event -> Synapse event/result` 闭环。

## 约束

- 不做 UI、Feishu/Lark、Cron、Bridge/WebSocket、Management UI、多工作区、完整 slash command、Claude Code 长驻 session。
- 不启动 dev server、浏览器、Playwright 或 Chrome DevTools。
- 不绕过 Electron main/renderer/preload 边界。
- 不裸用 `ipcMain.handle/on`、`webContents.send`。
- Agent 子进程只走第零步受控边界 `ControlledProcessRunner`，保留 `PermissionGuard` 和 `AuditSink`。

## 实施步骤

1. 复查第零步状态并提交。
   - 已在 `第零步` 分支运行 `pnpm desktop:typecheck`、`pnpm desktop:test`、`pnpm desktop:check:hard-constraints`，均通过。
   - 已提交：`chore: complete zero step foundation`。
   - 已从第零步切出 `第一步` 分支。

2. 重新阅读迁移文档和 CC Connect 原始源码。
   - 已阅读 `3.1 整体开发顺序.md` 与 `4.0` 全部过程文档。
   - 已复查 CC Connect `core/interfaces.go`、`core/message.go`、`agent/codex/session.go`、`core/engine.go`、`core/session.go` 的指定方法。

3. 扩展受控进程边界。
   - 在 `ControlledProcessRunner` 增加 `stdin` 支持，保证多行 prompt 通过 stdin 传给 `codex exec ... -`。
   - 增加 stdout/stderr line handler，供 JSONL adapter 在受控 runner 内处理流式行事件。
   - 保持权限检查、env allowlist、audit 记录不变。

4. 新增 AgentRuntime MVP。
   - 新建 `desktop/electron/services/agent-runtime/`。
   - 定义 `AgentMessage`、`AgentEvent`、`AgentAdapter`、`AgentRuntimeTurnResult`。
   - 实现 `AgentRuntimeService.send()`，负责 conversation 读取/写入、调用 adapter、保存 thread id/history、发出 agent EventBus 事件。

5. 实现 Codex exec adapter。
   - 构造新会话参数：`codex exec --skip-git-repo-check --json --cd <workDir> -`。
   - 构造 resume 参数：`codex exec resume --skip-git-repo-check <threadId> --json -`。
   - 支持可选 `model/provider/baseUrl/effort/mode` 参数。
   - 解析 stdout JSON Lines，映射 `thread.started`、`turn.started`、`item.started`、`item.completed`、`turn.completed`、`turn.failed`、`error`。

6. 接入第零步地基。
   - 将 `agent.runtime` 注册为 project-scoped service。
   - 从 `core.project-containers` 创建 project service 时注入 scoped `conversations` namespace。
   - 子进程通过 `createControlledProcessRunner({ permissionGuard, auditSink })` 启动。

7. 补测试和验证。
   - 补 Codex args/parser 测试。
   - 补 AgentRuntime service 测试。
   - 补 ControlledProcessRunner stdin/line streaming 回归测试。
   - 执行 typecheck、相关 vitest、全量 vitest、hard constraints、改动文件 eslint。

## 不做项

- 不暴露复杂 Chat UI。
- 不新增 renderer/preload API。
- 不做远程 connector 或主动回传。
- 不实现 session lock/queue/permission prompt 回写，这些留到第二步。
