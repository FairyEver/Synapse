# 13.0 执行计划

## 1. 成功标准

- Codex exec 与 live session 都能把中间事件尽早进入 runtime event/outbox 链路。
- Bridge 支持 `preview_start`、`preview_ack`、`update_message`，并避免 text/result 重复发送。
- Feishu 在无 update 能力时提供少量进度降级，最终回复不重复。
- Renderer timeline 展示紧凑进度、引用入口与命令面板。
- 本地引用只允许 workspace 内路径；`/show` 能安全查看文件片段或目录。
- Custom Commands 支持 prompt/exec/list/add/delete，exec 走 PermissionGuard/AuditSink 并限制远程风险。
- Skills 能发现 `SKILL.md` 并通过 slash 构造 skill invocation prompt。
- CommandPublisher 向 Renderer、Bridge capabilities、Feishu `/commands` 输出同一套命令清单。
- agent-native slash 默认只允许显式 allowlist，未知远程 slash 不透传。
- 必须命令全部通过并写入测试记录。

## 2. 实施步骤

### A. 长任务事件与预览

- 给 exec adapter 增加实时 `onEvent` 回调，Runtime 避免重复 emit。
- 新增 preview/progress helper，复刻 CC Connect 的节流、冻结、最终去重语义。
- Bridge dispatch 改为按 reply target 维护 turn state。
- Feishu dispatch 改为 progress 降级 + final-only 文本。

验证：agent-runtime 与 bridge/feishu 单测。

### B. References 与 `/show`

- 新增 reference parser/render/view 工具。
- `/show` 作为安全内置命令，workspace 内读取文件片段或目录。
- Renderer timeline 识别本地引用，提供打开入口。
- Agent IPC 新增 `openReference` 和命令清单查询。

验证：reference 单测、IPC 单测、renderer typecheck。

### C. Custom Commands

- 新增 DataRepository schema 与 registry。
- `/commands` 支持 list/add/addexec/delete。
- prompt command 展开后进入 Agent；exec command 通过 ControlledProcessRunner。
- 远程 exec 必须 admin 或显式 allowlist；默认不向 Feishu 开放 exec。

验证：registry、command-router、runtime 单测。

### D. Skills

- 新增 SkillRegistry，扫描 workspace/user skill dirs。
- `/skills` 列出 skill；`/<skill>` 构造 CC Connect 风格 invocation prompt。
- Skills 进入统一命令发布。

验证：skill-registry 与 command-router 单测。

### E. CommandPublisher 与 UI

- Bridge capabilities snapshot 输出 built-in/custom/skill/agent-native 命令。
- Renderer 命令面板使用 shadcn `Command`，不写自定义颜色。
- Feishu `/commands` 返回同一套清单。

验证：bridge capabilities、renderer typecheck。
