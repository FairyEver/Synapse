- 已完成 12.0 真实完成度核验，并写入 `13.0 前置检查.md`。

- 新增 `agent.commands` 与 `agent.command-settings` DataRepository schema。
- 新增 Custom Commands registry，支持 runtime prompt/exec command、workspace/user command 文件、placeholder 展开、list/add/addexec/delete。
- 新增 SkillRegistry，发现 workspace/user `SKILL.md`，解析 frontmatter，并生成 CC Connect 风格 skill invocation prompt。
- CommandPublisher 语义接入 `AgentRuntimeService.listPublishedCommands()`，Renderer、Bridge capabilities、Feishu `/commands` 共享同一命令清单。
- Feishu connector 给 Agent message replyCtx 注入 `isAdmin`，用于远程 exec 管理权限判断；真实远程平台只接 Feishu。
- Renderer Agent 面板新增 shadcn `Command` 命令面板，timeline 本地引用可点击打开，UI 未使用自定义颜色、内联 style 或新视觉系统。
- 新增 Agent IPC：`listCommands`、`openReference`；`openReference` 受 workspace 边界、PermissionGuard 与 AuditSink 约束。

## 2. 对齐说明

- Stream preview：Bridge 走 CC Connect 同类的 `preview_start`/`preview_ack`/`update_message`；无 ack 时降级最终 reply。
- Compact progress：Bridge 使用 update message + progress payload；Feishu 使用少量文本进度降级。
- References：Renderer 可点击引用；远程和 `/show` 均不允许 workspace 外路径。
- `/show`：支持 head/context/line range 的安全文件查看，目录展示限制条目数。
- Custom Commands：prompt command 投喂 Agent；exec command 走 `ControlledProcessRunner`，默认只开放本地 Renderer。
- Skills：slash skill 调用转换为标准 skill invocation prompt。
- 命令发布：Renderer palette、Bridge capabilities snapshot、Feishu `/commands` 来自同一发布方法。
- Agent-native slash：默认只允许显式 allowlist，未知 slash 不透传。
