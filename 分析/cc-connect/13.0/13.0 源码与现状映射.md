## 2. 长任务体验对齐点

CC Connect 的核心行为：

- `streamPreview` 累积文本，按时间间隔与字符增量节流。
- 支持 `preview_start` + `preview_ack` + `update_message`。
- 遇到 thinking/tool/permission 时冻结或丢弃 preview，避免最终重复发送。
- `compactProgressWriter` 维护最多 10 条结构化进度，优先用 card payload；没有 card/update 能力时降级。
- `EventResult` 阶段如果 preview 已承载最终内容，则不再重复发送普通回复。

Synapse 当前现状：

- `AgentEvent` 已有 `text/thinking/toolUse/toolResult/permissionRequest/result/error`。
- `CodexExecAdapter.execute()` 当前一次性返回 events，`AgentRuntimeService` 执行后再统一 emit，缺少 exec 模式实时事件回调。
- `BridgeAdapterService` 已支持 `update_message` 能力判断，但没有 `preview_start/preview_ack` 状态管理，也会把 text/result 分开发送，存在重复回复风险。
- `FeishuReplyService` 当前无 update message 能力，只能文本或卡片降级；需要用少量进度文本和最终回复去重。
- Renderer 当前按事件平铺 timeline，缺少紧凑进度和引用入口。

## 3. References 与 `/show` 对齐点

CC Connect 的核心行为：

- 解析 markdown 链接、`file://`、绝对/相对路径、`path:line[:col]`、`#LxCy`。
- 忽略 web URL、代码块和 inline code。
- 渲染时把本地路径收敛成相对路径或短路径。
- `/show` 限制 head/context/range/max entries，读取文件片段或目录列表。

Synapse 当前现状：

- Agent Runtime 没有统一 reference parser。
- Renderer timeline 没有可点击本地引用。
- IPC 没有专门的安全 `openReference`。
- Electron shell/file 能力必须在 main 侧受 workspace 边界、PermissionGuard 与 AuditSink 约束。

## 4. Custom Commands / Skills 对齐点

CC Connect 的核心行为：

- Custom Commands 支持 prompt command 与 exec command。
- prompt command 支持 `{{1}}`、`{{2*}}`、`{{args}}`、默认值，并把展开后的 prompt 投喂 Agent。
- exec command 只允许 admin，并通过受控 shell 执行。
- Commands 可从配置与 agent 目录加载。
- Skills 从 `SKILL.md` 目录递归发现，解析 frontmatter，slash 调用时构造标准 skill invocation prompt。
- `/commands` 与 `/skills` 提供列表与管理入口。

Synapse 当前现状：

- `command-router.ts` 只有内置 `/model`、`/mode`、`/new`、`/status`，以及简单 registered prompt command。
- 没有 DataRepository 持久化 custom commands。
- 没有 SkillRegistry。
- 没有统一 CommandPublisher。
- Bridge capabilities snapshot 中 `commands` 为空。
- Feishu 非自动化 slash 会进入 Agent Runtime，但未知 slash 当前只返回 unsupported，不会透传给 Agent。
