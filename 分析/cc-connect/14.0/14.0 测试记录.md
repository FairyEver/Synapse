  - `synapse:ops:diagnostics`
  - `synapse:ops:open-log-directory`
  - `synapse:ops:run-as:*`
  - `synapse:ops:webhook:*`
  - `synapse:ops:relay:*`

## 中途失败与修复

第一次运行 `pnpm desktop:test` 时失败 4 项：

- `desktop/electron/bootstrap/__tests__/descriptors.test.ts`
- `desktop/electron/bootstrap/__tests__/registry.test.ts`
- `desktop/electron/runtime/data-repo/__tests__/schemas.test.ts`

原因：

- 新增 `core.execution-isolation`、`core.relay`、`core.automation-ingress` 服务后，bootstrap descriptor/registry 的固定断言未同步。
- 新增 `run_as.*`、`webhook.*`、`relay.*`、`agent.compress_state`、`ops.diagnostics` namespace 后，schema 固定断言未同步。
- `webhook.config` 存储 webhook token，按设计为 `encrypted-json`，旧测试只允许 `secrets` 加密。

修复：

- 同步 bootstrap 服务 ID 与依赖断言。
- 同步 schema namespace、backend、encrypted 标记断言。
- 再次运行 `pnpm desktop:test` 后通过。
