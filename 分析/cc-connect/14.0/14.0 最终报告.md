## 本次落地内容

### run_as_user

- 新增 `ExecutionIsolationService`：
  - 项目级 run_as 配置。
  - passwordless sudo preflight。
  - 目标用户不可 sudo 校验。
  - workspace 读写执行校验。
  - audit probe 输出 effective user/uid/gid/workspace/env。
- `ControlledProcessRunner` 增加 `run_as_user` isolation：
  - 非 Windows 下使用 `sudo -n -iu <user> --preserve-env=... -- <command>`。
  - 环境变量按 allowlist 传递。
  - permission context 与 audit 均记录 launch/isolation 元数据。
- Agent Runtime、cron/heartbeat、webhook exec 均接入 isolation resolver。

### Webhook 自动化入口

- 新增 `AutomationIngressService`：
  - 默认关闭，默认绑定 `127.0.0.1`。
  - 通过 `NetworkServiceRegistry` 注册。
  - Bearer/header/query token 鉴权。
  - 256 KiB payload 限制。
  - 60/min 限流。
  - webhook config 使用 encrypted-json 保存 token。
  - prompt/exec 互斥，支持 async 与 wait。
  - prompt 进入 Agent Runtime，exec 走 `ControlledProcessRunner`。
  - 支持 Feishu reply context 重建，不新增微信、Telegram、Slack、Discord、Lark。

### Relay

- 新增 `AgentRelayService`：
  - source/target project 校验。
  - relay run 持久化。
  - target 使用独立 `relay:<sourceProjectId>:<sourceSessionKey>` session。
  - 超时返回 partial，后台继续 drain/save。
  - visible 模式通过 Feishu 发送开始/结果记录。
- side-channel 新增 `/relay/send`：
  - 通过 `NetworkServiceRegistry` 承载。
  - 本地 token 鉴权。
  - source session 必须是已记忆 reply target。
  - 增加统一限流与入口审计。
- Feishu 新增 `/relay` 命令：
  - `/relay list`
  - `/relay bind <project-id>`
  - `/relay unbind <binding-id>`
  - `/relay send <project-id> <message>`

### /compress 与 auto-compress

- Command router 新增 builtin `/compress`。
- Agent Runtime 新增 manual compress 与 auto-compress 状态：
  - Claude Code 使用 `/compact`。
  - Codex 当前无 adapter compression command，安全跳过。
  - compression 不写普通对话历史，单独审计。
  - compression 期间 permission request 默认拒绝，不做自动授权。

### 运维增强

- 新增 `ops` IPC 模块：
  - diagnostics
  - open log directory
  - run_as get/update/preflight/auditProbe
  - webhook status/update/runs
  - relay bindings/runs/unbind
  - compress get/update
- preload 与 renderer bridge 类型已同步。
- settings Debug/Logs 面板增加诊断卡片：
  - app version、single instance、log path
  - Side-channel/Webhook/Relay/Feishu 状态
  - 打开日志目录
- UI 使用现有 shadcn/Radix 组件与 Tailwind token，未新增自定义颜色或内联样式。

## 安全边界

- 所有新增 HTTP 入口通过 `NetworkServiceRegistry`。
- Webhook 和 side-channel relay 均有鉴权、限流、审计。
- 所有新增 shell/exec 路径均通过 `PermissionGuard`、`AuditSink`、`ControlledProcessRunner`。
- 打开日志目录等运维敏感操作先经 `PermissionGuard`，再记录 `AuditSink`。
- run_as_user Windows 明确不支持。
- Relay/compress 中的 permission request 不自动批准。
- 当前真实远程平台只接入 Feishu。

## 已知差异与后续边界

- CC Connect 的多平台远程入口未迁移；本步按要求只支持 Feishu。
- CC Connect 的 observer/STT/TTS 未纳入本步实现。
- shell/http hook 的完整事件编排未在本步展开；当前重点是 webhook、relay、run_as、compress 与运维入口。
- `/compress` 当前仅 Claude Code adapter 对应 `/compact`；Codex adapter 暂无对等压缩命令。
- `pnpm desktop:check:ipc-codegen` 在未提交新增 generated IPC 文件时会失败，见测试记录。
