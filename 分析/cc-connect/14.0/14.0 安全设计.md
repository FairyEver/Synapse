# 14.0 安全设计

## 1. 外部入口

本阶段新增或扩展的入口：

- Webhook HTTP：默认 disabled，默认 `127.0.0.1`，token required。
- Side-channel `/relay/send`：复用 side-channel 本地 token。
- Feishu `/relay` 管理命令：仅 Feishu admin 可修改 binding。
- Renderer 配置/诊断 IPC：通过 IpcModule + preload typed API。

所有 HTTP 入口必须：

- 通过 `NetworkServiceRegistry` 注册。
- 使用 constant-time token compare。
- 限制 HTTP method。
- 限制 payload size。
- 限流。
- 生成 request id。
- 记录 DataRepository run/status。
- 记录 `AuditSink`。

## 2. 敏感动作

敏感动作和强制路径：

- Agent spawn：`PermissionGuard -> AuditSink -> ControlledProcessRunner`。
- shell exec：`PermissionGuard -> AuditSink -> ControlledProcessRunner`。
- webhook exec：同 shell exec，并默认更严格。
- cron exec：继续走 runner，并接入 run_as isolation。
- relay prompt：进入 `AgentRuntimeService`，不绕过 session queue/lock。
- Feishu reply/network：继续走 Feishu connector 的 `network.connect` 权限和审计。
- 打开日志目录：只通过 main process typed IPC，不在 renderer 读文件系统。

## 3. run_as_user

默认 disabled。启用条件：

- 项目级配置指定 target user。
- 平台为 macOS/Linux。
- preflight 通过。

进程包装：

```text
sudo -n -iu <targetUser> --preserve-env=<allowlist> -- <command> ...
```

env 策略：

- 不透传整个 `process.env`。
- run_as 默认 allowlist 使用保守集合。
- Agent provider env、side-channel env 必须显式加入 allowlist。
- `ControlledProcessRunner` 负责过滤 env，并把实际 env key 写入权限上下文。

preflight 至少检查：

- target user 非空。
- 当前用户可 `sudo -n -iu targetUser -- /bin/true`。
- target user 不能 `sudo -n /bin/true`。
- target user 可进入并读写 workspace。

audit probe 记录：

- supervisor user。
- target user。
- effective identity。
- workspace read/write。
- env key allowlist 结果。

Windows：

- 本阶段 unsupported。
- 不实现半成品提权逻辑。

## 4. Webhook

认证：

- Bearer token。
- `X-Webhook-Token`。
- query `token`。

限制：

- 默认 disabled。
- 默认 POST only。
- `prompt` 和 `exec` 互斥。
- 多项目必须提供 `projectId`。
- payload size 默认限制。
- rate limit 按 remote address + token 维度。

执行：

- prompt 构造 `platform: "webhook"` 的 `AgentMessage`。
- exec 走 `ControlledProcessRunner`，并接入 run_as。
- 所有 run 写入 `webhook.runs`。
- 非 mute 可通过 Feishu reply target 回传短结果。

## 5. Relay

认证：

- 仅 side-channel token。
- source project/session 优先从 `CC_PROJECT`、`CC_SESSION_KEY` 所绑定的 runtime env 可信上下文推断。
- 请求中不能任意伪造 source project。

限制：

- rate limit。
- payload size limit。
- target project 必须存在。
- relay run 写入 `relay.runs`。

执行：

- target session key 使用 `relay:<sourceProjectId>:<sourceSessionKey>`。
- target run 使用 side session，不污染用户主会话。
- timeout 返回已收集 partial 或 run id。
- timeout 后后台继续 drain，保存 final result。
- visible Feishu 记录只发送简短发起/完成提示。

## 6. Compress

- `/compress` 是 builtin command。
- Codex 无明确压缩命令时返回 unsupported。
- Claude Code 发送 `/compact` 到 live session。
- 压缩过程不写普通聊天 history。
- auto-compress 默认 disabled。
- min gap 默认 30 分钟。
- 自动触发失败只记录错误，不阻断后续 queued messages。

## 7. 不做项

- 不实现新远程平台。
- 不实现 shell hook。
- 不实现 STT/TTS。
- 不照搬 Go daemon/self-update。
- 不默认公网开放 Webhook。
