# 4.0 最终报告

## 完成内容

本次只执行 `3.1 整体开发顺序.md` 的“第零步：地基整理”，未实现 AgentRuntime、Feishu、Cron、Bridge UI 或多工作区。

已完成：

1. 全局 runtime 服务注册
   - 新增 `core.data-repository`、`core.permission-guard`、`core.audit-sink`、`core.process-runtime`、`core.network-registry`、`core.project-containers`。
   - `ServiceContext` 改为真实 DataRepository/EventBus/PermissionGuard/AuditSink/ProcessRuntime 类型。
   - `bootstrap/registry.ts` 使用 registry-backed proxy，新增服务不再拿 placeholder。

2. Project-scoped persistence
   - `ProjectScopedDataRepoImpl` 对 `providers/connectors/conversations/outbox/audit` 做字段级 `projectId` 隔离。
   - 写入自动补 `projectId`；显式跨项目写入会拒绝；`list/get/remove/onChange` 自动过滤。
   - `projects/secrets/core.*` 等全局 namespace 保持 pass-through。

3. 业务 schema 升级
   - `providers` 支持 global/project scope、provider refs、active provider/model、models、secretRef。
   - `projects` 支持 active provider/model。
   - `connectors` 支持 platform、secretRef、status、allowlist、sessionKeyPolicy、reconnect/dedupe。
   - `conversations` 支持 sessionKey、agentSessionId、pastAgentSessionIds、history、userMeta、active/name。
   - `audit` 支持 actor/resource/outcome/projectId/sessionId/metadata。
   - `outbox` 支持 destination/payload/attempts/status/lastError。

4. Agent 子进程启动边界
   - 新增 `ControlledProcessRunner`，统一表达 actor、`agent.spawn`/`shell.exec`、cwd、env allowlist、command/args、timeout/abort、stdout/stderr 输出约束、audit。
   - 默认 env 只走 allowlist，不暴露 raw spawn 到 renderer。
   - 只定义受控边界，不实现 AgentRuntime adapter。

5. 本地网络服务边界
   - `NetworkServiceRegistry` 保留端口分配和默认 `127.0.0.1`。
   - 增加 descriptor lifecycle `start(binding)` / `stop()` 和 audit hook。
   - `unregister()` 释放端口并调用 stop；start 失败会释放分配。

## 边界与剩余风险

- `core.audit-sink` 当前仍是 in-memory sink；业务 audit namespace 已就绪，后续接入时需要把持久化 AuditSink 落到 DataRepository。
- `ControlledProcessRunner` 是统一 spawn 边界，但尚未接入 AgentRuntime；后续 AgentRuntime MVP 必须通过该 runner 或等价受控封装启动 CLI。
- `NetworkServiceRegistry` 管 lifecycle 和 audit hook，但不直接创建 HTTP/WS server；Bridge/API/Webhook 后续应注册 descriptor 后再启动实际 server。
- project scope 采用字段级隔离，不是路径级隔离；满足第零步最低要求，后续如需要物理隔离可在 backend adapter 层演进。
