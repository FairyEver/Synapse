## 实施步骤

1. 会话持久化
   - 在 `conversations` namespace 上新增 `AgentSessionRepository`。
   - 支持 active session、`sessionKey`、`name`、`history`、`userMeta`。
   - 保存 `agentType`、Agent 原生 session id、`pastAgentSessionIds`、`resumePolicy`。
   - 提供清理当前 agent session id 的方法，供后续 `/new`、切 Agent、切 Provider 复用。

2. Session lock 和 pending queue
   - 同一 `sessionKey` 只允许一个普通 turn。
   - busy 时只排队消息元数据，不中途写 stdin。
   - 队列设置上限并按顺序继续处理。

3. Permission pending
   - 在 `AgentEvent` 中新增 `permissionRequest`。
   - `AgentRuntimeService` 保存 pending permission。
   - 暴露 allow/deny 回写接口。
   - agent/remote actor 不能直接 allow；敏感动作经过 `PermissionGuard` 和 `AuditSink`。

4. Claude Code adapter MVP
   - 使用 `claude --input-format stream-json --output-format stream-json --permission-prompt-tool stdio`。
   - 长驻 session 支持 stdin 写入一行 user JSON。
   - stdout stream-json 解析为统一 `AgentEvent`。
   - `control_request` 映射 `permissionRequest`。
   - allow/deny 写回 `control_response`。
   - 进程启动走 runtime/process 受控边界。

5. 输入和输出治理
   - 建立统一 governance 服务入口。
   - 覆盖 disabled commands、admin allowlist、role policy、user/global rate limit、banned words、outgoing rate limit、message dedupe、旧消息过滤、allowlist、群聊 @ 过滤。
