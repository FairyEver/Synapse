# 6.0 问题修复记录

## 已修复问题

### 1. `ConversationResumePolicyV1` 未从 schema barrel 导出

现象：

- `pnpm desktop:typecheck` 首轮失败。
- 报错：`Module '"./schemas"' has no exported member 'ConversationResumePolicyV1'`。

原因：

- `resumePolicy` 类型已加入 `schemas/placeholders.ts`，但 `schemas/index.ts` 未同步导出。

修复：

- 从 `desktop/electron/runtime/data-repo/schemas/index.ts` 导出 `ConversationResumePolicyV1`。

复测：

- `pnpm desktop:typecheck` 通过。

### 2. Claude adapter 启动期 stdout 缓冲变量触发 `prefer-const`

现象：

- 本次改动文件单独 ESLint 首轮失败。
- 报错：`'liveSession' is never reassigned. Use 'const' instead`。

原因：

- Claude adapter 为处理进程启动早期 stdout，使用 `let liveSession` 在闭包中延迟赋值。

修复：

- 改为 `const liveSessionRef` 引用对象，保留启动期缓冲行为。

复测：

- 本次改动文件单独 ESLint 通过。
