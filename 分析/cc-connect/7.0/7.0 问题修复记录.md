# 7.0 问题修复记录

## 1. `/model` 集成测试 alias 未解析

现象：

```text
expected 'Model changed: fast' to be 'Model changed: gpt-5.3-codex'
```

原因：

- 测试用 `BlockingAdapter` 的 `agentType` 是 `blocking`。
- `ProviderConfigService` 会按 agentType 过滤 provider。
- 测试没有显式传入 `agentType: "codex"`，导致 Codex provider 被过滤，`/model switch fast` 没有模型列表可解析 alias。

修复：

- 在 AgentRuntimeService 命令路由集成测试中显式传入 `agentType: "codex"`。
- 复测受影响单测通过。

## 2. Claude Code per-agent override key 兼容

现象：

- 任务书与 CC Connect 源码中同时出现 `claudecode` 与 `claude-code` 命名。

修复：

- `ProviderConfigService` 的 per-agent override 解析统一走 agentType normalize。
- `claudecode` 与 `claude-code` 都映射为同一 agentType，避免 endpoint/model/model list override 因 key 命名差异失效。
