
结果：失败。

- 5 个文件通过，1 个文件失败。
- 失败用例：`AgentRuntimeService > handles /model before the adapter and clears the current agent session id`
- 原因：测试使用 `BlockingAdapter`，未显式声明 runtime `agentType: "codex"`，导致 provider 按 `blocking` 过滤后无法用 alias 解析模型。
