# 7.0 最终报告

## 完成内容

本次完成 CC Connect 迁移计划“第三步：Provider、模型与基础命令控制”。范围限定在 Electron main 侧服务、AgentRuntime 接入、数据 schema 和单元测试；未做 Provider UI、Feishu/Lark、Cron、Bridge/API、side-channel 或多工作区绑定。

已完成：

1. ProviderConfigService
   - 支持 global provider。
   - 支持 project provider refs。
   - 支持 project inline provider 覆盖同名 global provider。
   - 支持 active provider、active model、active mode。
   - 支持按 agentType 过滤，覆盖 `codex` 与 `claude-code`/`claudecode`。
   - 支持 endpoint、agent model、agent model list、Codex config 等 per-agent override。
   - provider state 只保存 `secretRef`，secret 明文只从 encrypted `secrets` namespace 读入 runtime view。

2. Agent runtime view
   - Codex：生成 `model`、`provider`、`baseUrl`、`effort`、`mode`、env。
   - Codex：启动前写 `$CODEX_HOME/config.toml` 和 `auth.json`，写入经过 `PermissionGuard.check({ action: "fs.write" })` 和 `AuditSink`。
   - Codex：`auth.json` 使用 `0o600`。
   - Claude Code：生成 `model`、`mode`、env。
   - Claude Code：第三方 base URL 使用 `ANTHROPIC_BASE_URL` + `ANTHROPIC_AUTH_TOKEN`，并设置 `ANTHROPIC_API_KEY=""`。
   - Adapter 不直接读取 DataRepository；由 AgentRuntimeService 解析 runtime view 后注入 adapter options。

3. 基础命令路由
   - 支持 `/model`、`/mode`、`/new`、`/status`。
   - 命令在进入 queue/adapter 前处理，不发送给 Agent。
   - `/model` 支持列表、直接模型名、`switch`、index、alias。
   - `/mode` 支持列表与切换。
   - `/model`、`/mode`、`/new` 都会关闭当前 live session 并清空 current agent session id。
   - 未知 slash command 返回 `Unsupported command: /xxx`，不转发给 Agent。
