## Bridge 支持范围

- 支持 WebSocket `/bridge/ws`，默认 `127.0.0.1`、preferred port `9810`、local token 鉴权。
- 支持 adapter `register`、`ping`、`message`、`card_action`。
- 支持 adapter list/status、同名 adapter 替换旧连接、断开状态记录。
- 支持最小 `capabilities_snapshot`，不暴露命令、技能、provider secret。
- 支持 Bridge 入站 message 转 `AgentMessage`，project 显式优先，单项目 fallback。
- 支持出站 `reply`、`update_message`、`typing`、`card`、`error` 与 capability fallback。
- 支持 `perm:<requestId>:allow|deny` 权限 card action。
- 支持 `/bridge/sessions` list/create/switch/delete 最小协议。

## side-channel send 支持范围

- 支持 localhost HTTP `POST /send`。
- 支持 `project/projectId`、`sessionKey/session_key`、`message`、`images`、`files`。
- 支持 token 鉴权、body limit、project/session target 校验。
- 文本 send 通过当前 session 的 `ReplyTarget` 投递，并写 outbox。
- 图片/文件会先经过附件策略；Bridge adapter 若缺 `image/file` capability 会结构化失败并写 outbox failed。
- 未实现 CLI wrapper；不声明 `synapse send` 已可用。

## 附件策略

- 单文件最大 `10 MiB`。
- 单次请求最大 `25 MiB`。
- image MIME：`image/png`、`image/jpeg`、`image/gif`、`image/webp`。
- 普通 file MIME：`text/plain`、`text/markdown`、`application/json`、`application/pdf`。
- 文件名净化为安全 basename。
- 路径只允许 workspace 或受控 temp 根 `tmp/synapse-side-channel`；外部路径需 PermissionGuard 明确允许。
- 拒绝 symlink 路径，避免逃逸。

## 新增依赖

- 新增 `ws` 与 `@types/ws`。
- 原因：仓库没有 WebSocket server 依赖；Bridge 需要真实外部 adapter WebSocket 注册能力。`ws` 是最小 server/client 依赖，避免引入 Express/Koa/Fastify 等 Web 框架。
