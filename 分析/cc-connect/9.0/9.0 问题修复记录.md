# 9.0 问题修复记录

## 1. 首轮 typecheck 测试桩类型不匹配

- 失败命令：`pnpm desktop:typecheck`
- 失败摘要：
  - Codex env 注入测试返回的 `ControlledProcessResult` 少字段。
  - Bridge service 测试的 fake `ProjectContainerRegistry` 未实现泛型 `get<T>()`。
- 原因：新增测试桩没有完全按现有接口补齐。
- 修复：补齐 fake process result 字段；将 fake project container 的 `get<T>()` 按泛型返回并在边界处显式 cast。

## 2. 首轮受影响测试失败

- 失败命令：受影响 Vitest 命令。
- 失败摘要：
  - Bridge 出站测试超时。
  - side-channel path escape 测试没有拒绝 outside path。
- 原因：
  - WebSocket 测试在出站发送后才开始监听消息，导致事件丢失。
  - 附件策略把系统 temp 目录整体作为允许根，边界过宽。
- 修复：
  - Bridge 测试改为发送前注册批量 message listener。
  - 附件策略只允许 workspace 与受控 `synapse-side-channel` temp 根。
