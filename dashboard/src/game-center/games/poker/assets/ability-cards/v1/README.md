# 德州扑克能力牌封面

存量规则的 60 种牌对应本目录 `01.png`–`60.png`。新版「五选其一」单独使用 [`v2/07.png`](../v2/07.png)，其余新版能力牌复用同牌效的封面。

按[能力牌美术规则](../../../../../../../../docs/agents/game-ui.md#德州扑克能力牌封面)从牌效重新构图。所有正式封面使用满幅奇幻法术厚涂插画，画面不出现脸、文字和卡框。

各版本 `manifest.json` 记录独立生成的原始 PNG、实际提示词、尺寸、SHA-256 和逐张检查结果。内置 GPT 生图工具未提供具体模型名和 seed。手牌、详情和日志各按现有位置裁切原图。

`cardArtwork(artId)` 使用完整封面引用映射清单核对过的本地资源。新增或替换资产后运行 `pnpm --filter @synapse/dashboard check:poker-card-assets`。
