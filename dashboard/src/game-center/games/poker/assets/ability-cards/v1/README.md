# 卡牌封面 v1

60 种卡牌分别对应 `01.png`–`60.png`，同名实例复用对应封面。图片均通过内置 GPT 生图工具独立生成，完整实际提示词、尺寸、SHA-256 和逐张检查结果见 `manifest.json`。工具未提供具体模型名和 seed，清单如实记录，不推测版本。

统一使用暖象牙底色、纸张与瓷器质感、香槟金细节、少量鼠尾草绿、左上柔光和三分之四视角。主体集中于中央安全区，不包含生成文字、点数、UI 边框或水印。01、11、33 先用于风格校准；其余图片沿用同一基准。

保留工具输出的 1122 × 1402 原始 PNG；界面按居中 4:5 展示。没有重绘、压缩或拼接。07、17 的花色通过 GPT 图像编辑修正，对应修改提示词保存在清单中。最终 60 张均检查了全图、缩略显示、主体含义和风格。

`cardArtwork(cardId)` 只映射清单核对过的本地资源。面板仅渲染当前持牌或候选牌，图片使用 lazy loading，不预加载整套图片。新增或替换资产后运行 `pnpm --filter @synapse/dashboard check:poker-card-assets`。
