# 数据服务 - 产品设计

## 概述

Synapse 内置一个本地 SQLite 数据服务，让用户自由记录数据，不需要考虑数据存哪里。数据完全存在用户本地，不进仓库，不上云。通过 API、MCP、CLI 三种方式访问，所有功能依赖 app 在运行。

## 架构

```
用户 ──→ 管理界面（渲染进程）──→ IPC ──→ 主进程 ──→ SQLite
                                              ↑
CLI ──→ HTTP (动态端口) ──→ 主进程 ──→ SQLite
                              ↑
MCP Server (stdio 脚本) ──→ HTTP ─┘
```

## 数据库

- 文件位置：`userData/synapse-data.db`，全局唯一，跟仓库无关
- 系统表 `_meta_tables`：追踪所有用户表的元数据（表名、描述、创建时间等），用户不可直接操作，API 自动维护
- 初始自带一张 `bookmarks` demo 表，含几条示例数据，仅作演示用途

### 建表规则

- 每张用户表自动加自增 `id` 列做主键，用户无需定义主键
- 表名只允许字母、数字、下划线，不能以 `_` 开头（`_` 前缀保留给系统表）
- 支持的字段类型：TEXT, INTEGER, REAL, BLOB, JSON
- 建表后可加列，不可删列、不可改列类型

### 导入导出

- 全量导入导出，格式为 `.db` 文件（SQLite 原始格式）
- 导出即复制数据库文件，导入即替换

## HTTP API

### 服务启动

- 主进程启动时起 HTTP server，动态分配端口，无认证
- 端口信息写入 `userData/data-server.json`：

```json
{
  "port": 19530,
  "pid": 12345,
  "startedAt": "2026-04-22T10:00:00.000Z"
}
```

- CLI 和 MCP 启动时读取此文件获取端口，可通过 PID 检查 app 是否存活

### 接口风格

RPC 风格，统一入口 `POST /api`，通过 body 中的 `action` 字段区分操作。

### 结构化接口

| action | 说明 | 参数 |
|---|---|---|
| `listTables` | 列出所有用户表 | 无 |
| `createTable` | 新建表 | `name`, `description?`, `columns: [{ name, type }]` |
| `dropTable` | 删除表 | `name` |
| `describeTable` | 查看表结构 | `name` |
| `addColumn` | 给表加列 | `table`, `column: { name, type, default? }` |
| `insert` | 插入数据 | `table`, `data: { ... }` |
| `query` | 查询数据 | `table`, `where?`, `orderBy?`, `limit?`, `offset?` |
| `update` | 更新数据 | `table`, `id`, `data: { ... }` |
| `delete` | 删除数据 | `table`, `id` |

### 特殊接口

| action | 说明 | 参数 |
|---|---|---|
| `rawSQL` | 执行原始 SQL | `sql`, `params?` |

`rawSQL` 拥有完整的读写能力，不做权限限制。

## 消费端

### 管理界面（渲染进程）

- 通过 IPC 访问主进程数据库服务
- 轻量表格浏览器：查看表结构、翻页浏览数据、手动增删改
- 显示当前 HTTP 服务端口号
- 提供导入/导出按钮

### CLI

- 打包在 Synapse app 内，app 安装时自动将 CLI 脚本安装到系统 PATH
- 设置界面提供"重新安装 CLI"按钮
- 通过读取 `userData/data-server.json` 获取端口，调用 HTTP API
- 依赖 app 在运行

### MCP Server

- 独立 stdio 脚本，打包在 app 内
- 内部通过 HTTP 调用 API，与 CLI 共享同一套接口
- app 内提供一键注册按钮，自动写入 `~/.claude/settings.json`
- 设置界面提供"重新注册 MCP"按钮
- 依赖 app 在运行

## MCP Tool 定义

MCP Server 暴露的 tool 与结构化 API 一一对应：

- `list_tables` — 列出所有表
- `create_table` — 新建表
- `drop_table` — 删除表
- `describe_table` — 查看表结构
- `add_column` — 加列
- `insert` — 插入数据
- `query` — 查询数据
- `update` — 更新数据
- `delete` — 删除数据
- `raw_sql` — 执行原始 SQL
