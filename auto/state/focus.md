# 当前关注方向

> 本文件由提示词在 Step 0.5 读取，用于引导审查方向。你也可以手动编辑来指定下一轮关注点。

## 优先审查区域

- 错误处理：节点执行失败后的恢复路径、用户反馈、重试机制
- 执行引擎：超时处理、取消机制、异常边界
- untouched 文件：workflow-service.ts、window-manager.ts、run-snapshot-service.ts 等从未被审查的服务层

## 允许的小优化范围

- 给现有功能补充缺失的状态处理（error / loading / empty）
- 修复交互断路（操作无反馈、无入口、状态不清）
- 完善日志覆盖（关键路径无日志）
- 修复数据流不一致（状态更新未同步到所有消费方）

## 禁止范围

- 新增节点类型
- 新增 UI 页面或独立视图
- 新增 IPC channel（除非修复缺陷必需）
- 改变数据模型结构
