# Create a new Figma file

The local Desktop MCP is read-oriented and does not expose file-creation tools. Explain this limitation instead of attempting a nonexistent tool. The user can create or open the Figma or FigJam file in Figma Desktop and then ask Synapse to inspect the selection with `get_design_context`, `get_metadata`, `get_screenshot`, or `get_figjam`.
