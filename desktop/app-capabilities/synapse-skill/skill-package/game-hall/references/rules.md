## 可选 Roll 房规（roll-v1）

room_create(ruleOptions={roll:true})开启，缺字段或{}按关闭；两种资金模式和牌组都适用，创建后规则及服务端定价版本固定。当前行动的非弃牌、非全下本手玩家可在preflop/flop/turn换牌，河牌不可用；stack必须严格大于费用。normal指定0/1号旧底牌后随机一张；super指定后抽三张，可选择一张或在原槽按新报价继续付费重抽。旧牌不参与本次抽取，完成后旧牌和未选牌回收洗匀。候选和旧槽仅本人私有；不开放给教师或对手。

普通/超级共用本人本手次数k，跨阶段累计。令C=本人普通累计投入+当前stack，P=所有本手参与者min(普通累计投入,C)之和（含弃牌死钱），E=其他未弃牌者max(0,min(stack,C−其普通累计投入))之和，T=10P+E；preflop/flop/turn的(u,v)依次(1,3)/(2,5)/(4,8)。N=max(2000,uT)，S=max(N+2000,vT)，两档费用分别ceil((1+k)N/2000)、ceil((1+k)S/2000)，服务端用整数精确计算。使用当前报价，不按实际暗牌或真实牌堆收费，不临时估价；同公开资金条件报价相同。

费用独立普通下注，全额按当时其他未弃牌原参与者均分，包含全下者，整数余数按庄家左侧顺序分配。补偿本手冻结，不能下注或再换牌；普通主边池派彩后释放。在桌原入座到账桌面；已离场points到账原用户账户及netProfit，后来新入座不接收旧资产；practice离场或取消手的补偿清零，不兑换点数。总净delta=普通扑克净变化−rollPaid+rollReceived，payout仍仅普通派彩。Hall total=available+inPlay+pending，netProfit包含确权pending；旧响应无pending按0。

Roll不消耗正常下注机会、不延长原600秒。super待选禁止下注或推进，可不选候选、按当前报价在原槽再次付费Roll；成功放回并洗匀旧候选再抽取，保留旧费用和补偿并累计次数，失败不改原候选。choose不再扣费或增加次数。断线、关闭面板及控制交接保留当前候选；超时先选当前第一个候选再原check/fold撤出，无退费。有限策略和试玩价格不保证任何玩家获利。
