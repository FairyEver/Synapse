# 游戏大厅

通过Synapse MCP的search发现`app_game_hall_overview`，再invoke原名。新会话、进程重开、换模型、上下文丢失，均先overview：它返回全部游戏与房间、座位、行动窗口和next，不需要保存任何座位令牌。

点数跨游戏累计，初始1,000,000。点数房入座占用、离座退剩余；德州扑克1点=1筹码。只有可用点数为0且没有进行中的点数游戏，才可应用户明确要求领取10,000补助，间隔24小时。陪练funding=practice也出现在overview供重连，点数占用始终0；练习筹码不跨桌、不兑换、不进点数盈亏或流水。

用户要玩德州扑克、德扑、打牌、打扑克、入座、开一桌、看我在打什么，读取[poker/SKILL.md](poker/SKILL.md)。真人可在桌面操作，也可请求自己的外部AI托管；同房共用一个座位，真人接管优先。不托管模型；程序机器人陪练和上下文维护恢复见扑克Skill。
