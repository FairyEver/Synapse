# 内网穿透

只在用户要求公开本机服务时申请链接。任何拿到链接的人都可直接访问；申请前明确目标端口，不能推测任意本机服务。只支持本机 HTTP 端口 1–65535，支持网站、API、WebSocket 和 SSE。

通过 MCP `search` 查找 `app_tunnel_mapping_*`，再用 `invoke`；参数见 [API](api-reference.md)。不使用 shell、frp 或另外创建代理。

- 一个账号可申请多个长期固定链接，同时使用。链接绑定原电脑；其他电脑只能读取或删除，不能接管。
- create 前保存一个 UUID `requestId`。响应不明时以相同 UUID 和端口重试；不要生成新 UUID。已删除链接永不复活。
- 修改、启停或删除前读取最新 revision；409 重新读取，不覆盖并发修改。
- 已开启且本机仍授权的映射在启动后自动恢复。停止保留域名，删除永久退役。离线或本机服务未运行不改变 URL。
- 不启动用户的本机服务，不重放访问者请求，不读取或记录代理正文、Cookie 或 query。不返回设备密钥或数据通道票据。
