## 改动点 1：面板头部强化

### 设计

```
┌─────────────────────────────────┐
│ ⚡ 总结用户需求          ··· ▼  │
│  prompt · 2 输入 → 1 输出       │
├─────────────────────────────────┤
```

### 交互说明

| 元素 | 行为 |
|------|------|
| 节点图标 `⚡` | 根据节点类型显示不同图标（prompt=MessageSquare, switch=GitBranch, end=LogOut） |
| 节点名称 | 默认显示为文本，点击变为输入框（inline editable） |
| `···` 按钮 | DropdownMenu：复制节点 / 删除节点 |
| 副标题行 | 节点类型 + 连接摘要，纯展示 |

### 连接摘要规则

- `2 输入 → 1 输出`：统计实际连接的 edge 数量
- 无连接时显示 `未连接`
- Switch 节点显示 `2 输入 → 3 分支`

## 改动点 2：分区折叠

### Prompt 节点分区

```
▾ 执行配置                        ← 可折叠
  [Agent 选择器]

▾ 输入映射                   3个  ← 可折叠，右侧摘要
  [变量绑定编辑器]

▾ 指令                     328字  ← 可折叠，右侧摘要
  [Prompt 编辑器]
```

### Switch 节点分区

```
▾ 执行配置
  [Agent 选择器]

▾ 输入映射                   2个
  [变量绑定编辑器]

▾ 判断指令                  156字
  [Prompt 编辑器]

▾ 路由规则                   3条
  [分支列表]
  [默认分支选择]
```

### End 节点分区

```
▾ 输入映射                   2个
  [变量绑定编辑器]

▾ 输出模板                  89字
  [Template 编辑器]
```

### 折叠行为

- 默认全部展开
- 折叠后只显示标题行 + 右侧摘要数字
- 摘要内容：变量数 / 字符数 / 分支数
- 折叠状态不持久化（切换节点时重置为全展开）

## 改动点 3：Prompt 编辑区增强

### 设计

```
┌─────────────────────────────────┐
│ 你是一个需求分析师，擅长从用户   │
│ 的描述中提取核心需求。           │
│                                 │
│ 请根据 [name] 提供的 [ctx]      │
│ 进行总结，输出格式按照 [fmt]    │
│ 的要求。                        │
│                                 │
│                                 │
│                                 │
├─────────────────────────────────┤
│ [name] [ctx] [fmt]       328字  │
└─────────────────────────────────┘
```

### 变量高亮

- `{{变量名}}` 在编辑区中以 inline badge 样式渲染（方括号 + 背景色）
- 实现方式优先级：
  1. 首选：overlay 层在 Textarea 上方渲染高亮（Textarea 本身保持纯文本编辑）
  2. 备选：底部变量 chip 栏 + 纯文本 Textarea（实现成本低）

### 底部工具栏

| 元素 | 说明 |
|------|------|
| 变量 chip | 显示当前已绑定的所有变量名，点击插入 `{{name}}` 到光标位置 |
| 字符计数 | 右对齐，显示当前字符数 |

### 变量 chip 样式

```
┌──────┐ ┌──────┐ ┌──────┐
│ name │ │ ctx  │ │ fmt  │
└──────┘ └──────┘ └──────┘
```

- 使用 Badge variant="secondary" 样式
- 点击行为：在 Textarea 光标位置插入 `{{chipName}}`
- 如果变量列表为空，不显示 chip 栏

## 改动点 4：变量绑定可读性优化

### Before

```
┌───────┬──────────────────┬──┐
│ name  │ 固定值 │ 张三    │🗑│
├───────┼────────┼─────────┼──┤
│ ctx   │ 上游   │ 需求收集 │🗑│
└───────┴────────┴─────────┴──┘
```

### After

```
┌─────────────────────────────────┐
│  name                           │
│  ← 固定值  "张三"           🗑  │
├─────────────────────────────────┤
│  ctx                            │
│  ← 上游节点  需求收集        🗑  │
├─────────────────────────────────┤
│  fmt                            │
│  ← 工作流参数  output_fmt    🗑  │
└─────────────────────────────────┘
```

### 设计说明

- 每个变量占两行：第一行变量名（可编辑），第二行来源信息
- 来源类型用不同颜色的小标签区分：
  - `固定值` — muted 色调
  - `工作流参数` — secondary 色调
  - `上游节点` — accent 色调
- 删除按钮右对齐，hover 时显示
- 空状态：

```
┌─────────────────────────────────┐
│                                 │
│   还没有变量绑定                 │
│   添加后可在指令中用 {{name}}    │
│                                 │
│        [+ 添加变量]             │
│                                 │
└─────────────────────────────────┘
```

### 编辑态

点击变量行进入编辑态：

```
┌─────────────────────────────────┐
│  [name_________]                │
│  [▼ 固定值   ] [张三________] 🗑│
└─────────────────────────────────┘
```

非编辑态为纯展示，减少视觉噪音。

## 改动点 5：上下文感知状态条

### 位置

在面板头部的副标题行中集成：

```
┌─────────────────────────────────┐
│ ⚡ 总结用户需求          ··· ▼  │
│  prompt · 2 输入 → 1 输出       │
├─────────────────────────────────┤
```

### 运行状态（如果有 runner 数据）

在副标题行右侧追加状态指示：

```
│  prompt · 2 输入 → 1 输出  ● 成功│
```

状态颜色：
- `● 成功` — green（使用 token 而非硬编码）
- `● 失败` — destructive
- `● 运行中` — 动画 pulse
- 无状态 — 不显示

### 数据来源

- 连接数：从 `definition.edges` 中统计 `target === nodeId` 和 `source === nodeId` 的数量
- 运行状态：从 runner state 中读取（如果当前在运行模式下）

## 组件拆分建议

```
NodeConfigPanel (容器)
├── PanelHeader (头部：图标+名称+菜单+连接摘要)
├── CollapsibleSection (可折叠区块，通用)
│   ├── title: string
│   ├── summary: string | number
│   └── children: ReactNode
├── AgentSelector (Agent 选择器，从现有提取)
├── VariableBindingEditor (重构后的变量编辑器)
│   ├── VariableCard (单个变量卡片)
│   └── EmptyState (空状态引导)
├── PromptEditor (增强的 Prompt 编辑器)
│   ├── Textarea (编辑区)
│   ├── VariableChips (底部变量快捷插入)
│   └── CharCount (字符计数)
└── BranchEditor (Switch 专用分支编辑器)
```

## 实现优先级

| 优先级 | 改动点 | 理由 |
|--------|--------|------|
| P0 | 分区折叠 | 结构性改善，影响最大，其他改动依赖此骨架 |
| P0 | 面板头部强化 | 小改动大感知，与分区折叠一起做 |
| P1 | Prompt 编辑区增强 | 核心交互体验，变量 chip + 字符计数 |
| P2 | 变量绑定可读性 | 需要重构现有组件，工作量较大 |
| P2 | 上下文感知 | 需要和 runner 数据打通 |
