Web Audio 主增益固定 0.35。下注与普通派彩共用碰撞次数曲线：金额不超过 12 时一元一次，超过 12 时按 `min(16, 12 + ceil(log2(amount / 12)))` 平滑增加，最多 16 次；例如 5 元五次、10 元十次、32 元十四次、100 元十六次。金额增加不减少碰撞次数。

下注（含盲注）把这些碰撞集中成短促的一簇，首个碰撞立即播放；碰撞分布跨度为 `min(180, 30 + count × 10)` 毫秒，通过 `progress^1.15` 略微错开节奏。5 元的碰撞集中在 80ms、10 元在 130ms、100 元在 180ms 内，连同原始素材尾音整体不超过约 0.44 秒。首个碰撞保持 0.5 增益，其余为 `0.6 / sqrt(count)`，比先前提高 20%（约 1.6dB），增强整把筹码的碰撞感并保留清晰起音；最多十六个声源的线性峰值预算为 0.9625（含主增益），避免单次下注自身叠加削波。碰撞次数用于表达一把筹码的丰富程度，不逐个数拍。

普通派彩沿用原节奏：碰撞间隔为 `max(55, round(105 - log2(max(1, amount)) × 6))` 毫秒，单次增益 0.5。新公共牌每张一次，三张响三次，相邻间隔 120ms；转牌、河牌各一次，重复快照不重播。新手最多六次发牌声，同批动作归并而不排长队，同批最多调度 40 个声源，覆盖下注、翻牌及派彩组合。退款不冒充中奖；无背景音乐或持续倒计时音。
