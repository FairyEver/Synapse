# 未来开发计划

本文件记录尚未启动的产品方向。这里的内容不是当前实现要求，也不自动授权新增功能；设计当前边界时只需避免明显封死路线，不提前实现完整系统。

用户明确说“未来要做”“先记录规划”时，默认把目标、边界、触发场景和可能影响整理到本文件。除非用户明确要求实现或设计详细方案，否则不要把计划当成当前开发任务。

## 云盘文件编辑与同步

- 支持直接编辑云盘文档，使其既可预览也可作为可编辑内容来源。
- 支持远端单文件与本地文件关联并双向同步。
- 支持远端文件夹与本地文件夹关联并双向同步。
- 支持用户通过 MCP 修改自己拥有的文件，以及他人分享且授予修改权限的文件。
- 设计时预留文件身份映射、冲突处理、同步状态、变更检测、权限校验和失败恢复；未有明确当前需求前不得提前实现完整同步系统。
