## 动效实施设计（本任务取舍）

复用CSS transition/keyframes，无新依赖。采用权威table快照作为单一运动时序，事件流继续服务日志；避免两个轮询竞态导致收池丢失。新快照只播放新增actionSeq；首载、超过3秒断流、隐藏/返回窗口只建立基线；控制切换与布局变化清理运动。快速跨街合并，优先最终状态，不积压旧手。

|触发|玩家需要理解|反馈与结束/中断|
|---|---|---|
|编辑/快捷金额|总额与实际追加|选中态、稳定数字、追加预览；未确认不飞筹码|
|确认成功新增动作|谁追加多少|实际seat plate→本轮下注锚点，短筹码组+金额；失败无成功运动|
|本轮结束|本轮投入进底池|含盲注的下注锚点→实际底池，先追加后归集；快进合并|
|本人轮次变化|现在轮到你|一次短促座位/行动区提示，不夺焦点，无无限脉冲|
|新手/新增公共牌|阶段推进|首载直接显示，后续短顺序显牌，不渲染未知暗牌|
|服务端结算|谁赢得哪些筹码、净盈亏|先合法结果/座位赢家标记，后按分池派彩，返还单独表达；只有净盈利本人短庆祝|
|下一手/接管/后台/缩放|当前真实状态优先|清除旧运动，资金与控制不依赖动画回调|
|reduced motion|仍理解状态与金额|静态标记/金额、无位移翻转庆祝|
