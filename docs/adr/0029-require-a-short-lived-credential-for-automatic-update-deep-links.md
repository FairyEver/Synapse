# Require a short-lived credential for automatic update deep links

`synapse://update` 不作为可被任意网页直接调用的自动重启命令：裸深链只打开客户端更新页面，只有 `https://synapse.d2.pub/desktop/update` 在用户点击更新后取得并附带的短时更新凭证，才能授权客户端继续检查、下载、倒计时安装和重启。凭证使用独立的 `DESKTOP_UPDATE_INTENT_SECRET` 由服务端签名、不落库，有效期内允许重放；客户端通过服务端接口在线验证，重复触发由幂等的客户端更新状态机合并。自定义协议无法向客户端证明来源页面，短时凭证增加一次服务端签发与在线验证以及一项独立部署密钥，但能阻止第三方网页仅靠构造裸深链绕过承接页提示，也避免为一次性消费新增持久化会话、过期清理和客户端验签密钥轮换契约。公开签发接口不是本机恶意进程的权限边界；若未来需要抵御能伪造 HTTP 请求并调用本机协议的进程，必须增加客户端内确认或受信平台证明。
