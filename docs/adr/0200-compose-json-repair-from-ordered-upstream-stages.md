# Compose JSON repair from ordered upstream stages

JSON processing uses a fixed best-effort pipeline built from `repair-json-stream`: explicitly unwrap an outer Markdown fence, try whole-input `repairJson` plus `JSON.parse`, then try `stripLlmWrapper` plus repair and parse, and finally run source-ordered `extractAllJson` candidates through the same repair-and-parse gate. The explicit unwrap only recognizes one complete outer block whose opening fence is exactly three backticks with no language or a case-insensitive `json` tag and whose closing fence is an independent three-backtick line; it supports LF and CRLF, preserves the captured body, and leaves every other fence form untouched for upstream best-effort handling. This order preserves upstream JSONP, MongoDB wrapper, malformed JSON, LLM cleanup, and whole-input multi-root-to-array behavior without reimplementing the repairer, while keeping embedded multi-candidate input deterministic and single-result.

`@synapse/desktop` consumes the public package exports as an exact production dependency on `repair-json-stream@1.3.1`; Synapse does not vendor or copy the upstream repair implementation. Any upgrade is deliberate and requires source and changelog review, the fixed compatibility corpus, contract tests, and a packaged Electron module-resolution smoke test. The distributed product retains the upstream MIT license notice.
