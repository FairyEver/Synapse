# Gate problem-feedback release on cross-layer failure tests

V1 release requires a cross-layer matrix covering the shared validator and synthetic privacy corpus; strict anonymous HTTP parsing and no-leak behavior; exact application dual-bucket behavior; coarse Nginx pre-body network and global throttling; the one-ingress, one-admission supported topology; credential-free one-shot desktop transport and outcome classification; three-column persistence, administrator access, transactional audit, deletion, retention, and backup exclusion; Dashboard plain-text and memory boundaries; and Skill trigger, semantic review, two-turn confirmation, authorization, and five-result behavior. Perimeter tests do not require cross-instance atomicity or zero deduction across its coarse throttles, while application tests retain both guarantees. End-to-end fault injection must commit the database row and then truncate the response, proving that the Agent receives only `SUBMISSION_OUTCOME_UNKNOWN` and performs no second POST. All privacy fixtures use synthetic canaries, never real credentials, paths, or business data.
