# Use a fixed problem-feedback redaction placeholder set

V1 defines case-sensitive ASCII placeholders: `<secret>`, `<token>`, `<credential>`, `<home>`, `<project>`, `<module>`, `<file>`, `<user>`, `<organization>`, `<customer>`, `<device>`, `<session>`, `<request-id>`, `<timestamp>`, `<url>`, `<value>`, and `<redacted>`. They may form logical expressions such as `<project>/<module>/<file>` or `Authorization: Bearer <token>`. The deterministic checker exempts only a complete exact placeholder value, never arbitrary angle-bracket content; a placeholder mixed with real text remains subject to normal rejection. Ordinary abstraction receives no bypass, and secret, path, or identifier positions use the fixed set. Placeholders appear in the exact user-visible confirmation draft, persist unchanged, and receive no later server substitution.
