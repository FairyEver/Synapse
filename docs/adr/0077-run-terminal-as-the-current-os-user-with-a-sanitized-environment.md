# Run Terminal as the current OS user with a sanitized environment

The initial Terminal runs without a sandbox as the current Synapse OS user. Capability and authorization metadata explicitly publish `executionIsolation=none` and `executionIdentity=current_os_user`. Creating and controlling an ordinary shell may execute arbitrary commands available to that user; terminal and group authorization scopes are not file, network, credential-agent, or process security boundaries. `command.launch` limits selection to an approved saved input sequence but does not constrain that sequence's OS effects. Shell rc and profile scripts may independently load user credentials, so the product does not claim a secret-free shell.

UI and MCP share `TerminalEnvironmentResolver`. Implementation first searches for and reuses existing safe shell or login-environment services rather than duplicating one. The resolver constructs the child environment from explicit cross-platform sources and allowed entries, not by copying all of `process.env` and attempting an incomplete denylist. The exact HOME, USER, PATH, locale, temporary-directory, SystemRoot, ComSpec, and related set is established by packaged tests on all target platforms.

Synapse internal tokens, MCP authentication, provider secrets, update keys, debug injection, and related values are excluded through a shared sensitive-variable registry or source boundary rather than scattered string checks. Additional variables require explicit user Terminal or group configuration. Sensitive values are encrypted; reading or overriding them requires the appropriate permission, and logs and audit record only key names or field categories.

Cwd, shell, and PATH receive existence, type, and platform validation but are not presented as a security allowlist. Override authorization and audit still apply. Detached daemons, PM2-managed processes, and external services may outlive the PTY and remain outside stop and force-stop guarantees. Three-platform tests cover necessary tool availability and non-disclosure of internal sensitive variables.
