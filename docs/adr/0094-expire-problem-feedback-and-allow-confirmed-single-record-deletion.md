# Expire problem feedback and allow confirmed single-record deletion

Problem-feedback records expire 180 days after `receivedAt` and are then hard-deleted without trash, archival, backup recovery, or per-record retention extensions. First-party backups exclude their data; if a legacy or self-hosted external backup restores rows, it preserves the original receipt time so expired records are hidden and cleaned again before administrator access. Long-term conclusions move into a separately reviewed formal Issue rather than retaining the anonymous body. Because privacy detection cannot be complete, an active administrator may also hard-delete one record immediately after an explicit confirmation. V1 has no bulk delete. The authenticated administrator deletion audit records the administrator identity, existing audit IP, record ID, time, result, and required action metadata, but never the feedback body, an excerpt, summary, hash, or User-Agent.
