# Place problem-feedback behavior in three Synapse Skill layers

The built-in Synapse Skill documents problem feedback in three non-duplicated layers. Root `SKILL.md` adds natural-language routing and the high-threshold cross-domain evidence trigger, then points to `app/index.md` without copying the workflow. `app/index.md` is the behavioral authority for proactive and user triggers, semantic privacy review, placeholders, minimum context, two-turn confirmation, one-attempt authorization, and result handling; feedback always remains a direct App MCP action, even when the issue arose in Workflow. `app/api-reference.md` contains only the strict tool contract, text and 256-KiB rules, stable errors, and no-retry semantics. Domain guides do not repeat the feature, and no guide claims availability until the tool and server ship together.
