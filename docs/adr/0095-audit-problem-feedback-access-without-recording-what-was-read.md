# Audit problem-feedback access without recording what was read

Each administrator list open or page change writes one `admin.problem_feedback.list` audit containing administrator identity, the existing authenticated-admin audit IP, audit time, result, requested page, and page size. It does not record feedback content, excerpts, summaries, hashes, returned record IDs, search terms, or User-Agent, and it does not emit one audit per returned record. Confirmed single-record deletion uses a separate audit containing administrator identity, the existing audit IP, record ID, time, and result. This authenticated security audit does not weaken the anonymous submission route's zero-IP-persistence boundary. Authentication failures continue through the existing guard audit without accessing feedback content.
