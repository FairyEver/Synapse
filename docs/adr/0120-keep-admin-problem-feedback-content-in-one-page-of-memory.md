# Keep administrator problem-feedback content in one page of memory

The table derives a preview only in Renderer memory from the first line's first 120 Unicode code points, appending a visual ellipsis when truncated. Neither server nor storage, audit, logs, analytics, or error reporting receives this preview. Table text, titles, tooltips, and accessible labels never contain the full body and use only that preview. The Sheet reads unchanged content from the current page, displays it as escaped React text with existing pre-wrap and word-breaking utilities, and adds no HTML, Markdown, active links, or dedicated copy control. Only the current ten records remain in memory; paging, leaving, or logout discards them, with no localStorage, IndexedDB, persistent query cache, crash recovery, browser cache, frontend log, Toast, exception report, or UI operation log containing content.
