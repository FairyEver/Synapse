# Expose one minimal problem-feedback MCP contract

The tool schema is a strict object with one required string `content`, `additionalProperties: false`, `minLength: 1`, and `maxLength: 262144` only as a safe code-point coarse bound; its description states that the shared runtime owns the exact 256-KiB UTF-8 and all complex rules, plus complete display, current confirmation, privacy and path prohibitions, one call per confirmation, and no automatic retry. Dispatcher success is `{ ok: true, data: { success: true } }`, normalized for the Agent to only `{ "success": true }`. Failures are strict `{ ok: false, code, error, data? }` MCP errors: `INVALID_INPUT` has only `{ field, reason }`, `PRIVACY_RISK` only `{ category }`, and `RATE_LIMITED`, `SUBMISSION_FAILED`, and `SUBMISSION_OUTCOME_UNKNOWN` no data. Fixed English error text never embeds retryability, delay, HTTP status, content, excerpts, lengths, raw failures, or destination; Agent behavior depends only on `code`.
