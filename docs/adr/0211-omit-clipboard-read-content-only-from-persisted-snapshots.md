# 只在持久化快照中省略剪贴板读取正文

状态：已实施。

剪贴板读取结果必须在当前 Workflow Engine 执行期间保持完整，才能供下游变量绑定使用，但把它写入运行历史会默认长期留存可能敏感的系统剪贴板内容。读取节点因此不改写 Engine 结果；实时界面及 Workflow MCP 状态或结果沿用现有约 10,000 字节的统一有界预览与截断标记，持久化快照则固定完全省略该节点的 `output` 与 `outputs.text`，只保留状态、时间和稳定错误。实现必须拆分实时有界清理与持久化省略边界，不能让快照策略清空实时预览或 Engine 数据流。V1 不增加 Clipboard 专用全文查看、下载、IPC 或保存开关，也不追踪文本传入后续节点后的敏感数据流。

写入节点采用相邻但不同的保留规则：插值后的最终文本和运行时变量值不进入实时或持久化节点 `input`，其 `input` 固定为 `{ variables: {} }`；快照内嵌 Workflow 定义仍保留作者已经持久化的原始模板与变量引用，以维持历史结构和既有重跑语义。分享导出同样保留模板并以 sensitive 位置提示，而不是自动脱敏。

该分层不能通过改写 Workflow Engine 结果实现。Engine 与必要下游持有完整文本直至当前运行释放业务引用；JavaScript 内存不提供可靠的字符串原地清零，V1 不作安全擦除承诺。
