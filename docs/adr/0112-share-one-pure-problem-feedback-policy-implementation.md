# Share one pure problem-feedback policy implementation

The existing `@synapse/shared` package owns the only deterministic problem-feedback policy module used directly by desktop and server. One side-effect-free function enforces a strict object with only `content`, multiline Unicode rules, the 256-KiB UTF-8 limit, six deterministic privacy categories in fixed priority, and stable first errors; it never trims, normalizes, redacts, logs, or reads environment, account, IP, or device context, and success preserves the original content. Skill-level semantic review remains instructional, while HTTP size and rate limiting remain server boundaries. A single synthetic fixture corpus drives shared, desktop, and server contract tests, and equivalent rule copies are forbidden. The server always revalidates and is authoritative across deployment-version differences; policy versions are not transmitted or persisted, and a newer rejection requires a newly reviewed and confirmed draft rather than compatibility bypass or silent editing.
