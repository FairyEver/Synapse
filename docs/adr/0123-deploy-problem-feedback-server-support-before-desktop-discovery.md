# Deploy problem-feedback server support before desktop discovery

V1 deploys and verifies the database migration, anonymous POST, administrator APIs, and Dashboard before releasing one desktop version that enables both the MCP tool and updated built-in Skill. No feature flag, health preflight, login state, or probe controls discovery; a supporting desktop always registers the tool. The server preserves the endpoint contract throughout supported 1.x desktop lifetimes, and breaking status, error, or privacy-category semantics require a capability major version and migration strategy. A self-hosted mismatch returning 404, HTML, or an older protocol becomes an unknown outcome without fallback to the official or alternate path. Dashboard may arrive first, but guide and tool enable together. Rollback never replays submissions, and server rollback requires proving no supported client dependency remains.
