# Authenticate platform administration with an environment secret

Synapse separates platform administration from ordinary-user identity: `/admin` is unlocked by the server-only `ADMIN_ACCESS_SECRET`, which creates an eight-hour database-backed opaque `AdminSession`, while `/console` remains account-backed through `UserSession`. This replaces `AdminUser`, administrator JWTs and role-switched Dashboard sessions because administrators do not need personal product accounts, must not authenticate the desktop client, and need a credential that can be rotated only by changing server configuration. The trade-off is that shared-secret administrators cannot be attributed to people; audit therefore records the fixed platform-admin actor plus a non-sensitive session ID, and future per-person administration would require a new identity design rather than extending this secret into an account.
