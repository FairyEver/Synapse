# Confirm problem feedback in a separate conversation turn

The built-in Skill uses a two-turn confirmation protocol. One message states that a code block contains the complete submission body and that its fence is excluded, then uses a fence longer than any backtick run in the content, asks only whether to submit that exact text, and does not invoke the tool in the same turn. A new, unambiguous affirmative reply in that explicit context—such as “确认提交”, “确认”, “提交”, “可以”, or “可以提交”—authorizes one attempt; silence, emoji, ambiguity, or standing authorization does not. Any simultaneous edit or condition overrides affirmative wording, requiring a newly displayed full draft and another wait. After confirmation the Skill reuses the displayed `content` string without rewriting or added labels. Cancellation or a topic change discards the draft.
