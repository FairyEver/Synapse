# Handle problem-feedback results without repeating the body

On success the Agent says only “问题反馈已提交”, without promising review, reply, or action. Stable failures use fixed Chinese category mappings and never repeat content, match locations, or internals. `INVALID_INPUT` and `PRIVACY_RISK` may lead directly to a safely corrected full draft and new confirmation, but stop if minimum context cannot be preserved. `RATE_LIMITED` supplies no guessed delay or automatic retry. `SUBMISSION_FAILED` states definite non-submission, but retry still requires redisplay and confirmation. `SUBMISSION_OUTCOME_UNKNOWN` states that submission may or may not have occurred, warns of duplicate risk, and permits another redisplayed attempt only after the user explicitly chooses it with that understanding. Only a new confirmation draft repeats the full body.
