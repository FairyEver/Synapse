# Replace the unreleased open-file node contract

The existing `open_file` node contract never shipped in a formal release, and the repository contains only one persisted workflow using it: the current Workflow schema sample `open-file-workflow`. Synapse will therefore replace that baseline in place with node type `file_opener_file_open`, configuration `{ path, variables }`, and required share capability `app.file_opener.file.open@1.0.0`, implemented inside the File Opener application-capability package. The current Workflow 2.3.0 schema contract and fixture plus that workflow are updated in place without a version bump, legacy field adapter, old capability identity, or migration step; implementation is complete only after the updated workflow is verified to run through the shared File Opener service.
