# Limit deterministic problem-feedback privacy checks to high-confidence signals

The shared privacy checker blocks only locally recognizable, high-confidence syntax. It uses no risk score, broad keyword accumulation, heuristic code or customer-name classification, Unicode normalization, decoding, entropy analysis, network lookup, or model call. Contextual judgments such as organization names, ordinary relative paths, source or business fragments, URL necessity, and the origin of an ordinary hash remain with Skill semantic review and user confirmation. Passing means only that no deterministic rule matched, never that the body is safe. Every rule has synthetic rejection fixtures, nearby allowed counterexamples, and exactly one existing risk category; there is no hidden score or unknown category, and rule additions update the sole shared corpus.
