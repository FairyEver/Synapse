# Expose problem feedback as one high-risk MCP capability

V1 uses App ID `problem-feedback`, namespace `problem_feedback`, service ID `core.problem-feedback`, capability ID `app.problem_feedback.report.submit`, and MCP tool `app_problem_feedback_report_submit` at contract version `1.0.0`. The capability is `mutates: true` and `risk: "high"` because it transmits and persists user-confirmed text remotely. Its only public server write is anonymous `POST /api/problem-feedback`; active administrators use only the paginated list and confirmed single-record delete under `/api/admin/problem-feedback`. V1 has no Workflow node, Deep Link, Renderer trigger IPC, desktop System App, CLI, public web form, or alternate submission path; the management UI lives only in the existing Dashboard.
