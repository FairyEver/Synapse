# Agent 对话图片分享

桌面对话顶栏与单条消息工具栏进入原位选择，原有侧栏、时间线、草稿和附件保持。选择栏占用原悬浮输入框位置；返回预览保留选择，取消恢复输入。主窗口与独立对话窗口共用 `AgentConversationWorkspace`。

## 内容与状态

- 用户消息和 AI 最终回复独立选择，支持按轮、Shift 连选、全选、仅 AI、最近一轮和清空。输出始终按原顺序，不连续选择显示省略标记。
- 进入时冻结当前消息；补齐向前分页历史时保留已有快照，之后追加的消息不自动加入。流式及过程回复不可选，退出后重新进入可选择已完成回复。
- 全选 / 仅 AI 必须完成全部历史分页。失败时保留已加载消息和选择，可重试或分享已加载部分，不把部分历史声称为全选。
- 分页与所选长正文校验归属和前进游标。最多 10,000 条历史、8 MiB 快照、单条 2 MiB 正文；超过范围明确提示，不静默截断。退出、切换会话和组件卸载使旧异步操作失效。
- 不包含思考、工具调用 / 结果、权限卡、Token / 费用、诊断信息和附件原文件。正文中用户主动写出的内容仍属于正文；邮箱隐藏不代表完整敏感信息检测。

## 预览与 PNG

- 复用实际消息正文和 Generated UI renderer，独立只读控制器恢复图表 / 表单绑定状态，不保存归一化值，不提交动作或打开外链。默认隐藏邮箱同时处理正文、标题、模型名和嵌套绑定状态，不改源消息。
- 标准 / 宽版为 720 / 960 CSS px；2× / 3× 输出为 1440 / 1920 / 2160 / 2880px 宽。显式 `dpr: 1`，输出不受预览缩放或屏幕倍率影响。
- 使用固定 SnapDOM 3.3.7，异步加载导出模块；在无缩放的独立副本上调用 PNG `toBlob`，Canvas 先冻结位图，PNG IHDR 必须达到目标尺寸。
- 等待字体、图片、Generated UI 与布局稳定。资源缺失、渲染错误、嵌入网页 / 视频、溢出的滚动内容、库降级警告和尺寸降低均不能报告成功。横向溢出提示改用宽版；不能完整静态化的内容需取消该条消息。
- PNG 上限 32 MiB、1.28 亿像素、64,000px 高；剪贴板上限 3,200 万像素、32,767px 高，超过时引导保存。超过保存预算要求缩小范围，本轮不自动分图，也不静默降低分辨率。

## 原生输出边界

- Renderer 仅传 `action + pngBase64 + fileName`，不能指定写入路径。私有 IPC 绑定实际调用窗口，系统保存对话框由该窗口持有；取消返回 `success: false`。
- 主进程校验 PNG 类型、字节和尺寸预算，再经 PermissionGuard / AuditSink 使用 Electron ClipboardItem 或原子文件保存。审计只记录尺寸、字节数、动作和错误类型，不含消息或图片正文。
- 写入失败保留选择和设置，可重试；输出期间锁定设置和重复点击。已开始的系统写入不保证能取消，切换会话只抑制旧界面的后续反馈。
- 不上传、不创建公开链接，不新增公开 MCP、capability、System App、Dock、Workflow、Automation 或 Deep Link。新增 preload 接口需完整重启客户端后生效。

## 验证边界

自动测试覆盖选择 / 预览、只读状态、历史及正文分页、游标变化、取消 / 失败 / 旧请求、PNG 倍率 / 降级 / 资源错误，以及主进程真实临时文件写入和系统接口载荷。真实桌面剪贴板粘贴、保存后打开 PNG 和不同图表的像素效果需在启动客户端后人工验收；未运行应用时不能宣称已完成该项。
