SynapseMobile 输入栏重构

照着微信底部输入栏的逻辑重做手机端的输入区：语音不再是输入框里的一个按钮，而是输入栏的一种模式。终端与 Agent 对话共用这一条栏。
直接在手机上按住那个「按住 说话」试。

结构

微信式（左端常驻切换键）
现状（＋ 在最左、麦克风在框里）

「点击开始·结束」是你 2026-09-16 拍的板，也是 PC 端现在的做法。两种都能试，见右侧待拍板第 1 条。

微信 → Synapse 的对应

左端「语音 / 键盘」常驻切换键照搬
输入框右侧的麦克风快捷入口去掉 —— 与左端切换键等价，两个入口只会让人猜哪个不一样
语音态输入框变「按住 说话」照搬，宽度与位置不变
松开 → 发语音消息松开 → 转文字，落进输入框由人确认后发送
「滑到这里 转文字」（右侧区）砍掉 —— 恒定转文字后，右区没有第二个出口。只留上滑取消
录音时全屏变暗不遮罩 —— 终端输出要能一边说一边看
波形气泡实时转写气泡 —— 流式识别本来就有字可显示，不假装有波形
表情面板不做
按住上限 60 秒同（腾讯云引擎上限），到点自动收尾转文字

待拍板

  1. 手势：按住说话，还是点击开始·结束。你两天前拍过「不是按住说话」，那是三端一起定的。iOS 单端改成按住，三端手势就不一致了 —— 要不要接受这个不一致？
  2. ＋ 从最左挪到输入框右侧。这是微信的顺序，也让左端腾出来给切换键。不想动 ＋ 的话，切换键只能和 ＋ 挤在左边。
  3. 转文字落地后自动切回键盘态（本原型）还是留在语音态连着说第二段？
  4. 录音时要不要遮罩终端。原型选的是不遮罩 —— 终端在跑东西时还能看着。

键盘收起时，输入栏直接坐在屏幕底边；点输入框会起系统键盘，点工具栏最左边的 ⌨ 起应用自己的按键面板 —— 这两件事没动。
