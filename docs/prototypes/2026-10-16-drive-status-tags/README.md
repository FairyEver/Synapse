# 云盘分享与同步 Tag 交互原型

直接打开 `index.html`。运行时、组件样式、字体和文件图标均已内嵌，无需联网或启动服务。示例分享链接使用保留域名 `example.invalid`，不对应真实文件。所有状态变更只保留在页面内存中；刷新或“重置示例”恢复初始数据。

## 产品设计

- 文件名称后按“分享、同步”排列最多两个可点击 Tag。分享复用 `Badge outline` 和链接图标，同步复用 `Badge secondary` 和双向箭头；需要处理时使用现有 destructive variant。状态不能只靠颜色表达。
- 只展示已存在的关系，不给普通文件批量添加“未分享 / 未同步”。同步正常时显示“同步”，持续表达关系；“已同步”作为详情内的运行状态。
- 暂停、冲突、上传中、离线直接体现在同步 Tag 文案；离线是本机整体状态，顶部在线按钮切换全部关系的连接状态。离线时禁止修改同步与分享设置。
- 宽窗口中文件名先截断，Tag 不缩小、不隐藏。窄窗口将 Tag 放到名称下一行，保持名称与两个 Tag 的阅读顺序。
- 点击 Tag 打开锚定该 Tag 的 Radix Popover，不触发文件夹导航。一次只打开一个；点击外部、按 Escape 或关闭按钮可收起。按钮支持键盘聚焦和 Enter / Space。

分享弹窗只呈现访问权限、有效期、密码保护，提供复制链接和分享设置。密码只显示是否开启，不在弹窗曝光口令。过期分享显示失效状态，先延长再复制。分享设置中的关闭操作二次确认，文件保留。

同步弹窗呈现本机与云盘的双向关系、同步来源、本条目对应的本地路径、当前状态和最近同步时间。文件夹内的子项复用同一关系；“管理文件夹同步”明确动作范围。暂停与移除作用于整条关系，不伪装成仅操作当前子文件。移除确认明确保留两端文件。

排除项显示“已排除同步”，说明排除规则，不能同时显示“已同步”。只有部分子项独立同步的父文件夹显示“含同步项”，不能暗示整个文件夹都在同步。无标记只代表本机没有已知关系，不代表其他电脑未设置同步。

## 演示路径

1. 点击根目录“项目资料”后的分享和同步 Tag，对比两种小弹窗。
2. 打开“项目资料”，查看“需求说明.md”的继承关系、进入“素材”检查深层继承，再查看“dist”的排除原因。
3. 点击“Gitee缺陷分析报告”的暂停 Tag，进入管理并继续同步，查看 Tag 更新。
4. 点击长文件名后的冲突 Tag，进入处理冲突，保留两个示例版本。
5. 打开“发布归档”的“含同步项”，查看真正参与同步的子文件。
6. 使用顶部“在线 / 离线”和主题切换按钮验证连接状态与深浅主题。关闭分享、移除同步后，相关 Tag 消失；重置可恢复。

复制使用浏览器剪贴板；若权限或打开方式不支持，则显示可选中的文本供手动复制。HTML 无法打开本机 Finder，因此原型提供真实可用的“复制路径”，正式应用可复用现有“打开本地位置”能力。

## 实现边界

本目录为产品交互演示，未修改正式云盘，不接入真实账号、文件、同步服务或遥测。未增加依赖，不记入产品待发布说明。列表的外围操作仅保留打开 / 预览以聚焦 Tag；不建议据此删除正式应用的既有行操作。

正式接入时，父子归属应使用稳定 item ID 和祖先关系，排除规则复用主进程权威匹配；不能用名字猜测，也不能将整个绑定的冲突显示为每个子文件都有冲突。同步快照加载或读取失败不能等同于无绑定。此原型使用预设样例数据，不替代同步引擎验证。

源文件：`model.ts` 提供数据和文案，`use-prototype.ts` 管理交互，`prototype.tsx` 组合现有组件，`build.mjs` 将 HTML 打包为独立文件。

```sh
node docs/prototypes/2026-10-16-drive-status-tags/build.mjs
node docs/prototypes/2026-10-16-drive-status-tags/verify.mjs
```

验证直接加载最终 HTML，在 JSDOM 中检查交互与焦点，不覆盖真实浏览器像素布局。
