# Markdown 阅读布局原型

打开 [index.html](index.html)，默认展示新的阅读模式。HTML 内嵌运行时和主题，离线可用；构建命令不自动打开浏览器。

- 正文、标题、列表维持现有 `max-w-3xl`（768px），在内容区居中。
- 表格、流程图独立占满内容区宽度，保留左右 16px / 24px 页面留白；目录占用的宽度不属于内容区。
- 图表结束后，后续段落回到同一正文版心。
- 窄屏自动隐藏目录；大表和流程图在各自容器内横向滚动，正文不随之横移。
- “宽屏”让所有内容展开；“原版对比”在阅读模式中切回旧的整体限宽，可重复切换。对比仅用于评审，不建议加入正式产品。
- 目录锚点、收起目录和原文链接可用。

内容节选自用户提供的[评论回复消息失效：产品与现状评估](https://synapse.d2.pub/share/shr_QX517XYDXZTVT7YWTQDDVWWZN6H3XK30)，读取版本 `dfv_afb676c73cb842f3b2c140b5d1e19d65`。图采用原文 Mermaid 的 12 个节点及 11 条连线，静态 SVG 重新排版，仅用于验证阅读布局；不改变原文与线上文档。表格与段落内容用于演示，不在本任务评审其业务结论。

复用 dashboard 的 `Button`、`Table`、Lucide 图标和 `theme.css`；新增部分仅使用 Tailwind 布局/主题类及结构化 SVG，不自定义 CSS 或配色。原型页面仅含目录、阅读布局与对比，不模拟评论或编辑。

```sh
node docs/prototypes/2026-10-21-markdown-reading/build.mjs
```

本次是独立设计交付，没有改变正式 Markdown renderer、评论定位、MCP 或能力注册；不写产品待发布说明。正式接入时应保留 Markdown 文本顺序与映射，并验证目录/评论栏开关、评论锚点、高亮和滚动定位。

已通过原型构建，以及最终 HTML 的 JSDOM 交互检查：阅读/原版对比/宽屏切换、目录开关与锚点、表格和流程图结构、键盘滚动入口、编译后的 768px 版心和离线资源。未启动浏览器或正式应用，未执行像素验收。
