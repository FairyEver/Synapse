# 邮件内联快速回复原型

直接打开 `index.html`。单文件包含运行时、样式和字体，可离线使用；不会连接账号或发送真实信件。

## 交互

- 快速回复输入框放在邮件主题、发件信息和时间之后，正文之前；右侧为「发送」按钮。
- 输入文字后点击「发送」或按 Enter 均可回复。输入法确认不会误触发送，空内容不能发送。
- 发送期间输入框和按钮锁定，按钮显示「发送中…」；成功后清空输入框、保留焦点并提示已回复，失败时在输入框下方显示错误且保留内容。
- 列表右键和详情「更多」中的原有「快速回复」继续保留。两处入口展示不同，发送前的内容校验、预览、发送请求和刷新结果复用同一套底部逻辑。
- 平台公告不显示内联快速回复，也不能通过原有入口回复。

## 实现建议

真实页面把内联输入框的提交动作直接接到 `useMailQuickReply(mail.detail)` 返回的 `send`，不要复制 `sendPreview` 或 `send` 请求逻辑。现有 `MailQuickReplyDialog` 保持原样，两个入口共享同一个 hook 契约。

内联组件应以邮件 ID 为 key。切换信件时清空草稿和错误，不把上一封信的内容带到下一封。
