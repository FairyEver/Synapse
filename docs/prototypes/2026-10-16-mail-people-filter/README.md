# 站内信人员筛选原型

直接打开 `index.html`。单文件包含运行时、样式和字体，可离线使用；不会连接真实账号或发送信件。

- 收件箱按发件人筛选；已发送按收件人及抄送地址筛选，组织不展开为成员。
- 名单与未读数基于完整示例信箱；支持人员查找、主题正文搜索和只看未读。
- 同名账号独立展示；系统公告有系统标识。切换人员清除信件选择，切换信箱清除筛选。
- 支持读取、已读切换、批量删除确认、全箱清空、空结果、深浅主题及重置示例。
- 宽窗口使用现有可调三栏布局，窄窗口使用可搜索的人员下拉框。

示例共 9 封收件与 6 封已发送。原型不接入正式站内信，未改变产品行为，不计入待发布说明。

使用仓库已安装依赖重新生成，不需要安装依赖或启动服务：

```sh
node docs/prototypes/2026-10-16-mail-people-filter/build.mjs
```

`model.ts` 管理演示数据和筛选规则，`use-prototype.ts` 管理交互状态，`prototype.tsx` 组合现有 shadcn 组件与站内信布局。
