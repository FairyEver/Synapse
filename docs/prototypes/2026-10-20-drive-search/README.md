# 云盘文件搜索交互原型

直接打开 [index.html](index.html)。默认展示用户截图对应的云盘 Dock 模式，搜索入口位于顶栏“同步管理”左侧。点击“搜索”后，在“根目录”同一行展开输入框，下一行出现范围和筛选；⌘F / Ctrl+F 同样可以打开。

本次只设计文件搜索，未修改正式云盘、服务端或分享能力。样例日期固定为 2026-10-20，所有变化只保存在内存，不读取真实账号。周边同步、新建、分享、删除、系统目录和其他 App 保留实际入口与外观，仅搜索、目录导航、预览和定位流程可体验。

## 与实际界面的对应关系

默认保留截图中的容量条、顶栏操作、“根目录 / 已上传 3 项”、单层文件表格、“公开素材 / 回收站”、分享标签、相对时间、行内操作和底部 Dock。前几个文件的顺序沿用截图，额外示例目录放在末尾。

| 部位 | 直接复用的现有代码 | 搜索新增内容 |
| --- | --- | --- |
| Dock 模式页面与唯一顶栏 | `EmbeddedSystemAppShell` + `ModulePage` | 无独立标题或第二条应用顶栏 |
| 容量 | 现有 Progress、尺寸与用量文案结构 | 无 |
| 右侧操作 | `DriveToolbarActions`、`SystemAppTopBarActionButton` | “搜索”放在“同步管理”左侧，随后仍是“新建 / 刷新 / 更多” |
| 内容导航 | 现有面包屑和上传状态的布局 | 展开输入框；搜索时面包屑追加结果状态 |
| 文件表格 | `ModuleContentPanel`、`DriveTableColumns`、`DRIVE_FILE_TABLE_COLUMNS`、现有 Table | 保留名称、更新时间、操作三列；搜索结果名称下增加可点击父级路径 |

外层标题仅表示应用窗口，不仿制 macOS 原生交通灯。底部通知和账号沿用截图的位置与标签；不新增主题按钮、演示工具栏或功能说明段落。没有自定义 CSS、颜色、项目依赖或组件库变更。

## 搜索行为

- 仅匹配文件名、文件夹名和扩展名。忽略大小写，兼容全角输入，空格分隔的多个关键词共同匹配。不包含正文、拼音或路径搜索。
- 默认范围为整个个人云盘；进入文件夹后可切换“当前文件夹及子文件夹”。不查询回收站、公开素材库或他人文件。
- 停顿 250ms 后查询，Enter 立即查询；中文输入法组词期间保留原结果，不提交中间态。Escape / 退出搜索收起输入与筛选，恢复原目录；清除关键词仍保留搜索展开状态。
- 类型、更新时间和分享状态可组合筛选；清除筛选保留关键词。默认相关度优先，也可按最近更新或名称排序。
- 命中高亮，完整父级路径区分同名文件；长名称和路径保留悬停提示。搜索结果不增加类型、大小等常驻列。
- 点击文件预览、文件夹进入目录；点击路径或“更多 → 在文件夹中显示”进入目标目录并高亮文件。保留“返回搜索结果”，恢复关键词、范围、筛选、排序和加载范围。
- 延续实际云盘每批 100 项、底部“加载更多”的方式，不把普通浏览改成 12 行分页。
- 最近搜索最多 5 项，确认搜索或打开结果后记录，可清空。空结果提供修改关键词、清除筛选或扩大范围；失败保留条件并重试。加载使用共享 Skeleton。

## 体验入口

1. 从默认界面顶栏“搜索”进入，输入“云盘”。观察名称和时间列不变，路径作为第二行出现。
2. 筛选“图片 → 今天 → 已分享”，体验空态，再清除筛选。
3. 打开“云盘文件搜索设计.md”，预览后关闭；点击其路径定位，再返回搜索结果。
4. 同名文件分别位于 Synapse / ERP，路径可区分。
5. 在末尾“项目资料”进入文件夹，打开搜索并切换“当前文件夹及子文件夹”。

## 接入与验证边界

正式开发应在 `DriveToolbarActions` 的现有 children 位置注入搜索入口，在 `DriveViewNavigation` 旁展开输入与过滤；让 `DriveFileList` 复用原表格展示搜索结果。示例查询不是正式实现，后续需由服务端在账号权限内完成全盘递归、过滤、排序与分页，不能只过滤已加载数据。

请求需要防抖、取消和丢弃迟到响应；定位使用稳定 item ID 与实际祖先关系，预览和行内动作继续复用现有能力与校验。原型不改变长期产品契约，故不更新能力注册表、MCP 指南或产品待发布说明。

```sh
node docs/prototypes/2026-10-20-drive-search/build.mjs
node docs/prototypes/2026-10-20-drive-search/verify.mjs
```

运行时、样式、字体和图标内嵌，CSP 禁止联网。构建禁用遥测，将顶栏的 sync barrel 解析到同一个同步按钮源码，只保留 Dock 必需常量，避免加载无关运行时。验证在最终 HTML 的 JSDOM 中检查实际壳层、入口顺序、三列和列宽、系统目录、行操作、Dock 与搜索交互；不启动浏览器、正式应用或服务端，不声称完成像素验收。
