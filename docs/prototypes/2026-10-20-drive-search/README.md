# 云盘文件搜索交互原型

直接打开 `index.html`，无需联网或启动服务。顶部“演示场景”可切换全盘搜索、文件夹内搜索、无结果和搜索失败。示例日期固定为 2026-10-20，所有交互仅在内存中生效。

## 设计范围

用户最终确认只做文件搜索。本原型展示搜索方案，未修改正式云盘代码、分享功能、MCP 或服务端，不代表正式功能已上线。保留分享标记仅用于识别文件与筛选。没有产品行为交付，因此不更新待发布说明或能力注册表。

搜索栏常驻文件列表上方，复用现有 shadcn/Radix Nova、主题 token、文件图标与按钮尺寸。没有自定义 CSS、颜色或新增项目依赖。首屏保留熟悉的文件列表，不改造成独立搜索中心。

## 交互约定

- 搜索文件名、文件夹名或扩展名，不承诺正文全文检索。不区分大小写，兼容全角输入；空格分隔的多个关键词共同匹配。不支持拼音、正则或按路径匹配。
- 默认搜索整个个人云盘，进入文件夹后可选“当前文件夹及子文件夹”。名称匹配文件夹时显示文件夹本身，不把其中所有文件误当作名称匹配结果。回收站、公开素材库以及其他人的文件不进入个人云盘搜索范围。
- 输入停顿 250ms 后搜索，Enter 立即搜索。输入法组词期间保留原结果，不提交中间态。⌘F / Ctrl+F 聚焦搜索，Escape 退出搜索并清除关键词与筛选，保留正在浏览的位置。
- 类型、更新时间、分享状态可组合筛选；无关键词时也能筛选。清除筛选保留关键词。默认相关度优先，完整名称、前缀依次优先，同级按最近更新排序；也可选更新时间或名称排序。
- 结果展示命中高亮、完整父级路径、文件类型、大小、更新时间和分享标记。同名文件分别显示所在路径。窄窗口收起低优先级列，文件名和位置保留；长名称可悬停查看。
- 点击文件行预览，点击文件夹行进入。路径和“定位”均打开所在文件夹并标记目标；行内操作不触发行主操作。“返回搜索结果”恢复关键词、范围、筛选、排序和页码。预览关闭保留搜索。
- 每页 12 项，筛选和排序变化回到第一页。定位会进入目标所在页，避免目标不在第一页时无法看见。
- 最近搜索最多 5 项，仅在确认搜索或打开结果时记录；空输入聚焦显示，可一键清空。原型不落盘，刷新清除本次变化。
- 无结果按上下文提供清除筛选、扩大范围或修改关键词；失败保留输入和筛选并支持重试。加载使用共享 Skeleton，不以空列表代替加载或失败。

## 推荐体验路径

1. 输入“云盘”，确认根目录和深层文件夹同时命中；两个“云盘文件搜索设计.md”通过 Synapse / ERP 路径区分。
2. 筛选“图片”→“今天”→“已分享”，体验无结果；清除筛选保留“云盘”。
3. 打开一项预览，关闭后点击“定位”，再返回搜索结果。
4. 选择“文件夹内搜索”，对比当前文件夹与整个云盘；筛选文件夹并打开“设计素材”。
5. 搜索“.MD”体验大小写兼容和分页；搜索“云盘 设计”体验多关键词；切换“搜索失败”后重试。

## 正式接入边界

这些是待评审的搜索设计建议，不改变现有产品契约。正式接入时应由服务端在账号权限内执行递归范围、关键词、过滤、排序和分页；不得只过滤已加载的一页。基于稳定 item ID / 祖先关系定位，移动和重命名后重新解析路径；搜索结果中的分享标记使用权威状态。

请求需防抖、可取消并丢弃迟到响应，结果数、排序和筛选口径一致。正文预览继续复用现有文件类型能力与权限校验。历史搜索若需持久化，应遵循现有账号数据与主进程存储约定，支持清空，不与其他账号混用。正式开发仍需另行实现并验证这些服务端契约。

## 构建与验证

```sh
node docs/prototypes/2026-10-20-drive-search/build.mjs
node docs/prototypes/2026-10-20-drive-search/verify.mjs
```

`build.mjs` 复用已有云盘原型的离线打包方式，将运行时、项目主题、字体和图标内嵌，禁用遥测并通过 CSP 禁止联网。`model.ts` 提供固定样例和查询规则，`use-prototype.ts` 管理状态，`prototype.tsx` 组合现有组件。验证直接运行最终 HTML 的 JSDOM 交互，不覆盖真实浏览器像素布局或生产服务端。
