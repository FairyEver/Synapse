# 对话分享：产品方案与交互原型

打开 [index.html](index.html)。单文件内嵌 React、现有桌面组件、主题 token 和 SnapDOM 3.3.7，不依赖 CDN，离线可操作。仅供设计评审，尚未接入正式客户端。

初始展示完整桌面对话。点击右上角新增的分享图标，在原消息旁勾选，再点底部「预览图片」。消息悬停时的分享图标只预选该条消息。关闭预览会返回原来的消息位置并保留选择，取消分享恢复输入框。

## 与真实桌面布局对齐

本轮修订以用户提供的客户端截图和真实组件源码交叉核对。读取正在运行的 Electron 44.9.3 开发版时，其内容区为空白，随后窗口退出；没有重启或修改运行中的应用。

- 保留 macOS 标题栏、项目侧栏、单行对话顶栏、原始时间线、悬浮输入框和底部 Dock，不再以独立分享工作台替换会话。
- 侧栏起始宽度 240px，可拖动到 220–420px；范围沿用 `SidebarContentLayout`，截图中的实际侧栏宽度也在该范围内。侧栏不因进入分享模式被隐藏。
- 时间线沿用 `AgentTimeline` 的 `max-w-4xl`、16px 横向留白和 14px / 28px 正文字号行高。用户气泡直接复用 `AgentMessageBubble`，右对齐、`max-w-lg`；AI 正文保持左侧开放排版。
- 顶栏沿用当前会话标题、模型信息、上下文条，以及终端 / 复制 / 调试包 / 新窗口图标，仅在调试包和新窗口之间插入分享图标。
- 原型直接复用 `AgentComposerInputBox`；输入框仍悬浮在底部、`max-w-2xl`。选择模式在同一位置显示选择操作，不新增独立左侧消息列表。
- Dock 使用仓库内的真实应用图标，尺寸沿用 `AppShellDock` 的 48px 点击区域 / 40px 图标，并保留消息中心和账户入口。
- 图片配置只出现在 `DialogFrame` 预览弹窗中。原会话 DOM、滚动位置和侧栏宽度在选择 / 预览返回时保留。

标题栏的「原型说明」仅供本次评审，正式版不增加该入口；其他现有操作只展示，不操作真实客户端。

## 产品判断

用户需要把有价值的部分对话发给别人。分享对象应是消息，而不是当前屏幕：不受滚动位置、窗口大小或虚拟列表影响，也不需要先滚动截屏再裁剪。

推荐「原会话就地选择 → 图片预览弹窗」。选择时保留熟悉的阅读宽度、消息顺序和用户 / AI 位置，避免多列面板挤压现有对话。配置输出样式时才打开预览，返回选择无需重新定位。第一版的多栏工作台不再作为推荐方案。

本轮交付 HTML 交互原型和设计方案；不改正式聊天、IPC、能力注册和云端服务。因此不更新待发布说明，也不向生产应用增加依赖。

## 主流程

1. 顶栏分享图标进入选择模式，不自动预选；单条消息入口仅预选该条。可用「最近一轮」快速选择已完成问答。
2. 在原对话中勾选消息。用户消息和 AI 回复独立选择，可跨多轮、不连续选；底部操作栏显示已选数量，并提供按轮和批量选择。
3. 点击「预览图片」，在弹窗中检查图片内容、标题和隐私，选择清晰度。返回选择保留已选内容及滚动位置。
4. 「复制图片」将 PNG 写入剪贴板；「保存图片」下载 PNG。正式客户端使用系统保存对话框。

进入和退出分享不修改原会话。分享时暂停自动追随底部；新增消息不自动加入已选内容。流式回复未完成时不能选入，结束后再加入可选列表。

## 选择规则

| 操作 | 行为 |
| --- | --- |
| 单条勾选 | 独立选用户或 AI 消息，不强制成对 |
| Shift 连选 | 从上次勾选位置到本次位置连续选中或取消 |
| 选择本轮 | 同时选择该轮问答；再次操作取消本轮 |
| 全选 | 正式版加载全部历史并冻结快照后，选择所有可分享消息；原型为 6 条模拟消息 |
| 仅 AI | 选择所有 AI 最终回复，不包含用户消息 |
| 最近一轮 | 替换为最后一轮完整问答 |
| 清空 | 清空选择，显示空预览，禁用导出 |

输出始终使用原消息顺序，不支持拖动重排。非连续选择在中间保留「已省略内容」标记，避免看起来像连续问答。第一条之前和最后一条之后不用加省略标记。

默认包含正文、Markdown、代码、表格、图片和可静态化的可视化结果；不包含思考过程、工具调用、权限卡、Token / 费用、运行日志、项目路径和附件原文件。正文中用户主动写出的内容另行检查，不把隐藏诊断信息带入分享。

## 图片规格

「二叉图」在本轮按 Retina / 2× 高清图理解；如指另一种排版，需在正式接入前确认。

| 设置 | 默认 | 输出 |
| --- | --- | --- |
| 文件 | PNG 长图 | 文字、图表完整排版后生成 |
| 版式宽度 | 标准 720 CSS px | 宽版 960 CSS px，适合表格和代码 |
| 清晰度 | 高清 2× | 标准 1440px 宽，宽版 1920px 宽 |
| 超清 | 3× | 标准 2160px 宽，宽版 2880px 宽 |
| 标题 | 开启，可修改 | 最多 60 字，可关闭 |
| 邮箱隐藏 | 开启 | 只影响导出快照，预览同步显示 |
| 时间、模型 | 关闭 | 用户选择后加入图片 |
| 底部标识 | 开启，可关闭 | 小型 Synapse 标识 |

预览根据可用空间缩放，可切换 100%；输出尺寸独立于预览倍率和设备 DPR。原型显式设置 `scale: 2/3`、`dpr: 1`，避免 Retina 屏幕额外乘倍。使用无缩放的独立节点导出，读取 PNG IHDR 校验宽高，失败时不声称高清导出成功。

高倍率无法恢复低分辨率原图的细节。原型图表为 SVG，可按目标分辨率绘制；正式版的 Canvas、Mermaid、OpenUI、嵌入网页等应逐类验证，尤其不能假定跨域 iframe 可以被 DOM 库捕获。

超长 PNG 保存使用 SnapDOM `toBlob({ format: 'png', scale, dpr: 1 })`；不使用容易受到单 Canvas 尺寸限制的 `toPng()` 路径。原型在复制超过 3200 万像素时引导保存，以限制剪贴板内存压力。正式版需实测并确定更准确的预算；保存超过平台或目标软件能力时按消息边界分图，不能静默降清晰度。分图流程本轮未实现。

## 隐私与状态

- 只在本机生成图片，不自动上传、不创建公开分享链接。
- 原型只演示邮箱隐藏，样本为 `demo@example.com`；未复用截图中的真实邮箱。邮箱隐藏不是完整的敏感信息检测，正式版应提供预览检查和手动遮挡，并明确作用范围。
- 复制时直接在用户点击中发起 `ClipboardItem` 写入，图片由 Promise 异步生成，避免等待渲染后丢失用户手势。
- 不支持剪贴板、非安全环境、权限拒绝和生成失败均显示明确失败提示，保留选择，可改用保存。
- 浏览器只确认发起下载，文案为「已发起图片下载」，不宣称文件已落盘。正式版需等待保存桥接返回成功或取消。
- 导出时锁定消息及设置，防止生成中途变更内容；生成节点在 `finally` 移除，对象 URL 延迟释放。
- 截图库出现资源缺失或降级警告时拒绝显示成功。正式版应针对可忽略警告建立经验证的策略，不能掩盖缺图。

## 与现有客户端的衔接

现有 `AgentConversationWorkspace` 顶栏提供复制全文、导出调试包、新窗口等操作；当前下载不是用户要的图片分享，应新增独立的「分享」入口，保留调试用途。

正式接入建议沿用现有 Agent 模块：消息 ID 与完整历史读取生成不可变分享快照，分享选择状态放在单独 hook，排版与图像生成放在模块 service / helper，特权读写使用窄 preload bridge。复用现有 Button、Checkbox、Switch、DialogFrame 和主题 token，不改公共组件风格。共享窗口和独立对话窗口使用相同分享组件。

需要覆盖：历史加载失败、消息被删除 / 变更、生成中退出、图片未解码、跨域图片失败、嵌入图表不能捕获、超长内存、剪贴板拒绝、用户取消保存。客户端正式功能、MCP / Skill 暴露范围和发布说明在接入时另行实现与同步，本原型不新增能力注册。
