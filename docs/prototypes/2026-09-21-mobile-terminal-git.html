手机端终端 · Git 操作

可交互原型 · 2026-09-21 · 点着走一遍

三条入口/形态

  • 顶栏第二行：当前目录是 Git 仓库时，显示 分支名 · 改动数；不是仓库时保持现状（运行中 · 版本号）。
  • 操作全部收在右上角 ⋯ 菜单 → Git，点开是面板。
  • 不是 Git 仓库时，⋯ 菜单里没有 Git 这一行（不摆点开是空的入口）。

面板里的动作

  • 看：分支、远端、领先/落后、改动文件数。
  • 切分支 / 新建分支（两处都有搜索框）。
  • 提交（全量，不挑文件；可开「提交后立即推送」，默认关）。
  • 推送、同步。
  • 合并：两个方向都支持。

冲突

  • 一旦冲突：自动取消合并并回退，弹框说明 + 把冲突信息复制到剪贴板，你粘给别的 Agent 处理。
  • 同步走的是快进式，不会产生冲突；会冲突的只有「合并分支」。

脏工作区切分支

  • 三个选项：提交并切换 / 丢弃改动并切换 / 取消。已去掉「暂存并切换」。

手机端不传文件列表

  • 除了「提交页那一个改动数量」和「冲突时电脑拼好的那段文本」，手机端不接收任何文件清单 / diff。为的是省流量。

两个已定口径（可推翻）

  • 「把当前分支合并到其他分支」的实际链路是切到目标分支 → 合并 → 切回原分支，因为 git 没有「不切分支就合并过去」的原语。合并页会把这三步写在脸上。
  • 顶栏第二行不可点（按你说的，操作收在 ⋯ 菜单）。如果想让它点开面板，说一声。
