UI 日志补全 Skill

当任务涉及 UI 操作日志、交互日志、点击、输入、Tab、表格、列表或滚动记录时使用。

工作流程

  1. 读取现有日志工具和调用点。
  2. 找出缺失的交互事件。
  3. 按当前日志结构补齐记录。
  4. 运行相关测试和硬约束检查。

注意事项

新增日志不应改变业务行为，也不应引入额外视觉样式。错误处理继续使用结构化 logger。
