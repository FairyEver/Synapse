# 平台托管文档图片

本文取代 `2026-06-26-drive-markdown-images-design.md` 中关于在线文档图片扫描、归属判断和转存的产品方案；旧文档仅作为历史记录。

## 边界

- 浏览器 Markdown/MDX 编辑器粘贴、拖入或选择的图片无需额外确认，立即上传到平台托管对象存储，正文写入稳定 `/object/<objectId>` URL；当前图片对象使用 `img_*` 标识。
- 图片不属于用户、不进入公开素材列表、不占用用户云盘配额。上传仍要求登录且对目标文档有实时编辑权限。
- 既有相对图片、`/files/`、外部 URL 和旧文档保持原样，不扫描、不迁移、不提供迁移操作。
- 本地 Markdown 上传继续保留相对目录并把图片作为用户 Drive 文件；HTML 继续作为文件分享或 Site；明确的图床/直链请求继续创建用户公开素材 `/files/<assetId>`。
- 平台托管图片没有 MCP 上传、列表、迁移或用户管理能力。

## 生命周期与安全

- 支持 PNG、JPG/JPEG、GIF、WebP、AVIF、ICO；禁止 SVG；单图上限 20 MB；上传准备接口每个身份每分钟最多 60 次。
- 上传完成后图片可预览并处于 24 小时临时态。只有同一目标文档保存且正文引用该 URL 时，才在正文版本事务内激活。
- 临时图片过期自动清理；激活后即使正文移除引用或文档删除也保留，避免历史版本失效。
- 对象位于私有 `PLATFORM_MEDIA_COS_*` bucket 的 `document-images/` 前缀，公开访问只经过服务端 `/object/<objectId>` 代理；生产环境缺少该配置时拒绝启动。`/object` 是平台托管对象的稳定公共命名空间，不限定未来对象类型。
- 管理员可以列表、打开、隔离、恢复和永久删除。永久删除必须先隔离；底层对象删除失败进入 `delete_pending` 并由定时任务重试。
- 备份包包含平台媒体 `document-images/` 对象清单，但不复制对象字节。
