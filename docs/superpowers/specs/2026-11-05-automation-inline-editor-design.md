# 自动化页面内编辑

日期：2026-11-05。用户已确认网页原型并明确要求直接实施。本文替代 2026-06-03 automation-editor-redesign 中有关独立窗口的要求。

- 新建和编辑在当前自动化页面的内容区完成，保留应用导航；不再创建自动化编辑窗口。
- 2026-11-05 交互补充：新建和编辑作为应用框架内的独立子页面，通过 `SystemAppWindowShell headerMode="replace"` 声明替换顶栏。顶栏仅保留返回列表按钮，移除面包屑、新建/编辑标题及草稿/保存状态；主体是表单，保存进度和错误在表单操作区反馈。返回列表恢复原顶栏。
- 本次用户再次确认两步 HTML 原型，并明确取消底栏。本条取代此前双栏及保存后留在编辑页的要求。
- 复用现有一个触发器对应一个执行器的模型与注册表配置表单；新建、编辑共用两步：第一步选择并配置触发条件，验证后进入第二步选择并配置执行操作、填写名称。操作按钮紧跟居中表单内容并随内容滚动，不设置页面底栏、固定或 sticky 操作栏。
- 使用共享 GuidedFlow 的页面形态；已有弹窗向导默认不变。回退保留触发和执行配置，更换类型前确认并仅替换对应配置，保存前检查因本次更换而失效的已声明变量引用，保留未列入展示元数据的旧运行时变量。Cron 语法和时区验证由触发器 Renderer 定义提供，不在 Automation Core 硬编码类型。
- 顶部不显示新建/编辑大标题；两步进度靠左紧凑排列，连接线不撑满表单。移除重复的“何时触发？”和“执行什么操作？”可见标题及“取消更换”入口；选择区保留无障碍名称，重新选择当前类型可回到原配置，替换其他类型仍需确认。
- 列表行进入独立只读详情，行内编辑直接进入表单。详情以文本展示配置，凭据字段脱敏，保留编辑、分段修改、启停和返回列表。
- 保存成功进入所保存记录的详情；再次编辑更新同一条记录。仅保存不提交已有启停状态，新任务默认停用；保存并启用显式启用，最终状态以服务端真实保存响应为准。
- 未保存离开使用页内提示：继续编辑、暂存草稿并返回列表、放弃修改。草稿仅在当前模块会话内保留；跨应用导航或关闭时阻止未确认的数据丢失。保存中禁止离开和重复提交。
- 运行记录只在详情页以标签展示，编辑页不混入查看模式。Cron 常用/高级配置和触发变量在页内展开；第二步也可查看和复制当前触发变量。保留运行结果、停止、重试等既有能力。
- 列表保留既有管理能力，增加搜索和启停筛选，编辑返回后保持筛选条件。
- 不新增依赖，不改变调度、权限、存储、MCP 业务工具或触发器/执行器数量。移除仅为独立编辑窗口服务的私有 IPC、preload 和 Renderer 入口。
- 使用现有 shadcn/Radix 组件和主题 token；不启动应用或浏览器。运行组件交互测试、类型检查、硬约束与 IPC 生成检查，按风险进行构建检查。
