# 自动化页面内编辑

- 只读详情沿用白色标题区和浅灰工作区；触发条件、执行操作在宽容器并列，窄容器纵向排列，运行策略独立分组。运行历史使用单一白色列表，统一展示开始、结束、状态与耗时，结果中不重复耗时；保留错误、诊断、停止、重试及原执行器的终端入口。

日期：2026-11-05。用户已确认 `docs/superpowers/previews/2026-11-05-automation-feishu-prototype.html`，并在当前对话明确要求直接实施。本文取代此前两步编辑器及独立编辑窗口的页面组织要求。

- 新建和编辑作为应用框架内子页面，通过 `SystemAppWindowShell headerMode="replace"` 保留唯一共享顶栏，顶栏仅含返回列表按钮，不创建独立编辑窗口，不以 Dialog 或 Sheet 承载整个表单。
- 一个触发器对应一个执行器。配置页同时显示「当以下情况发生时」与「执行以下操作」；宽容器双栏，窄容器纵向排列，不显示中间连接箭头。浅灰工作区使用 `bg-surface`，每栏用一个 `bg-card` 白色配置面板承载选择与表单，深色主题复用同一组 token。两栏标题、类型入口与字段使用一致的间距和对齐。
- 名称与配置/运行记录标签收拢到工作区上方的白色标题区；共享顶栏仍仅保留返回。名称直接修改，保存中或运行记录视图中不可编辑。
- 空白态按注册表分组列出触发类型，尚未选定可用触发器时执行类型不可选。不得复制原型的演示场景栏、虚构账号、运行记录或未注册类型。
- 选定节点直接在原位置展示对应配置。标题是类型菜单入口，使用共享 Radix Portal 菜单及当前项标记；更换前确认并仅替换本侧配置，保留另一侧内容。收起与展开不卸载配置表单，不丢失局部编辑。
- 保留注册表配置与校验。Cron 常用/高级配置直接在节点内展示；未来运行时间、Agent 会话/超时逐层展开。生效日期/时段位于触发卡下方的独立附加条件卡，不进入 Cron/固定间隔配置。不新增额外邮件过滤、多触发器或多执行步骤。
- 左侧仍可搜索、分组查看和复制触发变量；提示词旁可搜索并在光标/选区插入变量，支持 Webhook 动态字段路径。更换触发器后更新变量集合；保存前检查被替换触发器的已声明变量，保留元数据未声明的旧运行时变量。
- 两侧下方实时生成流程摘要，摘要与保存按钮集中在同一白色操作区，宽容器左侧摘要、右侧动作，窄容器自然换行。操作区紧跟配置内容并随页面滚动，不设置固定或 sticky 底栏；保存进度及错误在动作区显式反馈。
- 已有任务可在编辑页切换配置与运行记录标签，记录依据已保存任务读取，不提交草稿；切回配置保留输入。运行结果、停止及重试复用既有面板及 hook。未保存的新任务不能查看运行记录。
- 列表行继续进入独立只读详情，行内编辑直接进入配置；详情分段修改定位同页对应节点。保存成功进入所保存记录的详情，再次编辑更新同一条记录。
- 仅保存不提交已有启停状态，新任务默认停用；保存并启用显式开启，最终状态以真实响应为准。保存中禁止重复提交、离开和切换运行记录。
- 未保存离开（返回、切换应用或关闭）统一使用共享 AlertDialog，只有「放弃」「保存」两个操作，不显示顶部提示条，不提供暂存或恢复会话草稿。保存复用完整配置校验，新任务默认停用，已有任务保留实时启停状态；保存成功后完成原离开动作，失败保留对话框与输入并显示错误。Esc 取消离开并恢复焦点，保存中禁止关闭对话框、重复提交及离开。返回列表保持既有搜索与启停筛选。
- 使用现有 shadcn/Radix 组件和主题 token，不新增依赖，不改变调度、权限、存储、IPC/MCP 契约或能力注册数量。Agent 配置表单的可选触发变量只影响自动化 Renderer；其他调用者继续正常使用。
- 验证覆盖编辑器、模块导航、共享顶栏、Agent 配置和触发器回归，以及 desktop typecheck、硬约束和 IPC 生成检查。不因本次任务启动应用或开发服务器；实机展开态视觉验收另行记录，不以源码或构建通过替代。
