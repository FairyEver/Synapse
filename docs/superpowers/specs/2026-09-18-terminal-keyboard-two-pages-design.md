## 1. 要解决什么

手机端终端底部的键盘面板有四页（常用 / 方向 / 功能 / 全键盘），产品负责人 2026-09-18 在真机上指出两件事：

1. **四页里有两页各自装不满。** 「常用」只有五颗键、「功能」只有六颗键，点进去都是一片空。分类本身成了需要用户去学的东西，而它能提供的选择又很少。
2. **键行上下比左右松。** 每一行的框比键本身高出一截（点击区下限 44pt 撑起来的），行与行之间的缝明显宽于键与键之间的缝，整块键盘因此偏高。

决定的解法是并页 + 方块键，两件事一起做。

---

## 2. 决策

### 2.1 四页并成两页：`键盘` / `导航`

- 「常用」并进「全键盘」，合并后的页叫 **键盘**；
- 「方向」与「功能」并成一页，叫 **导航**（方向键与 `home`/`end`/`PgUp`/`PgDn`/`del` 都是「把光标挪到哪」的键）；
- 键盘页排第一，打开面板就落在它上面。

命名口径与上一轮一致：名字要能自己说明白这一页是什么，不要求用户点进去才知道。

### 2.2 常用那五颗横在键盘页最上面一行

`esc`、`tab`、`⇧tab`、`⌫`、`回车` 五颗等宽平分整宽，摆在修饰键行**上面**。

- `esc` 在左上角 —— 和真键盘一致，手指知道角落在哪；
- 等宽而不是正方形：`tab`、`⌫`、`回车` 在真键盘上本来就是宽键，一行五颗等宽的长方块比五颗小方键更好按也更好认。

### 2.3 方向簇靠左，功能簇靠右，同一页

两簇各自的几何不变（倒 T / 六键簇、Insert 那格留空），只是从上下两页并为左右两块，都靠上。功能簇的键宽从 64 收到 56：并排之后 `56×3 + 56×3 + 间距` 才放得进一行，两簇同宽也读起来更整齐。

### 2.4 键是正方形，行距 = 键距 = 4pt

- 键盘页十列铺满整宽，所以字母键的边长由屏幕宽度定下来，iPhone 上正好 **≈34pt**；
- 每一行的框 = 边长 + 4pt，正方形在框里居中 —— 行与行之间因此只隔和左右一样的 4pt；
- **点击区 = 行高 ≈38pt**，不是 44pt。

**这里推翻了 Apple 的 44pt 最小点击目标（`Metrics.minimumTapTarget`），是有意的。** 4pt 行距下 44pt 的点击区在物理上不存在：要么让行距回到 10pt（高度就省不下来了），要么和上下邻居重叠 —— 重叠区归被画在上面（也就是下面那颗）的键，等于每颗最后还是 38pt。所以取 38pt 这一档：比 44 小，但仍然比键自己画出来的正方形大（上下各多 2pt），手指落在那道缝上也算数。

### 2.5 面板高度 370 → 351，两页仍然同高

键盘页是较高的一页，面板按它定高，导航页多出来的高度空着（上一轮已定的口径：一页高度，切页时上面的终端不动）。

### 2.6 `⇧tab` 保留独立键

Shift 与 Tab 现在同一页了，理论上 `⇧tab` 可以靠「锁住 Shift 再按 Tab」拼出来。仍然给它独立键：它是从手机驱动 Claude Code 最常按的一颗（切权限模式），不该因为组合变得可表达就涨到两次点击。

### 2.7 宽屏上键盘不再铺满

正方形的键跟着宽度长，而面板只有一档高度：宽屏上放任它长，六行会高过面板、压到终端上。所以键的边长到 **34pt 封顶**，超过之后键盘不再铺满、改为居中。iPad 上因此是一块居中的键盘，而不是一张被拉扁的键盘 —— iPad 本来就不是这一版的目标（见上一轮 §10.4）。

## 4. 几何

iPhone 17 Pro（屏宽 402pt，面板左右内边距各 14pt）：

```
边长  = (402 − 28 − 9×4) / 10  = 33.8
行高  = 33.8 + 4                = 37.8
板高  = 6 × 37.8                ≈ 227
```

面板高度：

```
上内边距 8 + 分类条 32 + 12 + 读数条 26 + 8
  + 键盘 227 + 提示 9 + 15 + 下内边距 14   ≈ 351
```

键盘页的六行：常用键、`Ctrl`/`Shift`/`Alt`、数字、三行字母。

## 5. 验收基线

1. 面板只有两个分类：`键盘`、`导航`，没有「常用 / 方向 / 功能 / 全键盘」。打开面板落在 `键盘`。
2. 键盘页最上面一行是 `esc` `tab` `⇧tab` `⌫` `回车`，`esc` 在最左。
3. 键盘页每一行的上下缝与左右缝一样宽（都是 4pt），每颗字母键画出来是正方形。
4. 键盘页仍然有 `Ctrl` / `Shift` / `Alt`、数字行、三行字母，以及读数条与提示。
5. 导航页上方向簇在左、六键簇在右，两块都靠上；`↑` 在 `←` 正上方，Insert 那格是空的。
6. 两页上的每一颗键发出去的东西与并页之前**逐字节相同**（`esc`/`tab`/`⌫`/`回车`/方向/`home` 等仍然是按键，不是文本）。
7. 切页时锁住的修饰键被清掉、读数条清空（与上一轮一致）。
8. 面板高度比上一版矮（351 < 370），切页时上面的工具栏、输入框和终端都不动。
