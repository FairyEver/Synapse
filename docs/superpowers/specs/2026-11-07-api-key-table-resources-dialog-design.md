# API 密钥表资源弹窗设计

## 意图

让用户在 API 密钥的表资源配置中快速理解当前范围、搜索表、批量选择，并持续看到跨页保留的选择结果。

## 目标

- 将资源范围从普通下拉改为两个语义明确的选项卡片。
- 将“表目录”和“已选资源”并列展示，避免同一表在上下两处重复扫描。
- 在当前查询结果上支持全选/取消全选，并保留现有跨页选择集合。
- 继续通过现有 `cloudTableApi.resources` 保存 `{ mode, tableIds }`。
- 保持现有游标分页请求和“不可见的已选 ID 仍可移除”行为。

## 非目标

- 不改变 API、数据结构、权限语义或分页接口。
- 不新增依赖，不重构云表请求层。
- 不把该弹窗改成多步提交流程；进度提示只用于解释信息层级。

## 交互方案

- `selected` 模式显示左侧表目录和右侧已选资源摘要。
- 表目录提供名称/标识搜索、当前结果全选、逐项选择。
- 已选资源显示完整集合，移除操作只修改本地集合，不触发重新查询。
- `all_owned` 模式隐藏表目录，显示范围说明；保存仍传空 `tableIds`。
- 保存成功沿用现有缓存失效和关闭行为；失败沿用现有 toast 错误反馈。

## 约束

- 使用 Dashboard 当前 HeroUI v3 组件和浅色主题 token。
- 弹窗在 320px、390px 和桌面宽度下可用，主体可滚动，底部操作保持可见。
- 所有按钮使用 `onPress`，不在业务组件内引入请求或日志副作用。
