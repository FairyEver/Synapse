# Agent 对话 OpenUI

本地桌面 Agent 使用官方 OpenUI 组件库展示表格、图表和表单，普通回复继续使用 Markdown。模型执行仍由现有 Claude Code / Claude Agent SDK 负责。用户无须开启开关；组件协议只进入系统提示，不成为额外聊天消息。

## 协议与归属

- 只有新生成的主会话 Assistant 正文中、顶层未缩进的 `openui` 或官方 `openui-lang` 围栏进入 UI 分段；工具、子 Agent、普通代码块和没有宿主元数据的旧历史不转换。
- 混合消息由宿主追加完整程序规则：关闭上游 `inlineMode`，因为该选项内置仅输出变更语句的规则，与独立消息块不兼容。保留官方组件签名、绑定、函数和动作说明，附上使用实际 schema 校验的筛选报表及提交示例；更新时必须重发完整块。
- 流式事件复用现有 EventBus；预览不可交互。完整块由主进程生成 UUID、序号和 SHA-256 摘要，和轮次、协议及官方库版本一起保存到 `generatedUi` 元数据。
- UI 描述保留在原历史正文；展示与交互状态存入 `agent.generated-ui-state`，不迁移 Agent 历史存储。长内容通过既有窄全文分块接口补齐，不解析截断预览。
- 沿用完整官方组件、schema 和 CSS；ThemeProvider 和 openuiLibrary 统一从 `@openuidev/react-ui` 主入口导入，避免不同 bundle 各自创建主题 context。主题仅作用于生成界面区域和对应 portal，并跟随桌面已解析的浅深色外观。

## 交互与持久化

- 三个 UI 专用 IPC：读取状态、带 revision 保存、带 submissionId 提交。它们不注册 capability 或 MCP。
- 主进程复核项目、会话、块及原文摘要。表单操作作为普通用户数据送回来源会话，复用排队、CLI 接续只读边界和既有工具权限。
- 保存与提交按项目内 conversation 串行。草稿合并写入，版本冲突必须显式重载。提交接收前保存 uncertain 收据；已接收收据幂等，崩溃或状态不明不自动重发。
- 官方 named Form 事件只包含该表单的普通字段；提交时同时加入当前 `$binding` 值，避免填写备注后丢失范围选择。不把其它表单的草稿加入操作消息。
- 对话删除或重置清理状态。调试导出包含 UI 原文、版本与脱敏状态；状态、提示词和表单值不写入生产日志。

## 执行边界

- Renderer 不获得 toolProvider；拒绝 Query、Mutation、@Run、宿主覆盖弹窗和主动加载外部资源的组件/Markdown 图片。源码解析后以及官方组件接收计算后的 props 时均检查资源，覆盖字符串拼接、恢复的绑定值和后续响应式更新。链接点击继续走主进程受控打开能力。
- 显示解析单块上限 128 KiB、500 条语句；语法嵌套和对象遍历有界并检查引用循环。历史全文补齐最多 2 MiB；超出仅保留既有全文查看入口。限制只影响展示，不截断原始 SDK 消息或工具结果。
- 安全遍历按对象身份缓存已检查子树及其高度，避免报表重复引用数据时重复展开 AST 消耗预算；沿更深路径复用仍检查 32 层限制，活动路径检查循环，遍历工作量仍受 10,000 次访问限制。缓存仅在单次检查内有效，响应式更新及恢复状态仍重新校验资源。
- 块级解析或渲染失败显示必要错误和可复制源码，不创建隐藏修复 query，不自动重复操作。每个官方组件外加失败边界，先于上游自动恢复边界捕获运行错误，防止错误组件持续重新挂载。
- 唯一非致命参数例外是 `Stack` 的 direction/gap/align/justify/wrap 类型错误，沿用官方解析器移除无效可选参数后的默认布局，保留整份报表；不修写原文、不猜测数据或动作参数。其它错误继续阻止该块，诊断只显示有界标识符，不能回显参数值。云端 Autofix 需要额外密钥与请求，不在本地接入范围。

## 验证

自动化覆盖混合内容、流式分段、官方组件渲染、资源拦截、状态恢复/冲突、提交去重、来源失效、CLI 只读、清理与导出。交付前运行 Agent/IPC/Renderer 专项测试、desktop typecheck、硬约束、IPC codegen 和构建；正式包检查组件说明与 CSS，并验证真实 SDK 同会话往返。

手动集成命令：`pnpm --filter @synapse/desktop run test:agent:openui-sdk`。它使用已有 Claude SDK 登录与模型配置，在 JSDOM 中操作真实官方组件，只开放一个只读夹具 MCP 工具；从 7 天改为 30 天后提交，核对两次查询属于同一 SDK 会话，并重新挂载以验证状态恢复。不启动桌面应用、不查询业务数据；该测试不进入默认测试集合，也不额外调用修复轮次。
