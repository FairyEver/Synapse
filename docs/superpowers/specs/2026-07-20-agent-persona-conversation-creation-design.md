# 智能体改为新建对话时选择

日期：2026-07-20

状态：当前生效

取代：`2026-06-30-agent-persona-chat-integration-design.md`

## 决策

智能体是 conversation 级身份，只能在新建对话时选择。conversation 创建成功后，智能体 ID 不可修改；输入框和运行时不提供中途切换能力。

智能体配置仍以当前可访问的云端定义为准。已有对话每次开始新一轮运行时解析最新提示词、工具策略和模型绑定；配置变化导致现有 live session 关闭并重建，不使用 SDK 热切换接口。

## 新建对话

所有用户主动创建 Agent 对话的入口统一打开同一弹窗，包括侧边栏新增、对话闲置提醒、权限模式要求新会话和独立窗口新增。弹窗包含：

- 名称
- 智能体
- 模型

智能体默认选择“普通”，并按“系统内置”和“我的”展示可用定义。未登录、无缓存或智能体列表加载失败不影响普通对话创建。

模型决策如下：

| 智能体 | 模型 |
|---|---|
| 普通 | 必须选择对话模型，默认沿用全局默认或首个可用模型 |
| 未绑定模型 | 必须选择对话模型 |
| 已绑定模型 | 只读显示绑定模型，创建时不可覆盖 |

新建对话使用紧凑宽屏弹窗，名称与智能体在常规宽度下左右排列，窄屏时自动改为上下排列。弹窗最大高度与视口边缘保持安全间距。普通和未绑定智能体直接在弹窗内显示无表头的供应商与模型档位矩阵，模型档位在常规宽度下两列排列，窄屏时回落为单列；点击档位立即成为当前选择，不再打开第二层模型弹窗。模型区域独立滚动；供应商列表加载中显示骨架，加载失败提供原位重试。其它独立模型选择入口继续使用带确认操作的模型选择弹窗，两者共用同一受控矩阵组件。

已绑定智能体只显示带锁图标的模型摘要行和“智能体绑定”状态，不显示可编辑矩阵。从已绑定智能体切回普通或未绑定智能体时，恢复用户此前手动选择的模型和模型区域滚动位置，不重新请求供应商列表。绑定供应商或模型档位已归档、缺失、不可选择时，智能体显示“模型不可用”并禁止选择或创建。

创建调用失败时弹窗保持打开，名称、智能体和模型选择不丢失。

## 创建事务

`createSession` 接受可空 `personaId`。主进程在写入 conversation 前完成以下工作：

1. 读取当前可访问的智能体定义。
2. 校验智能体存在且绑定模型可用。
3. 计算最终 provider 和 model tier；绑定模型覆盖 renderer 请求。
4. 生成 persona ID、名称、来源和 definition hash snapshot。
5. 原子创建 conversation，并同时保存基础模型和 persona snapshot。

任一校验失败时不得写入 inactive placeholder、空 conversation 或其它半成品。

未绑定智能体和普通对话使用 renderer 请求的模型。已绑定智能体把绑定模型同时保存为 conversation 基础模型；以后解除绑定时，运行时自然回退到该基础模型。以后新增或修改绑定时，最新绑定优先。

## 运行时与异常

运行时身份只从 conversation 的 `activeMainThreadPersonaId` 解析，不读取发送请求或待发送队列中的 persona 字段。

对话顶部显示固定智能体名称和实际生效模型；普通对话只显示模型。历史条目的 persona metadata 继续读取 conversation 创建时的 snapshot，旧数据中已有的逐消息标签保持可读和可导出。

如果固定智能体被删除、账号切换后无权访问或本地缓存不存在：

- 不降级为普通对话。
- 保留历史查看、复制和导出。
- 禁用发送区。
- 显示“新建对话”操作。

普通旧对话和已有 persona 对话不做持久化迁移，继续使用当前 conversation schema。旧 persona conversation 已保存的 `activeMainThreadPersonaId` 从本版本起视为固定身份。

## 删除的能力

以下能力不再属于产品或公开接口：

- `session-persona:update` IPC 与 preload/bridge 方法
- repository/lifecycle 的 persona 更新保存方法
- 发送请求、待发送队列和 `AgentMessage` 的逐消息 persona ID、名称与来源
- composer persona 菜单、状态和乐观切换
- live session 的 `setMainThreadAgent`
- `applyFlagSettings({ agent })` 热切换路径

## 验收基线

- 普通、未绑定和已绑定三种创建路径分别生效。
- 普通和未绑定智能体打开弹窗后直接显示模型矩阵，只需一次“创建对话”确认。
- 绑定模型只读，切回后恢复手动模型；无效绑定不可创建。
- 离线缓存智能体可创建，普通对话不依赖智能体列表成功加载。
- 所有用户新增入口使用统一弹窗，独立窗口创建后正确替换目标。
- composer 不出现智能体菜单；缺失智能体阻止发送但不影响历史操作。
- persona 配置变化重建 live session，永不调用热切换 API。
- IPC codegen、公开 bridge 类型、runtime、renderer 和历史兼容测试保持一致。
