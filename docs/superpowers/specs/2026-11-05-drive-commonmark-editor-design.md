# Drive 普通 Markdown 编辑兼容

## 已确认范围

用户选择保留 MDXEditor，关闭普通 Markdown 的 JSX 解析，统一正文和文末留言的兼容处理，并验证编辑保存重开不会丢失内容。保留 `.mdx` 的现有 JSX/表达式和 ESM 源码回退路径；不增加依赖，不修改后端存储、权限、协同或发布流程。

## 方案

使用 MDXEditor 官方 `suppressHtmlProcessing`，以 CommonMark/GFM 解析普通 Markdown。共用配置包含该属性、序列化选项和兼容插件，正文与留言不再独立拼装两套策略。停止为 JSX 解析预先改写比较符、自动链接和泛型。

原始 HTML 的注释用不可见节点保存；`br` 和图片保留可编辑能力；不能直接编辑的 HTML 片段以安全的源码节点展示并原样导出，绝不注入或执行原文 HTML。源码节点不参与原文评论定位。混合普通/任务列表继续走完整源码回退。保留有序列表编号、图片末尾段落和表格 Shift+Enter 行为。

比较过替换 Milkdown 和仅提供源码编辑；本次按用户选择采用现有 MDXEditor 的纯 Markdown 配置，避免迁移评论、目录、图片和编辑恢复逻辑。

## 验收

真实 MDXEditor 导入、修改、导出、重开测试覆盖中文尖括号、未闭合标签、比较符、泛型、URL/email 自动链接、HTML 注释与片段、换行、相对/托管图片、代码、表格、列表。不得以吞错、删除未知节点或只检查模拟组件代替内容保留验证。运行相关集成测试、Dashboard 全量单元测试、类型与 UI 边界检查；不启动应用或浏览器。
