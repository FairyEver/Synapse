# OpenUI 参考按需加载与暂存 Skill 隔离

用户于 2026-10-24 授权实施已讨论方案，并要求同场景改前/改后真实模型模拟。只在当前分支开发，不改用户全局配置，不扩大到其它 Skill 或工具精简。

## 方案

普通桌面会话常驻简短 OpenUI 入口说明，明确在聊天内图表、筛选、表单适用时先用 Read 完整读取受控静态参考，再生成或修改完整独立程序。完整参考与现行官方库、例子和安全协议一致，随应用资源交付；不按用户输入关键词决定是否加载。参考不存在、会话本身没有 Read 能力或 dontAsk 模式时保持完整参考常驻，避免 Persona 受限导致功能退化。普通代码交付和纯文本不读取参考。精确宿主参考读取在既有 Persona、toolPolicy、子 Agent 检查后自动允许，不新增其它读写权限。

与新增 MCP 工具相比，复用 Read 不扩大公开工具表面；与运行时写入用户目录相比，随包参考无需改用户文件。`appendGeneratedUiPrompt` 保留完整模式以支持回退和对照。旧 SDK 会话的 system prompt snapshot 不强制改写；新会话采用短说明。

只通过 SDK `settings.skillOverrides` 将可见的 `.synapse-install-dir-` 加 6 位字母数字的暂存目录别名设为 off；保留正式 synapse-skill、用户/项目/插件其它设置。扫描只读取当前 SDK 配置根与项目祖先的 Skill 目录，不删除、改写全局文件，不把正常隐藏 Skill 一概排除。合并既有 overrides，discovery/正式/原生查询均使用同一设置。SY 自己的 slash 索引也忽略这一精确暂存前缀。

## 验证标准

固定场景先运行当前全量提示，再使用相同模型、工具、夹具数据、权限和用户原文运行候选实现：自然语言交互图表、连续筛选修改、表单提交往返、纯文字与代码反例。记录模型原文、API usage、工具调用、参考读取、官方 parser/组件渲染与同会话状态，明确固定夹具不代表业务查询。不得用自动修复轮次掩盖首次失败。

比较原始生成成功与界面兼容后的效果；任何失败保留并定位。若短说明不足以可靠引导读取，不交付未经验证候选。回归覆盖缺资源、禁 Read、Persona 合并、Read/非桌面边界、参考与生成器一致、暂存名过滤、原生 SDK 生效和全局源文件不变。更新 OpenUI 原设计、Agent Runtime 规则和发布说明。

## 实施记录

保留完整参考回退，参考以静态资源交付并通过测试与官方生成器逐字一致校验。SDK 原生实测使用暂存目录别名覆盖，虽然 supportedCommands 将三份显示为相同 frontmatter name，过滤后仅剩正式一份；未按正式 name 一刀切禁用。参考读取已在真实模型中发生；第二轮界面以真实输出离线重放补验，避免只解析源码却未渲染更新结果。
