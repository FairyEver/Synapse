# 云端数据表 v1

2026-11-04 补记：用户已确认桌面 MCP 应与云盘一样使用当前登录账号。以下是 v1 初版设计，关于 MCP 的限制已由 [桌面 MCP 方案](../plans/2026-11-04-cloud-tables-mcp.md)取代。开放 API 的认证规则仍以本文及接口契约为准。

用户确认的目标是为自建网页、AI 与脚本提供有类型的数据后端：Console与REST API，文档可整页复制为Markdown供AI调用。用户后续明确取消独立Skill，不再提供Skill文件、下载入口或分发配置；不新增桌面入口、MCP、依赖或用户物理数据库表。

使用 PostgreSQL 元数据和 JSONB 行。开放 API 仅识别个人 API 密钥或匿名身份，忽略 Cookie 和普通登录 Token；分享网页仅执行匿名开放操作。Console 使用既有登录身份，表主管理结构、ACL、回收站，协作者按授权维护记录。现有分享机制不改，同源用户 HTML 与 Console 的通用隔离风险尚未解决，分享内容仍以可信团队使用为前提。

按操作配置匿名访问及指定 SY 用户权限，读取/修改/删除支持全部或本人记录。密钥同时受 scope、资源范围和实时表授权限制；已有密钥不扩权。selected 是默认范围，只有 all_owned + tables.manage 密钥能建表。

字段支持 text/integer/number/boolean/date/datetime/singleSelect/multiSelect/url/json，稳定字段与选项 key、必填、默认值。未知字段和不兼容数据明确拒绝，类型变更不静默转换。记录版本检查、原子批次、24 小时幂等确认，写操作只返回最小确认。表、记录和归档字段保留 30 天；恢复检查当前结构，整表恢复关闭匿名权限。

不设账号容量、表数、记录数、总字节额度或低固定 RPM。操作边界：请求 1 MiB、记录 64 KiB、每表100字段（含待清理归档）、100 条批次、最多 20 条筛选和 3 个排序，分页默认 50/最大100。数据库侧筛选和游标分页，不默认 COUNT。云表专用连接池、公平队列，按表 owner 而非调用者分配；默认全局并发8、owner并发2、owner队列32、全局队列128/16MiB、排队5s、SQL2s、锁250ms。真正取消/回滚超时工作，繁忙503且提供Retry-After。单服务实例，多副本前须补全局协调。

2026-11-02读取增强：查询支持fields活动业务字段投影与filterMode同级all/any；默认请求、权限和分页预算不变，字段选择在SQL执行，系统元数据保留。新增显式count/exists端点，仅接受相同filters/filterMode，按当前可读且未删除范围精确计数或短路判断。OR不能绕过表/own/软删除/游标边界；count超安全整数拒绝，超时仍503。列表不附带COUNT，跨请求不保证快照，exists不保证并发去重。不新增索引、迁移、MCP、Skill或Console控件。详细契约见[首批读取API设计](2026-11-02-cloud-tables-read-apis-design.md)。

2026-11-04 补记：表主可显式发布受限的今日分类汇总，按配置时区和同表主的公开候选目录返回分组计数及布尔真值数。没有对应目录项的记录合并为其他，不暴露自由文本或原始记录；不提供通用聚合查询或实时订阅。参见[公开今日汇总](../../../document/open-api/api/cloud-tables.md#公开今日汇总)。

表主亦可仅公开无筛选的未删除记录总数。桌面 MCP 的发布前检查返回当前账号、站点与服务器能力，网页发布仍使用 Drive，公网可达性须单独验收。

Console复用HeroUI，支持字段/数据/权限/回收站/API示例/日志/JSON和安全CSV导出。页面沿用Dashboard V2的共享Header/Main及ServerDataTable；筛选按所在背景选择原生控件变体，游标翻页使用HeroUI Pagination，不虚构总数；标签文字保持单行，窄屏在标签栏与表格内部滚动。AI使用API文档与OpenAPI契约，通过私有环境变量持有密钥并发现表schema。无附件、公式、关联、SQL、实时订阅、修改历史、付费计量、专用CSV导入器。操作日志固定元数据保留30天，不记录values/凭据。

验收使用隔离本地PostgreSQL16，覆盖权限、跨表、Cookie不升级、并发/幂等/撤权/schema竞态、恢复/清理、锁竞争、公平性和批量突发。完成UI桌面/窄屏自动测试、相关全套单测、类型和构建/契约检查。当前仓库当前分支实施，只本任务本地提交，不push或部署。
