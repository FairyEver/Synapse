# 能力牌筹码经济 v3

日期：2026-11-03。范围：新建点数与陪练卡牌房的全部八种能力牌。旧版房间、本手快照、归档、Roll、卡池配方、牌效、行动时限和公开/私密边界沿用各自规则。

## 目标与取舍

价格应让玩家在保留当前牌、花小钱尝试和付溢价多选之间有真实取舍。保留随机换错、错过补牌和付费后被反制的风险；牌费在随机结果揭晓前明确，无追损促销、保底或隐藏概率。首次使用可试，连续使用有机会成本，防守牌仍可在短筹码时使用。参考 [Prospect Theory](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Behavioral_Decision_Theory/Kahneman_Tversky_1979_Prospect_theory.pdf) 对确定支出与不确定收益的区分；不从该研究推导具体价格或玩家使用率。

旧公式在示例翻牌底池 120 时，约 99% 的计价权重来自未下注的对手余额；五选一报价 778。线性放大未来余额会把纸面最大风险当成已发生的下注。由于牌费进主池，还会反过来抬高后续报价。旧版把双换按单换两倍计价、五选一按三选一 1.5 倍计价，这两个比率也没有体现选槽和结果分布。

| 方案 | 取舍 |
| --- | --- |
| 每张牌固定大盲倍数 | 好理解，小池大池价格相同；深池里容易变成必用。 |
| 按实际牌力、对手或真实候选逐手计算 | 经济上更精细，但能从价格反推隐私，临场不可预测；不采用。 |
| 大盲起步价 + 有效普通底池抽样校准 + 有上限的连用加价 | 小池保留取舍，大池价格跟着当前风险增长，报价可复算。采用。 |

在只有主池且双方直接摊牌的对照中，已有主池为 P，换前与换后权益为 q、q′，价格为 C，净增期望为 `P(q′−q) − C(1−q′)`。第二项考虑费用进主池后，赢家可赢回其一部分。以 20 筹码大盲、3/12/40 BB 底池扫描，下列参数下，首次换牌的正期望状态比例分别为 32–38% / 46–62% / 49–70%；3 BB 池第三次降为 18–21%，40 BB 池第三次仍为 43–56%。这是从玩家可见状态的模拟估计得到的选择空间，不是玩家使用率，也不包括之后下注、诈唬、对手选牌或行为数据。三选一的槽位控制和五选一的上行尾部互有优势，采用同价。双换均值低且分布宽，保留低起步价，池额费率略高于单换以覆盖大底池的双张重抽机会。

截图给出了一个直观反例：已知三张方块公共牌和本人 7♦/J♣ 时，在标准牌组、无额外私有情报下，47 张未知牌中有 9 张方块。三选一指定 J♣，立即成同花的概率为 `1−C(38,3)/C(47,3)≈48.0%`；五选一仅在锁到 J♣ 时能立即成同花，概率为 `0.5×[1−C(38,5)/C(47,5)]≈33.6%`。这里只比较本次立即成同花，不等同于最终胜率。

情报、补牌、防护没有与换牌可比的直接摊牌权益，不把它们混进同一统计：情报价值在于改变决策。例如对 12 BB 底池面对 4 BB 跟注，若两种等可能情形的权益是 10% 与 40%，无信息最优跟注 EV 是 0；完全区分时平均 EV 为 1.2 BB。实际效果可能低得多，亦可能很强（单挑查看对手两张牌）。因此先知价低、会因洗牌失效；明察价更高、可能被反制。补给以实际抽牌数计成本；均匀 64 张初始池中，抽两张的首层期望额外补给数约 0.25，实战剩余配方会变，不把后续换牌费用预收。反制只抵消一次敌意效果，卡实例本身就是资源，保留免费且不可叠加。

## 最终计价规则

P = Σ min(各席位已投入的实际普通筹码, 使用者剩余筹码 + 使用者已投入的实际普通筹码)。包含已弃牌者的投入和当街未归拢的下注，排除自己够不到的超额投入、牌费及暂存；P 是报价用的可匹配资金上限，实际派彩仍以边池引擎为准。只有公开资金、阶段和本手出牌次数参与换牌计价；补给使用自身可抽的数量档位，仅本人报价可见，不展示牌池组成或精确余额。

| 卡 | 大盲部分 | P 部分 | 阶段 / 连用系数 |
| --- | ---: | ---: | --- |
| 01 换牌术 | 0.25 BB | 3.5% | 使用 |
| 02 重整旗鼓 | 0.25 BB | 4.5% | 使用 |
| 06 左右逢源 | 0.75 BB | 12% | 使用 |
| 07 五选其一 | 0.75 BB | 12% | 使用 |
| 11 先知之眼 | 0.25 BB | 1.5% | 无，河牌仍禁用 |
| 14 明察秋毫 | 0.5 BB | 4% | 无 |
| 22 灵感迸发 | 每张实际可抽能力牌 0.25 BB，最多两张 | 无 | 无，空池仍禁用 |
| 48 反制咒 | 免费 | 无 | 无，不能叠加 |

仅四张换牌：P 部分依翻前、翻牌、转牌、河牌分别乘 0.5 / 1 / 1.25 / 1.5。加上大盲部分后，整笔再乘 `1 + 0.35 × min(本人本手已经承诺的换牌次数, 3)`，即 1 / 1.35 / 1.70 / 2.05；在最终一步向上取整。换牌次数跨街共享，免费防护、情报、补给和完成候选选择不计次。状态加费和豁免仍由现有支付链执行。以翻牌 P=120、BB=20、首次为例，八张报价依次是 10 / 11 / 30 / 30 / 7 / 15 / 10 / 0；五选一后续同条件为 40 / 50 / 61。

## 扣款、兼容与验证

- 复用现有报价指纹、房间事务与幂等回执；支付后保留至少一枚筹码。实付进入主池且不参与下一次报价、不改变边池资格、不会凭空增减筹码。候选在付款后揭晓，选择不二次扣款。确认用牌后被反制仍按旧规则扣费。
- 新房用 `cards-v3,chips-v2`，在房间与本手快照中固定；牌效与配方复用 v2，新的规则摘要包含定价策略。v1/v2 与旧 Roll 仍按原规则执行；不迁移数据，不静默切换当前房。兼容发布时须带支持 v3 的 Web 客户端。若要回滚新房报价，可将 `shared/src/game-poker-cards.ts` 的默认版本改回 v2；保留 v3 的读写、报价与结算实现，直至存量 v3 房完成。
- 验证八张牌报价、边池可匹配上限、阶段和连用、牌费不推高报价、抽一张按一张付、反制扣款、重放/过期报价、待选恢复、旧版读写和 Web 版本协商。以后按筹码深度/池额、阶段、卡种、首次/重复观察使用率、弃牌率、支付分布和主池归属；先在陪练与真人桌实测再校准，不把当前模拟当作真人平衡验收。
