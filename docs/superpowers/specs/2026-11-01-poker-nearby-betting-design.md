# 就近下注操作

用户于 2026-11-01 批准第一种方案：高频操作放在底栏，自定义在下注按钮附近向上展开。取代此前必须先打开金额表单、浮层固定靠右且重复牌面摘要的组织方式。

- 底栏常驻合法的弃牌、过牌/跟注、带金额的下注/加注确认按钮，以及最小、半池、一池、自定义工具栏。档位仅选择金额，主按钮才提交；默认选服务端合法最小额。
- 自定义以实际触发按钮为锚点向上展开，包含金额输入、范围、追加额、滑块和全下入口；不重复牌面和决策摘要，不重复放置提交按钮。关闭保留本轮选择，Escape 返回触发焦点。
- 全下以及耗尽筹码的跟注/下注继续二次确认；取消保留金额。未知结果只复用原动作重试，禁用新的选择与提交。轮次/手牌/控制权变化继续清除旧表单和金额。
- 工具栏使用 HeroUI 默认浅色系统控件，主要玩法操作保留 PokerButton。宽窄屏预留相同底栏高度，展开浮层不挤压或重挂画布；窄屏碰撞避让并允许面板滚动。
- 不改服务端、协议、MCP、资金计算、依赖或数据库；不部署。游戏内容不进入发布说明。

只移动现有面板仍会让高频金额多一次点击，因此采用已批准的常用档位外露方案。
