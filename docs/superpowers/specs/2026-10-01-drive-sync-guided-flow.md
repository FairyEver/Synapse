# 云盘同步向导

本规格替换 2026-06-28 设计中“不同内容禁止首次绑定”的限制；保留自有云盘对象、进程内双向同步、强制排除、权限审计和可恢复删除边界。公共交互遵循 `docs/reference/guided-flow.md`。

## 入口与操作树（2026-10-16 更新）

- 云盘未绑定条目菜单「与本机同步…」固定当前云端对象和文件/文件夹类型，直接进入本地位置步骤。显示完整云端路径，提供「选择保存位置」和「关联已有文件…／关联已有文件夹…」。选择器取消不改变已有草稿。
- 条目已有同步时，菜单「同步详情」直接打开该关系；不重新创建。
- 顶部「同步管理」打开同步列表；工具栏及同步列表中的「新建同步」只负责创建，不再提供新建／修改／删除的通用操作页。
- 通用新建先选择「从本机上传并同步／从云盘下载并同步／关联两端已有内容」，再显式选择文件夹或文件。
- 本地上传 → 本地对象 → 云端父目录和新名称 → 文件夹范围 → 预览 → 上传并开始同步。云端父目录预填入口所在目录，可修改。
- 云端下载 → 云端对象 → 本地保存路径 → 文件夹范围 → 预览 → 下载并开始同步。条目菜单入口省去云端对象选择。
- 两边已有 → 本地对象 → 云端对象 → 以本地 / 云端为准 → 文件夹范围 → 预览 → 确认变更 → 对齐并同步。条目菜单入口省去云端对象选择。
- 下载预览被阻止且本地存在同类型对象时，提供「关联此文件／文件夹」和「更换位置」。关联保留两端路径和范围草稿，仍须显式选择本次依据，并重新预览确认；不得自动采用云端覆盖，也不得绕过其它预检限制。
- 同步详情「修改同步」直接进入范围／本地位置／云端对象／重新对齐。更换位置选择已有同类型对象并再次选择依据；需要新建目标时使用新建流程。范围修改保留未改动的规则组。
- 暂停、继续与移除留在同步列表或详情。移除先确认，取消运行与排队工作，删除关系并保留两端文件；不经创建向导。

场景、类型、修改内容和对齐依据等纯单选步骤点击即确认并进入下一步，每个选项左侧配语义图标。上下文中已确定的对象与类型不重复询问；未知类型及覆盖依据仍显式选择。路径输入、同步范围和最终执行仍需显式继续；选择覆盖依据仅触发预览，不执行覆盖。

取消返回进入前的位置：条目菜单和云盘工具栏回文件列表，同步管理内创建回同步列表，修改回原关系详情。成功创建后打开该关系详情，显示实际状态；失败或冲突保留原因和查看详情入口，不把保存记录当成功。最终确认始终显示两端完整路径及「后续双向同步」。复用现有 GuidedFlow、DialogFrame 和主题组件，不叠加配置弹窗。

## 首次对齐

`bind_existing` 不带 authority 时继续要求精确一致。显式 authority 为 local 或 remote 时，纳入范围内的另一侧与基准侧一致：补齐缺少项、更新不同文件、将目标侧独有项移入可恢复回收站。后续仍双向同步，authority 不持久作为冲突优先级。

预览返回 alignment 和 confirmationToken；令牌绑定账号、两端对象、位置、排除规则、authority、替换目标及内容哈希。创建要求携带同一个令牌，重新扫描后不匹配则阻断。MCP 与 UI 复用同一主进程服务。

本地覆盖先保存到可恢复回收站，失败则不覆盖。云端文件替换复用现有版本化上传，将预览时的版本作为 expectedVersionId 提交，服务端拒绝覆盖期间发生的新版本；无法取得当前版本时阻止覆盖。文件夹按路径逐项执行，创建父目录后再处理文件，移除子项后再移除父目录；不将目录下载作为递归覆盖捷径。

同路径文件/文件夹类型冲突要求先改名或排除；不自动替换。待移除目录内存在排除项或新出现内容时阻断，避免连带删除。符号链接、不可表示路径与跨绑定重叠继续遵循现有校验。

## 修改与失败

替换关系预览时只排除被替换关系自身，其余重复及祖先/后代重叠照常阻断。最终提交先暂停旧关系，再复核预览；旧配置和基线保留至新关系对齐验证成功后才删除。原来暂停的关系替换成功后仍暂停。

替换不保证文件级原子回滚。执行失败保留新记录为暂停并显示原因，旧记录也保持暂停；重叠关系不得恢复，用户保留所需配置并删除另一关系后再处理。不自动重试旧的权威覆盖决定。重新配置须再次预览与确认；恢复已有初始化记录只能走精确一致校验。

首次对齐完成后重新核对全树哈希，建立共同基线并回放云端游标，再启用持续同步。首次检查与用户确认都不能替代执行时检查。普通传输的既有重试规则不变。

## 验证要求

覆盖快捷入口跳过已知选择、通用创建三种场景、回退与取消草稿、返回来源位置、已有本地目标转关联、成功进入详情、上传目标父目录、规则顺序与 gitignore 选择、移除不删文件、修改保留规则、失败结果、过期确认、可恢复覆盖失败、父子处理顺序与排除项保护。现有同步服务测试必须保持通过。

## 列表阅读与搜索

云盘同步弹窗及同步向导打开时保持列表快照，后台同步通知不替换当前列表；手动同步等用户操作执行期间展示实时状态，完成后更新快照并恢复阅读冻结；手动刷新也更新快照，关闭弹窗后恢复最新状态。登录与连接状态仍即时生效。同步列表支持按名称、本地路径、云端路径搜索，搜索与状态分类共同过滤。
