## 1. 要解决什么

产品负责人发了真机截图（`IMG_5822` / `IMG_5823`），一句话：

> 把回车键和上下左右键放到第一屏里。有的时候 Claude Code 会有那种选项提示，有选项提示的话，我就需要摁方向键和这个回车键。所以这种高频操作应该出现在第一屏。

看截图能对上：第一页是数字行 + 三行字母，回车已经在右下角，但**方向键全在第二页**——一次选择要翻页、按两下、再翻回来。第二页那些 F 键、`Ins`/`Home`/`PgUp`，在实际使用里几乎不碰。

同时提了一条：**把两页的布局重新设计，让它更易用一些。**

---

## 2. 现状与它的来历

`SynapseMobile/SynapseMobile/Features/Terminal/TerminalKeyboardPanel.swift` 一个文件，两页板子，面板高度固定 346。

| 页 | 用了几行 | 内容 |
|---|---|---|
| 第一页 | **4 行**（板子 6 行） | 数字行、QWERTY、ASDF+⌫、ZXCVBNM+Space+Enter |
| 第二页 | 6 行 | 符号行十列，下面四行「F 键左三列 + 导航右三列」，方向键做倒 T |

**关键事实：板子是六行高，第一页只用了四行，底下两行是空的。** 上一轮把它写成有意的代价——「一档高度换翻页时终端不动」（上一轮 §5、§7 第 21 条）。

也就是说，这一次**不需要加高度、不需要加面板**：那两行空白正好装得下方向键和一条动作行。

---

## 3. 决策

### 3.1 两页都铺满六行

方向键搬到第一页，代价是零：第一页从四行变六行，第二页把方向键腾出来的位置分给别的键，仍然是六行。**板高不变（252），面板高不变（346），翻页时终端依旧一动不动**——上一轮为此付的那两行空白，这一轮换成了键。

### 3.2 第一页：字母板 + 方向键行 + 动作行

```
 1  2  3  4  5  6  7  8  9  0
 Q  W  E  R  T  Y  U  I  O  P
 A  S  D  F  G  H  J  K  L  ⌫
 Z  X  C  V  B  N  M  ,  .  /
 ←   ↑   ↓   →                    ← 四颗各 2.5 格，约 78pt 宽
 Esc  Tab    Space    Enter       ← Space / Enter 各 3.5 格，约 109pt 宽
```

- **第 4 行补上 `,` `.` `/`**（共 `,`→`<`、`.`→`>`、`/`→`?` 三个双图例键）：真键盘的字母底行就是这么收尾的，而这三个字符原先只在第二页有。加上这一行，第一页能打出全部小写字母、数字和这三个标点。
- **方向键一整行四颗等宽**，占满整宽。**不做倒 T**：倒 T 在十列的板子上每颗只有约 31pt 宽，而这是要闭着眼睛按的键；一行四颗 78pt 才配得上「高频」。左右与上下按真键盘的读序排（`←` `↑` `↓` `→`）。
- **`Space` 和 `Enter` 搬到动作行，各占 3.5 格**（原先各 1.5 格、和 `M` 挤在一行）。`Esc`、`Tab` 与它们同一行——`Esc` 是选项提示的第三条出路（取消），`Tab` 是补全，四颗都是要顺手够到的键。
- **`⇧tab` 因此从「两步 + 一次翻页」变成「两步」**（上一轮 §3.8 记下的那笔代价，这里还掉）。

### 3.3 第二页：符号 / 编辑 / 功能，五列六行

```
 -_    =+    [{    ]}    \|
 ;:    '"    `~    Caps  Ins
 Del   Home  End   PgUp  PgDn
 F1    F2    F3    F4    F5
 F6    F7    F8    F9    F10
 F11   F12   PrtScr ScrLK Pause
```

- **五列六行，三十格三十颗键，一格不剩。** 页一是十列，页二是五列——两页列宽不同和上一轮一样（上一轮是十列与六列）。
- 分组从上到下按使用频率：**符号 → 编辑与导航 → 功能键**。
- **`-` 换掉 `±`。** `±` 不是任何一块电脑键盘上的键，而 `-`（连字符/减号，`--help`、`-la`）**原先在两页上都打不出来**——这是这次顺手补上的一个真实缺口。
- `PrtScr` `ScrLK` `Pause` 仍然照画、压暗、不发（上一轮 §3.3 是产品负责人选的「严格照抄」，本轮不动）。位置从原来的第二行挪到 `F12` 后面——真键盘的功能键行就是这么排的。它们在这里还顺手把第三十格填满，页二因此没有空位。
- 页二**不再有方向键、`Esc`、`Tab`、`,` `.` `/`**：这些都住在第一页了，一块板上同一个键只出现一次。

### 3.4 全 ASCII 覆盖（这次补齐的）

上一轮之后，键盘能打出的可打印 ASCII 里缺 `-`。这一轮之后：

| 来源 | 覆盖 |
|---|---|
| 第一页 | 26 字母、10 数字、`Shift` 后的 `!@#$%^&*()`、`,` `<`、`.` `>`、`/` `?`、空格 |
| 第二页 | `-_` `=+` `[{` `]}` `\|` `;:` `'"` `` `~ `` |

**合起来是全部 94 个可打印 ASCII**，一格不缺。

## 4. 没改的部分

- 修饰键行（`Ctrl` `Shift` `Alt` `⌘`）两页常驻，四颗等宽，「组合键」开关只管锁存、不动版面。
- 锁存三条规则：点一下锁住、发完弹回；0.35 秒内第二下锁定；一次只锁一个。
- 命名键与修饰键的对照表（无 → 自己；`Shift` → 只有 `Tab` 成立；`Alt` → `ESC` 前缀；`Ctrl` → 一律拒绝）。方向键因此也走这张表：锁 `Alt` 按 `←` 仍然是 `Escape` + `←`（readline 的退一个词）。
- `Ctrl+I` / `Ctrl+M` 仍然不在白名单里，按 I 发 `Tab`、按 M 发 `Enter`。
- **协议零改动**：这次搬的都是已有键名（`ArrowUp` `ArrowDown` `ArrowLeft` `ArrowRight` `Enter` `Tab` `Escape`）和已有字符，`MOBILE_KEYS` 一个字不动，服务端和桌面端都不需要重新部署。

## 5. 几何

| 量 | 值 | 怎么来的 |
|---|---|---|
| 面板高 | **346**（不变） | `8 + (42+8) + 板 + (8+14) + 14` |
| 板高 | **252**（不变） | 六行 × 42，两页都是它 |
| 键高 / 键距 / 行距 | 36 / 6 / 42（不变） | 缝归上面那颗键的点击盒 |
| 键宽（十列页） | 屏宽定，约 32 | `(宽 − 9×6) / 10` |
| 键宽（五列页） | 屏宽定，**约 68** | `(宽 − 4×6) / 5`（上一轮是六列，约 56） |
| 方向键 | 约 78 | 2.5 格 |
| `Space` / `Enter` | 约 109 | 3.5 格（原先 1.5 格，约 47） |

**两页行数相同（六行），所以板高仍然是一个数，翻页仍然不动终端。** 上一轮那条「第一页底下空两行是有意的」作废——它换来的东西（一档高度）现在靠两页都铺满同样拿到。

## 6. 验收基线

逐条走，每一条都要能说出「怎么验的」。

1. 打开面板落在第一页，**方向键四颗和回车都在这一页，且都点得到**。
2. 第一页六行：数字、QWERTY、ASDF+⌫、ZXCVBNM+`,` `.` `/`、四颗方向键、`Esc` `Tab` `Space` `Enter`。**底下不再有空白行。**
3. 第一页按 `↓` → 电脑端收到 `key:ArrowDown`；按 `Enter` → 收到 `key:Enter`。（断言「键画出来了」不够：键名拼错、字节接反都照样是绿的。）
4. 第二页五列六行：符号两行（`-` `=` `[` `]` `\` / `;` `'` `` ` `` `Caps` `Ins`）、编辑一行（`Del` `Home` `End` `PgUp` `PgDn`）、功能三行（`F1`…`F12`，`F12` 后面跟 `PrtScr` `ScrLK` `Pause`）。
5. **第二页上找不到方向键**（同一颗键不在两页各画一份）。
6. 第一页按 `,` → 文本 `,`；锁 `Shift` 再按 → 文本 `<`。第二页按 `-` → 文本 `-`；锁 `Shift` 再按 → 文本 `_`。
7. `F1`–`F12`、`Ins` 都在，**按 F1 电脑端收到 `key:F1`**。
8. `PrtScr` 按下去**一个键都不发**（等一个来回之后最后一行没变）。
9. 锁 `Shift` 按 `Tab` → `Shift+Tab`，**在同第一页内两步完成**，不需要翻页。
10. 锁 `Alt` 按 `←` → 同一次 intent 里的两个动作：`Escape`，然后 `←`。
11. 锁 `Ctrl` 按 `Tab` → **一个键都不发**，且 `Tab` 压暗。
12. 「组合键」关掉 → 四颗修饰键一颗不少、一个点都不动。
13. **板子纵向的缝和横向的缝一样宽（都是 6pt）**：同列相邻两颗 `minY` 之差是 42，同行相邻两颗 `minX` 之差减去键宽是 6。
14. **翻页时终端一动不动**（两页同高），且**两页的底行都不靠滚动就够得着**（`F12` / `Enter` 直接点得到）。
15. 面板开着时按一颗键，新出现的行落在终端可视区里（`scrollViewDidScroll` 那条判别没退化）。
16. 终端不在跑时每一颗键都不可点（含修饰键与翻页点）。
17. 浅色与深色模式下键、修饰键行、翻页点都取系统色；「组合键」开关在深色下能看见圆点。

## 7. 非目标

- **游戏键盘。** 产品负责人明确排除（沿用上一轮）。
- **双修饰组合**（`Ctrl+Shift+X`）、**`Ctrl+\` / `Ctrl+Space` / `Ctrl+]`**。沿用上一轮。
- **给面板做增删改、长按弹菜单。** 面板是按键，不是命令。
- **让面板高度按页变化。** 两页同高，这次连「空行」都不需要了。
- **改协议。** 这次只搬已有键名，`MOBILE_KEYS` 不动。
- **把 `PrtScr` / `ScrLK` / `Pause` 删掉。** 它们发不出去，但上一轮是产品负责人选的「严格照抄」，本轮不推翻。
- **iPad 专属布局。**
