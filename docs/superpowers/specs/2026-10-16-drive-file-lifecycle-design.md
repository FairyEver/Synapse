# 云盘文件更新与同步关系管理

## 目标与授权

用户已确认按本轮代码审查方案完整实现覆盖上传、同步管理、解除同步和重新映射，并同时交付 AI 工具与界面。所有开发在当前仓库和分支完成，不创建或切换 worktree、分支，不启动应用，不发布或推送。

## 文件新版本

- 文件菜单提供「上传新版本…」，支持选择同扩展名、不同本地文件名的成品；保留云端名称、itemId、分享及历史版本。
- 显式整文件替换独立于基于原文的局部编辑。原有 Markdown 补丁与无基线上传保护继续有效。
- 预览绑定账号、目标身份及当前版本、本地字节哈希和有效同步关系；提交重验。目标移动、改名、云端版本或本地内容变化时拒绝过期提交。
- 修复 HTTP 上传入口未转交 expectedItemId 的缺口。版本化上传继续在 item 锁与协同代际协调下完成，提交后验证新版本内容。
- 检查本机独立和父文件夹继承的同步关系。覆盖与该关系的工作串行，保留暂停状态；未同步本地修改、冲突不得被隐式丢弃。其他设备继续执行各自冲突规则。
- 区分云端更新完成与本机/其他设备同步完成。网页上传同样锁定目标及版本。

## 同步管理

- 列表复用共享 Table 呈现连续行，不为每个对象建立描边卡片。名称下提供可截断的本地路径识别信息，状态与最近成功同步时间按列对齐；窄窗口隐藏时间列，完整路径和精确时间在详情保留。点击行的主要区域直接进入同一个弹窗的详情，不增加中间 Popover。
- 搜索与筛选在内容工具栏排列，空间不足时换行；计数按当前搜索范围计算。正在执行与等待重试分别筛选，自动重试不直接升级为需要人工处理。同原因的多个等待项目集中说明原因和已知的最近重试计划，不将等待显示为正在传输。
- 行菜单只保留详情、打开位置、立即同步、暂停／继续与解除。更换两端对象、选择对齐依据、范围修改及全量核对集中在详情「修改同步」菜单；全量核对仍显式确认，等待重试期间禁用主动核对和立即同步。
- 详情按当前状态、原因和恢复计划、同步位置、冲突／范围、最近活动组织。状态使用短文本；最近成功同步以 lastSyncedAt 为准，缺失时显示尚未同步，不以关系更新时间替代成功时间。重试展示真实 nextRetryAt，不虚构倒计时；只读期间不显示可写控制或重试计划。
- HTTP、JSON 与异常堆栈不直接铺在正文；正文使用简短原因，原始错误和尝试次数在可展开、可选择和复制的技术详情中去重保留。活动摘要按实际操作状态呈现，不把排队／失败描述为已完成。路径支持完整查看与复制，云盘目录未知时明确标识，不猜测目录；精确活动时间按需查看。
- 列表与详情分别使用适合阅读的尺寸，复用 DialogFrame、ScrollArea 和主题 token。详情不常驻危险操作页脚；解除入口收进菜单，文件去向仍由已有解除预览与确认流程决定。
- 搜索、筛选、选择和阅读顺序稳定，后台状态允许更新，不靠冻结旧状态避免跳动。1280×800 标准窗口目标至少 8 条记录。
- 暂停与继续保留关系。解除同步默认保留两端，另可只保留本地、只保留云端或将两端同步内容移入回收站。

## 解除与删除

- 删除须预览与内容指纹确认，先停止并持久解除，再执行可恢复删除，防止误删保留端。
- 范围限定纳入同步的对象，保护排除项、.git、符号链接边界和额外未管理内容。不能递归删除含受保护内容的根目录。
- 展示云端删除对分享及其他同步设备的影响。按端保存执行进度，部分失败可重试，已成功端不得误删重建后的内容；失败不得显示全部完成。
- UI 与 MCP 复用同一服务与权限、审计。旧 remove 未提供 disposition 时继续保留两端。

## 重新映射

- 详情「修改同步」提供更换本地位置、更换云端对象、重新选择对齐依据及范围入口，跳过已确定步骤；列表通过详情进入，避免行菜单堆叠配置项。
- 同类型映射继续通过显式单次依据、内容预览及确认令牌；原路径文件保留，后续仍双向同步。
- 失败保留原配置与可恢复内容，提供清晰的未完成状态及恢复操作，不承诺文件级原子回滚，不自动重复旧权威覆盖。
- 文件夹继承关系引导到实际绑定根，不创建父子重叠关系。

## 网页产物

网页文件更新与 Site 发布分开呈现；更新已有 Site 使用重新发布并保留 URL。普通目录上传继续合并，不能暗中删除云端独有文件。完整镜像删除必须走带差异和可恢复删除的同步对齐预览。

## 验证

覆盖目标身份、过期版本/本地文件、扩展名、继承同步、未同步本地改动、暂停、并发、防重入、版本回读；解除四种去向、排除项、部分失败重试；紧凑列表、搜索筛选、实时状态、直接重映射入口及失败恢复。同步更新权威 Skill/API 说明、注册表、产品边界和待发布说明。最后运行相关完整专项测试、desktop/server/dashboard 类型检查及 hard constraints，检查 diff 后仅本地提交。
