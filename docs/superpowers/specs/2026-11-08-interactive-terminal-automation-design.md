# 自动化与手动终端功能一致

用户要求：自动化创建与用户点项目加号相同的交互式终端，等待启动与真实网格就绪，再原样输入配置命令并回车。保留自动关闭、日志、退出码、超时、取消，以自动化和手动同命令进行功能对照，不以展示文字或重排冒充一致。

普通与自动化共用 Shell argv、启动文件及集成、项目分组、目录、环境、PTY 和输入通道。删除独立 `-c` 启动和合成启动文字。Shell 集成为普通及自动化终端提供会话随机 token/PID/递增 prompt 序号/原始命令状态的非显示回执，流式解析并从终端输出及日志移除。只接受本会话、本 PID、新序号；启动或回执缺失不回退到非交互模式。用户命令本身拥有同一进程树权限，回执不承诺抵御用户故意破坏 Shell 集成。

先实现并实测本机 zsh、bash 的原生 prompt 回执；多行命令优先使用 Shell 实际启用的 bracketed paste，同用户粘贴后回车。旧 Bash Readline 通过原生 quoted-insert 将换行等控制字符放入同一个编辑缓冲，专用按键绑定同时用于普通和自动化终端；不改变命令文本。没有可靠回执或原生多行输入能力时明确失败，不包 eval/source/函数替代用户命令。程序选择不设白名单。其他 Shell 在命令输入前明确拒绝，不能伪称已获得功能验收。

以实际桌面完整终端网格采样初始化新终端，并在输入前确认本会话或最近同项目/全局完整终端布局。采样晚于自动化创建时也应在输入前实际应用。没有真实采样时最多等待60秒，不猜测80列后执行；超时明确失败。缓存是本进程最近确认尺寸，不代表未知窗口未来尺寸；实际打开后的 resize 仍沿用现有链路。手动和自动化使用相同初始网格来源。手机已明确接管尺寸时以其实际测量为准，不因自动化准备覆盖手机所有权；现有 resize 水位不变。

命令回到主 Shell prompt 即完成，退出码来自 prompt hook；exit/exec 使 Shell 结束时使用真实 PTY exit。关闭自动关闭则保留可继续操作的交互式 Shell，主动保留会占运行名额；命令显式结束 Shell 时自然结束。默认自动关闭先保存转录与命令状态，再有界关闭属于该终端的进程。超时/取消先中断前台命令，必要时有界清理受控进程树；绝不波及另一终端。未确认停止不删除，重启不重放。

正常完成后的关闭遵循手动终端语义，不把 prompt 回归解释成所有后台作业结束；刻意脱离终端或忽略挂断的后台程序可能继续运行。取消/超时只认领仍绑定本 PTY 的进程；ps失败、超时、截断或根身份丢失且仍有作业时不得宣称停止确认。exec替换根进程后若忽略中断，先清理已确认归属的作业，再有界终止本 PTY 根。运行日志是实际终端转录（含原生提示符与输入回显），并非纯程序stdout。

边界加固：命令数据含ESC时不用bracketed paste，改用原生quoted-insert，避免数据自带结束分隔符改变命令。Bash5.1以前即便PROMPT_COMMAND是数组也只执行首项，集成按对应版本保留其原生语义。日志按完整UTF-8字符截断，不补替换字符或拼接遗漏后的后续输出。启动/尺寸等待失败也必须先保存已有转录与未知命令退出码再关闭；保存失败时保留终端（可能仍运行），明确报告保存错误，不自动重放。

验证必须包含真实 PTY 的手动/自动同命令对照：交互标志、启动配置中的 alias/function/env、cwd、TTY、stty尺寸、彩色多列ls、内建及非零状态、管道与重定向、多行、交互式read、后续继续输入、exit/exec、取消忽略信号的前后台子进程、无关终端隔离、记录先保存后关闭。会话随机身份与时钟类值不作字节相等断言。配置/文档/发现契约同步，源码本地提交，不启动服务、不打包安装或发布。
