# 自动化终端执行器

> 历史记录：下文的非交互启动、合成展示头、只读保留和进程组清理已由同日[交互式终端设计](2026-11-08-interactive-terminal-automation-design.md)替代；当前验收见[新验证记录](2026-11-08-interactive-terminal-automation-verification.md)。

用户已确认：新增可运行任意用户命令的终端执行器；默认勾选执行完成后自动关闭；关闭前保存日志与退出码；覆盖超时、取消并测试。此任务不恢复退役的 command/script/Node 专用执行器，不改现有自动化配置，不启动开发服务或打包。

采用独立 `builtin.terminal` Action 与现有 TerminalService，而非让 AI 代发命令或每个业务脚本自行调用 MCP 关闭。命令使用终端配置的 Shell 与自动化工作目录；不限定 Node/Python。配置为 command、autoClose（默认true）、timeoutMins（默认30，null禁用）。命令是用户提供的代码，不把事件正文或模板变量插入可执行命令；程序参数、文件重定向由用户在命令中指定。此次不新增触发数据输入通道，避免将有行缓冲和控制字符语义的 PTY 当作字节管道。合并日志上限64KiB，超出明确标记截断；沿用已有脱敏规则。

运行创建独立终端且不切焦点，保存关联后才能启动。以真实 PTY 退出事件判断完成，保存有界合并输出、截断标志、退出码和信号。PTY不区分stdout/stderr，不伪造拆分。记录先持久化，再按autoClose清理；关闭该选项保留只读的已结束会话供查看，不保留占用运行名额的空闲shell。记录保存失败则保留终端并报错。应用重启沿用现有运行中记录中断恢复，不自动重放命令。

可选 `projectId` 选择 Synapse 已配置项目；复用其终端项目分组与当前启动设置，等效于该分组普通点加号。选择后不传自动化 cwd 覆盖，目录、Shell、环境沿用分组/全局解析，包括项目无可用目录时的既有兜底。未选时保持原默认非项目分组与自动化 cwd 规则。项目分组不存在则启动前明确失败，不静默转到其他分组；关联和结果记录 projectId，重新打开终端时校验归属。配置表单提供“不指定项目”以清空选择，不自动创建项目或改变现有自动化。

新启动的自动化在原始终端缓冲和仿真器中先写入实际目录/脱敏命令展示头，控制字符转为可见文本；它不发送到 PTY，也不进入程序 stdout 回调及自动化输出日志。保留的只读画面首次打开从开头显示，尺寸只适配本窗口，不请求已退出 PTY 改尺寸，不修改历史网格/水位。运行中尺寸屏障和手机所有权保持原规则；既有历史额度不变，旧会话缺失的启动信息不能倒补。

终端普通会话仍自然退出即删除。仅本执行器内部创建的会话可延后清理，日志/退出码保存后显式清理。取消/超时停止该次进程组，等待退出，必要时执行有界终止兜底；不影响其他会话，不声称能回收刻意逃离终端会话的守护进程。任务超时与手动取消保留各自状态，不能丢掉退出结果。

执行需现有shell.exec权限和审计，命令/日志不进入全局诊断。结果沿用敏感信息脱敏与DataRepository运行历史，不裸写业务文件。主进程/renderer执行器注册、发现schema、配置及结果UI、能力清单、模块规则、系统Skill指南和更新说明同步修改。

验证覆盖：任意用户命令、默认/关闭自动关闭、真实退出码、错误、快速退出、启动失败、日志截断/脱敏、保存失败、超时/取消、其他会话不受影响、注册/退役兼容、编辑器表单。真实PTY用非服务、非应用构建方式验证Node/Python及进程清理；Windows语义单测与跨平台限制如实报告。
