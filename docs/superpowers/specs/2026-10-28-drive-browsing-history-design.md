# 云盘浏览历史

用户已通过三轮 HTML 原型评审，并明确要求实施。原型：`docs/prototypes/2026-10-28-drive-browsing-history.html`。

- 现有桌面云盘顶栏增加“浏览历史”，右侧 Sheet。顶部只有统一搜索框和类型选择；列表按日期分组，只显示类型图标、名称、用户，不显示表头、数量、排序说明、类型文字、邮箱或 URL。
- 搜索标题、链接、作者公开账号及可用昵称/邮箱，NFKC 和大小写归一，多词共同匹配；无时间/字段筛选。按访问倒序、游标分页。
- 浏览器当前登录的账号拥有每次成功访问。每次打开独立保存，昨天、今天及同日重复访问不合并。上报重试仅按访问事件 ID 幂等。
- 分享页在成功就绪后上报；直接打开 Site、分享 render/reader/download、公开素材由服务端识别浏览器顶层导航并在成功后记录。不记录匿名、MCP、子资源、iframe、失败页面、分页/后台刷新。
- 点击通过既有受控外链能力在默认浏览器打开，浏览器重新校验原分享权限；历史不保存密码、认证参数和正文，不授予额外访问权限。
- 账号隔离；清空只删除本人全部历史，需要确认。请求失败保留条件；切换账号、关闭或变更搜索时丢弃过期响应。保留到本人删除，无自动期限，不补录上线前历史。
- 清空同时擦除标题、路径、作者和私有检索快照；仅保留不含详情的事件去重凭据，避免已提交访问的迟到重试恢复已清空记录。新访问使用新事件 ID，仍正常记录。
- 浏览器 BFCache 返回同样属于一次新访问：SPA 与服务端 HTML 均监听 `pageshow.persisted` 后生成新事件，不依赖 `no-store` 禁用页面恢复，不通过重载页面破坏用户状态。服务端 HTML 初次由 HTTP 采集，恢复脚本只处理缓存恢复；二进制下载不改写字节。
- 作者显示复用公开 handle；昵称和邮箱只作为本人历史的私有检索索引，不新增公开分享资料字段。
- 本次提供 UI 私有 IPC，不增加 MCP capability/工具。同步检查系统 Skill 与能力清单，记录此例外。
- 当前 main 原位实施，不新建分支/worktree，不新增依赖，不启动应用、部署或执行业务数据库迁移；只生成 SQL 迁移，使用测试和静态检查验收。

实施及验证记录见同日计划。原始 HTML 自带严格 meta CSP 或格式异常时，浏览器可能阻止追加的缓存恢复脚本；服务端仍记录实际导航请求，不改写二进制文件。真实浏览器、数据库及发布后验收未在本次执行。
