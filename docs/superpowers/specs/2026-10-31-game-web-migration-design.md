## 已批准的边界

- 复用 dashboard 多页构建增加独立 `/game/` 页面，不加载 Console Layout。Console 普通用户侧栏用新标签页链接进入。大厅、房间、记录、档案拥有浏览器历史路由。
- 整体移动最新游戏 UI、素材、动画、音效和测试，移除 desktop Renderer 与 System App/Dock/启动台入口及 24 项游戏 UI IPC/preload；保留本机后台服务、26 项 MCP 能力、权限审计及原有公开调用语义。
- 复用 Web HttpOnly 用户会话与登录页；合法同站游戏地址登录后整页回跳。Cookie 游戏请求绑定预期 userId，身份不一致拒绝，写请求校验同源；Bearer MCP 保持兼容。Cookie invoke 不开放 AI 专用操作和真人动作的 MCP 绕行。
- 共享必要类型、UI 操作定义、响应校验及路由；shared 复用现有 Zod 版本，完整构建 ESM/CJS。Web 不得导入 desktop 源码。
- 真人 REST 与 MCP 决策投影、控制 epoch、幂等、未知写结果及服务端生命周期不变。页面离开不自动改变座位或控制权，不增加托管 AI。
- 保留最新视觉、850px 操作布局、三场景缩放、动画与音效。独立游戏页沿用局部游戏调色板，Console 浅色规则不变。
- 建房选项以 userId 隔离存浏览器 localStorage，仅非敏感选项，不迁移桌面旧配置，不改变 MCP 默认。
- 历史游戏深链改为受控打开对应 Web 页面；新提醒使用 HTTPS 游戏链接，不重写历史记录或牌局数据。
- 更新能力清单、规则和系统 Skill/Agent 指南；游戏不进入任何发布说明或发布通知。
