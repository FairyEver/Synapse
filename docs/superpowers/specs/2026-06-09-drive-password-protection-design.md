# 云盘分享与发布密码保护设计

日期：2026-06-09
范围：`server/`、`desktop/`、`shared/`

## 2026-08-05 当前默认

新建文件、文件夹和网页分享默认不需要密码并永久有效。用户主动开启密码时仍由系统生成密码。现有分享不迁移、不重置；本设计原有的旧分享迁移流程仍保持“需要密码、迁移后 3 天有效”，以下对应内容作为历史迁移决策保留。

## 2026-06-16 当前基线

本设计中关于网页发布、网站发布、`DrivePublication`、`/pages`、`/sites` 和旧 `/files` 分享路径的内容已经被新版 Drive URL 基线取代。当前 Drive 只保留分享访问，不再支持网页发布或网站发布；公开分享路径统一为 `/share/:shareId` 和 `/share/:shareId/items/:itemId`，下载统一走 `/download`，HTML 渲染统一走 `/render`。

密码、有效期和 cookie 保护仍适用于分享访问，但不再适用于已下线的发布模型。

## 目标

为 Synapse Drive 的文件分享、文件夹分享、网页发布和网站发布增加统一的密码与有效期保护。

用户点击分享或发布按钮后，不再立即生成结果，而是先确认访问设置。默认需要密码，默认 3 天有效。确认后服务端创建或覆盖当前资源的公开访问设置，并返回可复制的带密码链接。

公共访问必须由服务端强校验。受保护的网站不是在前端盖一层密码页，而是在密码验证前完全不返回真实 HTML、JS、CSS、图片或文件下载资源。

## 已确认产品决策

- 文件分享、文件夹分享、网页发布、网站发布都使用同一个设置弹窗模式。
- 设置弹窗默认开启“需要密码”。
- 有效时长默认 3 天，可选 7 天、30 天、1 年、永久。
- 密码由系统自动生成。
- 密码格式为 8 位易读大小写字母和数字，排除 `0/O`、`1/l/I` 等混淆字符。
- 用户再次分享或发布同一个资源时，覆盖当前链接设置，基础 URL 不变。
- 覆盖设置会重新生成密码并重算有效期。
- 结果弹窗展示链接和密码。
- 默认复制带 `?password=<password>` 的完整链接，同时支持单独复制密码。
- 打开带密码链接后，服务端自动校验密码。校验成功后写入 HttpOnly 会话 cookie，再 302 跳转到去掉 `password` 参数的干净 URL。
- 正确输入一次密码后，同一浏览器会话内记住到链接过期或浏览器会话结束，取更早者。
- 创建者可以在分享管理和发布管理列表里随时查看密码。
- 有效期控制整个分享或发布。到期后链接、下载接口、网页资源和旧 cookie 都不可访问。
- 文件和文件夹分享都必须有承接网页。文件分享不再打开 `/files/:shareId` 就直接 302 下载。
- 上线后所有旧的有效分享和发布自动变为需要密码，并设置为迁移时间后的 3 天有效。
- 旧链接迁移时自动生成密码。创建者在管理列表中查看密码、复制带密码链接，不弹迁移提示。

## 当前上下文

现有 Drive 分享和发布已经分离：

- 分享 URL：`/files/<shareId>`
- 网页发布 URL：`/pages/<publishId>`
- 网站发布 URL：`/sites/<publishId>/...`

当前 `DriveShare` 已有 `passwordEnabled`、`passwordHash` 和 `expiresAt` 字段，但创建、访问和管理链路尚未使用这些字段。`DrivePublication` 当前没有密码和有效期字段。

当前公共文件分享行为不一致：文件分享会直接重定向到下载地址，文件夹分享才渲染服务端 HTML 列表页。本设计要求文件和文件夹分享都先进入承接网页，再由页面上的下载操作进入下载接口。

当前发布内容通过 Synapse 服务端代理返回快照资源。密码保护必须插入到这个代理前，避免未验证访问者拿到真实网页内容或静态资源。

## Hard Rules

- 密码保护必须在服务端校验。公共页面不能只依赖前端遮罩、前端路由或客户端状态。
- 未验证前不得返回受保护发布的真实 HTML、JS、CSS、图片、字体或其它站点资源。
- 未验证前不得返回受保护分享的真实文件信息、文件夹列表、下载跳转地址或 zip 内容。
- `/files/:shareId/download`、`/files/:shareId/:itemId/download`、`/files/:shareId/zip` 必须和承接页使用相同访问校验，不能成为绕过入口。
- `/pages/:publishId`、`/sites/:publishId/`、`/sites/:publishId/<relativePath>` 必须和发布入口使用相同访问校验。
- `?password=` 只用于首次自动验证。验证成功后必须跳转到去掉密码的 URL。
- 访问 cookie 必须绑定具体资源身份，不能用一个分享或发布的 cookie 访问另一个资源。
- 到期、取消分享、取消发布后，已有 cookie 和带密码链接都必须失效。
- 公共密码页不得泄露资源名称、文件夹内容、网页标题或其它受保护内容。
- 创建者可查看密码，因此服务端需要保存可恢复密码；公共访问校验使用 `passwordHash`。
- 密码和带密码链接在日志、错误摘要和不相关 DTO 中必须按现有敏感信息规则脱敏。
- 不新增依赖，除非实现阶段用户明确批准。

## 非目标

- 不做访问次数限制、流量统计、下载统计或访问者审计 UI。
- 不做自定义密码输入。第一版只使用系统生成密码。
- 不做多个密码、访问者分组、按用户授权或团队权限。
- 不做密码找回通知、邮件通知或访问者通知。
- 不做自定义域名、CDN、缓存刷新或边缘鉴权。
- 不改变发布快照语义：网页和网站发布仍按当前发布快照访问，重新发布才更新内容。

## 桌面端交互设计

### 创建设置弹窗

分享文件、分享文件夹、发布网页、发布网站四个入口都先打开设置弹窗。

弹窗字段：

- `需要密码`：开关，默认开。
- `有效时长`：选项为 3 天、7 天、30 天、1 年、永久，默认 3 天。

弹窗操作：

- 取消：关闭弹窗，不创建、不覆盖任何设置。
- 确定：调用对应创建或覆盖 API。成功后关闭设置弹窗并打开结果弹窗。

文案保持克制，只保留标题、字段 label、操作按钮和必要错误状态。UI 使用现有 shadcn/Radix 组件和 Tailwind token，不新增自定义颜色、渐变或卡片套卡片。

### 结果弹窗

结果弹窗展示：

- 访问链接：默认为带 `?password=<password>` 的完整链接。
- 密码：系统生成的 8 位密码。

操作：

- 复制链接：复制带密码链接。
- 复制密码。
- 打开链接。
- 关闭。

结果弹窗仍可沿用现有分享/发布成功弹窗结构，但需要把密码和带密码链接作为一等信息展示。

### 管理列表

分享管理列表显示：

- 名称
- 类型
- 来源状态
- 是否需要密码
- 到期时间
- 创建时间
- 操作

发布管理列表显示：

- 名称
- 类型
- 来源状态
- 是否需要密码
- 到期时间
- 更新时间
- 操作

操作包括：

- 复制带密码链接。
- 复制密码。
- 打开。
- 取消分享或取消发布。
- 发布管理中的重新发布只更新内容快照，不改变密码和有效期。

## 公共访问设计

### 文件和文件夹分享

`GET /files/:shareId` 永远返回承接网页。

如果分享不需要密码且未过期：

- 文件分享显示文件详情页，包含下载按钮。
- 文件夹分享显示文件夹列表页，可下载单个文件或整个 zip。

如果分享需要密码：

- 请求带正确 `?password=` 时，服务端签发访问 cookie 并跳转到干净 URL。
- 请求已有有效 cookie 时，返回真实承接网页。
- 请求无密码、密码错误或 cookie 无效时，只返回居中的密码输入页。

下载接口：

- `GET /files/:shareId/download`
- `GET /files/:shareId/:itemId/download`
- `GET /files/:shareId/zip`

这些接口必须先校验分享存在、启用、未过期以及密码访问状态。校验失败时不返回下载地址、不创建 zip、不暴露文件信息。

### 网页和网站发布

发布访问入口：

- `GET /pages/:publishId`
- `GET /sites/:publishId`
- `GET /sites/:publishId/`
- `GET /sites/:publishId/<relativePath>`

如果发布不需要密码且未过期，按当前代理快照资源的逻辑返回内容。

如果发布需要密码：

- 对入口 URL 带正确 `?password=` 的请求，服务端签发访问 cookie 并跳转到去掉密码的 URL。
- 对已有有效 cookie 的请求，按当前代理快照资源的逻辑返回内容。
- 对无密码、密码错误或 cookie 无效的 HTML 入口请求，返回密码输入页。
- 对无密码、密码错误或 cookie 无效的站点静态资源请求，返回受控不可访问响应，不返回密码页 HTML，也不返回真实资源内容。

这一设计确保网站没有通过开发者工具直接请求静态资源绕过密码的路径。

### 密码页

密码页是服务端渲染的轻量页面。

展示内容：

- 密码输入框。
- 确认按钮。
- 必要错误提示。

不展示内容：

- 文件名。
- 文件夹名。
- 网站名。
- 网页标题。
- 文件数量。
- 任何受保护资源元数据。

自动验证使用当前 URL 的 `password` 查询参数。密码页里的手动输入使用 POST 提交到当前资源的解锁入口。无论哪种方式，成功后都必须跳转到干净 URL。

## 数据模型

### 共享访问设置

分享和发布需要表达同一组访问设置：

```ts
type DriveAccessProtection = {
  passwordEnabled: boolean
  passwordHash: string | null
  passwordEncrypted: string | null
  expiresAt: Date | null
}
```

`passwordEncrypted` 保存可恢复密码，用于创建者在管理列表查看和复制。`passwordHash` 用于公共访问校验，避免每次校验都解密比较。

`expiresAt = null` 表示永久有效。

### DriveShare

`DriveShare` 已存在以下字段：

- `passwordEnabled`
- `passwordHash`
- `expiresAt`

需要补充可恢复密码字段。创建和覆盖分享时写入密码 hash、可恢复密码、有效期和启用状态。

### DrivePublication

`DrivePublication` 需要增加：

- `passwordEnabled`
- `passwordHash`
- 可恢复密码字段
- `expiresAt`

发布内容快照和访问保护属于同一个 publication 记录。重新发布只新增 deployment，不改变访问保护字段。

### DTO

面向创建者的 DTO 需要返回：

- `passwordEnabled`
- `password` 或受控命名的明文密码字段
- `expiresAt`
- `url`
- `urlWithPassword`

公共 DTO 不返回密码。

共享 URL helper 可增加带密码链接构造函数。脱敏 helper 需要覆盖 `?password=`，避免日志和错误摘要泄露。

当 `passwordEnabled = false` 时，`urlWithPassword` 与 `url` 相同，复制链接不追加空密码参数。

## 服务端 API 设计

创建或覆盖分享：

```text
POST /api/drive/items/:id/share
```

请求体：

```ts
{
  passwordEnabled: boolean
  expiresIn: "3d" | "7d" | "30d" | "1y" | "forever"
}
```

返回分享 DTO，包含创建者可见密码和带密码链接。

发布网页和网站：

```text
POST /api/drive/items/:id/publications/page
POST /api/drive/items/:id/publications/site
```

请求体同分享。正常发布或覆盖当前 active publication 的访问设置，并创建新的发布快照。

重新发布：

```text
POST /api/drive/publications/:id/redeploy
```

不接收密码设置，不改变访问保护字段，只更新发布快照。

列表：

```text
GET /api/drive/shares
GET /api/drive/publications
```

返回创建者可查看的密码、带密码链接、是否需要密码和到期时间。

## 迁移设计

上线迁移覆盖所有当前有效分享和发布：

- 对 enabled 的 `DriveShare`，如果没有密码，则生成密码。
- 对 active 的 `DrivePublication`，如果没有密码，则生成密码。
- 设置 `passwordEnabled = true`。
- 设置 `expiresAt = 迁移执行时间 + 3 天`。
- 写入 `passwordHash` 和可恢复密码字段。
- 保持 `shareId`、`publishId` 和基础 URL 不变。

迁移后旧无密码链接会进入密码页。创建者可在分享管理和发布管理列表中查看密码、复制带密码链接。

迁移必须可重复执行。已经有密码的记录不应被重复改密码，避免覆盖用户已经复制出去的新密码。

## Cookie 与安全

访问 cookie 推荐包含：

- 资源类型：share、page、site 或统一 publication。
- 资源公开 id：shareId 或 publishId。
- 过期时间。
- 服务端签名。

cookie 必须为 HttpOnly。生产环境应使用 Secure 和 SameSite 合理默认值。

校验规则：

- 资源不存在、已取消、已过期：拒绝。
- cookie 签名无效：拒绝。
- cookie 资源身份不匹配：拒绝。
- cookie 过期时间晚于资源过期时间时，以资源过期时间为准。
- 永久链接的 cookie 仍为浏览器会话级，不做长期持久 cookie。

## 错误处理

- 密码错误：停留在密码页，显示短错误。
- 链接过期：显示不可访问状态，不签发 cookie。
- 分享或发布已取消：显示不可访问状态。
- 资源不存在：使用现有公共不可访问语义，不泄露是否曾存在。
- 公共站点资源未验证：不返回真实资源。
- 公共 HTML 入口未验证：返回密码页。
- 公共静态资源未验证：返回不含真实资源内容的不可访问响应。
- 服务端创建密码或加密失败：创建/覆盖操作失败，不生成半初始化分享或发布。

## 测试计划

服务端测试：

- 创建文件分享时默认参数生成密码、hash、可恢复密码、3 天有效期和带密码链接。
- 再次分享同一资源覆盖密码和有效期，但 shareId 不变。
- 发布网页和网站时生成访问保护字段。
- 重新发布不改变密码和有效期。
- 旧分享和旧发布迁移后变为需要密码和 3 天有效。
- 迁移重复执行不覆盖已有密码。
- `/files/:shareId` 对文件和文件夹都返回承接网页。
- 文件下载、子文件下载、zip 下载在未验证时不能返回真实下载内容。
- `/pages/:publishId` 和 `/sites/:publishId/<relativePath>` 未验证时不能返回真实发布资源。
- 正确 `?password=` 签发 cookie 并跳转到干净 URL。
- 错误密码不签发 cookie。
- 过期链接不签发 cookie，已有 cookie 失效。
- cookie 不能跨资源复用。
- 不需要密码但未过期的分享和发布仍可直接访问。

桌面端测试：

- 分享和发布按钮先打开设置弹窗。
- 设置弹窗默认需要密码和 3 天有效。
- 取消设置弹窗不调用创建 API。
- 确认设置后调用对应 API，并打开结果弹窗。
- 结果弹窗展示带密码链接和密码。
- 复制链接复制带密码 URL。
- 复制密码复制明文密码。
- 管理列表展示是否需要密码、到期时间和密码。
- 管理列表复制链接使用带密码 URL。
- 再次分享或发布同一资源覆盖设置并保持基础 URL。

共享类型与工具测试：

- DTO 类型包含访问保护字段。
- 带密码链接构造函数正确追加 `password` 查询参数。
- URL 脱敏函数会隐藏 `?password=`。
- 现有分享和发布 URL 构造保持兼容。

## 验收标准

- 文件、文件夹、网页、网站公开访问都可以设置密码和有效期。
- 默认创建出的链接需要密码，3 天有效。
- 创建者能随时查看密码并复制带密码链接。
- 访问者打开带密码链接会自动验证，并跳转到干净 URL。
- 未验证访问者无法通过下载接口、文件夹接口、网页 URL 或网站静态资源 URL 绕过密码。
- 旧有效分享和发布上线后自动变为需要密码并 3 天有效。
- 所有新增 UI 符合现有 shadcn/Radix 与 Tailwind token 规则，不增加冗余说明文案。
