# 云端数据表首批高收益读取 API 设计

状态：用户于2026-11-02批准，按本方案实施。

## 目标与范围

用户要求从高级 API 中挑选相对安全且收益较大的首批能力，并同步更新文档。建议本批提供字段投影、同级 AND/OR 筛选、条件计数、存在性判断，减少数据传输和客户端分页处理。

沿用当前 REST、JSONB 存储、查询编译器、身份和授权模型，不新增依赖、数据库迁移、桌面入口、MCP、独立 Skill 或 Console 控件。当前仓库与当前分支开发，不创建分支或 worktree；实现验证完成后仅提交本次任务，不 push 或部署。

## 方案比较

- 推荐方案：增强读取 API。复用已有筛选与权限，在不改变写入行为的情况下减少下载量和请求次数。
- 扩展写入方案：增加 Upsert、唯一键和条件批量修改。收益明确，但涉及唯一性、恢复冲突、目标稳定性和新授权判断，不适合本批的低风险目标。
- 大规模处理方案：异步导入导出及任务续跑。需要任务持久化、取消和部分完成协议，留待后续需求明确后独立设计。

用户已批准推荐方案；其余两种方案不在本次范围。

## 接口契约

### 扩展 POST /api/open/v1/tables/{id}/records/query

- 新增可选 `fields: string[]`，只允许当前活动业务字段 key，不接受系统字段 key；最多100个，不允许重复或未知/归档字段。省略返回全部活动业务字段，空数组返回 `values: {}`。
- 字段选择在数据库 SELECT 内执行，响应保留现有 id、version、创建者和时间等系统元数据。筛选与排序可以使用未返回的字段。投影只是返回内容选择，不构成字段级权限。
- 新增 `filterMode: "all" | "any"`，省略为 `all`，兼容旧请求；只组合当前同级 filters，不新增递归分组或 NOT。
- 最多20个条件，操作符和字段类型范围沿用现有规则；两种模式空条件均表示不增加业务筛选，仍受表、未删除和本人范围约束。
- SQL 必须为 `表范围 AND 未删除 AND 权限范围 AND (业务条件组合) AND 游标边界`，OR 不得包含权限或分页边界。
- 旧请求的默认语义和响应不变。默认 all、未指定 fields 的游标绑定保持原有形式；显式投影和 any 模式加入绑定，续页不得切换模式或投影。schema 变化继续使旧游标失效。
- 保持现有分页、响应预算和非快照语义。

示例：

```json
{
  "filters": [
    { "field": "status", "op": "eq", "value": "pending" },
    { "field": "priority", "op": "eq", "value": "urgent" }
  ],
  "filterMode": "any",
  "fields": ["title", "status"],
  "limit": 50
}
```

### 新增 POST /api/open/v1/tables/{id}/records/count

- 请求仅接受 `filters` 和 `filterMode`，默认值与记录查询一致；不接受 sort、cursor、limit、fields。
- 返回 `{ "count": 123 }`，是当前可读且未删除记录的精确匹配数，不是全表数量；计数与另一次列表请求不承诺同一快照。
- 使用数据库 COUNT，不加载记录正文。结果超出 JavaScript 安全整数范围时明确报错，不静默舍入。
- 受已有 SQL 超时和公平调度约束；无法在预算内完成时返回现有503，不返回近似值，不承诺常数时间。

### 新增 POST /api/open/v1/tables/{id}/records/exists

- 请求与 count 相同，返回 `{ "exists": true }` 或 `{ "exists": false }`。
- 使用 EXISTS 或 LIMIT 1 短路，不先计算 COUNT 或读取记录正文。
- 只能判断当前可见记录是否存在，不能作为不存在重复数据的并发保证。

新增两个 POST 接口沿用当前云表成功状态201，不改变其他路由状态约定；读取接口不声明写入幂等键。

## 授权和资源边界

所有能力沿用 `tables.records.read`、密钥表资源范围、实时表ACL和 own 记录范围；匿名仅在表已开放 read 时可用。写入或管理权限不隐含读取权限。

复用认证、有界公平队列、专用连接池、SQL/锁超时、请求取消和固定元数据日志。查询值及记录正文不进入日志。不新增索引或放宽SQL超时，也不承诺任意OR条件都能命中索引。

不开放 JSON路径、多选筛选、SQL、关联、公式、实时订阅、聚合、唯一键或条件写入，不改变现有长期边界。
