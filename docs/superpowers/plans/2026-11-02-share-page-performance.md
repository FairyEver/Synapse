# 优化现有分享页加载速度

用户确认的执行范围：保留现有 URL、页面与功能，不新增 HTML/独立分享入口，不引入 SSR、依赖或数据库迁移，不切换分支/worktree，不推送或部署。

## 实施项目

1. 分离 Markdown prepare/render：源码、解析树、投影、目录进入有界缓存，资源 URL 与最终 DTO 按请求生成；复用有效当前投影，重建才持久化；实时内容不得写入检查点历史。每次复验权限、版本与当前投影摘要；缓存 16 项/32 MiB，包含树容量，并合并同修订计算。固定标签诊断源读取、投影、解析、渲染、权限与缓存，不含内容和凭据。
2. Nginx gzip 级别 5、阈值 1024 字节、Vary；仅成功的哈希构建资源一年 immutable，HTML 再验证、缺失资源 404；Site、密码内容与下载保留原规则。
3. 富文本/代码 renderer、留言富文本、版本弹窗动态加载，排查 fallback 的静态引用；保留外层草稿和加载时的图片文件，模块失败可重试。
4. 浏览器 Markdown 首图 eager、后续 lazy、异步解码；保留作者尺寸，不猜宽高，不加缩略图服务。PDF 显式 eager。不改写用户 HTML/Site。
5. 现有分享入口并行 session/正文初始化，身份未定前不允许编辑/讨论/协作写入；控制台和所有者启动顺序不变，兼容 reader/render/Site 不进入此启动分支；保留导航、深链、密码清理和访问记录。

## 验证与交付

- 回归权限、版本/同版本投影重建、并发/失败重试、实时修订，及编辑/评论/留言/目录/版本/PDF。
- 检查生产构建静态依赖闭包，两端类型检查与单元测试、相关 Chromium 几何回归；真实 Nginx 检查压缩字节、缓存、404、API/render/Site 与二进制下载。
- 已有基线位于本机诊断产物，未部署时不能声称线上变快或达到 30% 目标；生产环境在授权部署后，用同设备/内容/网络至少各 5 轮缓存和冷刷新测量。
- 仅提交本次代码、测试、规则及待发布说明，保护工作区其他任务改动。

## 本地实施验收（2026-11-02）

- Dashboard 全量 1331 项通过；阅读器 Chromium 43 项通过；两端类型检查、Dashboard 生产构建与 UI 边界检查通过。
- Server 全量 2430 项通过、156 跳过；唯一失败为既有 dev-scripts.spec.ts 的 healthz/readyz 启动断言，未改动该测试。
- 真实 Nginx 容器验证压缩/字节一致、缓存/404、API/render/Site 私有响应头及二进制下载通过。
- 最终构建静态闭包约 1.40 MB，阅读器主块约 124 KB，编辑器等分块不在静态依赖中；不等同于线上 LCP 收益。
- 独立审查发现的首次 session 讨论深链丢失与协作预览图片策略覆盖问题均补回归修复。
- 未推送、部署、改动外层 Caddy 或执行数据库迁移；线上五轮性能及 30% 目标待授权部署后复测。
