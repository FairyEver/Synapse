# 能力牌筹码经济实施

设计与数据：[能力牌筹码经济 v3](../specs/2026-11-03-poker-card-economy-design.md)。

1. 在现有新版牌桌引擎夹具写 v3 的失败测试：八牌报价、有效底池截断、免费与付费卡、跨牌连用、候选只扣一次、旧版报价不变。
2. 新增 `engine/cards/pricing-v3.ts` 的版本化整数策略，在统一 `quoteCardPlay` 按本手版本选用。复用 v2 目录，建立带策略摘要的 v3 快照。收费继续走 `chips.pay` 和主池。
3. 扩展共享规则协商，新房默认 v3。服务端存档、主池资金守恒、公开日志、Web 手牌与动效均识别 v2/v3，旧版本保留原价和原权限。
4. 更新客户端协议/默认房间测试，运行共享、服务端游戏与 Dashboard 扑克测试和类型检查。记录复现实验、兼容和回滚点；提交本地 Git。
