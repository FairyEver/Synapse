# Agent 图片附件路径化实施计划

Status: complete 2026-08-25.

## 目标

删除图片 Base64、派发计划、隐藏批次会话和摘要回灌。所有 Provider 只通过同一主 Agent 会话接收运行时路径清单，并由模型自行调用 Read。

## 九个阶段

- [x] 1. 重写设计和规划契约，确定“原图路径 + Read”为唯一图片策略。
- [x] 2. 保留选择、粘贴、拖拽、50 图、缩略图、灯箱、暂存、清理和历史恢复能力。
- [x] 3. Renderer 只发送用户原文和有序 `attachmentId`，不生成图片标签或路径正文。
- [x] 4. 主进程解析路径型运行时附件，一次性校验所有权，不读取原图字节。
- [x] 5. 精确授权受控草稿根目录；文件夹单独授权真实路径，单文件和图片不授权原始父目录。
- [x] 6. 主 query 接收运行时专用的有序附件清单及不可信附件说明，历史不保存该清单。
- [x] 7. 删除 DispatchPlan、Base64、阈值、批次 loader、隔离 query、摘要注入和批次状态。
- [x] 8. 历史只保存正文和附件元数据，并投影时间线、日志与导出中的受控 Read 路径。
- [x] 9. 完成全部回归、类型、硬约束和打包边界验证，记录最终结果。

## 锁定边界

- 使用原图，不把 1568 预览图交给模型。
- 不按 Provider、模型名、端点或能力画像分支。
- 不追踪 Read 完整性，不补读、不重试、不阻止模型结束。
- Persona 禁用 Read 时保持禁用。
- 旧历史不迁移。
- 不恢复 raw image IPC、图片字节运行时或附件 MCP。
