# 待办快建与优先级实施计划

> 按已确认的 [桌面原型](../../prototypes/2026-11-03-todo-priority.html) 在当前分支实施。

1. 扩展现有待办接口。新增可空的高、中、低优先级，省略字段保留原值，显式传空可清除。数据库先筛选和排序再分页。默认排序仍按截止时间。
2. 保持升级兼容。旧版桌面使用严格响应解码，服务端只向声明支持优先级的客户端返回新字段。旧记录视为未设置。未设置的创建保留旧请求哈希。
3. 复用现有待办编辑校验和版本更新链路。桌面两行快建默认只需标题，按需展开截止、备注及额外提醒参数。失败保留草稿和请求标识，账号切换清空。筛选采用单选按钮，排序保留下拉框。列表和详情用红、紫、蓝底白字呈现等级，菜单和标签的等级文字前省去图标。
4. 验证数据库分页和权限、兼容响应、快建与优先级变更、状态切换期间的迟到响应和版本冲突。同步能力指南和待发布说明。
