# 云端数据表实施计划

Spec: ../specs/2026-11-01-cloud-tables-design.md

执行方式：当前仓库/当前main内联实施，不创建分支/worktree。每项先写测试并观察失败，再实现、验证。工作记录位于 .superpowers/cloud-tables/progress.md。

1. 模型、权威请求schema、字段校验、ACL、密钥资源范围；单元测试及迁移验证。
2. 专用数据库服务、数据库侧查询/游标、版本和schema锁、幂等原子批次、回收站/清理；真实PG事务验证。
3. 有界公平调度、准入/认证预算、专用连接池、超时和无凭据CORS；公平/压力/HTTP验证。
4. Console字段/记录/权限/回收站/日志/导出与密钥资源管理；组件和浏览器测试。
5. OpenAPI、可整页复制为Markdown的API文档和规则/发布说明；类型/构建/契约验证。用户后续明确取消独立Skill，删除相应文件、下载入口及专用分发配置。
6. 整体测试和独立代码审阅，修复有证据的问题，检查任务diff后仅本任务本地提交。

审阅重点：写响应不泄漏不可读数据；撤权与已排队任务；表字段变更与行写竞争；匿名和多key公平预算；删除后分页/恢复与幂等重放。
