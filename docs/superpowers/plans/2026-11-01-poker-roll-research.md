# Roll 牌完整定价与对局模拟研究实施计划

> 按当前 main 原地执行；本计划不授权产品接入、业务库迁移、部署或 push。

**目标**：交付可复跑的完整续局研究、具体候选收费公式、共享次数曲线、他人历史影响及独立验证结果。
**设计**：`docs/superpowers/specs/2026-11-01-poker-roll-rules-design.md`，并以用户本次完整执行计划为最新要求。
**架构**：研究目录自包含；通过只读 git show 固定已有纯引擎，不改生产文件。使用原引擎动作与结算、独立冻结补偿账本和原始资本断言；策略只有个人观测。训练、调参、最终检验按整手与种子分离。

## Review Focus

- 不允许策略通过完整 HandState 或耦合随机数读取他人底牌、真实牌堆或未来牌。
- 不用最高收益、最佳候选或选择样本噪声替代随机三选一的完整分布。
- 费用减少可下注筹码但不改变跟注／加注权；补偿冻结、整数守恒、原始资本不变。
- 他人 Roll 的资金变化和条件历史影响分别记录，后者不能伪装成已识别的普适因果效应。
- 样本量或净收益门槛不达标时明确失败，不把候选公式称为已平衡上线价。

## 数值合同

标准52／短牌32，2–10人，三阶段；深度10/25/50/100/250/500/1000/2500 BB；轮换位置、同类／混合对手、不同底池与筹码形状及全下边池。每个主要分组从2048个配对样本开始，上限32768；95%区间半宽目标max(报价10%,0.25BB)。不设使用率目标。收费由公开特征决定，个人次数系数共享；推荐点比较付款方剩余价值和对手确定补偿的归一化max-min，独立检验付款方自主选择Roll净增益下界>0。不达标保留失败和误差。
