## 复审补充修复

- 时区与实际附加条件通过Editor→Builder→Cron表单→预览完整传递，新增宿主集成回归。
- 默认本地时区与显式时区统一使用多offset日期搜索；春季有效时间、秋季重复小时、省略timezone均有回归。互相矛盾的Cron星期和附加星期返回null。
- 提交后在面板展开渲染完成后定位首错；再次收起并重新保存仍展开。没有具体无效控件时恢复原焦点，避免焦点掉到body。
- Agent模型档位错误映射模型按钮；权限、会话、超时均有实际错误节点和ARIA关联。
- 同一运行由running变failed/timeout会展开错误；运行终态清理停止失败提示；停止请求被接受后保留pending到终态。
