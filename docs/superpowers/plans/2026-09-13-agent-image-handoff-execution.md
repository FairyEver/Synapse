# 图片容量中断与持久交接实施记录

日期：2026-09-13。范围：用户批准的图片预算、SDK 停止屏障、原图续接与真实百炼验收。**本轮图片闭环验收通过。** 原失败对话未被改写；历史存储全面迁移、严格全文阅读和整体长期性能不在本轮验收内。

## 证据与实现

原失败会话保留原样。MCP 读取确认仍为 idle + failed/recoverable=true；首张原件只读取 PNG 文件头和 stat：970 × 1866、339,821 字节。未将该图片或原始日志发送给测试 Provider。单纯读取元数据不是视觉验收。其 Base64 成本是 453,096 字节，原预算错误地将这个数字与 200K token 余额比较。SDK 单独 close 导致额外请求只由隔离协议夹具证实，不推断历史对话必然发生相同泄漏。

- `AgentContextBudget` 分离序列化字节与显式/未知 token 成本，保留来源、批次与覆盖水位。图片只受 body 可用量约束；文本增量是标注来源的保守上界。重复快照和 compact 不清除水位之后的增量，native token 缩减不按比例清掉图片字节。图片不占用文本单批预览额度。
- 已取得的原生 Read 图片保存路径、大小、SHA-256 和原 toolUseId。`PostToolBatch` 等待并行结果完成后暂停下一请求，保存完整脱敏检查点；不重跑已执行操作。
- 停止路径为 interrupt 确认 → close → 原生迭代器实际结束。超时或失败不创建新代，不自动强杀；同进程再点继续仍被停止屏障拦截。旧代迟到事件丢弃，不能提交新代状态。
- `ConversationEntryV1.contextHandoff` 是现有 DataRepository 会话串行写入中的可选字段，含 generation、phase、检查点 artifact 引用和图片尝试状态。代次 CAS 拒绝迟到写入。未新增数据库或并行恢复系统。
- 新 query 保留 conversation/turn/taskListId、用户要求、工作目录、原权限配置与累计用量。主 query 通过原生 Read 呈现同一原件；校验原件和所有检查点文件后才恢复。原件引用不授予新权限。
- 同一版本原图最多一次容量交接尝试。接收确认来自原生 Read 后的主模型响应；缺少确认的 result 转为未完成错误，模型自称完成不能越过此门禁。接收确认不等于理解正确。
- 重启不自动执行。用户明确继续时可恢复尚未尝试的已保存图片；已提交但接收不明的尝试不自动重放。不可验证的原件、缺失检查点、权限撤销和保存/停止/创建失败保留恢复状态。
- 精确输入范围容量拒绝、已有 6 MiB body 错误和 native refill 故障进入原交接链路。网络、认证与普通服务端错误不自动重放。

200K 整理、5 MiB 安全预算、6 MiB 硬上限以及文本 8 KiB/24 KiB 预算保持不变。内部类型与系统 Skill 指南同步；没有新增公开 MCP 工具、schema 字段或权限范围，能力注册表数量不变。UI、历史和 MCP 继续使用已有失败/整理/恢复投影。

## 可重复验收方法

基础源码提交为 `f4d703602`；修复与测试源码提交为 `37d94ef0da4cad2fe81df858b623b712dc4b681b`。其后仅补充本文与 JSON 的提交引用，不改变运行时代码。真实运行的生产源码 SHA-256 保存在相邻测试数据中，避免把测试开始后修改过的代码当作已验收。SDK 从已安装 package.json 读取版本，模型固定为用户现有百炼配置的 `qwen3.8-max`。

测试入口：`desktop/electron/services/agent-runtime/__tests__/bailian-image-acceptance.test.ts`。默认跳过真实网络调用；明确设置 `SYNAPSE_BAILIAN_IMAGE_ACCEPTANCE=1`、独立 `SYNAPSE_IMAGE_ACCEPTANCE_ROOT` 和内存注入的 `SYNAPSE_IMAGE_ACCEPTANCE_TOKEN` 才执行。凭据不写入仓库、命令参数或测试证据。

实际链路为 ConversationRouter → SessionManager → ClaudeSDKSession → 已安装原生 SDK → 百炼 Anthropic 兼容端点。测试仅替换 Provider 选择入口及 SDK 的隔离工作目录、工具列表和配置来源；预算、检查点、停止与续接使用生产实现。独立 JsonNamespace 后端通过 DataRepository 接口持久化，不读取原对话，不运行开发应用。此验收不代表正式 Electron UI 或整个部署配置的端到端验收。

每轮 48 张合成 PNG，四位可核对数字位于上方，下方确定性噪声提供约 340 KB 传输负载。答案只在测试进程内保存，未提供给模型；模型逐张 native Read，向独立 answers.txt 追加答案。独立 oracle 检查 48 行逐项一致、无重复、文件摘要不变。另一个只执行一次的 Bash 写入计数器，完成后必须仍为 1。

- 默认轮：720 × 480，验证普通读取和自然累计到 5 MiB 后的多次续接。
- 受控压力轮：仅测试夹具在第一代的首个 Read 结果处加入 5 MiB 已保留非文本成本，强制复现首张图片无空间；产品阈值不变。
- 尺寸覆盖轮：同样连续 48 张，前四张为原失败图片的 970 × 1866，后 44 张为 720 × 480；原件约 340 KB。原生 SDK 可执行自身图片处理，宿主不缩图、不替换原件，不把 SDK 的重编码误认为原件被改动。

测试工具仅 Read/Bash，maxTurns=128、max output 环境配置 4096，SDK hooks 保持生产流程。使用隔离的 bypassPermissions 运行已明确授权的合成动作；另有独立协议测试撤销新代 Read 权限。不会将绕过权限的模型测试当成权限验证。

## 回归矩阵

| 场景 | 验证方式 |
|---|---|
| 453,096 字节不再被当作 453,096 token | 实际 AgentContextBudget；未知视觉 token、已知 token 超限与 body 超限分开断言 |
| 缓存输入、重复快照、compact、并行文本预留 | context-budget 与 context-usage；覆盖水位之后的增量保留 |
| 挂起 hook、无额外请求、关联原 toolUseId | 已安装 SDK + loopback，最后一个旧缺陷复现用例改为生产屏障防泄漏断言 |
| 图片先完成、Bash 后完成的并行批次 | 真实 Runtime + 原生 SDK；旧代无额外请求，新代原图字节进入请求，计数 1 |
| 未 Read 图片却宣布完成、Read 权限撤销 | Runtime 完成门禁必须报告失败，持久 pending 保留 |
| 保存失败、停止失败、创建失败、原件变化、检查点损坏、取消 | Router 故障注入；不产生可运行的新代或虚假成功 |
| interrupt 超时、close 返回而迭代器未终止、停止失败再点继续 | 有界停止与 Router 准入测试；不能判定安全交接 |
| 重启、显式继续、旧代状态写入 | 重建 DataRepository 后端读取；启动时不创建 query；校验后恢复；CAS 拒绝旧代 |
| UI/历史/MCP 失败与恢复读取 | 既有 timeline、phase、Agent control-service、导出专项与 Router 持久结果 |

Loopback 的固定 1000 token 响应只验证协议，不能用于视觉计量或百炼用量结论。真实百炼验证以匹配的 marker oracle、实际交接数量、后续任务完成和计数器为准；HTTP 200 或 Agent 自称完成都不构成通过。

脱敏数据：[百炼图片 Runtime 结果](../../reference/2026-09-13-bailian-image-runtime-results.json)。所有成功轮逐项匹配 48 个 marker，原件摘要保持不变，每轮计数器为 1；实际完成自动重呈现后继续处理到第 48 张。

普通样本 344,193–345,317 字节；同尺寸样本的完整尺寸、字节量、摘要和逐图 Read 次数见 JSON。F 的最终错误为 `body=467223，可用=0 字节；视觉 token 未知`，持久 `turnOutcome=failed/recoverable=true`。F 的 PASS 表示按预期失败且安全停止，绝不表示图片已完成。

A/B/C 是修复过程中的实测，不能替代最终源码证据。D 开始后仅补了一处终态处理：关闭后仍有 output-integrity 错误排队时允许 Router 取走错误，避免慢持久化时丢失具体失败。将这一处精确反向替换后，文件 SHA-256 与 D 的启动源码完全匹配；其它 D 生产文件与最终文件一致。该差异经 111 项 SDK session 专项、原生 Runtime 单件仍满回归及真实百炼 F 的最终源码指纹验证，未通过修改成功断言掩盖差异。
