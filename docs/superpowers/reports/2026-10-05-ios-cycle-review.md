## 范围与判定方法

本次覆盖 iPhone、iPadOS 的页面入口、按钮预期、实际导航与必要错误状态、原生组件、动态字体、深浅外观、无障碍语义，以及账号、电脑、连接和异步操作的生命周期。终端画布的显示内容、字体与渲染按用户要求排除；其外围导航、输入、附件、键盘、Files 和 Git 操作仍在范围内。

每次源码轮都重新通读所分配文件，不以只检查差异或修复点代替完整巡检。新独立问题和旧问题家族的新增遗漏路径均保留在发现当轮，修复不把当轮改记为零。源码零发现、正式测试通过、真实 UI 通过和最终发版是不同证据。

模拟器连接正式环境，正常使用既有功能；读取与可取消界面优先。涉及写操作的回归仅用受控自有测试对象，不向他人发送邮件或反馈，不修改用户真实工作区、主机权限或音频硬件配置。内部完整证据不随公开报告暴露账号、凭据、私有标识、进程号或业务链接。
