学习的是配置过程：把自动化读成一句因果关系，选择后原位展开，用同一套控件修改节点。原型采用 Synapse 的中性主题与紧凑组件尺度，不复制飞书的巨大弹窗和长按钮列表。

范围：一个触发器对应一个执行器。没有新增多步骤、条件分支、邮件筛选或 HTTP / Shell 执行器。Claude Code 独立执行器只在「方案」场景开放演示。所有账号、运行记录和响应均为样例，保存只作用于当前网页内存。Cron 仅演示五段格式检查，不执行表达式求值。
