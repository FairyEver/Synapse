# 逐步选择交互规范

适用：用户需要通过多个有依赖关系的选择完成配置；云盘同步是首个使用方。

## 标准组合

公共入口：`desktop/src/components/guided-flow/index.tsx`。

- `GuidedFlow` 组合现有 DialogFrameHeader/Body/Footer 和 Button，负责进度、步骤焦点、返回、取消和继续。
- `GuidedChoices` 组合 shadcn FieldSet/FieldLegend、RadioGroup、FieldLabel、FieldContent、FieldTitle、FieldDescription。
- 默认带说明的互斥决策使用 RadioGroup；点击即确认的决策使用 Button，支持 Tab、Enter 和空格激活；简短的工具栏显示切换才用 ToggleGroup。长说明不得塞入横排 ToggleGroup。
- 选项整行可点；标题是可访问名称，说明通过 aria-describedby 关联。保留 Radix 的方向键、空格键和焦点行为。
- 使用现有组件的选中、禁用和焦点状态，只增加布局类；不新增颜色、CSS、嵌套卡片或独立视觉主题。

## 选择与推进

1. 每步只完成一个主要决策；标题直接提问或命名当前任务。
2. 选项包含短标题、必要的结果说明、可选禁用原因。描述只解释选项差异、后果或限制。
3. 不替用户选择类型、场景、覆盖依据等重要决策。来自上下文的路径可以预填，但必须能检查与修改。
4. 默认点击选项只更新草稿，由「下一步」推进。同步向导的纯单选步骤使用 `onSelect` 按钮模式，点击或键盘激活即确认并进入下一步；选项左侧显示语义图标，不请求业务写入。
5. 页脚左侧放置 ghost 样式的「上一步」，取消和继续操作在右侧；没有上一步时右侧操作仍保持靠右。点击即确认的纯单选步骤隐藏「下一步」，输入、范围配置和最终确认仍保留继续按钮。最终按钮使用具体动作。按钮标准尺寸。
6. 动态分支只显示实际经过的步骤数；未选分支前按当前已知步骤显示。回退保留草稿；更改上游选择清除受影响的路径、依据、预览和确认。
7. 进入新步骤时聚焦步骤说明并播报进度；内容区滚动，标题和操作区保持可见。
8. 异步检查显示 busy，锁定输入和提交；错误保留在当前步骤，提供重试或返回修改。
9. 业务 hook 持有分支状态、检查、防重复提交和请求；公共组件不做 IPC 或业务判断。

## 预览与执行

- 配置阶段不写业务文件；预览阶段允许只读扫描和临时验证下载。
- 预览显示完整目标、后续行为及操作明细。覆盖、回收站操作须用户明确确认。
- 确认必须绑定当前配置与数据；过期结果不能继续执行。执行失败显示实际状态，不把保存记录当成功。
- 删除关系与删除数据是不同动作，必须按实际效果命名。
- 一个宿主中切换步骤，不叠加另一个配置弹窗。执行后可通过同步中心继续查看进度。

官方组合依据：[shadcn Field](https://ui.shadcn.com/docs/components/radix/field)、[Radio Group](https://ui.shadcn.com/docs/components/radix/radio-group)。项目内现有组件与主题是实现基线。
