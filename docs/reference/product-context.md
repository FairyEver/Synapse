# Product

## Register

product

## Users

Synapse serves developers and AI power users who manage reusable AI editor capabilities across local projects and content repositories. They are usually working inside a desktop workflow, switching between content management, editor installation, Agent sessions, workflow automation, diagnostics, and usage review.

## Product Purpose

Synapse is a cross-editor AI capability management tool. It helps users organize Rule, Skill, and Prompt resources, install them into editors such as Claude Code, Codex, Cursor, and Windsurf, run and inspect Agent workflows, manage local data and scheduled tasks, and keep the surrounding developer setup observable. Success means users can understand the current state quickly, act without hunting through editor-specific folders, and trust Synapse with local project and runtime operations.

## Brand Personality

Restrained, trustworthy, engineering-minded. Synapse should feel like a capable workshop for people already doing serious work: calm enough for repeated use, precise enough for debugging, and direct enough to stay out of the user's way.

## Anti-references

Synapse should not look like a marketing landing page inside the app. Avoid generic AI gradients, decorative glow, emoji headings, over-rounded showpiece cards, ornamental motion, and copy that explains implementation details instead of helping users act. Do not trade density, scannability, or standard product affordances for visual novelty.

## Design Principles

1. Preserve task flow over decoration.
2. Make state and ownership visible before asking users to act.
3. Prefer familiar controls for familiar jobs.
4. Keep words short, specific, and operational.
5. Treat local files, secrets, editor settings, and runtime actions as sensitive surfaces.

## Accessibility & Inclusion

Target WCAG AA for product surfaces. Preserve keyboard access, visible focus states, sufficient contrast, reduced-motion behavior, and readable density in both light and dark themes. Status, error, and confirmation states should not rely on color alone.
