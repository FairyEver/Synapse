# Pending Release Notes

## 新增功能

- 云盘 `.md` 文件的预览视图支持选中文字评论。能查看文档的用户都能看到评论，登录用户可以参与讨论；评论不会写入原 Markdown 文件。
- 云盘分享支持可编辑权限。创建分享时可以选择获取链接的人可阅读、获取链接的登录用户可编辑，或指定邮箱用户可编辑；文字类文件可在代码编辑器里保存修改，并生成新的文件版本。遇到他人先保存的新内容时，会提示用户下载自己的本地编辑版本或重新加载。
- 云盘新增“公开素材”和“回收站”固定入口。图片可以生成稳定公开链接；删除后的云盘文件和公开素材会先进入回收站，恢复后原链接继续可用。
- Synapse Drive MCP 新增公开素材直链和回收站工具。Agent 可以按“上传到图床”“生成直链”等请求上传图片公开素材、替换或恢复公开链接，并管理用户可见的云盘回收站。
- Model Price MCP 新增预设列表、导入预设和清空规则工具。Agent 可以按用户要求导入内置价格预设或重置价格规则，不再只能逐条维护。
- 管理后台用户列表新增用户名和管理员备注。管理员可以为用户维护仅后台可见的备注，便于区分账号来源、用途或服务状态。
- 管理后台云盘新增公开素材和存储视图。管理员可以查看全部公开素材、访问日志、历史版本，并下载或恢复需要处理的云盘文件。

## 功能优化

- Git 模块新增“安装 Git”和“访问”页签。未检测到 Git 时会直接引导到安装页；缺少 Git 身份时会跳到环境页；认证、凭据助手或 SSH 失败时会跳到访问页并保留重试操作，普通 HTTPS 仓库需要账号密码时会直接打开登录弹窗。
- Git 访问页清除 HTTPS 凭据前会先确认，避免误删当前主机的登录凭据。
- Git 访问页在 Linux 上不再主动提供凭据助手配置入口，避免第一期误引导到未支持的图形化配置。
- Git 安装页在 Linux 或检测失败时可以直接复制诊断信息，方便排查 Git 环境问题。
- Git 问题诊断日志更完整。导出 Syslog 后，开发者可以更快定位仓库状态异常、同步失败、认证权限和网络问题，同时日志会避免记录提交正文、diff、凭证和敏感远端地址。
- Git 仓库列表刷新会限制后台状态探测并发，仓库较多或慢盘环境下不再一次性拉起过多 Git 子进程。
- Git 仓库列表的添加、打开标记和删除会串行写入注册表，多窗口或并发操作成功后不再互相覆盖仓库记录。
- 修改仓库路径后，旧路径 watcher 的延迟回调不再关闭新路径 watcher，也不会误报新仓库目录已不存在。
- 知识库资料管理窗口会按需加载文件夹树，不再在打开大资料库时自动扫描所有根级文件夹。
- 知识库资料管理窗口在子目录添加 URL 时会把资料写入当前目录，成功刷新后可以直接看到新增条目。
- Git 工作台会在进入历史页后再加载提交列表，并且只在选择提交时读取完整 patch，打开改动页更轻量。
- Database MCP 的操作日志读取会限制单次返回数量，避免长期使用后一次请求拉取过多历史记录拖慢本地进程。
- Git 仓库列表在 Windows 上会识别大小写不同但指向同一目录的路径，避免同一个仓库被重复登记。
- Windows 上 Git SSH 检测会使用唯一有效的 `Path`，不再被旧的 `PATH` / `path` 环境变量干扰而误报 SSH 不可用。
- Workflow MCP 内置 Skill 会正确说明脚本节点的默认 shell：Windows 留空时使用 `cmd`，macOS/Linux 使用 `posix`。
- Usage Analysis 的原文搜索加载更多会从下一批会话继续扫描，并对输入做短暂去抖，减少重复读取历史 JSONL 的开销。
- Usage Analysis 的 Claude Code 原文搜索和会话列表会批量汇总候选会话用量，历史会话较多时减少大量重复数据库查询。
- Usage Analysis 加载大型 Claude Code transcript 时会按真实字节偏移续读，Windows/CRLF 日志继续加载不再重复或跳过事件。
- Workflow MCP 指南补齐 Claude Code 节点说明，Agent 通过指南创建本机 Claude Code 工作流时不再误以为只有 Codex 节点可用。
- Git 环境页改为更轻量的诊断布局。长路径、PATH 和远端分支会在页面内换行展示，不再把右侧内容挤出屏幕。
- 云盘顶部标题和容量用量之间的留白更舒展，页面顶部信息看起来更均衡。
- 云盘文件列表的图标更容易分辨。普通文件、普通文件夹、公开素材和回收站会使用不同图标，固定入口不再和普通文件夹混在一起。
- 云盘文件预览的操作区更统一。Markdown、代码和可编辑文档会把保存、重载、评论、目录和下载等操作放到统一顶栏；HTML 直接预览仍使用浮动按钮，避免遮挡网页内容。
- 云盘文件预览顶栏会用细分隔线区分文档自身操作和系统文件操作，保存、下载、历史版本等按钮分组更清楚。
- 云盘 Markdown 评论栏的删除操作更自然。首条评论可删除整条讨论时，菜单只保留“删除评论”，确认后会一并删除回复。
- 云盘 Markdown 评论栏和评论输入框不再出现内部滚动条，长评论会自然展开。
- 云盘 Markdown 文件默认打开阅读预览，仍可从“打开方式”切换到 MDXeditor 或代码视图。
- 云盘 Markdown 预览的目录和评论栏会贴近窗口左右两侧，正文继续保持合适的最大阅读宽度，宽窗口下不再把三栏整体居中。

## 问题修复

- 设置页关于面板里的版本号、更新状态和下载进度文字现在可以直接选中复制。
- 工作流调用节点的数字参数如果模板渲染为空白，会按缺少必填值处理，不再静默变成 `0` 传给子工作流。
- 工作流运行历史会脱敏 HTTP 请求节点的认证信息和脚本节点的环境变量；历史定义已脱敏时会改用当前工作流定义重新运行，找不到原始配置时会阻止重跑。
- Workflow MCP 的节点发现、节点描述和定义检查工具会经过 `workflow.read` 权限检查并写入审计记录，不再绕过工作流读取边界。
- 网盘在线编辑保存成功后，如果后续刷新失败，会保留已保存的新版本状态，不再把真实成功的保存反向提示为失败。
- Variable MCP 写入在授权后遇到重复名、缺少创建值或变量不存在等校验失败时，会记录脱敏的 `secret.write` 失败审计。
- 配置备份导入写入私人变量时会执行 `secret.write` 权限检查并记录脱敏审计，拒绝策略可以阻止备份改写变量。
- 下载 Rule、Prompt 或 Skill 到已有本地文件时，会先写入临时文件再替换目标，失败时不再破坏原文件。
- 从编辑器扫描结果复制 Rule 时，会提前拒绝 `CON`、`AUX`、`COM1` 等 Windows 保留文件名，不再等到写入目标编辑器时才失败。
- 生成 SSH 密钥时如果已有私钥但公钥丢失，会自动从私钥恢复 `.pub` 文件，不再静默成功却仍无可复制公钥。
- 默认关闭的自动化 Webhook 入口不再在桌面应用启动时写入加密配置，避免隔离环境或系统密钥存储异常时拖慢应用启动。
- 云盘分享页中的 Markdown 评论会在刷新后保留当前登录用户的编辑和删除权限，不再把自己的评论显示成只读。
- 云盘 Markdown 评论入口只会出现在 `.md` 文件上；文档改动导致评论位置失效时，右侧评论栏会明确提示“位置已变化”。
- 控制台网盘里的 Markdown 文件预览现在也能选中文字添加评论，不再只在独立预览窗口里可用。
- 云盘 Markdown 添加评论改为选区旁轻量入口和弹窗填写，右侧评论会尽量对齐正文中的批注位置。
- 云盘 Markdown 选区旁的“添加评论”按钮去掉了双层气泡外观，看起来更像一致的内部工具操作。
- 云盘 Markdown 添加评论时会保留选中内容的临时高亮，评论创建后会用不影响排版的覆盖层标出已评论文字，不再让正文、代码块或表格发生抖动。
- 云盘 Markdown 评论回复失败时会在输入框下方显示原因，点击发送、取消等操作也不再误触发评论卡片聚焦。
- 云盘 Markdown 右侧评论卡片样式更克制，回复输入、操作按钮和错误提示的层级更清晰。
- 云盘 Markdown 评论的操作权限更清楚。评论作者才能编辑或删除自己的评论，文件所有者删除整条讨论时会从更多菜单进入并二次确认。
- 云盘 Markdown 右侧评论栏标题不再被评论卡片遮住，滚动和锚点对齐时标题层级保持稳定。
- 云盘 Markdown 预览不再由三栏外层容器统一留白，滚动条位置和评论分隔线会贴合预览区域边缘。
- 点击云盘 Markdown 右侧评论卡片时，会按正文中的实际批注位置滚动，不再跳到不相关的段落。
- 云盘 Markdown 评论编辑和回复会发送正确的请求内容，不再因为把路径参数带进请求体而提示请求无效。
- 未登录访问云盘分享页时仍可阅读 Markdown 评论，但不再显示回复入口，和“登录后才能参与评论”的规则保持一致。
- 只读云盘分享不再允许登录访客创建、回复、编辑或删除 Markdown 评论，分享权限边界会和正文编辑保持一致。
- 云盘公开分享中的 Markdown 评论不再暴露评论者账号邮箱；没有公开昵称时会显示为通用评论者。
- 云盘空目录现在会提示“暂无文件”，不再误写成同级文件为空。
- Drive MCP 取消分享现在可使用记录 id 或公开 shareId，按分享结果里的 `shr_...` 也能正确关闭链接。
- Drive MCP 的递归文件树在分页越界时仍会返回真实总数和文件夹/文件统计，不再把空页误报成整棵树为空。
- 云盘公开素材和回收站现在可以按名称或素材 ID 搜索，刷新和分页会继续使用当前搜索条件。
- Drive MCP 的公开素材列表和回收站列表支持 `search` 参数，Agent 可以直接按名称、路径或素材 ID 查找，不必分页扫全量列表。
- 管理后台公开素材搜索现在忽略大小写，按文件名、素材 ID 或条目 ID 查找时不再因为大小写不同漏结果。
- 管理后台下载系统日志 ZIP 时会先脱敏日志内容，避免 token、Cookie、Authorization 等敏感信息随排障包导出。
- Drive MCP 上传或替换公开素材时会按本地文件路径判断图片类型，自定义展示名不再让有效图片被误拒绝。
- Drive MCP 上传本地文件夹时会拒绝符号链接目录，避免权限确认和审计记录显示的是链接路径、实际却读取了链接目标内容。
- Drive MCP 上传本地文件或公开素材时会拒绝符号链接文件，避免权限确认和审计记录显示的是链接路径、实际却读取了链接目标内容。
- 网盘历史版本恢复如果在数据库提交前失败，会清理已经复制出的新版本对象，避免看不见也不计入配额的残留文件。
- 知识库 `/wiki-lint` 和无主题 `/autoresearch` 会先按文件大小跳过超大 Markdown 页面，不再为判断超限而把整篇内容读入内存。
- 知识库 `/wiki-lint` 会使用 Synapse 内置确定性预检结果，不再提示 Agent 重新运行旧的 DragonScale 脚本。
- 知识库 DragonScale 语义分块会在预检、报告和日志中隐藏 Ollama URL 里的账号信息和敏感查询参数。
- Drive MCP 下载文件、历史版本或文件夹 ZIP 时会先写入临时文件，下载成功后再替换目标路径，失败时不再破坏已有本地文件。
- 云盘上传在完成响应短暂丢失时会重试确认完成状态，不再把已经成功的文件误报为失败。
- 工作流 Prompt、Switch 和 Script 节点会在保存或运行前检查已删除的项目引用，不再等到执行期才失败。
- 拖拽多个本地文件夹上传到云盘时，会按真实文件数累计上限，不再先完整扫描超量目录后才失败。
- 网盘浏览“加载更多”会忽略同一分页的重复触发，不再把同一批文件夹子项追加两次。
- 网盘会按常见图片扩展名识别缺少 MIME 的图片文件，Agent 通过 Drive MCP 上传 `.png`、`.jpg`、`.webp` 等图片后也能直接预览。
- Agent 回复里的裸域名路径不再被误识别成本地文件引用，`github.com/org/repo` 这类文本不会被当成工作区路径打开。
- Agent `/show` 预览目录时会按展示上限停止读取目录项，不再为了显示前几十条而全量读取和排序大目录。
- 知识库会话里的 `/wiki-ingest`、`/save` 等原生命令现在会出现在 `/commands` 和 Agent 命令发现结果中，实际可执行能力和可发现列表保持一致。
- 知识库 `/wiki-ingest` 大批量摄入只按文件数量分批，不再因为资料路径列表较长而提前漏掉本批次内的文件。
- 反复打开和关闭工作流独立窗口后，跨窗口广播不再扫描已经关闭的历史窗口记录，长时间使用时主进程更稳定。
- 回收站中的公开素材不再提供复制直链操作，避免用户复制恢复前必然 404 的链接。
- 知识库资料导出会阻止把目标目录选到当前 `.raw` 资料目录内部，避免导出时递归复制自身。
- 知识库资料导出会正确识别 `.raw` 内以 `..` 开头的子目录，避免选择这类目录时绕过内部目标拦截。
- 知识库地址分配会自动清理已退出进程留下的锁目录，避免崩溃后后续 `/wiki-ingest` 一直跳过地址和 manifest 收尾。
- 后台云盘删除审计写入失败时，服务端日志会脱敏错误摘要，避免 token、Cookie 或本地路径进入日志。
- Electron 审计记录会脱敏 Cookie header、cookie 赋值和 cookie 字段，避免会话值进入审计缓存或持久化日志。
- 文件夹上传在全部文件都失败时，会清理本次新建的根目录，避免刷新后留下空文件夹。
- 文件夹上传会拒绝同一批次中归一化后重复的相对路径，避免上传完成后在同一目录生成多个同名文件。
- 网盘公开链接列表不再显示已过期分享，避免复制或打开必然失效的链接。
- 云盘文件列表不再把已过期分享标记为“已分享”，避免点击后只能看到分享失效提示。
- 网盘整理应用后会在审计记录中保留脱敏的移动摘要，方便追踪哪些条目从哪个父级移动到了哪里。
- Git 克隆和添加本地仓库失败时，弹窗会直接显示失败原因，不再让用户停在表单里却不知道哪里出错。
- Git 克隆遇到登录或 SSH 访问失败时，会先在克隆弹窗里保留仓库地址和保存位置，并提供处理访问入口，不再立刻关闭弹窗让用户丢失输入。
- Git 状态页在窄窗口或滚动到提交区域时，不再因为长路径、diff 内容或按钮组把右侧撑出屏幕。
- 设置页和 Agent 默认项目匹配会识别包含 `.` / `..` 的等价路径，不再把同一个目录保存成重复仓库或默认到本地对话。
- 云盘分享页切换到代码编辑时，文件操作浮动按钮不再遮挡保存按钮。遇到文件已有新内容时，用户可以正常触达“下载本地版本”和“重新加载”操作。
- 云盘 Markdown 预览打开目录后，左侧目录不再比正文低一截，顶部对齐更自然。
- 云盘列表中的上传中、上传失败和删除中条目不再提供必然失败的预览或进入文件夹操作，状态按钮会和后端可用性保持一致。
- 网盘浏览加载更多失败后切换目录，会清空上一目录的分页错误提示，不再把旧错误显示到新目录。
- 云盘历史版本弹窗加载更多失败时会保留已有版本并显示失败原因，不再像按钮无响应一样静默失败。
- 管理后台用户、团队和邀请列表隐藏列后，可以在当前页面直接恢复列显示，不再需要刷新页面。
- 管理后台云盘列表中的删除中条目不再显示必然失败的删除按钮，避免管理员触发无效操作。
- 管理后台不再允许恢复已取消上传的隐藏云盘文件，避免用户列表出现无法继续上传、预览或分享的坏条目。
- 管理后台邀请列表改为展示服务端计算的邀请状态，不再受管理员本机时间偏差影响。
- 管理后台下载备份、审计 CSV 和日志 ZIP 前的预检不再触发真实导出，避免一次点击生成两次文件或写入重复审计记录。
- Code X 节点配置面板的帮助文案更克制，只保留必要配置提示，不再展示实现说明和过长风险解释。
- Code X 关闭保存调试文件后，运行历史不再展示已删除的临时 last-message 路径。

- 管理后台设备列表会把分页窗口下推到数据库，并只额外合并当前在线设备，不再为一页数据读取全部历史设备。
- Skill 目录导入会限制附件目录数量和深度，避免空目录树或依赖目录结构让创建、更新、发布长时间卡在递归扫描上。
- 本地网盘上传 URL 的凭据会随本地存储一起持久化，服务重启后仍可继续完成已准备的上传，不再让 pending 会话只能等过期清理。
- Drive Browser 切换目录或分享目标后会丢弃旧的加载更多成功响应，不再把上一页目录子项混入新页面。
- 公开分享密码页和状态页改为使用浏览器系统颜色 token，避免独立 HTML 页面复制一套固定主题色。
- Automation MCP 查看运行态时会只读取正在运行或已调度的自动化，不再为了状态检查投影全部自动化列表。
- Drive MCP 下载文件、历史版本或文件夹 ZIP 时会拒绝相对输出路径，不再把文件写到进程启动目录。
- 知识库 `/wiki` 模板不再要求 Agent 在操作结束后追加上游社区推广 footer。
- 仓库初始化遇到桌面、下载、源码目录等危险路径时会立即阻断，不再先扫描并统计目录里的全部顶层文件。
- 配置 Git 凭据助手失败时会尽量恢复原有 `credential.helper`，不再因为新配置写入失败而丢掉旧的凭据保存方式。
- Model Price MCP 内置 skill 会明确使用 `model_price_rule_enable` 启用已有规则，Agent 不再误把启用当成价格更新。
- 打开带密码的网盘分享链接时，即使初始密码已失效并回到密码输入页，也会从地址栏清理 `password` 参数。
- 知识库 `/wiki-ingest` 遇到结构异常的 Agent report 时会跳过并保留清单一致性，不再让 after-turn finalizer 直接抛错。
- 网盘文件列表打开“已分享”详情时会按分享记录直接读取，不再从第一页开始分页扫描全部分享。
- 知识库添加 URL 时会先做协议、凭据和本地/私网地址校验，不再为必然拒绝的 URL 弹出网络连接授权。
- 网盘回收站恢复条目后会刷新主文件列表，永久删除后会刷新容量信息，不再让成功提示后仍显示旧状态。
- 设置页运行诊断读取 Agent Relay 状态时只做轻量计数，不再为显示数量解析全部历史运行记录。
- 网盘公开素材搜索会忽略旧的加载更多响应，不再把上一次分页结果混入新的搜索列表。
- 设置页新建知识库会拦截创建中的重复点击，避免生成成功但没有出现在项目列表里的托管知识库。
- 网盘目录切换会忽略旧的列表响应，不再出现面包屑已进入新目录但列表显示旧目录内容的情况。
- 设置页导出诊断包会限制打包的轮转日志数量和总大小，避免长期运行后的大日志让导出卡住。
- Drive MCP 取消分享时的审计记录会隐藏公开分享 ID，避免把可访问公开链接的标识写入本地审计缓存。
