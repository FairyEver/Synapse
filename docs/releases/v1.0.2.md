# Pending Release Notes

## 新增功能

- 手机上可以直接开 Claude Code 对话了：以前只能看到和操作电脑上已经开着的终端，出门在外想用 Claude Code 就得先回到电脑前。现在点终端列表右上角的 ＋，上方选「对话」，挑一个项目就能在电脑上把它开起来，开完直接进终端页，能看能输入。整个 Claude Code 仍然跑在电脑上，用的是电脑上的供应商配置和密钥，手机上不会出现也不会传输任何密钥。

  第一次用需要选一次项目，之后面板会记住你上次用的项目和模型，再打开时三行都已经是上次的值，点 ＋ 再点「开始对话」两次就能建好，中间不用做任何决定。

  这台电脑上的 Synapse 需要先更新：手机端要比电脑端晚一步用上这个功能，否则请求会被静默丢掉，只看到一直转圈。如果手机上提示「电脑端版本太旧」，请在电脑上升级 Synapse 后重试。

- 桌面端新建弹窗里的「创建终端cc对话」改名为「创建 Claude Code 对话」：这个按钮建出来的会话标题一直是「Claude Code · 项目名」，同一个东西两个叫法容易让人以为是两回事。

## 功能优化

- 桌面端的语音输入可以用回车收工了：说完最后一句不用再回鼠标上找对勾，Agent 对话和终端里按回车和点它完全一样 —— 识别结果落进输入框（终端里是命令行），发不发、跑不跑仍然由你决定。回车只在录音期间生效；光标如果点回了终端命令行，那个回车仍然归终端，该执行就执行。

- 手机端终端页的标题栏现在显示正在使用的 App 版本和构建号：标题下方那一行从「运行中」变成「运行中 · 1.0.1 (3)」。同一个版本可能打包上传过好几次，只报版本号说不清是哪一次；反馈问题时连括号里的数字一起报，能直接对上你手机里装的那一版。

- 手机端 App 内的提示改到了屏幕底部：此前它固定在屏幕最上方，会盖住终端页左上角的返回按钮，想退出终端的时候点不到，要等 4 秒。现在提示出现在底部、浮在输入栏和标签栏之上，不再遮挡任何返回、标题或操作按钮；可以上下滑动甩掉，也可以点一下关掉。

- 手机端提示的停留时长按内容轻重区分：确认类（比如「已复制终端输出」）停 1 秒，出错提示停 5 秒。此前一律停 4 秒——确认类白占屏幕，错误类又常常看不完。

- 手机端终端页底部的输入栏和快捷按键行按 Apple 的触控尺寸规范调大：此前整条输入栏只有 42 点高，发送按钮的可点范围仅 26 点，快捷按键的行高约 28 点，都低于 Apple 规定的最小触控面积，手指容易点偏。现在输入栏加高到 56 点、快捷按键行加高到 48 点，按键文字从 12 点放大到 15 点，＋、麦克风、发送以及录音时的取消/确认/重试都拥有 44×44 点的可点范围，发送按钮图标从 26 点放大到 30 点。

- 手机端界面整套跟着系统字体大小走：此前登录页、终端列表、需要我、设置页和终端页导航栏的字号都是写死的，把系统的「文字大小」调大之后这些地方纹丝不动（只有底部提示条会跟着变）。现在全部改用系统文本样式，辅助功能里的大字号档位能正常放大。

- 手机端终端页的底部提示条现在点一下就能关掉：此前只有上下滑动能甩掉，但发布说明里写了「也可以点一下关掉」，实际点不掉。现在两种都可以，并且走的是同一套消失动画，不会一个快一个慢。

- 手机端终端里的选中文字多了一项「分享」：选中终端输出后可以直接走系统分享面板发出去，此前菜单里只有「拷贝」和「全选」。

## 问题修复

- 修复手机端好几处按钮点不中的问题：终端页的返回箭头可点范围只有 17 点、「更多」只有 30 点、附件卡片约 25 点、终端消息的关闭按钮 28 点、「去设置」只有文字那一行高，都远低于 Apple 规定的最小触控面积 44 点。现在它们都达到 44×44，而且不会因此看起来变大——能点到多大和画出来多大是分开算的。（附件条和终端消息行会因此变高约 16 点，只在有内容的时候才出现。）

- 修复手机端「等待确认」标记看不清的问题：琥珀色文字画在 12% 琥珀色底上，实测对比度只有 2.5:1，几乎是同色叠同色。现在改用不透明的、随浅色深色自适应的底色，浅色下 5.0:1、深色下 5.7:1。

- 修复手机端深色模式下错误提示偏暗看不清的问题：红色文字在深色列表里只有 3.2:1，低于正文需要的 4.5:1。现在红色和琥珀色都随浅色/深色分别取值，「等待」用的琥珀色在浅色下也从 3.4:1 提到 5.4:1。

- 修复手机端列表里能点进去的行看不出来能点的问题：「终端」和「需要我」两个列表里，点了会进入下一级的行此前没有右侧箭头——用了纯按钮样式，把系统自动加的箭头压掉了。现在换回系统导航链接，箭头和按压高亮都回来了。

- 修复手机端横屏时登录页的输入框和登录按钮被键盘盖住、够不着的问题：现在表单可以滚动，键盘弹起时也能摸到登录按钮。

- 修复手机端终端页的发送、快捷按键、录音起停没有任何触感反馈的问题：现在这些操作都有对应的触感——发送和确认是轻击，快捷按键是选择反馈，麦克风开和关是中等力度，按下去能感觉到。

- 修复手机端纯图标按钮对读屏用户没有名字的问题：返回、更多、添加附件、语音输入、发送、取消/确认/重试此前会被念成符号本身的名字，现在都有中文名。

- 修复手机端 App 图标角标使用了系统已废弃接口的问题。

- 修复手机端声明了一个其实用不上的后台模式的问题：应用此前声明支持「远程通知」后台唤醒，但服务端发的都是普通提醒推送，代码里也没有对应的后台入口。这个空声明已移除。


- 修复用户一多就登录不上、用着用着提示掉线的问题：登录、注册、刷新令牌这些接口此前全平台共用每分钟 5 次的额度（服务端拿不到真实客户端 IP，把所有人都当成同一个来源），别人多登几次就把额度占满了，一个人反复输错密码也足以让其他人这一分钟都登不上。现在额度按真实的客户端来源分别计算，登录放宽到每分钟 10 次、令牌刷新 60 次。

- 修复 AI 改云盘文档时覆盖掉你自己改动的问题：此前 AI 会把整份文档替换成它手里那份旧内容，你在在线文档里保存过的图片和文字会不声不响地消失。现在 AI 修改已有文档会先读取当前版本、在最新内容上改，并且必须声明它基于哪一版；如果文档在你手上又改过，它会拿到「文件已有新内容」而不是把你的改动覆盖掉，重新读取后再改。

- 修复打包后的应用无法使用语音输入：macOS 正式包缺少麦克风权限声明，系统既不弹授权提示也不放行录音；现在会在首次使用语音输入时正常请求麦克风权限。

- 修复终端侧边栏会话同时出现两个状态图标：等待输入的提示图标现在直接替换运行状态图标。

- 修复手机端终端页弹出键盘后输入栏两侧露出一对深色角：那是终端画布的底色从键盘圆角处透出来，和上面浅色的输入栏对不上。现在键盘背后的区域跟输入栏同色；键盘收起时，输入栏下方（Home 指示条那一段）也不再是一条深色带。

- 修复手机端复制终端输出时弹出橙色警告三角的问题：那个颜色在 Synapse 里专指「出错了，需要你处理」，复制成功却顶着它，看起来像是复制失败了。现在成功提示是绿色对勾。

- 修复手机端连续收到两条提示时第二条可能一闪而过的问题：此前第二条会继承上一条的倒计时，有时候只显示不到一秒就消失。现在每条提示都按自己的内容重新计时。

- 修复手机端一次选中多个超限文件时只看得到最后一条拒绝原因的问题：现在这些原因会逐条列在输入栏上方，不再互相覆盖、只剩最后一句。

- 修复手机端提示文字不跟随系统字体大小的问题：此前字号写死，把系统字体调大之后提示仍然很小。

- 修复手机端登录失败后不知道哪里错了的问题：此前失败原因飘在屏幕最上方，和刚填的输入框隔着大半屏。现在显示在输入框正下方、与输入框左对齐。

- 修复手机端发送失败、图片或文件读取失败的提示会自己消失的问题：这些是对你刚做的那次操作的答复，此前几秒后自动消失，低头打字再抬头就没了。现在它们停留在输入栏上方，直到你点关闭。

- 修复手机端附件传失败后看不到失败原因的问题：此前被拒的附件只标一个「没有送达」，具体原因（比如文件超过大小上限、一次选太多）被丢掉了。现在点开附件就能看到原因。

- 修复手机端麦克风权限未开启时只给一句文字的问题：现在除了说明，还提供「去设置」直接跳到系统设置页，提示也不再自动消失。

- 修复手机端断网时谎报「电脑离线」的问题：手机连不上服务器时，电脑列表要么根本没取到、要么是断线前的旧值，此时说电脑离线会把人支去检查一台其实开着的电脑。现在会区分这两种情况——连不上服务器时提示检查这台手机的网络，确实没有电脑在线时才提示去电脑上打开 Synapse。

- 修复手机端重连时状态含糊的问题：此前无论等网络还是等登录，都只显示「等待网络」。现在会说明具体在等什么（例如「网络中断，正在重连」）。

- 修复手机端「连不上服务器」和「无法获取电脑列表」两条提示会自己消失的问题：同一件事现在常驻显示在设备的连接状态里，不再几秒后无影无踪。
