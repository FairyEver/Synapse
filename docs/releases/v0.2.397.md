# Pending Release Notes

## 新增功能

- 云盘 Markdown 评论现在使用 CRDT 相对位置、稳定语义块、源码位置和引文上下文共同定位；原文移动或前方插入后仍能保持关联，删除、重复文本歧义或证据不足时会安全进入“未定位”，并支持选择新文字重新关联。
- 云盘 Markdown 代码编辑器新增可开关的多人实时协同，支持断线重连、本地副本保留、在线状态和手动“保存版本”；Markdown 阅读页会实时刷新正文、目录和评论变化。

## 功能优化

- 删除供应商时可直接批量删除仍引用该供应商的 Agent 会话，完成后会立即重新检查剩余引用；部分会话删除失败时会保留并提示失败数量。
- Markdown 协同编辑会在空闲、连续编辑上限、最后一位编辑者离开和手动操作时生成历史版本，不再为每次按键制造版本；上传覆盖、历史恢复和整文保存会先保护已确认内容，再切换到新的协同代际。
- 云盘分享的阅读、评论和编辑权限现在独立判断：登录且可阅读的访问者可以评论，匿名访问者只读评论，评论权限不会扩大正文编辑权限。
- 本次升级会一次性清理旧版 Markdown 评论；原文档、既有分享链接和历史版本保持不变，升级后创建的评论全部使用新版稳定定位方案。

- 安装内置 Synapse Skill 后，Codex、Cursor 等 Agent 可通过 Synapse MCP 将稳定的本地文件或文件夹直接绑定到云盘持续同步，并可查询状态、暂停、恢复、停止、重新扫描和处理冲突；同步前会展示首次传输汇总和有限变更清单，Agent 也能更可靠地区分备份等模糊说法、定位远端路径或已有绑定，并汇总多项操作的部分成功。未指定云盘目录时默认使用根目录，普通“上传到云盘”仍保持一次性上传。
- 新建文件、文件夹和网页分享现在默认无需密码且永久有效；需要保护时仍可主动开启由系统生成的密码。

## 问题修复

- 修复 Markdown 阅读页滚动时目录栏会随正文离开视口、滚动体感异常，以及文档底部评论可能被截断的问题；页面现在使用单一原生滚动区域，目录保持固定，评论仍随正文位置对齐。
- 修复 Markdown 评论卡片在内容、宽度、字体或样式发生变化后可能重叠或留下过大空隙的问题；评论栏现在会根据卡片实时尺寸自动重新排列。
- 修复 Markdown 协同文件在历史恢复或外部替换后，已可靠同步的编辑器仍错误停在旧协同代际的问题；已同步客户端现在会自动刷新当前版本，只有仍有未确认修改的客户端才保留本地副本与下载入口。
- 修复 Markdown 协同内容生成新检查点后，仍在阅读页的用户添加评论会被错误提示“位置已失效”的问题；客户端现在会即时采用最新检查点版本。
- 修复协同更新写入对象存储遇到临时故障后一直停在“正在同步”的问题；更新会保留并自动重试，成功可靠落盘后再确认同步。
- 修复评论选区被局部替换时可能误判为“原文已删除”的问题；CRDT 相对范围暂时塌缩时会继续使用稳定语义块和上下文恢复为“原文已修改”。
- 修复对象存储响应异常时服务关闭或开发热重载可能长时间卡住的问题；所有协同房间会并行执行有时限的退出持久化，未确认内容仍由客户端保留并在重连后重发。
- 修复云盘文件上传、覆盖或生成协同版本时可能因项目级并发锁返回值无法解析而失败的问题。
- 修复 Markdown 已包含评论或存在多个段落时，段落间结构空白会使后续评论选区偏移，导致重复文本等有效选区被错误判定为失效的问题。
- 修复开启实时协同后，Markdown 代码编辑器在严格模式或首次切换视图时可能一直停在连接中，或看似同步但实际未加入协同文档的问题。
- 修复协作者离开或在阅读、代码视图间切换后在线人数残留，以及阅读页加入已有协同房间时先显示旧检查点内容的问题。
- 修复远端协同内容保存为新版本后，直接切换到 MDXEditor 仍可能加载旧正文的问题；进入 MDXEditor 前会先刷新到最新检查点。
- 修复实时预览仍沿用旧锚点解析缓存，导致选区全文被删除后评论继续错误挂载的问题；同一协同代际内删除和恢复现在会立即更新定位状态。
- 修复协同房间把服务端自身计入在线人数，以及登录后返回带查询参数的云盘地址时生成重复查询串的问题。
- 修复评论原文跨越 Markdown 行内语法时，删除正文后残留的反引号等定界符仍可能被误认为原评论关系的问题；只有引文相似或完整上下文仍成立时才保持挂载。
- 修复本地文件首次创建云盘同步时可能覆盖目标目录同名文件的问题；文件和文件夹现在都会在绑定前阻止同名覆盖，并引导绑定已有内容或改用新名称、位置。
- 修复新版 Markdown 评论在文档保存或恢复版本后消失的问题；升级后创建的评论会始终跟随文档，原文被修改或删除时会保留在“未定位”区域。

## 技术调整

- 新增 Markdown 投影、评论 Anchor V2、Yjs 协同日志与检查点存储；Markdown 源文件仍是权威数据，协同更新和用户历史版本保持分离。实时协同由 `DRIVE_COLLABORATION_ENABLED` 控制，评论稳定定位不受该开关影响。
