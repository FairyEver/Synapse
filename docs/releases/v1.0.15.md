# Pending Release Notes

## 新增功能

- 手机端新增「剪切板」：电脑上复制过的文本会出现在手机上，点一条就进了手机的剪切板，可以粘到任何地方。两个入口——会话列表页顶部那台电脑右侧的图标，以及终端里快捷面板最左边的「剪切板」分段。列表按电脑分开保存，每台电脑在手机上各留最近 50 条，断网或退出 App 之后仍然能看、能复制；从密码管理器复制的密码不会同步过来。

## 功能优化

- 多台设备同时在线时不再互相拖慢：服务端处理每一次终端画面的固定开销，过去会随「整个平台上共有多少台设备」增长，别的用户设备越多，你这边的每一条终端消息都要多付一份固定成本；现在它只与你自己的设备数有关。
- 桌面端把终端画面推给手机的开销明显下降：同一帧不再被完整序列化两遍；同一台电脑的同一个终端同时被多台手机查看时，画面只读取一次，而不是每台手机各读一次。
- 手机上长时间看输出密集的终端（`tail -f`、构建日志、全屏 TUI 程序）不再掉帧：缓冲区满了以后，过去每来一行新输出都要搬动整个缓冲并重建一次行索引，现在按批处理。
- 手机端画面推进时只为发生变化的那部分重算行标识，不再整屏重算。
- 手机上显示的项目与 Provider 列表改为按需刷新（前提是手机已经连着、且期间没有发出任何操作）：在电脑上改了项目名或 Provider，手机上最多 15 秒后同步；从手机连上电脑那一刻起则是立即同步。过去是每秒刷新一次，代价是每秒都在重新读一遍电脑上的配置。
- 手机端终端自带的回滚缓冲深度从恒定的 6000 行变为在 5489–6001 行之间浮动。电脑端本身只保留 5000 行，所以你能往回翻到的最早内容没有变化。
- 管理后台的设备列表刷新改为按心跳节奏（最长 20 秒一次），不再每收到一条终端消息就刷新一次；列表内容本身不变。

## 问题修复

- 修复手机端「网络已断开」这条提示会一直挂在输入栏上方的问题。它现在会在连接恢复后自己消失，不需要手动关：这条提示说的是一时的连接状态，手机连上了它就没有依据了。
- 手机端点输入栏的麦克风想说话、而那一刻恰好连不上服务器时，提示条改说真实原因（「需要登录」「网络中断，正在重连」），不再把所有情况都写成「网络已断开」——登录过期的人不会再被支去查 WiFi。

- 修复手机端有时看不到会话列表的问题：服务端的会话列表缓存过去按「最早写入」而不是「最久没用」来淘汰，于是一直在用的那台电脑反而会被挤出去，而早就不再使用的电脑却占着位置。
- 修复电脑端在服务端反复「接受连接后立刻断开」时可能陷入约每 2 秒一次的无限重连的问题——这种重连过去不增长等待时间，也就没有上限。
- 修复弱网下电脑端把要推给手机的终端画面无限堆在内存里的问题：积压超过阈值时改为丢弃当前帧、等下一帧覆盖，而不是继续堆积。
- 修复终端顶部标签条在右侧还有空白时就出现横向滚动的问题：没有中间标签栏时，顶栏左侧内容现在会一直铺到右侧操作按钮之前。
- 修复手机端按工具栏上的指令（回车、Ctrl+C、/exit、/clear、自己加的指令）会弹出手机键盘的问题。此前按一下就把键盘叫起来，同时盖住终端里的输出、并让整条指令栏自己消失——想接着按第二颗键得先把键盘收掉；现在按指令只发送、不弹键盘，只有点输入框才会唤起键盘。
