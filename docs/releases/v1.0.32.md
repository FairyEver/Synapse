# Pending Release Notes

## 新增功能

- 手机端云盘可以换成网格看：右上角菜单里新增「显示方式」，选「网格」就是一格一枚图标加名字、手机上每行三个，选「列表」回到原来的样子。窗口越宽一行放得越多，格子和图标也跟着变大，iPad 上不会把手机上那套小格子铺满整屏。选过之后进哪个文件夹、退出重进都还是这个摆法。

## 功能优化

- 内置 Synapse Skill 现在认得「PH」这个简称：你说「用 PH 帮我查一下…」或「帮我改一下 PH」，AI 就知道指的是 Portal Headless，不用再把全称打全。
- 提醒类的话现在能听懂了：说「半小时后提醒我」「完事提醒一声」「给我手机发条消息」「结果推到我手机上」，AI 都会走同一条能力——本机弹一条通知，桌面端在线时同一条消息也进消息中心并推到你手机上。以前只有明说「通知我」才认，上面这些说法多半搜不到对应能力。说「给某个对话发消息」也不会被误当成通知你。
- 去掉了「单独发个声音」这条能力：它只会在这台电脑上播一段提示音，到不了手机、也不进消息中心，而电脑和手机的通知本来就自带系统提示音，留着只是多一个容易和「通知」搞混的入口。需要提醒时现在只有一条路——「通知」：本机弹通知，桌面端在线时同一条消息也进消息中心和你的手机。以前暴露给 AI 的那条「播放声音」工具也一并下线，若你在别的编辑器里保存过它的工具名，之后会找不到。
- 手机端点开云盘里的文件改成用系统浏览器打开网页版那一页：网页、Markdown、PDF、图片、Office 看到的就是它本来的样子，与在电脑上点开同一个文件是同一页；以前显示的是源码，或者应用自己画的一份预览。长按菜单里那一条也随之从「预览」改成「在浏览器中打开」。iPad 上云盘因此回到一列，右边那一栏预览没有了。
- 助手能替你做的门户操作补上了一大块：以前只够得着页面上的主列表，页面里**点开的弹窗、隐藏的详情子页、下钻进去的明细页**都够不着。这一轮把 65 处这样的操作接了进来——讲师给学员作业评分、学员作业与课堂记录查看、班级的岗位/学员/组织调整、班级与学员的统计下钻、课程评论与标签、月课堂的议案与评分记录、年度账结转的期初余额与试算平衡、绩效的管理分析与标准管理、招聘计划、供应商品牌、成本中心、结转单设置等。这些动作在门户里用户本来就看得见、点得到，只是助手以前做不了。

## 问题修复

- 网页版固定用浅色外观，不再跟随系统的深色模式：以前系统开了深色，网页版就只深了一半——标题栏是深色的、Markdown 正文和代码编辑器却还是一整块白纸，文档编辑器的下拉框、外观设置里的预览图、日期选择器也各有各的毛病。现在整个网页版（分享页、控制台、管理后台）一律浅色，不会再出现这种一半对一半不对的情况。外观设置里的「主题」一栏（浅色 / 深色 / 跟随系统）也随之移除了，因为只剩一种外观。
