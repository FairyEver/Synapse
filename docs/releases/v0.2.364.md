# Pending Release Notes

## 新增功能

- Agent 现在可以通过权限分级的 Terminal MCP 创建和发现 Synapse 终端、读取有界历史与实时状态、独占续写交互会话，并安全执行重命名、调整尺寸、停止和删除等与界面对齐的操作。
- 新增“HTML 生成器”系统应用、MCP 能力和 Workflow 节点，可用受信任的 EJS 模板与结构化数据生成完整 HTML，或以 UTF-8 可靠写入本地 `.html` / `.htm` 文件。
- “文本写入文件”现已支持完整 `.html` / `.htm` 文本，并对 HTML 固定使用 UTF-8；原有 `.txt`、`.md`、`.csv` 行为保持不变。
- 新增“文本写入文件”系统应用、MCP 能力和 Workflow 节点，可把完整文本一次写入本地 `.txt`、`.md` 或 `.csv` 文件，支持 UTF-8/UTF-16 LE、自动创建父目录和显式覆盖控制。
- 新增“默认应用打开”系统应用和 MCP 能力，可把一个已有本地普通文件交给系统默认应用；同一能力可在应用、Workflow 和 `synapse://app/file-opener/open` 深链中使用。
- 新增带有专属图标的“文本提取”系统应用，可在统一的内置应用界面中选择本地 PDF 或 DOCX，查看纯文本预览，并复制或保存完整结果；应用支持固定到 Dock 和独立窗口。
- Agent 现在可以通过同一个 MCP 工具安全提取本地 PDF 的已有文本层或 DOCX 的正文，并获得完整正文和文件信息；无文本内容或超出明确限制时会返回可判断的结果，不会静默截断。
- 工作流新增“文本提取”节点，可从固定路径、文件参数或上游路径读取单个 PDF/DOCX，并把完整正文直接交给后续节点。
- Agent 现在可以一次调用完成 PDF/DOCX 文本提取和本地 `.txt`、`.md` 或 `.csv` 保存；正文全程留在 Synapse 内部，不再经过 Agent 上下文或第二次 MCP 请求。

## 功能优化

- “HTML 生成器”现在使用专属 HTML 图标，在应用启动器和 Dock 中更容易识别。
- 内置 Synapse Skill 增加 Terminal MCP 的任务流程和典型示例，Agent 能用更少的重复读取、提示符探测命令、无效配额重试、租约重试和幂等键生成步骤创建分组终端、运行命令、续写或退出交互会话、观察长期服务，并按实际调用顺序汇报操作，正确处理本机策略限制、并发控制和不确定交付。
- 开发中的 Terminal MCP 收敛为一套当前工具契约，不再要求 Agent 传递 v2 版本字段或尝试旧工具别名，减少无效探测和兼容分支。
- Terminal MCP 不再限制单个客户端最多保留 8 个运行会话；仍保留整个 Terminal 的全局资源上限，避免异常创建耗尽本机资源。
- Terminal 会话创建、控制租约获取和续租现在会直接返回当前输入修订号，Agent 可以立即发送已决定的操作，不再为补齐参数额外读取状态或先触发一次无效请求。
- 工作流运行历史现在会显示更清晰的状态、开始时间、耗时和节点数；失败记录可先查看易读摘要，再展开完整错误详情。
- “文本提取”“默认应用打开”和“文本写入文件”统一为系统应用的任务表单布局，路径、选项、状态和主要操作更易扫描。
- “文本提取”的现有保存流程现在复用统一文本写文件能力，继续保持原界面和原生保存体验，同时获得一致的原子写入、权限审计和并发变化保护。
- 文本提取任务现在会共享受限队列，并支持等待或运行时取消；多个请求同时到达或单个任务异常时，不再无界占用系统资源或阻塞后续提取。
- Agent 对话现在可以在当前会话中直接读取新拖入或粘贴的外部文件和文件夹；手动输入的外部路径可在首次访问时按会话授权，不再要求新建对话。

## 问题修复

- 修复终端窗口调整大小或会话状态变化后，Codex 等全屏交互程序可能出现画面重复、跳回旧内容且无法滚动到底部的问题；终端现在从后台权威画面恢复，并按输出顺序原地调整尺寸。
- 修复 Agent 对话在“删除其他”时误删其他来源会话的问题，现在只会删除当前分类和当前可见分组中的其他对话。
- 修复数据异常的工作流无法删除的问题；运行和编辑仍保持保护，删除前会继续确认并检查引用，未来版本也可先导出原文备份。
- 修复 Terminal MCP 在权限或参数校验失败时只返回不可解析错误的问题，Agent 现在可以稳定读取错误码、类别、重试提示和关联标识；同时修复 MCP 删除当前终端后界面偶发误报“读取终端输出失败”的竞态。
- 修复 Terminal MCP 向 Codex 等交互程序发送长指令时可能只填入文字、没有真正触发提交的问题；Agent 现在也会在看到输入框清空或执行输出后再报告任务已开始。
- 修复本机 Codex 等客户端调用 MCP 时被错误要求认证的问题；Synapse 现在统一注册无 token 的 loopback HTTP MCP，并自动把旧 stdio 配置迁移到 HTTP，Terminal 创建、读取和操作能力保持不变。
- 修复工作流运行历史列表无法滚动、左右留白不一致，以及超长错误会撑破记录布局的问题。
- 修复“文本写入文件”能力把 Node.js 路径模块带入界面进程、导致应用启动后白屏的问题。
- 修复工作流开始阶段的 Agent 节点可能不显示“打开对话”入口，以及 Agent 已开始响应后节点仍停留在“等待响应”的问题。
- 修复导出工作流弹窗内容较多时无法滚动的问题，标题和底部操作会保持可见。
- 修复工作流导出时把运行参数或上游节点生成的动态路径误报为外部文件的问题。
