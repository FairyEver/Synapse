# Pending Release Notes

## 新增功能

- Markdown 云文档支持在文章末尾发布留言并无限层级回复；作者可编辑、删除自己的内容，文档所有者可删除他人内容。阅读页顶栏可一键跳转到留言区，Agent 也可读取和管理自己或分享文档的留言。
- 发送消息指南新增交互式请求构建器，可填写消息并复制 cURL、Node.js fetch 请求或路径式链接。

## 功能优化

- 桌面通知中心的列表和阅读区使用统一的自定义滚动条。
- 桌面通知中心的列表栏和内容栏更紧凑，阅读时减少面板对主界面的遮挡。
- 通知列表的“加载更多”操作区域更高，悬停时整行显示背景反馈。
- 桌面端常规操作按钮统一使用标准尺寸，行内操作和紧凑工具栏仍保持合适的密度。

## 问题修复

- 修复桌面顶部通知按钮与相邻账户按钮尺寸不一致的问题。
- 修复通知列表中标题、来源和摘要的行间距不一致。
- 修复发送消息请求构建器在密钥未填完整时隐藏预览、无法复制草稿的问题，并移除缺少正文的路径式示例。
