# Pending Release Notes

## 新增功能

## 功能优化

- 重做 iPhone 与 iPad 的工作区文件面板：紧凑呈现目录范围、文件视图和搜索，统一文件与目录列表，让更多文件直接可见；文件视图和更改范围菜单的整行点击区域与无障碍操作一致；大字体下保留可滚动的操作区域，iPad 分栏显示当前选中文件。
- iPhone 与 iPad 的登录、创建会话和录音操作采用系统按钮；键盘工具栏、录音列表、设置与首页随字体大小适配，并补全操作的无障碍名称和语音输入的辅助操作；通知和剪贴板空状态不再与电脑名称重叠，折叠菜单明确显示通知入口，录音详情和收件人选择移除重复或空标题，并扩大短文字操作的点击区域；修复 iPad 设置、会话和录音列表选中后文字看不清，以及深色模式下云盘移动确认按钮文字不可见的问题；云盘网格随字体大小调整列宽，避免短日期被截断。
- 新建会话明确区分“对话”和“终端”，项目或模型尚未配置时显示必要提示；切换到不支持快捷短语的电脑时，输入面板的选中项与实际显示保持一致。

## 问题修复

- 修复录音详情加载失败后持续转圈、重新转写后状态不更新、重试或删除失败缺少提示、切换录音时播放对象未更新，以及取消录音启动后仍留下空录音的问题；详情重试成功后清除旧错误，迟到的错误不再覆盖新操作结果，离开录音列表时取消的读取不再显示为网络错误；删除录音后不再恢复迟到的详情或音频缓存，语音输入结束后播放录音恢复声音。
- 修复语音输入取消或网络失败后麦克风仍采集、迟到的识别结果回填和重复完成的问题，并让灵动岛点按进入当前录音。
- 修复写信取消或下拉关闭时丢失未发送内容的问题，发送期间锁定草稿，并避免旧的发送预览和组织成员结果覆盖当前选择。
- 修复站内信往来分页重复、分页入口不可达、初始收件人恢复与编辑相互覆盖，以及未读筛选被迟到的列表恢复的问题；读写操作及时同步未读数，全部已读同步当前详情，删除其他信件时保留当前详情，操作失败在详情中显示原因，重试成功后清除旧错误；同一封信的迟到回执和详情读取不再覆盖随后完成的已读或未读操作。
- 修复通知重复加载、加载更多缺少反馈、读删结果被迟到的列表恢复、日期分组异常和无障碍角标未读数不准确的问题；重试成功后清除旧错误。
- 修复退出或切换账号后迟到的登录刷新、通知跳转、网页授权或站内信附件下载影响当前账号的问题，并避免同一账号并发刷新后误判退出；切换电脑时清理旧终端选择，已结束会话的跳转给出明确反馈；云盘新建、重命名、移动和停用分享的迟到结果不再触发已退出账号的刷新，旧操作提示与分享结果也不再带入当前账号，创建分享期间避免重复提交。
- 修复冷启动从 Widget 或通知打开终端时提前丢失跳转目标的问题；等待当前电脑状态和会话列表，重连后不再使用旧列表跳转，并优先保留用户随后主动选择的页面、电脑或会话；目标电脑已离线时正确退回会话列表，不再停留旧详情。
- 修复 Git 操作期间仍能重复执行操作、提交页返回后仍执行先前的切换或合并，以及工作区文件权限撤销后仍显示旧内容的问题；耗时操作显示进度并锁定提交按钮。
- 修复云盘导入失败缺少反馈、录音更名失败丢失输入和空文件夹显示多余横线的问题；云盘照片上传支持一次选择更多照片，不再受终端接力的 9 项限制。
- 修复云盘目录失败后重试错误位置、移动目录分页失败后无法继续、刷新后保留失效选择、旧列表覆盖操作结果和过期分享被复用的问题；单个文件夹现在可以导出 ZIP，上传地址更新后遇到新的同名文件仍需确认覆盖；离开云盘时取消的读取不再误报网络错误；删除或恢复后及时更新回收站总数，搜索结果不再影响入口总数。
- 云盘批量操作显示进度并避免重复操作，文件和分享列表加载更多时不再重复显示重叠条目，分享结果页和管理详情不再复制已经到期的链接，操作失效分享时给出明确提示。
- 麦克风权限被拒时如实提示并提供设置入口，未开始录音时不再显示保存提示；本机录音保存失败时停止采集并显示原因，保留已录部分供完成或取消；修复录音收尾读取失败时可能误提交未完整核对音频的问题，并保留可恢复录音；恢复上传时遇到已删除的录音记录会清理对应待传文件，网络或本地读取失败仍保留原件。
- 修复终端附件、站内信附件或云盘照片准备期间切换账号、电脑或目录后发往错误位置的问题；首次进入终端不再提前请求相册权限。
- 终端输入收到电脑确认后才清除；连接中断或发送失败时保留文字与附件，发送期间显示进度并避免重复发送；不同会话出现相同错误时，当前会话仍显示自己的失败原因。
- 终端附件撤销收到电脑确认后才移除，部分执行或结果不确定时停止继续删除输入；路径未插入时不再提供无效撤销。
- 修复 iPad 终端标题被未打开的资源面板覆盖、会话状态缺失，以及文件分页过期后看不到恢复操作的问题；快速切换文件时不再把旧 Markdown 预览带入纯文本文件。
- 修复录音详情返回列表后无法再次打开同一录音的问题。
- 修复电脑时间偏差导致会话运行时间显示为负数的问题。
- 修复长文件预览后返回目录、搜索或改动列表变空的问题，返回时保留当前阅读位置并重新读取必要页面；改动对比继续翻页和切换修改前后保持可用。
- 修复云盘导出刚开始就取消时留下临时下载目录的问题。
- 修复剪贴板历史连续清空后旧记录重新出现的问题；诊断日志导出会根据实际内容提示，正确区分上次与当前会话、统计丢弃字节，关闭记录时保留最后一批日志，避免关闭或清空与异常记录同时发生时写入其他文件，清空后保留原有记录开关状态，并补齐首次启动的异常捕获和文件统计。
- 修复工作区文件树展开文件夹后子层级缩进不清晰的问题：每层现在按系统列表标准均匀递进固定间距，展开的文件夹和它的子文件夹一眼可分，文件和文件夹的图标、文字始终对齐在同一列。
- 修复工作区文件面板顶部的长目录名换行后居中、撑高操作区的问题：普通字号保持单行，大字体下完整换行并左对齐。
- 修复工作区文件搜索框边界不清、阴影在列表边缘被截断的问题，并让搜索框随深浅色及字体大小正确更新。
- 修复部分正常 Git 仓库在工作区文件的“已修改”视图中误显示“Git 不可用”的问题。
- 修复较大 Git 仓库因重复扫描和读取计时而无法显示改动列表的问题。
- 移除工作区文件 Git 不可用空状态下多余的列表横线。
