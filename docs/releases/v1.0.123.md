# Pending Release Notes

## 新增功能

- 文档历史版本新增独立「变更历史」页面：在历史版本弹窗表格上方点击「变更历史」即可新开干净页面，支持按时间段和来源筛选、查看单次修改 Diff、任意版本范围对比、该时段累计变更以及按次总览，提供统一 / 分栏两种对比视图

## 功能优化

- 简化独立文档浏览链接，不再在地址栏附加多余的 `?surface=standalone` 参数（旧链接继续兼容）
- 移除文档历史版本中多余的「保留 / 取消保留」功能，历史版本全部长期保存并支持直接删除非当前版本
- 优化云盘同步筛选标签，分类数量为 0 时不再显示数字
- 对话后的「用量统计」卡片改为纯 Token 用量展示，不再显示任何价格或估算费用
- 优化对话导出压缩包与内部目录的命名规则，避免超长回退标题和特殊标点导致文件名过长或显示异常
- 优化流式诊断日志的采集保留策略与统计口径，优先保留结构事件与尾部明细，并明确区分采集期与导出期丢弃计数

## 问题修复

- 修复文档历史版本弹窗中版本列表出现多余外边框与圆角不一致的问题
- 修复 Agent 先输出正文、再执行收尾工具（如记录工作日志）时，正式答复被默认折叠进「已处理」区域导致看起来没有结果的问题
- 修复日志脱敏误伤正常 Token 统计字段并将缺失字段改写为 `[redacted]` 的问题
- 修复同模型大小写差异导致用量记录被拆分统计、未知模型误沿用 SDK 兜底美元价，以及缺少 `deepseek-v4.1-flash` 目录与价格预设的问题
