# Pending Release Notes

## 新增功能

- 手机端终端底部现在显示电脑上的那套快捷指令：电脑内置的「回车」「Ctrl+C」「/exit」「/clear」，以及你在电脑上自己新建的快捷指令，顺序和分组都与电脑上一致。手机上只能使用、不能修改，新增和删除仍然在电脑上做。电脑上那条「Clear」不会出现在手机上——它只是清空电脑自己的显示，在手机上没有对应效果。

- 手机端终端底部最左侧多了一个键盘按钮，点开是手机专属的键盘面板，分「常用 / 方向 / 功能 / 全键盘」四类：`esc`、`⇧tab`、`Tab`、`⌫`、`回车`、四个方向键，以及 `home`、`end`、`PgUp`、`PgDn`、`del`。键位照着电脑键盘上的真实位置摆放，按方向键不用低头找。面板点一下不会收起，可以连着按。

- 键盘面板的「控制」一栏改成了一块真正的「全键盘」。以前它画的是一整张 QWERTY，只有十个字母能按，其余十六个是压暗的、点了没有任何反应——它不是一个键盘，是十个固定按钮摆成了键盘的形状。现在最上面一排是 `Ctrl` / `Shift` / `Alt` 三个修饰键，下面是数字行和标准的字母区：点一下修饰键把它锁住（键会反色），再按一个字母就发出组合键，发完修饰键自己弹回；想连着按同一个组合（比如反复 `Ctrl+C`）就双击修饰键，它会保持锁定，再点一下解开。一次只会锁住一个修饰键，按第二个会换掉第一个，所以不存在「锁了两个、整块键盘按不动」的状态。

- 全键盘页在分类下面常驻一条读数：左边显示现在锁住了什么，右边显示这个键发出去会是什么——例如锁着 `Ctrl` 按 `C`，右边给出 `0x03 · 中断当前进程`。它同时也是安全网：任何一个键都不会「按了没反应」，发不出组合时会整条变黄并说明原因。

- 不锁任何修饰键时，按字母和数字就是**直接输入**这个字符。所以这个面板本身也能用来回答终端里的 `y` / `n`，以及审批提示的 `1` / `2` / `3`，不用收起面板再去点输入框。

- 随之新拿到一批以前在手机上根本发不出去的组合键：`Ctrl+B`（tmux 前缀）、`Ctrl+P` / `Ctrl+N`（上一条 / 下一条历史）、`Ctrl+F` / `Ctrl+B`（vim 翻页、按词移动）、`Ctrl+S` / `Ctrl+Q`（暂停输出 / 恢复输出）、`Ctrl+G`（取消）、`Ctrl+H`、`Ctrl+J`、`Ctrl+O`、`Ctrl+T`（交换相邻字符）、`Ctrl+V`（字面量插入）、`Ctrl+X`、`Ctrl+Y`（粘贴）。锁着 `Alt` 再按字母则发出 readline 的 Meta 组合（`Alt+B` / `Alt+F` / `Alt+D` 按词移动、删词）。

- 「常用」一栏中间新增一颗 `⇧tab`（Shift+Tab）。它是从手机驱动 Claude Code 最常按的键——切权限模式就靠它循环——而它此前在手机上无处可寻：`Shift` 在全键盘页、`Tab` 在常用页，切页会清掉已锁的修饰键，两边拼不到一起。这一格原本是空的。

- 电脑上多了一个「回车」按钮（内置命令的第一个）。这是为了让两端的内置命令逐条一致，也是手机回车的来源。

- 手机端终端的输入栏现在有两种状态：打字，和说话。最左边是一个位置永远不变的切换键，点一下，整块输入框变成「按住 说话」。按住不放就开始录；松手之后识别一结束，这**就是一句话发出去**，不用再点一次发送。输入框里本来已经有字的时候不发送，改成接在那些字后面等你确认——你在改一个路径、补一个参数的时候，这句话是来接上的，不是要单独发出去的。

- 手机端按住说话改成了**上滑选去路**：按住之后，输入栏上方会浮出一块录音面板（正在录、已录多久、电平、正在认出来的字）。手指**往上滑压到面板上**，面板上就盖一层和它一样大的蒙层、**左右一分为二**——左半「取消」、右半「固定」；压在哪一半，哪一半就整块变色并把名字显出来，手指不用挪很远也不用去找。压着左半松手就是把这一段丢掉（还留在语音态，方便重说）；压着右半松手就是接着录，手指可以拿开去翻终端，说完按输入栏那格的「完成」发出去。手不往面板上滑，松手就是把这句话发出去。

- 手机端语音态下的输入栏不再自己变形：它只写「松手会发生什么」（松手 发送 / 松手 取消 / 松手 固定 / 完成），要选的东西都在上面那块面板上——写在被手指压着的那一格上，正好被自己的手盖住。

- 手机端终端工具栏最右侧多了一颗 ⇧，点开是一个**指令面板**：电脑上的指令一次全铺在屏幕上，不用再一条条横着滑着找。面板分两段，上面一段是「快捷命令」，就是你电脑上终端工具栏里那套指令，分组之间有一根通栏横线，点一下立刻发送，和按工具栏上的按钮完全一样；下面一段是「快捷输入」，见下一条。面板默认半屏，往上拖到全屏，往下拖过一半松手就关掉。面板开着的时候 ⇧ 保持按下态。

- 手机端指令面板的第一段现在叫「**自定义命令**」，而且**只列你自己加的那些命令**。回车、Ctrl+C、/exit、/clear 不再出现在里面——它们就在工具栏最前面，贴着终端横着一滑就有，而面板的用处是「我不记得自己在电脑上加过什么」。一条自定义命令都没有的时候，这一段会直接写「暂无自定义快捷命令」。

- 手机端能用上你在电脑「快捷输入」里配的那些句子了。面板的「快捷输入」一段列的就是那份列表，顺序和你电脑上排的一样。点一行，这句话就进了输入框，**不发送、也不弹出键盘**——它是文字，不是动作，落在一个你接下来还要看一遍、改一改的地方，什么时候发由你决定。每行右侧有一颗眼睛，点开是这句话的全文（行里放不下的地方就省略号了），全文是可选中的普通文字，长按能勾选复制。你在电脑上改了句子，手机上会跟着更新。电脑上一条都没配的话，这一段是一句空状态说明——它不是「这台电脑不支持」，是「你还没配」。

- 手机端记得你上次看的是哪一段，下次打开指令面板还停在那一段。

- 手机端输入栏记得你上次选的是键盘还是语音。切到语音之后，下次进任意终端（重启 App 之后再进来也算）默认就是语音态，不用每次再点一下切换键；切回键盘态也一样会被记住。麦克风权限被关掉、或者当时没有网络的时候，进来会先停在键盘态（不提示），点一下切换键才会说明是为什么。

- 手机端切到语音输入之后就**一直留在语音态**，说完一句不会被自动打回键盘态：可以按住说一句、松手发出去、再按住说下一句，不用每句都去点一次切换键。模式只有左边那个切换键能改——滑走取消、固定之后收摊、录音中途断网、什么都没听清，都一样。两处代价：本来在输入框里已经有字时，说话接上去的那段文字在语音态下看不见（点一下切换键就看到）；什么都没听清时屏幕上看不出反应，那句「没有听到声音」留在输入框上，切回键盘态时才显示。

## 功能优化

- 手机端终端底部的键盘面板从四页并成了两页：「**键盘**」和「**导航**」，打开面板落在第一页。以前四个分类里，「常用」只有五颗键、点进去一片空，「功能」只有六颗键，两页各自都装不满一屏。现在「常用」那五颗（`esc`、`tab`、`⇧tab`、`⌫`、`回车`）横在键盘页最上面一行——`esc` 在左上角，和真键盘一样；方向和 `home`/`end`/`PgUp`/`PgDn`/`del` 并到一页上，方向簇靠左、功能簇靠右。两页上的键一颗都没少，发出去的东西也完全一样。

- 键盘页的键现在是**正方形**，行与行之间只隔和左右一样宽的缝。以前每颗键上下被留出的空白比左右大得多，五行键占掉的高度里有一小半是空的。改完之后整块键盘矮了一截，面板也跟着从 370 收到 351，终端能多露出一行。每颗键的点击区跟这个正方形的行高走（约 38pt）——手指按下去仍然落在整行上，不是只有那颗键画出来的部分。

- 手机端录音时浮出的那块面板，和下面的工具栏之间补上了与左右两边一样的间距——原来它贴着工具栏的上沿，圆角像是被工具栏切掉了一块。

- 手机端录音面板上「取消 / 固定」两半的图标和文字，现在各自落在半块的正中间。原先两样是上下摞着的，没压着的那半因此顶着一个偏上的图标、底下空着一行。手指在两半之间移动时，两半的颜色是跟着手指淡过去的，不再一下子跳过去。

- 手机端录音面板里「固定」那一半选中后的底色原来是发灰的，浅色模式下尤其明显，看着既不像选中、字也读不清；现在是一块实色。

- 手机端录音面板改回实色，没有任何一处半透明：浅色模式下是白的、深色模式下是黑的，跟着系统走；面板上所有的字、两半的底色和图标都用系统颜色写明，两种模式下都读得清。浮上来的时候从工具栏那一条线上弹出来，干脆的一下、过冲很小。系统里开着「减弱动态效果」时只保留淡入。

- 手机端语音输入不再限制时长：想按住说多久就按住说多久，屏幕上也不会出现任何计时或者「还能说多久」的提示。

- 手机端输入栏结构变了。以前语音是栏上的一个按钮：🎤 夹在输入框和发送键中间，是整条栏上最窄的落点，而录一句话要在三个位置之间瞄准——点 🎤 开始、点 ✓ 结束、不想承认还要点最左边那个 ✗。现在最左端是一个常驻的键盘/语音切换键，＋ 移到了输入框右侧，「按住 说话」那一格与原来的输入框一样宽、在同一个位置。

- 按住说话期间，下面那排快捷指令按钮（回车、Ctrl+C、/clear 等）照常可以按——一边说话一边按回车不是互斥的。

- 手机端终端工具栏改成**两头固定、中间横滑**：左边的键和右边新加的 ⇧ 永远钉在原地，只有中间那串指令会横着滑。以前整条栏是一个整体，指令一多，最左边那颗键就被挤着一起滑出屏幕，想开键盘得先把整条栏滑回起点。分组那根竖线仍然跟着指令滑，因为它分的是指令自己的组，不是这条栏的。

- 工具栏最左那颗键的图标从键盘换成了 **⌘**。它开的还是原来那个键盘面板，位置和用法都不变——换图标是因为它下面输入栏的最左端已经是一颗键盘图标，相邻两行同一个图形会被当成同一件事。

- 手机端与电脑端的语音交互不再一致：手机改成按住说话，电脑仍然点一下开始、点一下结束。两边的手不一样（拇指按住屏幕，和鼠标点击），这是有意的；识别为空不发送、不设时长上限这些规则三端仍然一致。

- 手机端「新建」面板里「对话」一栏的项目顺序，现在和你电脑对话侧栏里排的顺序一致。以前手机上只按电脑的默认顺序排：你在电脑上把项目拖到别的位置之后，手机上不会跟着变。面板里「终端」一栏的分组顺序本来就是跟电脑终端侧栏一致的，没有变化。

- 手机端终端右上角菜单里的「重命名」「复制全部输出」「停止终端」不再各带一个图标，整个菜单现在只以文字呈现——上面那两组显示模式选项本来就只有文字，图标只多在这三行上，摆在一起是两种样子。选中与否仍然用系统那一列对勾标示，不受影响。

- 手机端终端底部那个键盘面板，现在**坐在系统键盘的位置上**，不再浮在界面上方。以前它是一张浮层，会把工具栏和输入框一起盖住——你看不见自己在按哪一排按钮，也看不见终端最下面那几行，而这恰好是「一边看终端一边按」最需要的那部分。现在工具栏和输入框照常留在它上方、始终可见，终端自己让出这块高度。

- 键盘面板的高度四个分类统一了：在「常用 / 方向 / 功能 / 全键盘」之间切来切去，面板的上下边缘不动，工具栏、输入框和终端都不会再被顶一次。代价是常用、方向、功能这三页下面会空出一块——这是刻意的选择：「切页时手底下的东西完全不动」比「面板刚好包住键位」更值。

- 面板不再有下拉把手，也不能往上拖到全屏。它是键盘，不是抽屉。

- 面板和系统键盘从来不会同时出现。点输入框会用系统键盘换掉面板，点终端画面会收掉面板——和键盘熟悉的用法一致。

- 电脑上那个终端被手机接管时（面板顶栏标着「正在被 iPhone 使用」），整块会话现在是真的锁住了。以前只有终端画面被盖住，底部那排快捷指令按钮、麦克风、以及直接在键盘上敲字，都还能往手机正在用的那个终端里写字，现在一律不接受；从访达拖一个文件到画面上插路径也一样被挡住。唯一还能点的仍然是「转移到电脑」。面板顶栏本身不盖蒙层——它要留着说清楚是谁在用车——但里面的文件夹、平分、最大化、关闭按钮都置灰了，双击标题改名字也一并取消。锁只针对被接管的那一个面板：同一个分屏里的其它终端、左边的会话列表、以及应用顶栏都照常可用。

- 手机端的震动反馈从「只在终端里偶尔有」补成了全应用一套。判断标准只有一个：**屏幕上说不清的地方才震**。所以新增的震动集中在三类时刻——结果看不见的（复制成功、文件传到电脑、登录失败）、手指正压着屏幕或眼睛不在屏幕上的（录音被来电打断、录音中途断网、说了半天什么都没识别到、按到了这一层键盘发不出的组合键）、以及不能反悔的（停止终端、删除终端、退出登录、移除文件中转条）。每个结果只震一次，同一件事不会连着震两下；失败提示条自己负责震动，所以弹出提示条的地方不再额外震一次。

- 手机端录音松手时的反馈补齐了：按住说话往上滑到左半「取消」松手、以及录音固定后按 ✗ 放弃，现在各给一次轻震；滑到右半「固定」松手给一次比它重一点的，因为「手已经拿开了、它还在录」正是屏幕被手指挡住时最需要知道的一句。松手发送原本不震，现在也不震——发没发出去要等识别收尾才知道，那一下由发送本身给。

- 手机端键盘面板上按到这一层修饰键发不出的字母时，会震一下并保持读数变黄。以前只有颜色变黄，手指按在键上未必看得见。

- 手机端终端画布捏合放大缩放到头了会震一下。此前到顶之后画面只是不再跟手，没有任何说明。

- 手机端断线自动重连成功时会震一下。这是唯一一个「屏幕上什么都不变」的连接状态：断开时不显示、恢复时也不显示，用户无法判断刚发出去的命令到底有没有送出去。从后台切回前台的重连不震，正常启动的首次连接也不震。

- 手机端终端里的终端消息（电脑离线、命令没发出去、麦克风权限没开、图片文件读不出来）现在会震一下。这些提示挂在终端画面上，而触发它们的动作往往正好在手指底下。

## 问题修复

- 手机端按住「说话」的那一下不再顿一下。启动麦克风是一段会阻塞几十到几百毫秒的等待（等音频硬件和路由就位），它此前是在主线程上做的，正好落在按下那一刻——按下去之后要愣一下才开始录，屏幕上那一下也像是卡住了。现在这段等待挪到了主线程之外，按下去立刻就有反应，录音本身也没有变慢。

- 手机端按住说话时，识别出来的字在屏幕上看不见：字是占着位置的，末尾那根红色光标也在一个字一个字往后走，可就是没有字。现在读得出来了。

- 手机端终端工具栏最左的键盘键、最右的「全部指令」键，现在和下面输入栏的麦克风、发送键上下对齐了。以前上下两行差了 2pt：工具栏那两颗键的格子比下面两颗宽 4pt，两行都是左右各 12pt 内边距，多出来的宽度就顶得图标往里偏。

- 手机端终端工具栏两侧收紧了：键盘键和「全部指令」键的两侧各去掉一条多余的竖分隔线，中间那排指令也不再自带左右内边距，第一颗指令现在紧挨着键盘键、最后一颗紧挨着「全部指令」。两颗固定键本来就没有底色，它们自己的点击区域里已经各留了一段空白，工具栏上原本是这段空白再加上内边距、再加分隔线，边上一下子堆了三层。指令列表内部按分组出现的竖线不受影响。

- 手机端终端内容不满一屏时，内容的底边现在贴着工具栏，下方不再留白。以前它贴着顶部、空白留在下面，键盘一弹起来占用的正是这块空白，于是最新的几行被挤出可视区，得自己往上滑才能找回来。内容写满一屏之后这个变化不起作用，滚动、跟随最新输出、翻历史时不被拽回底部，这些行为都和以前完全一样。

- 修复手机端「新建」面板里「开始对话」按钮在深色模式下变成一块没有文字的白色方块的问题。按钮的底色和文字此前没有一起反色，深色模式下底色成了白色、文字也是白色，既看不出是什么按钮、也看不出能不能点。现在两者成对反色：深色模式白底黑字，浅色模式黑底白字，文字始终清晰。

- 手机端登录页在浅色模式下、邮箱和密码还没填完时，灰色「登录」按钮上的白字几乎看不清。未填完状态的按钮底色调深了一档，深浅两种模式下文字都读得清。

- 手机端打开应用时不再弹出「操作没有完成」这类提示。以前手机一连上电脑就会自己做几件事——拉一次终端列表、把上次开着的终端重新接上、重申终端尺寸——这些事你都没让它做，但只要其中任何一件没成，就会在屏幕底部弹一条报错。现在这些自己发起的请求失败只写进日志，不打扰你：它们描述的状态本来就已经显示在终端列表和设备行里了。

- 手机端每条失败提示现在都说出自己的原因，不再共用一句什么都说明不了的话。以前电脑端遇到它没法归类的错误就统一回一句「操作没有完成。」，这句话既没说在做什么、也没说为什么停下，看到的人只能得出「这应用又在乱报错」的结论。现在终端层面的失败按它自己的错误类型给出对应说法——终端已经不在了、电脑正在使用、控制权已过期、输出有断档等等；实在说不出原因的，也说清楚是哪个操作没完成（例如「刷新终端列表没有完成。」），不再用一句话回答所有失败。

- 手机端不再对着一个电脑上已经关掉的终端反复重试。你在手机上开过某个终端、之后在电脑上把它删掉，手机会一直记着它，每次重新打开应用、每次从后台切回来都要重新接一次，每次都被拒。现在电脑发来的终端列表就是准的：列表里没有了，手机就把它忘掉。同时打开一个已经不存在的终端会明确告诉你「该终端已结束。」，而不是一句「操作没有完成。」；删除一个其实已经没了的终端不再报错，因为它已经是你想要的状态了。

- 手机端同一个失败不再连着报两次。有些操作手机自己已经会显示结果，但结果回来时又会被当成一次「没人认领的失败」再弹一条底部提示。现在有归属的失败只出现在它该出现的地方。

- 修复管理后台「问题反馈」列表打不开的问题：筛选「未过期记录」的时间条件在数据库侧类型对不上，整条查询直接报错。同一处写法也用在客户端使用情况的过期数据清理上，让它每天定时跑一次、每次都以失败告终，旧数据一直没被清掉。两处一起修好。

## 技术调整

- 本次三端必须按 **服务端 → 桌面端 → 手机端** 的顺序上线，不能颠倒。手机端新增了一种下行消息（`mobile.toolbar`）和 13 个按键，旧的服务端不认识它们，会直接切断整条连接——用户看到的是「电脑/手机莫名离线」，日志里只有一句校验失败，排查成本很高。服务端先上之后，桌面端和手机端的先后是安全的：旧电脑连上来时手机会显示内置的四键兜底，不会空。

- 全键盘这一版又新增了 15 个按键（14 个 `Ctrl+字母` 和 `Shift+Tab`），所以**升级顺序仍然必须是 服务端 → 桌面端 → 手机端**，理由同上：新键名要被三端同时认识，旧服务端遇到不认识的新键名会切断整条连接。这次的键名全都追加在白名单末尾，原有的 23 个一个没动，所以旧手机连新服务端、旧电脑连新手机都是安全的。

- 这一版又新增了一条手机端下行消息（`mobile.quickPhrases`，即「快捷输入」那段列表），所以**升级顺序仍然是 服务端 → 桌面端 → 手机端**，理由与上一条相同：新消息名要先被服务端认识，否则旧服务端会切断整条连接。这一次是**新增一条消息**而不是新增消息里的字段，所以旧服务端遇到它同样会直接断连，不能跳过服务端先发两端。反过来是安全的：新服务端 + 旧电脑时，手机上的指令面板只有「快捷命令」一段，不会出现一个空着的第二段——「这台电脑还没发过」和「这台电脑上没配」在手机上是两个不同的答案。

- 每天凌晨的自动备份现在只在正式部署上执行。开发机上也放着一份生产备份凭证，自动备份一旦跑通，它就会按点把本机数据库传进生产备份桶、混进备份列表——现在按运行环境判断，开发机直接跳过（日志里留一行说明）。管理后台的「立即备份」不受影响，任何环境都能手动触发。
