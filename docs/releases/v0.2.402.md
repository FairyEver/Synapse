# Pending Release Notes

## 新增功能

- 终端支持全局、分组和快捷命令三级启动设置，可配置 Shell、工作目录和环境变量；同名设置按层级覆盖，并可恢复继承或明确不传入。全局入口位于终端顶部工具栏。

## 功能优化

- 终端快捷命令的启动环境会作用于新建的完整会话，已运行会话不受后续设置修改影响；环境变量值采用加密存储。

## 问题修复

- 修复含有快捷命令的终端分组无法保存名称、Shell、工作目录或环境变量设置的问题。
- 修复终端设置弹窗右上角重复显示两个关闭按钮的问题。
- 修复 Markdown 文档在代码块之后添加评论时高亮位置偏移的问题，已保存评论重新打开后也会定位到原先选中的文字。
