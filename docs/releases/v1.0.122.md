## 功能优化

- 邮箱收信自动化（`收到邮件` 触发器）新增可选的前置筛选条件：支持按发件人域名/邮箱、主题关键词以及「仅原发新邮件（排除回复与转发）」在拉取正文和启动 Agent 前直接过滤，减少无关邮件触发与模型消耗。
- 邮箱回复/转发草稿能力支持直接传入完整邮件引用链接（如自动化的邮件 ID 变量）以及回复正文内容，简化 AI 自动回复邮件时的调用步骤。

## 问题修复

- 修复共享同一公网出口 IP 时云盘批量覆盖上传容易触发“云盘请求过于频繁”限流并波及其他同事的问题：服务端认证接口改为按账号独立限流并放宽云盘条目与版本读取上限，桌面端同步减少批量覆盖上传时的重复目录查询并在触发读限流冷却时自动等待重试。
