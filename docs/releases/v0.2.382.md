# Pending Release Notes

## 新增功能

- 平台管理界面迁移到独立的 `/admin` 入口，通过服务端管理密钥解锁；普通用户继续使用 `/console`，两种会话可在同一浏览器中独立并存。

## 功能优化

- 管理后台表格统一列宽、长文本截断、数字对齐、固定操作列和加载骨架，长邮箱、名称与标识不再挤压状态和操作区域。
- 团队、成员关系和团队邀请已从管理界面、用户接口、公开页面及桌面账户信息中移除；原团队与邀请链接不再可用。
- Claude Code 与 Synapse 的组合名称统一显示为“CC/Synapse”。
- Git 仓库克隆改为选择父目录并明确展示最终保存路径；新分支首次推送可选择远端并自动建立跟踪关系。
- Git 操作增加同仓库排队、进度状态、取消与网络/超时重试；大型差异可安全截断预览，不影响提交。
- Git SSH 连接支持用户名、自定义端口和主机指纹确认；凭据助手尊重现有自定义及企业配置链。
- Git 的 HTTP/HTTPS 凭据按实际协议和端口隔离；多远端推送遵循仓库的 Git 配置优先级。

## 问题修复

- 修复 Git 提交预览与实际提交内容可能不一致、未跟踪文件无差异预览、新分支误显示已同步的问题。
- 修复移除 Git 仓库可能删除本地目录、并发操作产生仓库锁竞态、内容仓库冲突同步可能静默选择内容的问题。
- 修复自动内容提交可能夹带用户已暂存文件、提交后状态记录失败可能误报已同步、自动提交身份污染仓库配置的问题。
- 修复仓库注册表从备份读取后未恢复主文件、大提交详情不可用、快速切换历史记录可能显示旧提交的问题。

## 技术调整

- 管理员账号与管理员 JWT 已由 8 小时数据库会话取代；普通用户 Web 登录改用 HttpOnly 不透明会话 Cookie，桌面端登录流程保持兼容。
- 升级迁移会永久删除团队、成员关系、团队邀请及其明确归属的审计历史；升级前必须验证可恢复备份，回滚时必须同时恢复数据库，不能只回滚应用镜像。既有灾备包和服务器日志保留。
