## 功能优化

- 手机端的剪切板弹窗改用系统标准的标题栏：标题居中、右上角「清空」，不再和弹窗顶部的拖拽条挤在同一行。
- 手机端各个「没有内容」的页面改用系统标准的空态样式：一个图标、一句标题、一句说明，读者一眼能看出是这里空了，而不是某句话没写完。
- 录音列表读不出数据时不再自相矛盾：以前会同时显示「读取录音失败」和「还没有录音」，现在只说失败。
- 「我的」页里没有在线电脑时，会像终端页一样给出下一步该做什么，而不只是说一句「没有」。
- 手机端一批按钮的可点范围补到系统规定的 44 点下限：剪切板与快捷输入里的「看全文」、设备行的剪切板入口、重命名输入框的清空键、录音胶囊的「完成」、播放页的 ±15 秒、语音面板的「取消」。按钮画出来的大小没变，变的是手指能点到的地方；录音胶囊会因此变高一些。
- 跟随系统的「减弱动态效果」设置：键盘面板滑入和录音胶囊浮出这两个动画原来没有跟随，现在跟随了。
- 录音重命名弹窗改成和会话重命名同一个形状：半屏加拖拽条，不再是一张全高的弹窗里浮着两行字。
- 会议详情页的标题不再兼作重命名入口（它身上没有任何能点的提示），重命名只保留工具栏菜单一处。
- 会议详情页载入时说明在等什么，和同屏音频区的「正在下载」一致。
- 会话列表可以搜索了：下拉露出搜索框，按会话标题、所在路径、最后一行输出匹配，搜不到时会说明没找到。
- 新建会话里的「项目」和「供应商」两个选择器可以搜索了，电脑端项目多的时候不用一行行翻。
- 录音进行中的悬浮胶囊改成占自己的一条带子，不再压在导航栏上——以前它盖着当前页面的标题和右上角按钮。
- 终端底部命令条最左侧多了一颗「快捷输入」：点开是你在「快捷输入」里维护的那些句子，点一句就填进命令行。句子不会自动执行，按 Enter 才执行。这颗键钉在最左边，指令再多也不会被挤走。
- 终端里原来那套自定义按钮改叫「快捷命令」，和手机端的叫法一致了。以前它和「快捷输入」同名，点开却是两回事。

## 问题修复

- 修复手机端「＋ → 开始对话」按钮**看起来上下被切掉一条**的问题：iOS 26 会把列表里的这一行按分组卡片的圆角裁掉，而卡片圆角比按钮自己的大得多，46 点高的按钮左右两端因此只剩两三点的直边，读起来像一颗被削平了顶底的胶囊。这个按钮改到列表外面画，恢复成正常的圆角矩形。代价是它现在停在面板底部，不再紧贴上面那张卡片——列表会占满中间剩下的高度。
