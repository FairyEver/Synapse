# Pending Release Notes

## 新增功能

- 发版流程新增待发布说明记录机制：日常开发完成后会把用户可感知的功能、优化和修复先记录下来，后续发版成功后再统一整理到 GitHub Release 说明里。
- 系统设置新增“片段”入口，可维护常用多行文本片段，并可在 Agent 对话输入框中直接插入。
- 片段新增“直接发送”开关，新建片段默认可从输入区菜单一键发送，也可在片段列表中快速切换。

## 功能优化

- 管理后台登录页套用 shadcn 登录模板布局，并复用桌面端原版应用图标，让登录页和侧边栏品牌入口更一致。
- 系统设置侧边栏分类改用更清楚的名称，不再为了统一字数牺牲可读性。

## 技术调整
