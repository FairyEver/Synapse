# Pending Release Notes

## 新增功能

- Agent 对话页新增“导出对话”调试包，可将当前会话的消息、工具调用、事件、用量和可读 transcript 打包导出，方便排查问题；敏感密钥信息会自动脱敏。

## 功能优化

- 关于页的当前版本号现在可以直接点击复制，排查版本信息时更方便。

## 问题修复

- 对话页右上角的模型信息现在会同时显示供应商和模型名，新建会话不会只看到供应商名称。

## 技术调整

- 部署脚本现在会合并同步本机 `server/.env` 到服务器，同时保护生产数据库密码等初始化配置不被本机默认值覆盖；部署和重启前也会先校验数据库网络认证，避免服务切换后才发现无法连接数据库。
