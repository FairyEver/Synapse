# Pending Release Notes

## 新增功能

- 新增“密钥库”系统应用，原设置里的私人令牌会迁移到独立应用管理，安装内容时的占位符密钥也改为从密钥库读取和保存。

## 功能优化

- 云盘上传新增任务面板，批量上传时可以查看目标位置、文件列表、整体进度和失败项。
- 云盘批量上传任务会显示当前文件的传输进度和长路径尾部，首个文件耗时较久时也能看出上传是否仍在推进。
- Synapse Skill 现在作为独立系统应用提供安装入口，可直接查看全局编辑器状态并启动安装，不再混在资源仓库的内置资源中。
- 资源仓库移除了通用内置资源分类，列表现在只展示用户仓库中的内容。
- 统一系统应用顶栏样式，右侧操作按钮改为更轻量的无边框紧凑形态，减少顶栏视觉拥挤。
- 选择下拉菜单默认改为从控件附近展开，避免打开时当前选中项把菜单位置顶到中间。
- 自动化列表右侧新增显式编辑入口，查看或调整自动化配置时不用再依赖点击整行。
- 系统应用图标统一增加圆角底座和双层边缘质感，应用列表、Dock 和 Dock 管理里的图标视觉更一致。
- 收紧应用列表的图标、文字和行列间距，底部 Dock 图标间隔也更稳定。
- Synapse Skill 系统应用更换为专属图标，应用列表里和安装器入口更容易区分。
- Synapse Skill 支持按编辑器直接安装、打开目标目录，并可从底部入口进入标准安装流程选择 Agent。
- Synapse Skill 安装列表优化了行内对齐、目录路径展示、未安装项操作和状态摘要，安装状态更容易扫读。
- 密钥库列表默认隐藏已保存的密钥值，现在可以按单条密钥打开弹窗查看完整值并复制，弹窗会明确提示明文状态并给出复制反馈。
- 错误类消息提示默认停留更久，云盘批量上传失败或部分失败时有更多时间阅读原因。
- 普通删除操作支持按住 Option/Alt 点击直接执行，熟悉目标内容时可以跳过二次确认。
- 云盘发布站点会在疑似打包前端项目时提示相对路径配置，并提供可复制给 Agent 的调整建议，减少发布后资源 404。
- 云盘发布站点时会显示“发布中”状态，悬停可查看正在复制的文件数；站点文件复制改为并发处理，文件较多时发布更快。

## 问题修复

- 修复云盘上传任务面板里长路径会挤出右侧状态的问题，路径过长时优先保留末尾文件名。
- 修复云盘批量上传任务进度可能长时间停在 0 后直接跳到完成的问题，现在文件完成数会随上传过程实时更新。
- 修复批量上传云盘文件夹时文件传输或上传确认被普通接口限流误伤的问题，上传类请求现在使用更合理的额度，遇到短暂限流也会等待后再确认。
- 修复密钥库临时显示密钥值时可能一直提示读取失败的问题。
- 修复旧内置资源安装的 Synapse Skill 在新系统应用里显示为冲突的问题，重新安装时会平滑替换为当前版本。
- 修复账号刷新凭证失效后仍显示离线和重连中的问题，开发版现在会正确退出过期登录态，并避免后台同步反复触发异常重试。
- 修复安装 Skill 选择编辑器目标后可能触发页面崩溃的问题，避免安装弹窗进入无限刷新。
- 修复知识库 `/wiki-ingest` 更新旧页面时不会自动补齐 DragonScale address 的问题，避免重新摄入后留下 `wiki-lint` 地址错误。
- 修复 Bridge、Relay、Webhook 等全局 Agent 入口打开托管知识库时误用虚拟路径的问题，外部入口现在会使用知识库真实运行目录并加载对应 runtime 能力。
- 修复知识库 `/wiki-ingest` 静默跳过超过扫描上限的原始资料问题，Agent 现在会收到跳过文件及原因并提示用户处理。
- 修复 Windows/CRLF Markdown frontmatter 在知识库中被误判为空的问题，避免补地址时写出双 YAML 头，并让 DragonScale 与 lint 能识别 CRLF 元数据。
- 统一知识库内部路径归一化逻辑，避免不同入口对 `/` 和 `\\` 混用路径产生不一致的 manifest、lint 或资料管理结果。
- 修复知识库资料导出目标路径存在符号链接且子目录尚未创建时的校验绕过，避免导出内容意外写回 `.raw` 目录。
- 修复知识库资料删除后清单同步失败时错误不明确的问题，现在会记录一致性风险并提示用户检查 `.raw/.manifest.json`。
- 修复知识库资料导出时多个条目之间预算不共享的问题，避免单次导出绕过文件数或总大小限制。
- 统一 Agent 运行时错误消息脱敏逻辑，避免日志或命令错误结果遗漏 Bearer、API Key、平台令牌等敏感信息。
- 修复工作流 Codex / Claude Code 节点额外目录和配置文件路径缺少审计上下文的问题，运行记录现在能保留脱敏后的外部路径资源摘要。
- 修复 Agent 创建脚本工作流时缺少项目要求说明的问题，内置 Workflow 能力现在会明确提示脚本节点需要工作流默认项目。
- 修复工作流取消宽限期超时后运行中节点状态不可信的问题，超时取消现在会记录节点取消结果并忽略迟到完成结果。
- 修复 Agent 发送项目文件夹时被 `node_modules` 里的依赖符号链接拦截的问题，现在可以直接把常见前端项目目录作为附件发送。
- 修复 Agent 输入框粘贴本地路径文本会被误识别成附件的问题，现在复制路径说明时会按普通文字留在输入框里。

## 技术调整

- 修复 mac 发布脚本会把旧版本安装包混入当前版本 CDN 目录的问题，后续发版只会上传本轮版本对应的 mac 产物。
