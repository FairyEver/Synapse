# Pending Release Notes

## 新增功能

- 系统设置新增默认关闭的“Synapse MCP 工具按需加载”实验开关。开启后，新建的第三方 Anthropic-compatible Agent 对话只在需要时发现和调用 Synapse 工具，减少初始工具上下文；已有对话和 Anthropic 官方端点保持原行为，无法安全兼容当前 MCP 或权限配置时会自动回退并提示。

## 功能优化

- IDE 管理列出 Skill 时现在会优先显示由 Synapse 安装的条目；全局和项目范围使用一致顺序，同一来源内仍保持原有排列。
- Agent 现在会按 Provider 官方端点和精确模型 ID 使用内置模型能力目录配置新会话的真实上下文窗口，覆盖百炼文本生成模型及 Anthropic、Gemini、DeepSeek、Kimi、GLM、MiniMax、阶跃和 MiMo 等常用直连模型。用户显式窗口配置仍优先；顶栏继续只以 SDK 实际返回值计算比例，并在提示中区分运行窗口与模型官方上限。
- Synapse MCP 工具按需加载现在会按自然语言关键词覆盖度和语义距离优化搜索排序；查看云盘文件列表等中英文请求会优先返回通用文件列表工具，减少误选站点、回收站或递归工具。
- Agent 对话顶栏现在会实时显示当前主线程的上下文占用和窗口比例；流式回复期间持续更新，自动压缩后同步下降，主界面与独立对话窗口保持一致。回复下方的会话累计用量统计保持原口径。
- Agent 的 Slash 菜单现在优先展示最近使用和通过 Synapse 安装的 Skills，并将其它 Skills、知识库和命令分组排列，搜索与键盘选择保持一致。
- Git 改动与历史提交的差异预览现已显示新旧行号、增删内容和行内差异，并支持统一/分栏视图、自动换行及多文件逐项查看。
- Agent 输入框附件条的顶部与左右留白现已保持一致，附件布局更整齐。
- Agent 对话发送后的消息气泡现在会直接显示图片、文件和文件夹；气泡四边内边距保持一致，多图使用更紧凑的九宫格，消息内最多显示 9 个缩略图，仍可放大查看全部图片。重新打开会话后附件仍可查看，新消息正文也不再显示自动生成的图片占位符和路径清单。
- Agent 对话单轮最多可添加 50 张图片；图片原图现在通过受控路径交给当前模型按需读取，不再生成 Base64 或隐藏批次会话。百炼 Kimi、Qwen 与自定义兼容模型使用同一发送链路，不按 Provider 或模型能力白名单限制。单文件使用受控副本，文件夹只授权所选目录。

## 问题修复

- 修复部分模型在思考期间把高频 token 统计事件逐条显示在 Agent 对话中的问题；内部统计继续保留用于诊断，但不再占满消息时间线或触发重复界面更新。
- 修复 Agent 收到循环引用或异常深层 SDK 元数据时可能丢失诊断事件的问题；事件现在会安全截断并继续完成当前对话，敏感字段仍会脱敏。
- 修复 Git 差异预览读取 CRLF 补丁时可能保留不可见回车字符的问题；Windows 与 POSIX 换行现在使用一致的行级展示。
- 修复超长 Markdown 文档在小范围编辑后重新建立评论定位时可能明显卡顿的问题；未变化块的身份继承现在通过索引完成，长文档增量预览更稳定。
- 修复不含相对图片的 Markdown 预览仍进入图片重写流程的问题；普通文档现在会直接使用服务端渲染结果，避免额外解析并兼容非浏览器渲染。
- 修复 Agent 回复中的思考过程在重新打开会话后可能被拆成大量碎片的问题；SDK 元数据事件不再打断同一段连续思考，工具调用等真实边界仍会正确分段。
- 修复 Synapse MCP 工具按需加载的统一调用入口被误标为只读的问题；可写或外部操作现在会向模型声明真实风险，实际执行仍沿用原工具权限与审计，降级事件也不再保存内部诊断原因。
- 修复 Agent 顶栏上下文详情无法通过键盘打开的问题；用量摘要现在可获得清晰焦点并显示同一提示内容。
- 修复设置页响应式信息布局错位的问题；说明文字现在归入左侧标题列，实验开关、重置操作和服务器状态统一沿右侧基线对齐。
- 修复 Agent 附件发送失败或取消后无法重试、并可能残留已提交附件的问题；失败轮次现在会回退为可重试草稿，受控附件根路径也不会进入时间线或导出内容。
- 修复连续附件消息可能复用旧草稿目录授权的问题；每个附件批次现在使用独立受控范围，附件轮结束后会撤销该轮临时目录授权，后续消息无法继续访问未列出的旧附件。
- 修复文件夹附件的本地绝对路径可能进入草稿界面、历史恢复或导出的问题；界面和导出现在只保留文件夹名称，兼容旧消息的导出也会收敛路径，真实目录仅由主进程用于本轮精确授权。
- 修复切换或初始化其它项目时可能误删当前项目历史附件的问题；附件孤儿回收现在严格限定项目，重新打开会话后已提交图片仍可预览。
- 修复一次选择的附件超过数量或空间限制时可能只保留前半批的问题；配额失败现在会回滚本次选择，草稿不会出现不完整附件批次。
- 修复 Skill 发送失败时仍会被记录为“最近使用”并移除待发送消息的问题；只有成功发送才会更新最近使用记录。
- 修复子智能体结束事件可能覆盖主线程上下文窗口统计的问题；顶栏现在只跟踪主线程用量。
- 修复 Git 差异预览引入独立硬编码色板的问题；增删、行号、区块与行内差异现在统一使用应用主题，并继续支持统一/分栏与自动换行。
- 修复 Git 差异预览在窄窗口或长行下开启自动换行后仍可能横向撑开的问题；读取失败现在会显示明确错误，文件预览可通过原生键盘操作访问，大提交的文件列表也不会再无限拉长详情页。
- 修复 Agent 执行 `/compact` 后顶栏把压缩摘要误显示为完整上下文的问题；压缩完成后现在会读取 SDK 的完整上下文占用，无法读取时不再显示错误的极小数值。
- 修复少数 Provider 暂时报出超过窗口上限的上下文占用时，顶栏提示会显示负数剩余 token 的问题；剩余量现在最低显示为 0。
- 修复 Agent 手动压缩命令无法执行并重复显示错误的问题；现在可使用 SDK 官方 `/compact` 命令压缩当前会话上下文，旧 `/compress` 命令不再提供。
- Agent 对话完成后现在只展开每轮最终回答，中间回复、思考和工具过程统一折叠；同时修复处理组在事件追加时反复展开、折叠并带动页面滚到底部的问题。
- 修复云盘 Markdown 富文本编辑和阅读预览不显示有序、无序列表标记的问题；嵌套有序列表现在会在编辑和浏览时自动显示 `2.1`、`2.2.1` 等层级编号，并保留指定的起始编号，保存内容仍是标准 Markdown。
- 修复 Markdown 流程图左右存在额外留白、显示宽度比正文和表格窄的问题。
- 修复 Markdown 文档目录会显示无关 `heading N` 占位项的问题；空标题不再进入目录，正文定位与评论不受影响。
- 修复 Markdown 正文包含 `<=` 时富文本编辑器误判为 MDX 标签或保存后写入多余转义的问题；普通 Markdown 可继续富文本编辑，MDX 仍保持严格语法检查。
- 修复合法 MDX 组件无法进入富文本模式以及顶层 `import`、`export` 在富文本往返后丢失的问题；含 MDX ESM 的文档会安全地保留在源码编辑模式。
- 修复 CommonMark HTML 注释在富文本往返后被静默删除的问题；含源码注释的文档会保留在源码编辑模式，代码示例不受影响。
- 修复 `.mdx`、`.markdown` 等不支持评论的预览仍显示评论入口、服务端仍接受评论请求的问题；Drive 评论范围与 `.md` 限制保持一致。
- 修复云盘中包含大量文件的文件夹删除、恢复或再次删除时可能提示数据库操作失败的问题；整棵目录现在可以可靠移入和移出回收站，异常目录层级会安全拒绝操作，不会卡住或影响其他账号的文件。

## 技术调整

- Agent Runtime 已升级到 Claude Agent SDK 0.3.245，并同步其官方 SDK peer 版本，以支持上下文窗口配置和 `getContextUsage()` 统计链路。
