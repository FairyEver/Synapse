# Pending Release Notes

## 新增功能

- 云盘 Markdown 图片能力补齐了底层支持：后续编辑器可将粘贴或拖拽的图片上传到当前用户的公共素材，并提供图片来源治理入口，方便文档所有者识别外部图片或协作者素材并进行转存。
- 新增 Sound Notifier 系统应用，可通过 MCP 让 Agent 按消息、输入、完成、长任务完成和错误等场景播放本机声音提醒。

## 功能优化

- 云盘分享页右上角会显示登录状态；未登录访问分享文档时可以直接登录，并在登录后回到当前分享页面。登录入口现在固定在操作区最右侧，并与文件操作分隔开。
- 终端会话顶部新增常用操作栏，可以直接中断当前进程、清空显示，并快速输入 Claude、Codex 和 `code .` 等常用命令。
- 终端顶部操作栏现在更清晰，控制动作和启动命令分组更明确，按钮悬停和按下反馈也更顺手。
- 终端现在支持把本地文件或文件夹拖进去，自动把路径插入当前命令行，包含空格和特殊字符的路径会按终端习惯转义。
- 优化 Agent 对话和终端左侧树形列表的行距、缩进和右侧状态对齐，分组与会话列表看起来更稳定。
- 优化 Sound Notifier 的设置界面，提示音现在按提醒场景展示，不再需要设置默认声音或单独音量；试听时可以设置循环次数和间隔。
- Sound Notifier 试听界面的间隔按钮改为每次调整 100ms；MCP 播放参数仍可传入任意合法毫秒值。

## 问题修复

- 修复分享 Markdown 文档只有可编辑时才能评论的问题；现在登录用户即使只能阅读文档，也可以对选中的文字添加评论。
- 修复云盘 Markdown 编辑和评论的几处边界问题：重新加载未保存内容前会先确认，首次插入公开图片时会说明公开素材链接语义且确认后记住选择，`.markdown` 和 `.mdx` 文件也能使用评论能力，分享可编辑权限文案也更明确。
- 修复公开素材详情里访问日志和历史版本翻页时可能跳回第一页的问题。
- 修复终端顶部操作栏在默认状态下文字几乎不可见、部分窗口里整条操作栏不显示的问题；现在按钮默认保持可读，平台信息暂时不可用时也会正常显示。
- 修复云盘 Markdown 图片转存总是失败的问题；文档所有者现在可以把协作者插入的公开图片转存到自己的公共素材中，成功项会正常替换文档链接，失败的外链会保留原链接并返回明确失败原因。
- 修复 Agent 通过 Sound Notifier 播放提示音时偶尔无声的问题；现在不需要先打开设置页，MCP 触发的声音提醒也会正常发到应用窗口。
- 修复云盘 MDXeditor 里粘贴或拖拽图片没有反应的问题，并新增“插入图片”按钮；选择图片后会上传为当前用户的公共素材并插入到 Markdown。
- 修复云盘 MDXeditor 粘贴或拖拽图片后保存成 `<img ... />` 标签的问题；保存前会统一转成标准 Markdown 图片语法，避免阅读预览直接显示 HTML 标签。
