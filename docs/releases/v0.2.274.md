## 问题修复

- 修复桌面端顶部导航缺少数据库入口的问题，现在可以直接从顶栏进入数据库。
- 修复下载仓库 Skill 时附件缺失仍提示成功的问题，现在任一附件复制失败都会阻止生成不完整压缩包。
- 修复服务端部署镜像构建时因后台类型检查失败而中断的问题。
- 修复关闭所有窗口后点击自动更新通知只唤起应用、不打开更新页的问题。
- 修复 Codex 用量刷新不会因价格规则变化而重算费用的问题。
- 修复 Agent 对话标题过长时导出调试包可能因临时目录名过长而失败的问题。
- 修复内置工具权限检查异常时缺少失败审计记录的问题。
- 修复 Git 同步遇到路径或 Git 状态阻断时仍显示“立即同步”的问题。
- 修复 Quick Input 配置更新日志会记录片段正文的问题。
- 修复内容图片图标会跟随符号链接读取目标文件的问题。
- 修复 auto runner 面板漏显示无尾换行最终输出的问题。
- 修复需要更新的定时任务仍可点击运行的问题。
- 修复 preload IPC 失败日志会记录 Agent 和 Workflow 正文字段的问题。
- 修复状态型金手指快速连续触发时可能丢失一次切换的问题。
- 修复密码重置过程中用户被禁用后仍可能完成重置的问题。
- 修复需要更新的自动化仍可手动运行的问题。
- 修复作者侧内容公开或取消公开缺少确认的问题。
- 修复正式包里自动化 Webhook 触发器列表加载失败的问题，现在会正确读取账号下的 Webhook。

## 技术调整

- 拆分服务端本地开发配置和生产部署配置，部署时会使用生产配置直接同步到服务器，避免把本机数据库地址带到线上导致服务启动失败。
