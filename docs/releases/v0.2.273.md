# Synapse v0.2.273

## 新增功能

- 工作流新增 Codex 节点，可以在本机后台运行 Codex 提示词，并在运行历史中保留调试记录。

## 功能优化

- 工作流 MCP 创建节点时可以同时写入上下游连线，AI 搭建复杂工作流不再需要先保存会被校验拦截的孤立占位节点。
- 工作流 MCP 和内置工作流技能补齐了 Codex 节点说明，AI 通过 MCP 创建工作流时能正确识别 Codex 节点参数和使用边界。
- 工作流 Codex 节点的配置面板调整了顺序，输入、项目和指令会先展示，执行配置下移，编辑常用内容更顺手。
- 工作流 Codex 节点的执行配置更清楚了，模型可以直接输入也可以从建议中选择，审批、沙箱和高级参数都补充了中文说明。
- 工作流 Codex 节点的下拉框选中后只显示简洁值，展开后仍可查看每个选项的详细说明。
- 工作流 Codex 节点可以指定支持变量插值的工作目录，适合上游节点为每个任务准备独立 worktree 后交给 Codex 修改代码。
- 工作流 Codex 节点可以单独指定任务工作目录，适合在项目内的子目录或变量指定目录中执行自动化任务。
- 工作流运行中的状态信息更完整，MCP 发起的运行也会显示节点已解析变量、提示词和进度，排查卡住的节点更方便。
- 云盘公开链接弹窗默认停在分享列表，只保留“分享”和“发布”两个页签，弹窗宽度更紧凑，页签会显示在标题栏中间。
- 管理后台主题设置的默认侧边栏方案调整为标准侧边栏，重置后会回到当前默认外观方案。
- 网盘文件预览页默认把左侧信息区收窄到三分之一，右侧预览区扩大到三分之二，看图片和源码时空间更充足。
- 账号菜单里的用户信息现在可以直接打开自己的管理后台首页，本地开发和正式发布会分别跳到对应环境。
- 账号菜单顶部的用户信息区域更紧凑，打开菜单时不会显得上下留白过大。

## 问题修复

- 知识库资料重命名、移动或删除时会先校验并同步 raw 清单；如果清单写入失败，已移动的文件会自动回滚，避免资料目录和清单不一致。
- 知识库存储迁移会逐文件校验路径、大小和内容，不再让同大小但内容已损坏的副本通过迁移校验。
- auto 控制台刷新或重连后如果历史 worker 输出加载失败，会显示错误并提供重试，不再把空日志误当成正常状态。
- 管理后台受邀新用户从邀请链接创建账号后，登录会继续回到原团队邀请页，不再丢失邀请上下文。
- 管理后台找回和重设密码流程会保留登录前的目标页面，重设完成再登录可回到原页面或团队邀请。
- 管理后台删除备份前会先要求确认，删除请求进行中也会禁用按钮，避免误触或重复删除恢复资产。
- 管理后台删除邀请前会先要求确认，删除请求进行中会禁用按钮，避免误触导致已发送的邀请链接立即失效。
- Bridge AskUserQuestion 卡片现在可以提交答案，外部客户端不再只能跳过需要用户选择的问题。
- Usage Analysis 已打开的对话详情窗口再次定位同一会话的其它事件时，会刷新到新的目标事件，不再只把旧窗口置前。
- 设置页的软件更新状态收到新进展后会清除旧操作错误，不再让失败提示遮住后续检查、下载或安装状态。
- Server 部署文档不再给出可复制的固定数据库密码，改为要求生成随机密码并同步写入连接串。
- Webhook 接收新请求时不再同步硬删旧投递历史，管理员和用户可以继续翻查超过 100 条之前的投递记录。
- 管理后台清理系统日志前会先确认，避免误触删除仍需排障或复盘的日志文件。
- 编辑器目录创建入口会在主进程校验目标必须属于已知编辑器 rules/skills 目录，避免被异常 renderer 请求驱动到任意路径。
- Database 写操作成功后如果最近变更记录或界面刷新通知失败，主进程会留下脱敏告警，便于排查成功写入后记录缺失或界面未刷新的情况。
- Cron 编辑器会把语法合法但没有实际运行日期的表达式标为错误，不再让预览计算崩溃。
- auto 本地控制台会在新运行批次开始时清空服务端 worker 输出缓冲，避免刷新页面后混入上一批次日志。
- 仓库维护成功推送自己生成的整理提交后，不再清空仓库里已有的其它待推送记录，避免旧变更失去重试入口。
- 自动化的 Cron 和固定间隔触发器会把“活跃日”用于计算下次执行时间，不再先排到非活跃日再写入跳过记录。
- 管理后台未登录跳转登录页时会保留原页面的查询参数和 hash，登录后回到内容安装等页面不会丢失上下文。
- 管理后台按日期范围下载系统日志时会包含匹配日期的当前活动日志文件，避免页面能查到但 ZIP 包漏掉当天日志。
- 导入 Provider 配置包时会校验确认导入的文件内容仍然等同于预览内容，避免外部替换文件后导入未确认的供应商配置。
- Automation Ingress 会拒绝非法端口、请求体大小和限流数值，避免错误配置被持久化后导致 webhook 持续不可用。
- Data Store 多选项列编辑会在 SQLite 内聚合使用量和校验删除值，避免把整列 JSON 值一次性拉进主进程解析。
- 管理后台编辑 Skill 时，新建文本文件后会直接选中新文件，不再跳回排序靠前的旧文件。
- 管理后台重置 Webhook secret 前会先确认，避免误点后让旧 Webhook URL 立即失效。
- 普通用户退出登录时，即使成功审计短暂写入失败，也会保持退出成功响应，避免出现会话已撤销但前端误以为退出失败。
- 管理后台新建内容创建草稿时会禁用重复提交，避免慢网络或双击生成多个同名草稿。
- 仓库初始化在备份旧内容后如果后续步骤失败，会自动把原文件移回原位置并清理空脚手架，避免用户内容停留在隐藏备份目录里。
- 部署和重启脚本会使用远端 `.env` 中的 Postgres 用户和库名，已有部署使用自定义数据库身份时不再回退到固定 `synapse`。
- 内置工具窗口加载失败后会清理隐藏窗口状态，再次打开同一工具时会重新创建窗口并重试。
- 删除 Provider 时如果引用迁移只完成了一部分，设置页会停止删除并提示失败数量，不再先提示迁移成功。
- auto 本地 Web 控制台的可变 API 增加同源、JSON Content-Type 和 CSRF token 校验，避免网页跨站请求触发本机巡检。
- Server 容器健康检查会经过 nginx 对外入口，并在 nginx 或 Node 进程退出时让容器退出，避免出现假健康状态。
- 从扫描详情覆盖已有内容时，如果对应编辑窗口已经打开，会重新加载该窗口并应用本次扫描预填内容。
- auto 本地控制台会限制并发、超时和日志保留数量，避免错误配置一次性启动过多本机 worker。
- Automation Ingress Webhook 运行记录会自动保留最新历史并限制列表返回数量，避免长期启用后本地运行历史无限增长。
- 仓库缓存数据库在 schema 初始化失败时也会立即关闭 SQLite 连接，避免异常缓存库在 Windows 上留下文件锁。
- 导出诊断包前会提示其中包含数据库副本，用户确认后才会生成压缩包。
- Side-channel 和回复 outbox 的失败日志不再写入原始 Agent sessionKey，减少诊断日志暴露会话标识的风险。
- Scheduler 停止服务时会尽量停止所有活跃运行，并在失败后清理内存运行状态和定时器，避免半停止状态影响后续操作。
- Reply Outbox 会按回复目标保留最近的已发送记录，避免外部回复长时间运行后本地 outbox 历史无限增长。
- 网盘发布部署失败时写入数据库的错误摘要会先脱敏，避免 token、签名 URL、Authorization 或本地路径进入发布记录。
- MCP HTTP 未运行时，设置页会禁用手动注册，主进程也会拒绝写入无效的 `127.0.0.1:0` 配置。
- Synapse MCP HTTP 不再要求普通 AI 客户端额外配置静态认证头，已注册的 MCP URL 可以直接连接，并会清理旧配置里的静态 Authorization 字段。
- Server Docker Compose 不再为 Postgres 使用固定默认密码，部署时必须显式提供 `POSTGRES_PASSWORD`。
- 工作流 Prompt/Switch 节点遇到供应商鉴权错误时会把节点标记为失败，不再把错误文本当成正常输出继续往下跑。
- 工作流运行时 Agent 的实时输出不再把每段 token 流都写入长期事件和 outbox 记录，并补齐旧事件表的查询索引；主窗口也不会因后台 workflow 会话更新去刷新全量 Agent 会话，避免长输出或切回主窗口时造成无响应。
- 修复工作流 Codex 节点在新版本地 Codex CLI 下启动失败的问题，审批策略和搜索参数会按 CLI 要求正确传递。
- 工作流 MCP 取消运行会返回是否真的向活跃运行发送了取消请求，重复取消或运行已结束时也能明确看到结果。
- 统一 MCP/API 能力调用的审计身份，排查工作流、数据库、变量、自动化等外部调用时可以区分 MCP HTTP 与 MCP stdio 来源。
- Agent 会话删除后，排队中的消息会明确失败，不再静默进入新建空会话。
- 仓库目录校验改为只读，不会在用户选择的目录里自动创建内容目录。
- Git 仓库状态探测、同步、提交、推送和维护命令会进入统一权限与审计链路。
- 外部能力创建或更新的定时任务会保留来源，后台执行时不再伪装成本地用户操作。
- 定时 HTTP 请求的权限审计会移除 URL 中的账号密码部分，避免凭据出现在审计资源里。
- Scheduler MCP 返回运行记录时会对执行摘要和错误做脱敏，并且只保留安全的数值指标，避免历史运行摘要里的 token、Authorization 等敏感内容进入工具结果。
- Scheduler 和 Automation 的命令输出会在写入运行历史前脱敏，界面展示旧历史时也会兜底遮蔽 token、Authorization、Cookie 等敏感内容。
- Repository MCP 的工具描述会准确说明返回 uuid、名称、路径和激活状态，不再提示不存在的变量计数字段。
- 从本地目录上传 Skill 草稿时会先检查主 `SKILL.md` 大小，并把主文件计入总大小限制，避免超大说明文件进入读取和上传编码流程。
- Database MCP raw SQL 会阻止访问任意下划线前缀表，避免创建不进入元数据列表的隐藏表。
- Usage Analysis 打开很长的 Claude Code 对话详情时会先加载首批事件，并支持继续加载后续内容，不再一次性解析和渲染整份 transcript。
- Usage Analysis 刷新会限制 JSONL 扫描文件数和目录项数量；扫描被截断时不会用不完整文件集清理历史记录。
- 新建 Prompt、Rule、Skill 保存失败时会保留当前表单内容，用户可以直接修改后重试。
- Provider 密钥新增、更新和删除的成功审计会记录对应密钥引用，便于追溯且不暴露真实密钥。
- 从 CCS 导入 Provider 失败时，设置页日志只记录错误类型和长度，不再写入可能包含 token 的原始异常内容。
- 导出配置备份时会保留私人令牌变量的名称和描述，但不再把明文变量值写入 JSON 文件。
- 导出 Provider 配置包前会明确确认该文件包含 API Key 和 secret env，成功提示也会标明这是含密钥文件。
- 切换默认 Provider 中途写入失败时会回滚已写入的 active 状态，避免出现多个默认供应商或没有默认供应商的异常状态。
- 生产环境未配置重置链接交付时，找回密码请求会明确不可用且不会创建用户拿不到的重置 token。
- 未配置公开站点 URL 时，密码重置、网盘分享/发布和 Webhook 链接会明确报配置错误，不再从请求 Host 拼出可能被污染的外部链接。
- Webhook 请求日志会脱敏自定义密钥、token 和签名类 header，不再只依赖全局 cookie/authorization 遮蔽。
- Bridge WebSocket 入站消息新增帧大小和字段大小限制，避免本地适配器用超大 payload 拖慢主进程。
- 诊断包导出的日志文件会先脱敏 token、Authorization、Cookie 和敏感 URL 参数，排障时保留上下文但不再携带明文密钥。
- 压缩包创建失败时会先清理命令输出里的 token、Authorization、敏感 URL 参数和本地路径，再展示错误详情。
- 导入 Provider 配置包时，外部包里误放在普通 env 的 token、API key 等敏感变量会自动进入密钥存储，不再作为普通配置落库。
- Server 请求日志会脱敏 URL query 里的密码、token、secret 和 API key，网盘公开链接带密码访问时不会把密码写进访问日志。
- Server 审计失败摘要会脱敏 `accessToken=`、`refreshToken=` 等 token key 变体，避免失败审计落库真实凭据。
- Drive 本地存储会主动清理过期的上传和下载临时 token，减少长时间运行后的无效内存占用。
- Drive 公开分享下载会在当前请求内完成校验并直接流式返回文件，取消分享或链接过期后不再保留短时可用的存储直链。
- 工作流运行快照会在保存前脱敏运行参数，历史记录不再保留参数里的 token、密码或 API key 明文。
- Automation 和 Scheduler 调用子工作流时，写入运行历史的子工作流输出会先脱敏，不再绕过工作流快照清理规则。
- 保存模型价格规则时，空模型匹配或非法价格会明确保存失败，不再静默丢弃规则或把价格改成 0。
- 清空模型价格规则会写入结构化操作日志，排查误清空或清空后导入失败时能看到前置动作。
- 从本地目录导入 Skill 失败时，日志会脱敏路径和错误里的 token，不再写入完整外部目录或原始敏感错误。
- 用户注册成功后如果审计日志短暂写入失败，注册结果仍会正常返回，不再出现账号已创建但页面提示失败。
- 登录、找回密码请求、密码重置和桌面登录成功后如果审计日志短暂写入失败，已生效的凭证、重置链接或密码变更仍会正常返回结果，不再误提示失败。
- 修改个人资料时，如果审计日志短暂写入失败，资料保存结果仍会正常返回，不再出现提示失败但昵称已改变的状态。
- Dashboard Cookie 会话校验遇到数据库故障时会返回认证服务暂不可用，并记录安全错误摘要，不再误报为登录过期。
- Dashboard 退出登录时即使审计日志短暂写入失败，也会继续撤销会话并清理登录 Cookie。
- 替换安装 Skill 时，桌面备份路径会单独经过权限检查和审计，并使用唯一备份目录，避免静默删除已有备份。
- 内容图片图标读取会先检查 `icon.png` 是否为文件且未超过大小上限，避免异常大图标在列表或编辑预览中拖慢主进程。
- 管理员设备列表会显示仍在线但设备元数据暂未落库的桌面客户端，和用户自己的设备列表保持一致。
- 管理后台系统概览的 7 天趋势改为固定数量的数据库计数查询，不再把窗口内所有审计日志和实体明细拉回服务端分桶。
- 管理后台创建邀请时不再预加载全部团队；打开弹窗后按团队名搜索并只加载当前结果页。
- 管理后台批量删除邀请现在限制单次最多 100 个，并且审计日志只记录少量 ID 样本，避免异常请求放大数据库和日志负载。
- 内置转换工具运行中可以停止，关闭工具窗口也会终止正在执行的转换 worker，避免后台继续占用资源或写出文件。
- 取消更新下载后立刻重新检查时，旧下载的取消事件不会再清掉新一轮手动检查流程。
- 普通用户使用管理员邮箱注册失败时，审计日志只记录“邮箱已注册”，不再额外标记为基础设施异常。
- Live 客户端 registry 会定期清理已离线超过保留时间的连接记录，避免在线设备查询长期累积旧客户端。
- 管理后台云盘删除改为应用内确认弹窗，删除中会保持受控加载和禁用状态。
- 仓库同步遇到远端分叉时会按原始 Git 输出识别 non-fast-forward，并继续尝试自动 rebase，不再被中文错误提示阻断。
- DataRepository replace 导入在删除旧条目阶段失败时会恢复已删除的旧数据，避免备份恢复失败留下部分缺失状态。
- auto 本地 Web 服务会按真实路径边界校验静态资源请求，阻止同前缀兄弟目录被 `/assets/` 路径读到。
- 官网 Synapse MCP reference 已把 Variable MCP 描述同步为用户本机变量，避免继续按旧的仓库变量语义理解。
- 诊断包不再附带完整配置备份，改为写入不含变量值、绝对路径和 identity 的配置摘要。
- IPC runtime 在部分 handler 安装失败时会回滚已经安装的 handler，避免留下无法在诊断列表中看到的孤立通道。
- 知识库资料导出会在复制前检查选中数量、递归深度、文件数和总大小，超限时跳过对应条目，避免误选大目录导致主进程长时间复制。
- 审计事件持久化失败时，主进程日志会先脱敏底层错误中的 token、Authorization 和本地路径。

- 知识库存储迁移恢复记录会用原子替换写入；如果崩溃后恢复记录损坏，启动恢复会进入明确失败状态，不再直接中断恢复流程。
- Agent 会话导出包会遮盖 `sessionKey`，manifest、summary、timeline、conversation 和审计记录不再包含原始会话标识。
- 自定义知识库存储位置不可用时，资料管理窗口会在打开前被阻断，并提示先到设置中重新检测。
- 转换工具选择“仅返回结果”时会直接显示返回的 Markdown/文本，并提供复制按钮，不再只显示运行成功。
- Git 同步失败详情会先遮盖远程 URL 凭证、Bearer 和平台 token，再进入同步状态或待推送失败记录，同时保留普通本地路径用于排查。

## 技术调整

- 清理未接入生产路径的 IPC handshake 和 runtime scheduling 示例模块，减少仅靠测试自证的死代码。
- 收敛多处重复的错误日志元信息提取逻辑，统一记录错误名称、长度、可选错误码和脱敏消息。
- 知识库只保留实际有生产消费者的公开服务出口，未接入的 hot-cache 状态不再从模块 barrel 暴露。
