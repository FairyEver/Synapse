# Pending Release Notes

## 新增功能

- Desktop 本地 Skill 详情里新增“发布到商店”，可以把已安装 Skill 保存为云端草稿，并自动打开 Console 编辑页继续补充和发布。
- Console 新增“网盘”入口，用户可以在网页端浏览自己的云盘文件夹、下钻查看文件、预览图片/文本/HTML 源码，并下载文件或文件夹压缩包。
- 云盘分享链接改为统一的文件浏览器承接页，拿到链接的人可以浏览分享文件夹、预览支持的文件类型，HTML 分享默认看源码而不是直接执行网页。

## 功能优化

- 知识库支持迁移到自定义存储位置。迁移期间会显示不可绕过的进度窗口，只有安全取消或完成后才能关闭；自定义位置不可访问时会暂停知识库操作，并提供重新检测。
- 云盘分享和页面/站点发布会先确认密码与有效期，成功后展示可直接使用的访问链接、密码和到期时间，已分享/已发布列表也能复制带密码链接与密码。
- 云盘分享和页面/站点发布的有效期新增 3 天选项，并默认选中 3 天，短期分享更顺手。
- 云盘发布站点前会先检查文件夹根目录是否有可用的 `index.html`，没有入口文件时会直接提示，避免进入发布设置后才失败。
- 云盘文件列表新增预览入口，可以直接打开网页预览或浏览已上传内容，不需要先创建分享链接。
- 云盘里的 Markdown 文件现在也可以直接访问为渲染后的网页，表格、任务列表和代码块会按文档样式展示。
- 优化云盘分享、发布相关弹窗的布局和表格可读性，长链接、日期和操作按钮在弹窗里更不容易挤在一起。
- Usage Analysis 的今日页刷新按钮改为“刷新今日”，并且只刷新今天有变化的记录，查看当天用量时等待时间更短。
- 管理后台地址统一为 `/console`，旧的 `/dashboard` 地址会继续跳转到新的控制台入口。
- 优化模型价格覆盖表格，长模型名、来源、定价状态和费用数字现在更容易扫描，窄窗口下也不会互相挤压。
- CC 和 Codex 用量页进入时会自动刷新一次本机记录，并限制短时间内重复切换导致的频繁刷新。
- 新添加的价格规则会显示在表格最上方，便于立即填写和检查。
- 价格规则改为按需导入预设包；升级后会保留已有规则，用户可以先清空旧规则，再导入 DeepSeek 官方、阿里云百炼等预设。
- 阿里云百炼价格预设补齐文本模型、显式缓存和隐式缓存价格，导入后对千问、DeepSeek、Kimi、GLM、MiniMax、MiMo、Stepfun 等模型的费用估算更完整。
- 本地扫描详情的操作菜单按仓库/商店、废纸篓、复制到编辑器分组，多个操作放在一起时更容易扫读。
- Console 内容编辑页改为固定分区布局，文件列表和正文编辑器各自滚动，编辑长 Skill 时不会再和页面滚动互相抢焦点。
- Console 内容编辑页优化了表单、发布操作和 Skill 文件编辑区的布局，加载、错误、空文件和二进制文件状态更清楚，窄窗口下也更不容易挤在一起。
- Console Skill 编辑页把标题、描述和公开状态移到右侧属性栏，保存和发布放到页头，打开页面后可以直接看到更高的文件编辑区。
- 设置里的项目和知识库管理改为更紧凑的列表布局，路径、类型和操作更容易对齐扫读，空状态、加载状态和读取失败状态也更清楚。

## 问题修复

- Usage Analysis 今日页刷新时不再把按钮文案变成“刷新今日中”，加载图标会单独表达正在刷新。
- 修复 Console 我的内容详情页点击“编辑”后仍停留在详情页的问题，现在会正常进入编辑页。
- 价格规则不再把内部规则 ID 当作模型名称展示，并会迁移旧规则的内部 ID，避免模型匹配值和名称不一致造成误解。
- 修正 OpenAI 价格预设中 GPT-5.3-Codex 的价格，导入预设后的费用估算会更贴近官方 API 价格。
- Agent 手动停止后的结果会按“已停止”展示，不再把底层 SDK 中断误报成执行失败；真实网络或供应商中断仍会按失败提示。
- 修复从 Console 点击安装内容时 Synapse Desktop 安装窗口加载失败的问题，安装会话现在能正确读取并继续后续安装流程。
- 修复网页端网盘点进文件后仍显示上一级文件夹的问题，文件预览页现在会正确展示源码、图片或下载提示。
- 修复网页端网盘下载 COS 文件时文件名丢失的问题，下载后的文件会保留原始名称和扩展名。
- 修复本地开发环境中客户端登录仍打开旧 `/dashboard` 地址时出现 Vite base URL 错误的问题，旧登录地址会自动跳到新的 `/console` 承接页。
