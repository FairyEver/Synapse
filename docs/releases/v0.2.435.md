## 功能优化

- 终端支持在右侧递归左右、上下分屏；左侧仍以一个终端展示整个分屏工作区，并可一次关闭全部分屏和历史记录。macOS 与 Windows 均提供分屏、方向切换和关闭当前分屏的快捷键。
- 终端设置新增外观分类，可在小、中、大三档字号之间切换并记住选择。
- 终端持续输出时，重命名、分组设置和快捷命令等操作不再等待输出保存队列清空，提交后可立即生效。
- 终端持续输出改为批量增量保存，并降低恢复快照生成频率；长时间运行、输出内容较多时，滚动与交互不再被高频全量落盘持续拖慢。
- 终端文字行距更加紧凑，并加入短时平滑滚动，浏览较长输出时的滚动跳动感更轻。
