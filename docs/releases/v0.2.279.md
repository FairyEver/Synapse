# Pending Release Notes

## 新增功能

- Agent 对话支持在独立窗口中固定打开；主界面再次选中该对话时会提示已在新窗口打开，并可一键显示窗口。

## 功能优化

- 云盘列表把分享和上传状态并入名称列，已分享文件的行操作改为“取消分享”，删除也用同样的文字按钮移到行内，上传文件和上传文件夹收进统一的“上传”入口。
- 云盘的上传、新建文件夹、我的分享和刷新统一移动到顶部工具区，路径行只保留当前位置和状态。
- 云盘文件列表的行操作列去掉了可见表头文字，减少右侧重复信息。
- 云盘列表里的“已分享”状态现在可点击查看已有分享链接、密码和到期时间。
- 云盘列表中的文件名和文件夹名现在可以直接选中复制，点击名称本身不会进入文件夹。
- 云盘文件名和文件夹名支持右键菜单，可复制名称、复制网盘路径或直接重命名。
- 云盘列表行操作中的“打开”改为“预览”，更准确表达会打开独立预览页。
- 云盘分享完成弹窗调整了链接操作和密码信息排版，窄窗口下不再挤在同一行。
- Agent 对话独立窗口默认打开为 700×820，并保持 400×300 的最小尺寸，放大时不再设上限。
- Agent 对话里的用量统计在窄宽度下会自动排成两行，减少统计数字拥挤和截断。
- 知识库对话的资料管理入口移到输入框的知识库菜单里，顶部工具栏在不同对话类型下保持一致。

## 问题修复

- 修复独立云盘文件页中“在云盘中查看”没有跳回控制台对应位置的问题。
- 修复删除已在独立窗口打开的 Agent 对话后，独立窗口仍停留在旧对话界面的问题；现在删除成功会自动关闭对应窗口。
- 修复 Agent 独立窗口中从空闲提示新建对话后窗口目标没有完整切换的问题，现在会在原窗口内干净切到新会话。
- 修复 Agent 主界面的占位提示偏上显示的问题，现在未选择会话、独立窗口提示和空对话提示都会在右侧内容区居中呈现。
- 修复客户端多个账号功能同时刷新登录态时可能误掉登录的问题，例如云盘和实时连接同时恢复时不再互相抢占刷新令牌。
