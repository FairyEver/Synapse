## 功能优化

- Anthropic 内置模型价格补齐了 Claude Fable 5、Claude Opus 4.8 等新模型，并按最新官方价格和人民币汇率重算，费用估算更贴近当前账单。
- 价格管理的模型覆盖页调整了规则匹配和费用统计文案，更容易区分当前规则是否匹配以及历史记录中已计算的费用。
- 云盘文件预览顶栏的文件操作更克制，优先显示“在云盘中查看”“历史版本”“打开方式”，下载等次级操作收进更多菜单。
- Git 改动页的提交说明改为弹窗填写，文件全选操作移到改动列表顶部，查看差异时不再被底部提交区占用空间。
- Git 仓库工作台顶部信息更紧凑，提交、选择和分支操作分区更清楚，查看改动时能保留更多差异区域。

## 问题修复

- 修复 Git 仓库详情页缺少返回入口的问题，现在可以从改动详情回到仓库列表。
- 修复云盘 Markdown 预览中宽表格会撑出或挤压阅读区域的问题，长路径和多列表格现在会在表格区域内横向滚动，说明列不再被压成竖排。
- 修复云盘列表列宽分配不合理的问题，公开素材、回收站和分享列表的时间、类型与操作列不再互相挤压。
