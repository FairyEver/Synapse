# Pending Release Notes

## 新增功能

- Synapse MCP 新增终端分组、会话创建、读取、输入、调整窗口和停止能力，Agent 可直接继续操作 Synapse 终端会话。
- 新增“终端”系统应用，可在 Synapse 内创建、查看、输入和删除终端会话。
- 新增截图能力，可在系统应用中测试全屏/区域截图，也可供 Agent 对话、MCP 和工作流复用，并支持框选区域、隐藏当前窗口、复制到剪贴板或保存为 PNG。

## 功能优化

- 顶部入口升级为 Dock，Agent 对话、工作流、云盘、自动化、应用和设置都按系统应用统一固定展示。
- Dock 当前应用改用底部蓝色小圆点标记，移除图标激活时的浅灰背景。
- 应用体系补齐系统应用入口，内置功能和普通应用在同一套应用模型中管理。
- 应用页改为更接近系统启动台的图标网格，只保留图标和名称；点击应用会先在当前窗口打开，也可以从应用内切到独立窗口。
- 终端应用支持直接重命名和删除会话；删除运行中的终端时会先停止会话，并清理对应的保留输出。
- 收紧终端应用布局，右侧只保留终端区域，会话状态集中在左侧列表展示。
- 终端应用补齐分组管理，可新建、重命名和删除分组；删除分组时会一并清理组内终端会话。
- 终端分组现在可以设置默认目录和启动命令，新建该分组下的终端时会自动进入目录并执行命令。
- 终端分组设置里的默认目录支持直接打开本机文件夹选择器，不必手动粘贴完整路径。
- 终端应用会话栏改用与对话列表一致的分组样式，分组、选中态和行内操作更统一。
- 终端应用会话栏背景与对话列表保持一致，减少应用内不同侧栏之间的视觉跳变。
- 终端应用会话列表改用在线和断开图标展示状态，名称前方即可快速区分运行中与已断开会话。
- 终端应用会话栏移除分组标题和会话列表多余的左侧缩进，列表边界更贴合侧栏。
- 终端应用会话行的删除入口改为外显按钮，双击会话名即可重命名，删除会话不再二次确认。
- 优化终端应用的默认渲染效果，使用更适合 Powerline 分隔符的渲染路径，让 prompt、块状光标、字体和深色终端区域更接近 iTerm2。
- 终端应用移除单独的 Agent 控制开关，Agent/MCP 控制终端时不再需要先手动开启会话级授权。
- 更新终端应用图标，让应用列表和窗口入口更容易识别。
- 调整终端应用的操作层级：移除嵌入页头里多余的新建终端入口，终端创建仍保留在分组和空状态里。
- 更新截图应用图标，让应用列表和窗口入口更容易识别。
- Agent 对话输入框暂时移除截图入口，截图能力先保留在系统应用中统一使用。
- 更新 IDE 管理应用图标，让应用列表和窗口入口更容易识别。
- 更新模板生成文档应用图标，让应用列表和窗口入口更容易识别。
- 更新启动台图标，让 Dock 和应用入口的识别更统一。
- 启动台在最小窗口尺寸下也保持五列图标布局，减少入口换行带来的空间浪费。
- 更新对话、工作流、云盘、自动化、应用和设置应用图标，并将 Dock 调整到底部，同时放大图标与账号入口的可点击呼吸区，让入口更容易区分。
- 收紧底部账号入口的 hover 区域和左右留白，登录按钮在窗口圆角旁看起来更规整。
- 调整 Dock 固定入口顺序：对话、云盘、自动化、工作流、终端、设置、启动台。
- 主窗口打开应用时会按入口智能显示应用顶栏：从启动台进入保留返回和新窗口入口，从 Dock 进入只在应用需要工具栏内容时显示顶栏。
- Dock 暂时恢复为系统默认固定入口，不再支持从启动台拖拽固定、右键取消固定或拖拽排序，后续会重新设计自定义方式。
- 主窗口启动时会打开 Dock 里最靠左的可见应用。
- 更新官网文档为开发者视角，补齐桌面端当前能力说明，并将 GitHub 入口指向发布下载页。

## 问题修复

- 修复工作流 Claude Code 节点在配置额外目录或工具白名单时，可能把整段任务指令误当成命令参数，导致浏览器 MCP 实跑任务没有真正执行的问题。
- 修复终端应用嵌入到“应用”页时，顶部操作区可能反复刷新导致点击“新建终端”没有反应的问题。
- 修复终端会话行的更多菜单可能出现在页面左上角的问题。
- 修复终端应用创建、读取输出或写入输入失败时只写日志的问题，现在会在界面上提示失败。
- 修复终端会话断开后界面看起来还能输入但没有响应的问题，现在会以只读状态展示。
- 修复终端应用启动时可能因本地 `node-pty` helper 不可执行而导致主进程崩溃的问题。
- 修复终端分组启动命令过早写入导致打开终端时命令先在空白区域回显、看起来像执行两次的问题。
- 修复 MCP 控制终端时可能绕过权限审计的问题，并让应用退出时未结束的终端会话在下次启动后显示为已断开，而不是误标记为手动终止。
- 修复工作流运行结果窗口偶尔被带到依赖源码页面的问题，现在会拦截异常主窗口导航并记录更清晰的加载诊断。
- 修复截图应用区域框选时出现白屏、无法完成选择的问题，并让“隐藏当前窗口”只作用于发起截图的 Synapse 窗口；同时优化保存位置文案和表单对齐。
- 修复普通用户仍可能从 Dock、启动台或直接窗口入口看到/打开工作流的问题；金手指开启后工作流会按 Dock 配置位置恢复显示。
- 修复 Dock 激活圆点与图标重叠、图标看起来上移的问题。

## 技术调整

- Synapse MCP 工具主命名迁移到 `app_*` 体系，并同步更新内置 Synapse Skill；旧数据库工具名继续作为兼容别名可用，避免影响已硬编码数据库工具名的固定工作流。
