## 问题修复

- 修复「我的 → 诊断日志」里**「记录终端屏幕内容」开关在深色模式下看不出开关状态**的问题：深色下它整条轨道是一片白，圆点也是白的，开着和关着看起来都是同一个白方块。现在这个开关在深色和浅色下都用系统绿表示「开」，和设置里的其它开关一致。
- 修复登录按钮和「＋ → 开始对话」按钮**两端圆角过大、看着像被上下各切掉一条**的问题：这两个按钮只有 46 点高，圆角却几乎占满了整个高度，左右两端看着像一颗被削平了顶底的胶囊。现在恢复成正常的圆角矩形。
- 修复手机端看电脑终端时**画面自己反复上下滚动**的问题：电脑一次发不完的较长输出会被分成几批，手机把第一批当成了这次输出的结尾，于是先把已经收到的后面一截删掉，等剩下几批到了再滚回来。输出密集时一批接一批，看起来就是终端自己在上下乱滚。现在按整次输出的结尾处理，画面不再来回跳。
