## 新增功能

## 功能优化

- 涉及 CC/Synapse 的安装、设置和 Agent 选择项统一使用新的显示名称。
- Agent 对话中的助手消息头像统一显示为 Synapse 图标。
- 工具页打开的转换工具窗口默认变窄，并支持后续按单个工具配置窗口尺寸。
- 应用主窗口启动时默认高度增加，打开后可见区域更充裕。
- 创建自动化时，触发条件和执行操作的选项行更紧凑，内容较少时不再撑出空白。
- 顶部导航中的“本机”更名为“IDE”，设置侧边栏中的“本地仓库”“本地项目”“片段”“编辑器”“变量替换”更名为“资源仓库”“项目和知识库”“提示词片段”“本机IDE”“私人令牌”，入口含义更清晰。
- 私人令牌现在归当前用户所有，切换资源仓库不会再切换令牌；旧仓库里的变量会自动合并保留。

## 问题修复

- Agent 默认可执行轮次上限提升到 200；执行受限、超时或异常停止时会显示中文原因和继续方式，不再表现为空结果或直出英文错误。
- 新建知识库的资料页不再显示内部占位文件，用户只会看到自己添加的真实资料。
- 修复开发环境中长时间对话后偶发白屏的问题，并恢复主窗口的开发者工具快捷键。
- 知识库资料管理的面包屑移到操作栏下方独立显示，目录层级较多时不会再挤乱搜索和上传按钮。
- 自动化编辑窗口左右两栏现在各自独立滚动，右侧配置较长时不会带着左侧一起滚动。
- 自动化编辑窗口的长配置滚动条贴近窗口边缘显示，内容留白不再把滚动条挤到内侧。
- 权限模式菜单收窄，一级选项不再重复展示风险等级，风险说明集中放在二级详情里。
