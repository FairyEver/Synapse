## 问题修复

- 修复仓库身份资料刷新失败时误挡住整个应用的问题；本地身份已正常读取时，应用会继续打开并记录刷新失败。
- 修复手动触发 Agent 定时任务后可能自动跳到同项目其他会话的问题；现在只跟随定时任务生成的会话更新。
- 修复启动时配置读取失败后误用默认配置继续进入应用的问题；失败时会停在配置读取错误状态并支持重试。
- 修复仓库切换期间旧内容刷新结果可能覆盖新仓库列表的问题，避免 Rule、Skill、Prompt 展示错仓库内容。
- 修复仓库切换时 pending push 状态读取失败会中断切换流程的问题；切换后的内容列表会继续清空并刷新。
- 修复初始化已有目录失败后仓库条目残留在配置里的问题；失败时会回滚刚写入的仓库配置。
- 修复删除供应商时密钥清理失败会先移除供应商记录的问题；现在密钥清理失败会保留供应商，方便用户重试删除，避免残留孤立密钥。
- 修复供应商保存失败后密钥可能已经被新值覆盖的问题；现在元数据写入失败会回滚本次 API key 和敏感环境变量变更。
- 修复 Provider 配置 JSON 中自定义 token、API key 等敏感环境变量会按普通配置保存并回显的问题；现在这些值会进入密钥存储。
- 修复删除托管知识库项目后运行目录残留的问题；现在删除项目会先清理托管目录，清理失败时不会移除项目配置。
- 修复设置页打开知识库资料管理失败时没有反馈的问题；现在失败会提示用户，并避免重复点击。
- 修复被定时任务或工作流引用的供应商仍显示可直接删除按钮的问题；现在会要求先迁移引用。
- 修复新建知识库失败时可能直接显示底层文件系统错误的问题；现在界面只显示固定失败提示。
- 修复 MCP 配置文件损坏时设置页误显示为未注册的问题；现在会显示配置读取失败，并避免继续注册覆盖。
- 修复片段新增、编辑、删除、置顶和直接发送切换保存失败后缺少反馈的问题；现在失败会保留当前操作界面并提示重试。
- 修复新建托管知识库时项目配置保存失败会遗留运行目录的问题；现在会自动清理刚创建的目录。
- 修复配置备份导入/导出 IPC 返回值与前端类型不一致的问题；成功结果现在统一返回文件路径。
- 修复仓库初始化和初始化预检缺少主进程操作日志的问题；现在失败排查能看到对应仓库和请求结果。
- 修复内容模块多个写入和窗口 IPC 入口使用宽泛请求校验的问题；这些入口现在会先校验必要字段，避免畸形 payload 直接进入内容服务。
- 修复配置备份导入、导出和回滚日志会记录用户选择文件绝对路径的问题；日志现在只保留脱敏占位，避免导出日志泄露本机目录信息。
- 修复 Usage Analysis 刷新时单个日志文件被轮转或删除会导致整次刷新失败的问题；刷新会跳过该文件并使用通用错误提示，避免界面暴露本机路径。
- 修复新建 Rule / Skill / Prompt 时用户填写的标题会进入主进程日志的问题；创建请求日志现在只记录内容类型，避免诊断日志带出用户内容摘要。
- 修复审计记录的资源字段会保留本机 POSIX 绝对路径的问题；权限审计现在会脱敏用户目录路径和敏感参数，减少日志与审计数据中的隐私泄露。
- 修复知识库导入、扫描、manifest 读取和资料管理失败时缺少主进程日志的问题；失败原因现在会写入脱敏日志，便于排查导入失败、索引损坏和批量操作异常。
- 修复知识库 manifest 和地址计数器直接覆盖写入的问题；现在会先写入临时文件再原子替换，降低崩溃或断电导致索引与地址数据损坏的风险。
- 修复 Git worktree 仓库 rebase 失败后无法自动中止的问题；同步、内容提交和仓库维护会通过 Git 自身解析 rebase 状态，兼容 `.git` 文件形式的 worktree。
- 修复 Editor Scan 读取 Skill 主文件时会跟随符号链接的问题；扫描详情和快速发布现在会拒绝 symlink 主文件，避免读取扫描根外内容。
- 修复打开外部链接时完整 URL 被写入权限审计或 renderer 日志的问题；审计和失败日志会脱敏 userinfo 与敏感查询参数，实际打开仍使用原始链接。
- 修复托管知识库运行目录被替换为符号链接时仍会继续写入的问题；知识库服务现在会拒绝 symlink 根目录，避免写入落到非预期真实目录。
- 修复数据库 MCP 注册写入编辑器配置时绕过权限检查和审计的问题；手动注册与启动自动注册都会按外部文件写入记录允许、拒绝或失败结果。
- 修复 Automation Ingress webhook 未认证请求不计入限流、且可通过伪造 `x-forwarded-for` 绕过限流的问题，降低 token 探测风险。
- 修复内容安装或卸载已经成功后，安装状态刷新失败仍误报失败的问题；后置刷新异常会记录日志，不再影响已完成的操作。
- 修复工作流在其他窗口或外部路径被删除后，已打开编辑器仍显示旧内容的问题；编辑器会刷新到已删除提示。
- 修复 Bridge Adapter 和 Side-channel 本地监听被权限策略拒绝时缺少审计记录的问题，启动失败原因更容易追踪。
- 修复配置备份导入会丢失收藏、最近查看、排序偏好、仓库变量和 Agent 默认设置的问题，恢复配置时会保留这些字段。
- 修复安装状态缓存初始化失败会阻断桌面应用启动的问题；编辑器扫描目录不可读时会降级为空结果并记录日志，不再导致启动失败。
- 修复 run-as 配置更新缺少权限检查和审计的问题；启用 run-as 或关闭 preflight 前必须已有通过的 preflight 结果，避免绕过安全前置检查。
