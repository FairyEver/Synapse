## 功能优化

- Agent 回复下方会持续显示输入、输出、缓存读和缓存写 token 消耗，切回历史会话后仍可查看。
- 定时任务运行详情和工作流节点详情也会显示 Agent 调用的输入、输出、缓存读和缓存写 token 消耗。

## 问题修复

- 修复服务端多处审计和权限边界问题：模块权限读取会过滤已失效权限，用户登录审计会记录当次模块权限，越权访问 admin/user/team 端点会返回更准确的 403 并留下审计记录，备份和模块权限操作的失败审计也能关联到正确目标。
- 修复备份下载中途失败时连接未主动中断的问题，避免用户拿到看似成功但实际截断的备份文件。
- 修复批量删除邀请在并发场景下可能返回不可信结果的问题，删除数量不匹配时会整体失败。
