- 新增「状态同步」实时共享 JSON 状态树服务：支持同步空间与动态房间生命周期管理、路径级细粒度读写与订阅、乐观并发事务、掉线自动清理与在线成员感知，配套控制台管理页与实时 JSON 调试台、API 密钥空间权限范围与空间专属角色凭证、开放接口与中文文档，以及桌面端 MCP 能力和系统 Skill 指引，可直接用于多人联机小游戏与协同网页。
- 新增「开放 SDK 静态分发与版本发现」：提供零依赖的浏览器与 Node.js 通用状态同步 SDK，支持页面标签直引、ESM/CJS 导入及统一版本清单发现，无需安装依赖即可快速接入。
