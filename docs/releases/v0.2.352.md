## 功能优化

- 进入“关于 Synapse”时会自动检查更新；发现新版本后可选择“下载并安装”，下载完成会在可见的 3 秒倒计时后安装，也可选择稍后安装。
- Skill 卡片的安装目标图标现在用于重新安装；“可更新”支持选择多个安装目标批量更新，并可单独重试失败项。
- 密钥列表的查看按钮调整到掩码值右侧，各行操作位置更统一。
- 自动化的活跃日改为带勾选标记的星期选择器，Cron 和固定间隔的选中状态更直观。

## 问题修复

- 修复 IDE 管理卡片中勾选框、标题和路径信息没有对齐的问题，并移除路径前的装饰图标。
- 修复重新安装和更新 Skill 弹窗中勾选框、编辑器图标与名称没有垂直对齐的问题。
- 修复新建对话时智能体选项的长名称或说明可能超出下拉框边界的问题。
- 修复工作流分享包导入或更新后自动打开编辑器时，撤销入口可能在后台窗口过早消失的问题。
