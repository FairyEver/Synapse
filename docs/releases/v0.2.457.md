# Pending Release Notes

## 新增功能

- 云盘 Markdown 文件可从更多菜单直接导出为简洁的 A4 PDF；本人文件和已解锁分享均支持，云盘相对图片、托管图片、公共素材及安全的外部图片会随正文一并输出，失效图片和图表会以占位与数量提示继续完成导出。

## 功能优化

- 云盘文件、文件夹和网页分享在桌面端与网页端复制链接时，统一附带分享类型和名称，便于直接粘贴给他人。
- 埋点统计新增按访问会话计算的浏览器、浏览器版本、操作系统和系统版本分布及筛选；网页访问会识别常见浏览器，桌面端可区分 Windows 7/10/11 并记录 macOS 版本，离线积压事件也会保留采集时的系统归属。

## 问题修复

- 修复部分旧版浏览器打开云盘分享链接时直接显示 500 的问题；Windows 7 + Chrome 91 等能力不足的浏览器会自动进入轻量阅读页，仍可查看、浏览文件夹、输入分享密码和下载文件。
