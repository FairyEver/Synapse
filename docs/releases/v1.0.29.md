# Pending Release Notes

## 新增功能

- 开放接口发通知支持把密钥放进 URL：`POST /api/open/v1/notifications/{密钥}` 直接以路径段里的密钥发消息；也可以把密钥、标题和正文全部写进一条 `GET` 链接，不需要请求头和请求体，做成书签或快捷指令即可触发。这类链接只接受 `GET`，`HEAD` 探测请求返回 `405`；但链接预览、爬虫和浏览器预取只要真的发起 `GET` 就会发出通知，整条链接等同密钥，请按密钥保管，不要粘贴到聊天、公开仓库或截图里。
- 个人资料新增昵称，可以填汉字、符号和空格（最多 24 个字符，允许重名），但不接受控制字符和不可见的格式符号；桌面端账号区显示昵称，用户名继续用于分享链接和公开页面。

## 功能优化

- 优化 iPhone 远程终端「会话资源」的网页浏览体验：点开链接后改用系统浏览器界面，页面缩放、翻译菜单、加载进度和「在 Safari 中打开」都由系统提供，登录状态也与 Safari 共享，需要登录的分享链接可以直接打开。原自绘页面里的附件下载与「保存文件」按钮不再提供，这类内容改由系统处理。

## 问题修复

- 修复 iOS 发版归档阶段未使用已配置的苹果 API Key，导致另一台电脑即使配好凭证仍可能因 Xcode 账号不可用而中断的问题。
- 修复 iPhone Git 面板下拉刷新未获取远端新提交、因而误报分支已同步的问题；刷新后会显示实际落后数量，获取失败也会说明原因。状态中的“同步”现在可直接点击。
- 修复 iPhone 远程终端「会话资源」把链接截断的问题：链接被终端界面折行成两行时，之前只取到前半截，点开提示「链接已失效」；现在会拼成完整链接再提供。
- 修复 iPhone 远程终端长按不能选中文字的问题：长按会直接选中手指下的那个词（链接、路径、参数都可以），抬手即可复制或分享；继续拖动不会把已选中的词弄丢。
- 修复终端里选中含中文的行时，复制出来的文字与选中位置错位的问题。

## 技术调整

- 开放接口发通知的密钥改为随请求携带（请求体 `key` 字段或 URL 路径段），不再读取 `Authorization` 请求头；标题、正文、分组、HTTPS 链接和提醒级别的校验规则不变。日志与错误信息的脱敏现在也能识别 Synapse API 密钥，即使它以裸串形式出现在路径、堆栈或错误消息里也会被打码。
