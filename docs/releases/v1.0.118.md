## 新增功能

- **邮箱定时发送**：外部邮箱支持预约在未来任意具体日期与时间自动发送邮件（支持快捷预设与精确日历/时间选择），并在邮箱侧栏新增「定时发送」视图用于查看、修改时间、立即发送或取消并退回草稿；同时提供对应 MCP 工具供 AI 预约与管理定时邮件。到点时需保持 Synapse 运行并联网，休眠或离线延迟 30 分钟内恢复后自动补发，超时转为「已错过」并提醒人工确认。
