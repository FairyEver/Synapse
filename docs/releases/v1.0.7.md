# Pending Release Notes

## 新增功能

- 录音转写：转写过程中现在能看到进度了，电脑端和手机端都有。会显示「识别中 · 已用 01:20」，进度条按录音时长一路往前走，下面写着这条录音预计多久出来。腾讯云不提供百分比，所以这条是按「已经等了多久」比一个「预计要多久」画的，**最多画到 95%**——结果没回来之前不会画满。以前只有一条来回晃的条，一条 48 秒的录音卡住几分钟，你完全看不出它是在跑还是已经死了。

## 功能优化

- 手机端终端：顶部那条、工具栏、输入栏现在会**自己让开**。放着不动三秒，三条一起收起来，整个屏幕留给终端；点一下屏幕它们回来，继续正常用。正在按住说话、正在录音、键盘或 ⌘ 面板开着、正在拖看历史的时候，它们不会动。栏让出的高度是真的给了终端——电脑上那个终端窗口会跟着变大，所以手机上看到的行数和电脑是一致的。

- 手机端终端横屏：顶栏并进了工具栏，横屏只剩两行（原本三行占掉约四成的高度）。终端铺到屏幕两边，不再是黑画面配两条系统色的边。横屏打开自绘键盘时，键盘面板不会再把自己撑出屏幕。

- 桌面端终端会话列表与顶部会话标签去掉了「有新消息」小黑点。它原本只要后台终端打下任何一行字就亮，而 Claude Code 这类会话一直在输出，于是它几乎恒亮、看不出任何信息；你点进去看它就消失，不看它也不会留。真正需要你动手的会话仍然由旁边的琥珀色问号标记（等待输入），那个保留不变。右键菜单里配套的「标记已读 / 标记未读」一并去掉了。

- 录音回放：**听过的录音会留在本机，第二次点开直接就是播放态**，不再每次都重新取一遍；没网的时候，听过的那些照样能听，波形和拖动定位都在。第一次听一条长录音仍然要等它取完——一小时约 28 MB，家用宽带几秒。音频还没到本机时写着「正在下载」，转满 10 秒会给一个「重试」；**它不是失败**，网络恢复后自己会接着取完，不点「重试」也能好，那个按钮只是催一下。

- 手机上刚录完的那条，录完立刻进详情点播放是**秒开**。录音时那段音频本来就在手机上，以前收尾的时候会把它删掉，想马上回听反而要从头取一遍。

- 一台设备上删掉的录音，别的设备上也不会再留一份能播的副本：刷新列表时，本机那些已经不在了的录音会一并清掉。

- 本机最多留 2 GB 录音音频，超了自动从**最久没听过**的那条开始清。听过的会一直留着，没有时间过期。

## 问题修复

- 手机端录音：录音时那条波形以前稍微一开口就顶到满格，说得响和说得轻看起来一样高，从波形上完全看不出音量。现在按实际音量铺开——小声、正常、大声各占各的高度，只有真顶到满刻度才会占满一根柱子。录完回看时那条波形用的是同一条刻度，也跟着变。

- 手机端终端列表：每一行上会显示这个终端已经开了多久（「5 分」「2 小时」）。这一格以前**一直是空的**——电脑发过来的时间带毫秒，手机这边读不出来，而读不出来的时候它不报错，只是什么都不显示，所以看着像这个位置本来就不放东西。

- 手机端录音：**两分钟以内的录音以前存下来是一段打不开的音频**。列表、时长、波形全都正常，点播放却没有任何声音，电脑上、手机上一样。原因是音频文件的头部要在停止录音的那一刻才补全，而这段短录音的字节整个都在这批补全之前就传走了。现在短录音也能正常播放。

  这次更新**之前**录下的、时长不足两分钟的录音，音频本身已经损坏，无法恢复，需要重新录一条。时长超过两分钟的录音不受影响。

- 电脑端录音列表：手机上新录一条，电脑这边的列表会自己出现这条，不用把窗口关掉再打开。

- 录音转写：**转写失败以前会一直停在「转写中」，你永远等不到结果，也等不到失败。** 原因是转写任务每分钟会重新提交一次，而每次重新提交都把「已经试过几次」清零，于是失败重试永远到不了上限，任务在「提交 → 失败 → 重新排队」之间无限转圈，音频也被反复提交。现在识别引擎一旦判定这段音频不可识别就直接收尾——你会在一分钟内看到失败原因和「重试」，而不是干等。

- 手机端录音详情：停在详情页看转写进度时，进度和最后出来的文字以前**不会自己更新**，得退出去再进来一次才看得到。现在详情页自己会刷新。

- 手机端录音：录完之后上传或收尾那一步失败（比如中途断网），下次启动会自动把这条收掉。这条路以前不会重新核对音频开头那一片，收上去的文件可能打不开。现在收尾会把开头那一片按本机的定稿文件重发一次。

- 录音转写：一段**结构上就没写完**的录音（就是上面那种故障留下的文件），以前会先被送去识别、等一轮轮询之后拿回一句英文的 `Invalid audio file!` 给你看。现在录音上传收尾时会先看一眼文件结构，坏了就当场判失败，一分钟内给你一句中文的「这段录音的音频文件不完整，无法转写。」，那次识别调用也不再白花。这一关拦的不只是手机端这一次，是任何一个端的文件缺陷。
