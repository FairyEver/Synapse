# Pending Release Notes

## 新增功能

- 新增「频道」实时信号通道：可在控制台创建频道、按角色签发接入凭证（仅订阅 / 仅发布 / 双向），并通过实时调试台查看在线成员、实时事件流与最新 Retain 状态；开放 WebSocket 与 HTTP 接口无需 Synapse 登录态即可接入，适合手机遥控大屏、网页按钮实时控制自有后端等跨端联动场景，并支持在桌面端通过 AI 助手直接创建频道与配套页面。

## 功能优化

- 云盘历史版本不再自动清理：上传覆盖、在线编辑和恢复版本产生的每一份历史都会保留，可随时回看和恢复；历史版本会持续占用云盘空间，需要时可在版本列表手动删除。
