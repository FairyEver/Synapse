# 不同编辑器存储规则（核心版）

> 只列确定性最终结论，来源见完整版。

## Cursor

| 类型 | 路径 |
|------|------|
| 全局 Rule | 无官方公布的固定文件路径（仅 Settings UI） |
| 项目 Rule | `.cursor/rules/`、`AGENTS.md`（根及子目录） |
| 全局 Skill | `~/.cursor/skills/`、`~/.agents/skills/`（兼容：`~/.claude/skills/`、`~/.codex/skills/`） |
| 项目 Skill | `.cursor/skills/`、`.agents/skills/`（兼容：`.claude/skills/`、`.codex/skills/`） |

## Codex

| 类型 | 路径 |
|------|------|
| 全局 Rule | `~/.codex/AGENTS.md`（或 `$CODEX_HOME/AGENTS.md`） |
| 项目 Rule | `<repo-root>/AGENTS.md`、子目录 `AGENTS.md` / `AGENTS.override.md` |
| 全局 Skill | `~/.agents/skills/<skill-name>/` |
| 项目 Skill | `<repo-root>/.agents/skills/<skill-name>/`（从 CWD 向上扫描到仓库根） |

## Windsurf

| 类型 | 路径 |
|------|------|
| 全局 Rule | `~/.codeium/windsurf/memories/global_rules.md` |
| 项目 Rule | `.windsurf/rules/*.md`、`AGENTS.md`（根目录 always-on，子目录目录级） |
| 全局 Skill | `~/.codeium/windsurf/skills/<skill-name>/`（兼容：`~/.agents/skills/`、`~/.claude/skills/`） |
| 项目 Skill | `.windsurf/skills/<skill-name>/`（兼容：`.agents/skills/`、`.claude/skills/`） |

## VS Code (Copilot)

| 类型 | 路径 |
|------|------|
| 全局 Rule | `~/.copilot/instructions/`、`~/.claude/CLAUDE.md`、`~/.claude/rules/` |
| 项目 Rule | `.github/copilot-instructions.md`、`.github/instructions/`、`AGENTS.md`、`CLAUDE.md`、`.claude/CLAUDE.md`、`.claude/rules/` |
| 全局 Skill | `~/.copilot/skills/`、`~/.claude/skills/`、`~/.agents/skills/` |
| 项目 Skill | `.github/skills/`、`.claude/skills/`、`.agents/skills/` |

> 注：默认只发现当前打开的 workspace；父仓库发现需开启 `chat.useCustomizationsInParentRepositories`。

## Claude Code

| 类型 | 路径 |
|------|------|
| 全局 Rule | `~/.claude/CLAUDE.md`、`~/.claude/rules/` |
| 项目 Rule | `CLAUDE.md`、`.claude/CLAUDE.md`（从 CWD 向上递归读取） |
| 全局 Skill | `~/.claude/skills/<skill-name>/` |
| 项目 Skill | `.claude/skills/<skill-name>/` |
