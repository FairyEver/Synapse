# 步骤 6：本地仓库目录接入与同步

## 状态：已完成

## 目标

实现“选择本地目录、探测 Git 能力、手动同步仓库”的能力，并为后续直接提交 / 待同步队列 / 历史整理打底。

## 要做的事

### 6.1 本地目录选择

- 使用系统目录选择器选择本地目录
- 写入本地配置，不负责克隆仓库
- 目录显示名默认取文件夹名

### 6.2 目录状态探测

- 检查目录是否存在
- 检查目录是否位于 Git 工作区
- 返回：
  - `missing`
  - `ready + isGitRepository=false`
  - `ready + isGitRepository=true`

### 6.3 手动同步

- 工具栏刷新按钮触发 `git pull --ff-only --progress`
- 完成后刷新本地索引
- 当前不做静默自动 pull

### 6.4 同步失败

- 明确区分：
  - 目录不存在
  - 非 Git 仓库
  - 无上游分支
  - 网络问题
  - 认证失败
- 错误提示面向普通用户，不暴露多余 Git 术语

### 6.5 与新提交流程的边界

- “同步仓库”只负责拉取远端最新内容
- 创建 / 编辑 / 删除的 push 逻辑不放在这里
- 待同步队列的 flush 也走独立入口

## 注意事项

- 所有 Git 操作都必须在主进程执行
- 非 Git 目录仍然允许浏览本地内容
- 删除仓库配置不删除本地目录

## 验收标准

1. 可添加本地目录
2. 能正确显示目录与 Git 状态
3. Git 仓库可手动同步
4. 非 Git 仓库同步按钮禁用
5. 同步失败时有清晰错误提示
