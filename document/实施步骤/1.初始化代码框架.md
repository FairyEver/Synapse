# 步骤 1：初始化代码框架

## 状态：已完成

当前项目已完成基础脚手架搭建。

## 已完成内容

### 技术栈确认

- **Electron** 作为桌面客户端壳层
- **Vite** 作为前端构建工具
- **React 19** 作为前端框架
- **Tailwind CSS 4** 作为样式方案
- **shadcn/ui** 作为组件库
- **TypeScript** 全栈类型安全

### 项目结构

```
Synapse/
  electron/          # Electron 主进程
    main.ts          # 主进程入口
    preload.ts       # 预加载脚本
  src/               # 渲染进程（React）
    App.tsx          # 应用入口组件
    main.tsx         # React 挂载入口
    components/      # 公共组件
    lib/             # 工具函数
    styles/          # 样式文件
    types/           # 类型定义
  index.html         # HTML 模板
  vite.config.ts     # Vite 配置
  tsconfig.json      # 渲染进程 TS 配置
  tsconfig.electron.json  # 主进程 TS 配置
  components.json    # shadcn/ui 配置
```

### 开发命令

- `pnpm dev` — 启动开发环境（Vite + Electron 联调）
- `pnpm build` — 构建生产版本
- `pnpm typecheck` — 类型检查

## 注意事项

- 项目使用 `pnpm` 作为包管理器
- Electron 主进程和渲染进程使用独立的 `tsconfig`
- 开发模式下 Vite 固定监听 `127.0.0.1:5173`
- 主进程代码编译输出到 `dist-electron/`，渲染进程编译输出到 `dist/`
