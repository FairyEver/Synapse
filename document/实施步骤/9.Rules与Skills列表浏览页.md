# 步骤 9：Rules 与 Skills 列表浏览页

## 状态：已完成

## 目标

实现基于本地索引的 Rules / Skills 浏览页，提供搜索、分类筛选、列表展示和详情入口。

## 要做的事

### 9.1 页面骨架

- 左侧：搜索框 + 分类列表
- 右侧：内容卡片列表
- Rules / Skills 共用同一套骨架

### 9.2 数据来源

- 列表页从本地 `content_index` 读取
- 只展示 `deleted = 0` 的当前版本
- 不再每次打开页面都直接扫仓库目录

### 9.3 筛选逻辑

- 当前激活目录
- 当前分类
- 当前搜索词

### 9.4 卡片信息

- 图标
- 标题
- 简介
- 分类
- 最近修改者
- 最近修改时间
- 右侧操作区

### 9.5 状态

- 正在加载
- 当前目录不存在
- 当前目录不是 Git 仓库（可浏览，不可新建）
- 空列表
- 当前分类为空
- 搜索无结果
- 读取失败

## 注意事项

- 列表刷新依赖索引同步和本地 refresh signal
- 软删除内容不显示在列表中
- 详情弹窗编辑 / 删除成功后，列表要能刷新

## 验收标准

1. Rules / Skills 都能展示列表
2. 搜索和分类筛选正常
3. 软删内容不会显示
4. 新建、编辑、删除后列表可刷新
5. 非 Git 目录下浏览正常，但新建入口禁用
