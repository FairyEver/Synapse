# Dashboard V2 逐页视觉检查

检查日期：2026-11-01。当前 main，本地 V2，HeroUI 3.2.7 浅色。使用 bsk 检查 1467×835 桌面和 390×844 窄屏，结合真实 Chromium 布局与交互回归。

## 已修复

| 问题 | 原因与结果 |
|---|---|
| 用户表格首列占满可见区域、其他字段被挤走 | 移除旧表格的百分比列宽与 `max-w-0`，改为有上限的业务列宽；宽表格仍在自身区域横滚 |
| 备份文件名不可见 | 文件名列不再被压成零宽，长名称可以展开查看 |
| 窄屏空表格、加载失败信息看不到 | 状态放在表格横滚区之外，始终位于当前视口，保留重试操作 |
| 多页分页按钮被裁切 | 窄屏分页分行并允许按钮换行，桌面仍同排 |
| 多行筛选区的列按钮悬在中间 | 工具栏按屏幕宽度重排，筛选与列操作分组明确 |
| 列选择菜单显示内部字段 ID | 列元数据提供与表头一致的名称，菜单不再暴露 `email`、`createdAt` 等字段名 |
| 长文本提示无法可靠点击或键盘打开 | 使用 HeroUI Tooltip/Popover 的标准 Trigger；展开内容限制宽度并换行 |
| 设置页标签换行、密钥用词不一致 | 标签按内容确定宽度；统一使用“密钥” |
| 探索页同时高亮两个导航 | 按最长匹配路径确定唯一选中项，详情仍归属对应模块 |
| Skills 窄屏无法展开导航 | 列表、探索、公开详情均使用共享页头与导航按钮；空列表移除撑满整屏的旧边框布局 |
| 团队详情页头拥挤、组织区被推到屏幕底部 | 标题与成员信息纵向分组，表格使用内容高度；成员候选项的长邮箱可正确截断 |
| 埋点图表长名称被裁切、单条柱状过粗 | 轴标签按可用宽度截断，悬停显示完整名称和数值，限制柱条厚度并按条目数安排高度 |
| 系统日志操作超出窄屏 | 筛选、下载与清理按钮自动换行 |

内部专项：游戏外围 Tabs 保持单行；选手档案用 HeroUI TextField 正确排列标签、输入和提示；窄屏记录页不再被网格拉出大段空白。实际牌桌及下注、卡牌、缩放、音画源码未修改。
