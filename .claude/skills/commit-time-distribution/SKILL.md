# Commit Time Distribution — 提交时间分布图

## 目标

统计当前仓库（**所有分支、所有历史**）的提交在一天 24 小时中的分布，生成一张对齐整齐、强度条可比的 ASCII 直方图，并附上简短观察。

## 触发条件

用户明确要求统计提交的时段 / 作息 / 活跃时间，或提供了一张类似风格的样例图希望"为本仓库生成一份"。

触发短语：`提交时间分布` · `commit 时间分布` · `每小时提交数` · `commit hours` · `作息图` · `活跃时段` · `生成这个分布图`

## 执行流程

### Phase 1：取数据

在仓库根目录执行：

```bash
git log --all --format='%ad' --date=format:'%H' | sort | uniq -c | awk '{printf "%02d %d\n", $2, $1}' | sort
```

说明：

- `--all`：覆盖所有分支，不只是当前 HEAD
- `%ad` + `--date=format:'%H'`：作者时间的小时（本地时区两位数）
- 输出形如：
  ```
  00 4
  01 1
  08 9
  ...
  23 20
  ```

注意：

- 若只想统计主分支，去掉 `--all`；默认 **用 `--all`**，除非用户明确要求范围
- 使用作者时间 `%ad`（反映编码者本地作息）。若用户要求 UTC 或 committer 时间，可换成 `%cd`、`--date=format-local:'%H'`

### Phase 2：补齐空时段

命令输出只包含有提交的小时。要渲染 24 行完整图表，需补齐 `00`–`23` 中缺失的小时，计数填 `0`。

### Phase 3：计算强度条

- `max = max(count for h in 0..23)`
- 每行 bar 宽度：
  - 若 `count == 0`：显示单个 `·`（注意是 middle dot `U+00B7`，不是普通点）
  - 否则：`width = round(count * 40 / max)`，渲染 `width` 个 `█`（`U+2588`）
- `40` 是上限列宽，保证最活跃时段正好是 40 格

### Phase 4：渲染文本

用一个 fenced code block（语言标记 `text`）输出，固定列宽对齐：

```text
  小时   次数  强度分布
  ----   ----  ------------------------------------------------
  HH:00   NNN  ████████...
  ...
```

格式要点：

- `小时` 列：`HH:00` 两位零填充
- `次数` 列：右对齐，至少 3 位宽（提交数可能上百）
- 强度分布列：紧跟两空格后开始
- 所有 24 行按 00→23 顺序输出，**空时段也要占一行**

### Phase 5：给出观察

在直方图后补一段简短观察（不超过 4 条 bullet）：

- **总提交数**：所有计数之和
- **最活跃时段**：count 最高的 1–3 个小时
- **明显空档**：连续 count=0 的时间段（通常反映睡眠 / 无人作业）
- **双峰 / 单峰**：若出现明显的上午峰 + 晚间峰，点出"双峰分布"

观察要朴素、描述事实，不编故事、不推断作者生活习惯。

## 输出模板

```markdown
# 提交时间分布

全仓库 <TOTAL> 次提交的时段分布（bar 宽度按最大值 <MAX> 线性映射到 40 格）：

\`\`\`text
  小时   次数  强度分布
  ----   ----  ------------------------------------------------
  00:00   ...  ...
  ...
  23:00   ...  ...
\`\`\`

## 观察

- **总提交数**：<TOTAL>
- **最活跃时段**：...
- **空档**：...
- **分布形态**：...（可选）
```

## 范围控制

- 只读操作：只跑 `git log`，不改仓库任何文件
- 不生成图片文件、不生成 HTML、不引入依赖；仅输出 Markdown 文本
- 不把统计结果写入仓库；只在对话里回复

## 硬性规则

- **必须覆盖 00–23 全部 24 行**，空时段用 `·` 占位，不得跳行
- **使用 `--all`** 默认口径；若用户指定范围则照办并在说明里点出口径
- **bar 宽度使用四舍五入**（`round`），保证最活跃小时正好 40 格
- **不要夹带其他统计**（作者、文件、星期等），除非用户另外要求
- **不要自行改缩放逻辑**（如对数、平方根），保持线性映射便于跨仓库对比
