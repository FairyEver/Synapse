## 页面范围校正

- 页面不显示、操作也不使用的宝典媒体扩展、远端同步字段、IM隐藏枚举等不再列为该页AI消费字段，不要求额外动态schema。原始响应保留兼容透传，SDK明确这些扩展不用于展示、解释或操作。
- 分享时效、听课时长、四项保险金额按Portal原值展示；页面没写单位则不补单位或换算。图文可阅读量%和视频播放秒有明确页面依据，分别解释。
- IM状态读外层record.isDel，禁言读chatRoomMuted；课程ID、资源ID、creator按钮条件明确区分。
- 知识权限保存按弹窗成功回执完成；再看表单可选，超时回查。取消关闭未保存弹窗；兼容cancel重新保存旧值，不承诺完整子树回滚。跨账号效果证明不是额外完成门槛。
- 开放接口按页面isBound真值保护删除；同实例最近list行快照在prepareRemove和删除submit时生效。false/缺席沿用页面允许规则，不要求穷举技能证明全库无绑定，也不把缺席说成无绑定证据。

这些内容由真实 `describe/describeMethod/describePage` 返回；规范同步至conventions第33条、ai-description-contract与设计A6/D14。具体证据见 [semantic-blockers.md](semantic-blockers.md)、[权限与绑定验证边界](../pages/权限与绑定验证边界.md)。

## 唯一尚未闭合的页面功能

`ai-model-apply-handle` 与 `aiModel.prepareHandleApply`：Portal待处理行有“忽略”按钮，发送status=1；当前Java处理与查询校验仅接受0/3/4。SDK明确报协议冲突，不猜转驳回、不宣称忽略成功。按钮属于对齐范围，无需用户再决定是否需要它；解决Web/Java冲突超出本轮只改SDK的边界。

状态显示遵循statusName→平台字典→页面兼容标签→“-”；字典入口及value转数字规则已补齐。前轮一键填写已改为创建正确规则后写4；个人手机号目标、部分写回执、差旅项目负责人预览和候选查询修复继续保留。完整证据见 [model-compat.md](model-compat.md)。
