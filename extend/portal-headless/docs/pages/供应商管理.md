# 供应商管理（`/dashboard/setting/supplier/list`）

## 页面范围与证据

门户 → 系统设置 → 供应商管理，权限 `/dashboard/setting/supplier`，使用 `platform` HTTP 实例；页面路径不命中 module-type 规则，因此 SDK 与 Portal 一样不发送 `module-type`。

本页可达的动作是当前租户供应商分页、导出、删除、批量新建，以及从平台供应商库分页选择后添加到当前租户。Java 虽然还有单条 `create`、`update`、`get` 端点，但 Portal 当前页面没有详情或编辑入口，不把不可达后端接口扩为本页能力。新建页的品牌列及其全量品牌预取已经注释/不可见，也不作为当前表单的 SDK 前置步骤。

Portal 证据：`app/portal/menus/common.js`、`app/portal/views/dashboard/hr/setting/supplier/list.vue`、`[mode]/[id].vue`、`components/portal/supply/platform-table-select/supplier.vue`，固定提交 `bbcfc35154`。

Java 证据：`SysSupplierController`、`SysSupplierBaseVO`、`SysSupplierSaveReqVO`、`SysSupplierRespVO`、`SysSupplierServiceImpl`、`PlatformSupplierServiceImpl`，固定提交 `b7a359adc9e`。供应商删除的采购属性限制、平台供应商 useTenant 语义和平台添加的当前会话租户边界由 `test/setting-supplier.test.ts` 锁定；当前页面仍未做真实环境写入回查。

## 能力与权限边界

| 页面动作 | SDK 能力 / 方法 | 请求与副作用 |
| --- | --- | --- |
| 当前租户供应商分页 | `setting-supplier-list` / `settingSupplier.list` | `GET /admin-api/system/sys-supplier/page`；后端按当前会话租户和数据权限返回分页 |
| 导出当前筛选结果 | `setting-supplier-export` / `settingSupplier.export` | `GET /admin-api/system/sys-supplier/export`；返回 base64 文件，后端固定最多导出1000条 |
| 批量新建供应商 | `setting-supplier-create` / `settingSupplier.create` | `POST /admin-api/system/sys-supplier/batch-create`；返回按请求顺序排列的 ID 数组 |
| 删除供应商 | `setting-supplier-remove` / `settingSupplier.remove` | `DELETE /admin-api/system/sys-supplier/delete?id=...`；系统供应商物理删除，平台供应商只解除当前租户使用关系；有采购属性时后端拒绝 |
| 查询平台供应商库 | `setting-supplier-platform-list` / `settingSupplier.platformList` | `GET /admin-api/system/sys-supplier/select-platform-page`；只把 `selectable=true` 的行交给添加动作 |
| 添加平台供应商 | `setting-supplier-add-platform` / `settingSupplier.addPlatform` | `POST /admin-api/system/sys-supplier/update-use-tenant`；后端以会话租户更新 useTenant，请求体 tenantId 不能切换租户 |

## 参数与表单规则

- 当前租户列表默认请求参数为 `{ order: '', orderField: '', supplierName: '', supplierCode: '', type: undefined, pageNo: 1, pageSize: 20 }`；平台选择弹窗相同，但 `type` 默认是 `null`。分页大小沿用页面支持的 `10/20/50/100`。
- 导出只带当前页面的 `supplierName`、`supplierCode`、`type` 筛选，不带分页参数；后端把 pageSize 固定为1000，不能据此承诺超过1000条的完整导出。
- 新建页面至少保留一行。每行 `supplierName`、`supplierAbbreviation`、`type` 必填；`address`、`qualificationCode` 可空；`postalCode` 为空或必须为6位数字。页面输入会先去除非数字并截断到6位，SDK 对最终提交值执行同一条“空或六位数字”校验。
- 页面默认发送 `supplierCode: ''`，由后端按供应商类型生成唯一供应商号；不要在 SDK 中猜生成的编码。页面默认发送 `isSysCreate: true`，后端批量服务也会强制为 true。
- 页面当前品牌选择列已整行注释，提交前仍把空 `sysBrandIds: []` 转成 `sysBrandIds: ''`；SDK 接收品牌 ID 数组并按 Portal 规则转换为逗号字符串，不能把品牌名称代替 ID。
- 批量创建后端使用事务：任一行编码冲突、类型缺失、重复基础信息或业务校验失败，整个批次会回滚；成功返回的 ID 仍需逐行回查，不能只看 HTTP 或 ID 数组。
- 平台供应商弹窗支持跨页选择，但行选择器禁用 `selectable=false` 的记录。添加成功或超时后必须回查当前租户列表；请求体的 `tenantId` 是页面字段，不是授权凭据。
- 删除成功回执不统一代表物理删除：后端先检查任意组织的采购属性，有采购属性就拒绝；平台供应商移除当前租户的 useTenant，系统创建供应商才物理删除。响应超时先回查，不盲目重试。

## 操作步骤与失败处理

1. 用 `list` 获取当前租户供应商，保存行 ID；需要从平台库添加时单独调用 `platformList`，跳过 `selectable=false`。
2. 新建时按每行的名称、简称、类型和邮编规则构造 `suppliers`，调用 `create` 后按名称、简称、类型和返回 ID 逐行 `list` 回查。批量失败时按事务失败交付，不把部分行说成成功。
3. 导出时将返回的 base64 解码成文件；文件为空或响应失败都不能当作空表。
4. 删除前确认目标来自当前列表；成功或超时后回查，区分物理删除、解除当前租户使用和采购属性阻止。
5. 平台添加只提交当前平台列表中 `selectable=true` 的 ID，成功或超时后按 ID 回查当前租户列表；不能用请求体 tenantId 绕过会话租户。
6. 表单校验、编码冲突、采购属性限制、权限、租户范围、网络和后端业务错误均原样报告，不能降级为空列表、空文件或假成功。
