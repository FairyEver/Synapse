## Portal 页面行为

### 账套列表、表单和权限

- 列表是 `GET /salary/ledger/selectListByRole`，Portal 的 `customLoad` 不接收也不发送查询参数；返回数组。
- 列表支持跨页选择和批量删除，删除是 `DELETE /salary/ledger`，选中的 ID 数组放请求体。Portal 明确提示删除后相关人员可能失去账套使用权限。
- 账套表单字段是 `name`、`organizationId`、`organizationName`、`type`、`countRange`、`roleIdList`。`name` 必填、最多 50 个字符，但 Portal 不拒绝全空格名称；组织、类型、计税区间和角色数组必填。
- 新建和编辑的 `customSubmit` 都是 `POST /salary/ledger`。编辑只是在完整表单 payload 中保留 `id`，不能把编辑改成 `PUT`。
- 角色候选调用 `GET /sys/role/hrRoleListNew`；组件虽然接收 `project="3"`，实际请求不带该参数。组织组件先读取 `GET /org/organization/getTree`，打开选择器后按 `GET /org/organization/pageByOrgId` 分页，默认 `name=''`、`type=''`、`orgId=''`、`pageNo=1`、`pageSize=10`。
- 复制弹窗要求名称必填且最多 50 个字符，调用 `POST /salary/ledger/copyLedger`，请求体为 `{ ledgerId, name }`。

### 薪资项目子页和项目表单

- 项目列表是分页请求 `GET /salary/ledgerItem/page`，固定携带 `ledgerId`、`order=''`、`orderField=''`、`pageNo`、`pageSize`，默认页码 1、每页 20 条；支持跨页批量 `DELETE /salary/ledgerItem`。
- 引入弹窗先调用 `GET /salary/ledgerItem/getNotInsertSalaryItem?ledgerId=...`，确认后调用 `POST /salary/ledgerItem/importSalaryItem`，请求体字段名是 `salaryItemId` 数组和 `ledgerId`；未勾选项目时 Portal 不发请求。
- 项目编辑详情是 `GET /salary/ledgerItem/{id}`，保存是 `PUT /salary/ledgerItem`。项目名称编辑时禁用，并且 `validateOnlySpace` 拒绝全空格，最多 50 个字符。
- 项目属性为计算项（`attribute=2`）时，保存前先 `GET /salary/item/checkFormula?formula=...`，校验成功后才 PUT；属性变化时 Portal 会清除不适用的 `formula`、`parameter`，提交固定项时按 `scale` 对 truthy 的固定值执行 `toFixed(scale)`，非固定项的 `fixedValue` 为 `null`。
- 项目表单还约束 `type` 为 1 至 6、`scale` 为 0 至 4、`carryRule` 为 1 至 3、`sort` 为非负整数、`remark` 最多 200 个字符且非空时不能全空格；系统参数项（`attribute=4`）必须有 `parameter`。
- 公式候选来自 `GET /salary/item/getAllSalaryItem`，候选 ID 和名称必须保留，不能以名称或数组位置代替 ID。

## Java 后端与权限规则

`SalaryLedgerController` 提供账套列表、按角色列表、详情、POST 保存、复制、PUT 更新和 DELETE；`SalaryLedgerItemController` 提供项目分页、详情、POST/PUT、DELETE、引入和未引入项目查询。SDK 对齐 Portal 实际调用：账套编辑走 POST，项目编辑走 PUT。

`SalaryLedgerDTO` 的关键字段是 `Long id`、`String name/type/countRange`、`Long organizationId` 和 `List<Long> roleIdList`；项目 DTO 使用 Long/Integer/BigDecimal 对应 ID、枚举、金额和小数位。账套服务按当前用户的超级管理员/租户管理员状态和角色授权过滤 `selectListByRole`，重复名称会拒绝；删除是软删除，并会处理账套角色授权和初始化必需项目。项目服务拒绝修改项目名称、拒绝重复引入，并对计算项目执行公式校验；项目查询过滤 `is_del=0`，按 `sort ASC` 返回。

## SDK 能力与说明

实现文件为 `src/capabilities/salary-package.ts`，目录契约为 `src/catalog/contracts-salary-package.ts`。能力按列表、详情、组织/角色候选、账套创建/编辑/复制/删除、项目分页/详情/公式候选/公式校验/编辑/引入/删除拆分；所有写能力都用 `prepare → submit`，取消只丢弃草稿且不发写请求。

账套编辑契约特别声明 `POST /salary/ledger` 和 payload 中的 `id`，项目编辑契约特别声明“计算项先公式校验，再 `PUT /salary/ledgerItem`”。返回说明解释数组列表、分页 `list/total`、ID 归属、角色权限范围、空结果与写入后的回查步骤，不把 HTTP 成功回执当作业务完成证据。
