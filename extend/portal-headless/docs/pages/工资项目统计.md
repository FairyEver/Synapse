## 参数契约与逐字段基准

Portal 表单初值为：`organizationId: ''`、`name: ''`、`staffCode: ''`、`yearMonth: [上月, 本月]`、`ledgerIds: []`。`yearMonth` 的表单规则为 `required: true`，提示“请选择时间范围”。因此 SDK `.list` 省略范围时使用页面初值上月到本月；显式传 `null`、空数组或不完整范围时在本地失败且不发请求。`.export` 页面没有单独的表单校验，显式空范围会照页面行为发送空的 `startYearMonth`、`endYearMonth`。

列表请求固定先发送 `order: ''`、`orderField: ''`，再发送表单转换后的字段和 `pageNo`、`pageSize`：

```json
{
  "order": "",
  "orderField": "",
  "organizationId": 9,
  "name": "张",
  "staffCode": "1001",
  "startYearMonth": "2026-08",
  "endYearMonth": "2026-09",
  "ledgerIds": "11,12",
  "pageNo": 1,
  "pageSize": 20
}
```

`organizationId` 是角色组织树的数字 ID，不是名称；Java 服务先用 `getDescendantByAncestor` 展开后代组织，再叠加 `@DataScope(organizationAlias = "t2", organizationIdAlias = "organization")`。`name` 是员工姓名模糊查询。`staffCode` 页面输入为文本，Java DTO 按 `Long` 接收，SDK 接受数字或数字字符串，空值发送空字符串。`ledgerIds` 是账套 ID 数组，请求前按页面顺序连接为逗号字符串；空数组发送空字符串，服务端随后使用当前网页可见账套集合。可见账套集合为空时服务端直接返回空页，空账套筛选不能解释为绕过权限或查询全租户数据。

起止年月分别发送 `startYearMonth`、`endYearMonth`，格式为 `YYYY-MM`。列表不发送日期对象，也不发送名为 `yearMonth` 的后端参数。Java Mapper 用两者对工资单年月做 `BETWEEN` 筛选；传入年月必须是合法月份。

## 列表返回字段

返回 `{ list, total }`。`total` 是符合筛选条件的员工记录总数，只用于翻页。Portal 的“序号”是当前页行下标加一，Java `StaffSalaryItemDTO` 没有 `index` 字段，所以 SDK 不伪造 `list[].index`。

身份与范围字段：

| 字段 | 含义 |
| --- | --- |
| `list[].orgName` | 员工所属组织名称 |
| `list[].name` | 员工姓名 |
| `list[].staffCode` | 员工号；Java `Long`，按数字或字符串消费 |
| `list[].startYearMonth` | 汇总起始年月 |
| `list[].endYearMonth` | 汇总结束年月 |

金额字段均为服务端 `BigDecimal` 的数字或十进制字符串，SDK 不擅自转换浮点精度：

`basicSalaryTotal` 基本工资、`assessmentSalaryTotal` 考核工资、`orgAssessmentSalaryTotal` 部门考核工资、`orgProfitSalarySalaryTotal` 利润考核工资、`overWorkSalaryTotal` 加班工资、`educationSalaryTotal` 学历补贴、`workYearSalaryTotal` 工龄补贴、`communicationSalaryTotal` 通讯补贴、`labourSalaryTotal` 劳动费、`closureSalaryTotal` 封场费、`dutySalaryTotal` 值班费、`otherSalaryTotal` 其他工资、`heatstrokePreventionSalaryTotal` 防暑费、`heatingSalaryTotal` 取暖费、`tenancyPerkSalaryTotal` 租房补贴、`singleChildSalaryTotal` 独生子女补贴、`otherWelfareSalaryTotal` 其他福利、`bonusSalaryTotal` 奖金、`fullAttendanceSalaryTotal` 全勤奖、`highProductivitySalaryTotal` 高产奖金、`stableProductivitySalaryTotal` 稳产奖金、`projectSalaryTotal` 项目奖金、`trainingSalaryTotal` 培训奖金、`articleSalaryTotal` 稿费、`benefitSalaryTotal` 效益奖、`shouldSalaryTotal` 应发工资、`oldAgeSalaryTotal` 养老、`unemploymentSalaryTotal` 失业、`medicalSalaryTotal` 医疗、`largeMedicalSalaryTotal` 大额医疗、`personalSocialSecuritySalaryTotal` 个人社保、`personalProvidentFundSalaryTotal` 个人公积金、`taxableSalaryTotal` 应税工资、`personalTaxSalaryTotal` 个税、`housePurchaseDeductionSalaryTotal` 购房扣款、`otherDeductionSalaryTotal` 其他扣款、`healthDeductionSalaryTotal` 安康扣款、`deductionSalaryTotal` 扣款合计、`actualSalaryTotal` 实发工资。

`list=[]` 且 `total=0` 只表示当前筛选没有记录；不能据此判断没有权限。列表没有页面全量合计行，也不要把当前页金额相加当成全量汇总。

## 导出

导出只发送 `organizationId`、`name`、`staffCode`、`startYearMonth`、`endYearMonth`、`ledgerIds`，不发送 `order`、`orderField`、`pageNo`、`pageSize`。SDK 请求 `responseType: 'arraybuffer'`，返回 `fileName`、`contentType`、Base64 文件内容和原始 `byteLength`；空文件响应抛错。

Java 服务端将页大小改为批量大小，逐批查询当前用户可见的工资项目记录，为 Excel 行生成序号，并追加 `name=汇总` 的汇总行。服务端文件名为 URL 编码的 `部门员工工资项目汇总表.xlsx`，SDK 优先解析 `Content-Disposition`；这些 Excel 汇总行和序号不出现在 `.list` 返回中。Portal 页面本身用固定显示名 `工资项目统计.xlsx` 调用下载工具，SDK 不覆盖服务端文件名。

## 操作步骤、失败处理与验证边界

1. 先使用当前会话可见的角色组织树和薪资账套候选确认 ID，再决定姓名、员工号和起止年月。
2. 调用 `.list`，按 `total` 翻页；显式提交时必须提供完整的年月范围。
3. 需要文件时把相同筛选传给 `.export`，用 `byteLength` 和 `fileName` 确认下载结果，并把 Excel 汇总行与列表分页记录区分。
4. 非法年月、员工号、ID、页码或页大小，以及列表空年月，会在请求前失败；401/403、网络错误和后端业务错误原样保留。
