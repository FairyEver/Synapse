## 参数契约

**这是 POST，body 就是参数对象**（`customLoad: async (form) => http.post(url, form)`，
`salary/main/list.vue:92-95`）。所以：

- **没有 `_t`** —— `platform.js:36-41` 只给 `config.method === 'get'` 加。
- 但 **`order`/`orderField` 照样在 body 里**（`list.js:474-475` 无条件加，与"空值发不发"无关）。

顺序逐字取自页面 `form:` 初值（`list.js:466-468` 的 `convertFetchForm` 是透传默认值）：

```
order → orderField → name → year → month → orgIdList → pageNo → pageSize
```

页面初值（`salary/main/list.vue:98-103`）：`{ name: '', year: dayjs().format('YYYY'), month: dayjs().month() + 1, orgIdList: [] }`

## 逐字段基准

`baseline/perf-salary.browser.json`（2026-09-21 抓，测试环境）：

```
POST /admin-api/salary/basedata/hrsalarymanagement/page
Content-Type: application/json
{"order":"","orderField":"","name":"","year":"2026","month":9,"orgIdList":[],"pageNo":1,"pageSize":20}
```

同页还抓到一条 `GET /admin-api/org/organization/getRoleOrganizationTree?_t=<ts>` ——
那是页面上「组织筛选」下拉的候选，**不是本页的列表请求**，本能力不提供。

## ⚠️ 这一页与兄弟页最不一样的三处

| # | 这一页 | 另外两页薪酬列表 |
| --- | --- | --- |
| 1 | **`year`/`month` 默认是"当前年月"**（`dayjs()`，基准里就是 `"2026"` / `9`） | 默认**空串** |
| 2 | 字段序是 `name` 打头、`year`/`month` 在其后 | 工资找齐是 `year`/`month` 打头；考核导入是 `name` 打头但… |
| 3 | 组织字段叫 **`orgIdList`** | 考核导入叫 `organizationIdList` |

第 1 条最容易踩：`listSalaryMain()` **不传参**时发的是**当前年月**，不是"全部"。
要查别的月份请显式传，用 `buildSalaryYearMonth('2026-09')` 生成
（返回 `{ year: '2026', month: 9 }` —— **year 是字符串、month 是数字**）。

`orgIdList` **照页面原样发数组**（不是逗号串）。⚠️ 注意同一页的**导出**接口却是
`orgIdList.join(',')`（`salary/main/list.vue:177`）—— 两条链路两种序列化，
将来做导出能力时别照抄这里的数组形式。

## 真实验证

**本波没有对真实环境发过任何请求**（不冒烟、不开浏览器）。已验证的是：

- `test/perf-salary.test.ts`：显式传 `year='2026'` / `month=9` 时，**body 的每一个字段
  （含值）与基准逐字段一致**；不传参时另有一条钉住"默认 = 当前年月"。
- 反证：把 `name`/`year` 顺序对调 → 红 3 条；把默认年月改成空串 → 红 1 条；
  让 `buildParams` 丢掉空串字段 → 红 13 条。

列表**返回**的真实条数没有测过（没有冒烟）。`docs/pages/晨课堂.md` 那种"176267 条"
的实测数字，这一页**没有**。

## 敏感字段（⚠️ 请必读）

**这一页的列表**返回的是**逐人逐月的工资明细**。源码里 `columns`（`salary/main/list.vue:104-124`）
明写了这些列：

| 字段 | 含义 |
| --- | --- |
| `idCard` | **身份证号** |
| `staffCode` | 工号 |
| `basicSalary` | 基本工资 |
| `examineSalary` | 考核工资 |
| `profitSalary` | 利润工资 |
| `rewardSalary` | 奖励工资 |
| `totalSalary` | 合计 |

**处理方式：这些字段没有作为具名字段进 `SalaryMainRow` 类型定义。**

理由：能力定义里的具名字段是**给 AI 看的**（`ParamSpec`/行类型会被渲染进规格与提示词）。
把 `idCard` 与各项工资写成普通业务字段，等于把它们变成"模型默认会去读、去复述、
去记进日志"的东西 —— 而这个仓库里绝大多数能力都不需要它们就能完成任务。
用 `[key: string]: unknown` 透传，是**刻意**的取舍：调用方仍然拿得到（不丢数据），
但没有任何东西在**主动**引导模型去取。

**不具名 ≠ 不返回。** 调用 `listSalaryMain()` 拿到的行里**确实带着身份证号与工资**，
调用方自己要对返回值负责（别整行打印、别整行进日志）。

将来若要放开，建议**单独开一条能力**（例如 `perf-salary-main-detail`）而不是把字段
加回这个列表类型 —— 让"要看工资的人"显式去要，而不是让所有人默认拿到。

本页除列表外还有三个文件动作。它们的请求路径、字段形状和页面权限均已按 Portal 源码核对；`module-type: 13` 仍由页面上下文决定，不能由调用方自行改写。

| 顶部「导出」 | `POST /admin-api/salary/basedata/hrsalarymanagement/export`，Blob 响应；body 顺序为 `name → year → month → orgIdList`，其中 `orgIdList` 是选中组织 ID 用逗号拼接后的字符串。 | 只读文件动作；不能复用列表请求的数组形式。当前未做真实浏览器导出验证。 |
| 行内「详情」 | 路由跳转 `./detail/{id}`，详情页是本地桥接展示，没有额外 HTTP 请求。 | 不新增虚假的详情接口；需要详情时先使用列表返回的行数据，并保留该页面无额外网络动作的事实。 |

### 导入的 prepare → submit → cancel

1. `prepare` 校验文件扩展名为 `.xlsx`、MIME 与 Portal 一致，并保留文件名和内容；此阶段不发请求。
2. `submit` 以字段名 `file` 发送 multipart 请求；成功后重新调用本页列表，按年月、姓名和导入记录核对结果。
3. `cancel` 仅丢弃文件草稿，不调用导入接口。导入没有服务端撤销动作；重复导入、部分失败和幂等性仍未通过真实环境验证。

### 证据边界

本节的接口、参数顺序、文件规则和权限结论来自 Portal 前端源码及后端控制器静态审计。当前没有真实浏览器导入、模板下载或导出写入冒烟，也没有把未登录/无权限时的实时响应当作已验证证据；相关行为仍需在具备测试账号和可回滚数据的环境中补测。

## SDK 新增动作契约索引

本节是页面源文档维护区。`<!-- ai-contract-business:start -->` 后的生成片段目前只展示页面列表能力，不能覆盖这些新增动作；动作的实际说明以 [`src/catalog/contracts-business.ts`](../../src/catalog/contracts-business.ts) 和 `catalog.describe(id)` / `catalog.describe(id + '-llm')` 返回为准。

所有 submit 写入口都必须通过 `invoke` 传非空 `requestId`；同一次超时重试原样复用，新的业务意图使用新值。`requestId` 只用于 SDK 本地防重，不进入 Portal body。

组织参数的可执行候选是 `contract-support-role-organization-search`：传入组织名称关键字和 `scope=performance`，从 `list[].id` 取**绩效角色组织树 ID**。它不是普通部门 ID，也不替代调用方对可选节点的确认。

### 文件动作

- `perf-salary-main-download-template`：无业务参数，返回 `{ fileName, contentType, base64, byteLength }`。消费方式是解码 Base64 后保存或交给文件处理器；空文件是失败。未在真实登录浏览器中重放下载。
- `perf-salary-main-export`：参数为 `name`、`year`、`month`、`orgIdList`；`orgIdList` 使用上面的角色组织候选，提交时由 SDK 按 Portal 规则转成逗号字符串。返回同一文件结构，导出不写业务数据；未在真实登录浏览器中重放导出。

### 导入动作

- `perf-salary-main-prepare-import`：参数为 `fileName`、`base64`、`contentType`；只校验 `.xlsx`、MIME 和字节数，返回 `{ fileName, contentType, byteLength }` 草稿，不上传。确认后将本次 `args` 映射给 `perf-salary-main-import`；取消只丢弃本地草稿，不带 `capabilityId`，也不调用 submit。
- `perf-salary-main-import`：参数同文件动作，成功返回 `null | undefined`，不返回导入行。调用方须在提交前把本次列表筛选保存为 `context.importFilter`，写入后用其中的 `year`、`month`、`orgIdList` 调 `perf-salary-main-list`，逐条核对业务主键和金额。空回执不是写后证据；超时先复核再决定是否重试。未在真实登录浏览器执行导入或写后复核，不能报告已落库；写后复核是完成条件。

失败处理：文件校验失败按返回的字段修正后重新 prepare；会话/权限错误交由用户恢复；写入结果不确定时先按 `context.importFilter` 查询，禁止盲目重复上传。导入没有服务端 cancel/undo。

### `perf-salary-main-list`

查询奖励导入数据，默认当前年月；只读已有数据，不导入或发放薪资。

执行：`sdk.perfSalary.listSalaryMain`；性质：read。查询奖励导入数据，默认当前年月；只读已有数据，不导入或发放薪资。

- 边界：使用当前 SDK 用户与租户的数据权限；页面上下文由 SDK 绑定，调用方不要另拼 module-type。

| 参数 | 意义与来源 |
| --- | --- |
| name | 姓名（模糊匹配）；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| year | 年度，`'YYYY'` **字符串**（年选择器 value-format）。⚠️ 这一页**默认当前年**（dayjs().format('YYYY')），不是空。用 buildSalaryYearMonth 生成；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| month | 月份 1..12，**数字**（不是 '09' 这种补零字符串）。⚠️ 这一页**默认当前月**，不是空；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| orgIdList | 角色组织树所选组织 ID 数组；只选择 selectable=true 的节点；来源：contract-support-role-organization-search 返回 list[].id；由用户选定，不能以名称、编码或其他实体 ID 替代；候选：contract-support-role-organization-search list[].id |
| pageNo | 页码，默认 1；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| pageSize | 每页条数，默认 20；来源：用户给出的业务条件；格式和必填性按参数契约。 |

返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。

- list[].basicSalary：基本工资金额；金额单位元，不做元分转换；单位：元
- list[].examineSalary：考核工资金额；金额单位元，不做元分转换；单位：元
- list[].profitSalary：利润工资金额；金额单位元，不做元分转换；单位：元
- list[].rewardSalary：奖励工资金额；金额单位元，不做元分转换；单位：元
- list[].totalSalary：工资合计；金额单位元，不做元分转换；由四项工资相加后扣除 (signDeductScore+evaluateDeductScore)×moneyPerScore，必须用服务端合计，不能仅加页面四列；单位：元

- 消费：按工号与年月区分员工记录；仅当前页不得用于全公司总金额。
- 消费：五个工资金额字段均为元；totalSalary 已扣签订/评价扣分折现，直接展示服务端合计，不能简单相加页面四个工资分项替代。

完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。
