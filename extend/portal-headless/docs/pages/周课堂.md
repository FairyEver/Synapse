## Portal 可达来源

`weekly-lesson/list.vue` 的创建按钮绑定自定义 `actionCreate()`，弹窗确认后进入
`meeting/[mode]/[id].vue` 或 `assignment/[mode]/[id].vue`；编辑按钮按 `lessonKind` 进入
同两类路由。列表还绑定单删/批删、发布/取消发布/发布但不推送，以及会议式课堂的“课堂记录”。
被注释的 `rrList.actionCreate()` 和 `actionStudent` 均不计入可达动作。

Portal 固定检出 `CodeReview_Projects_Js@test/portal/main` 的 `acab69a…` 中：

- `list.vue`：`GET /study/lesson/studylesson/lessonList`，固定 `type: '2'`；
  `actionPublish` 在 `publish`、`publishAndNoPush`、`cancel` 间选择路径和 status。
- `meeting/[mode]/[id].vue`：详情 `GET /study/lesson/studylesson/{id}`，保存
  `POST /study/lesson/studylesson/saveLesson`；课堂记录使用出勤查询、`studentManage` 和
  `/study/lesson/lessonrecord/saveLessonRecordV1`。
- `assignment/[mode]/[id].vue`：编辑页按页面原样把 `year` 转数字、过滤没有 resourceId
  的 `linkDTOS`，创建 POST/编辑 PUT `/study/lesson/studylesson`。
- `list.vue` 的导出按钮：按 `mode` 发送选中的 `lessonIdList` 和 `lessonKind` 到
  `POST /study/lesson/studylesson/exportWeekLesson`，浏览器按“周课堂.xlsx”下载二进制响应。
- `components/course-record.vue`：会议式列表“课堂记录”弹窗也使用
  `/study/lesson/lessonrecord/saveLessonRecordV1`。
- `student/[id]/item-list.vue` 是隐藏学生管理源文件；周课堂列表中的学生入口函数是注释，
  不把它当成当前菜单页已绑定的按钮，但按用户要求保留其真实接口形状。

## 端点与能力

列表参数顺序为
`order → orderField → title → gradeNames → type=2 → linkNum → teacherName →
publishTimeStart/End → createTimeStart/End → startTimeStart/End → endTimeStart/End → pageNo → pageSize`；
全部时间结束日为 +1 天开区间，格式 `YYYY-MM-DD HH:mm:ss`。

动作实现位于 `src/capabilities/study-lesson.ts`，周课堂使用独立 `requestWeekly`：

| Portal 动作 | 能力 ID | 实际请求 |
| --- | --- | --- |
| 读取会议/作业详情 | `study-lesson-weekly-detail` | `GET /study/lesson/studylesson/{id}` |
| 保存会议式周课堂 | `study-lesson-weekly-prepare-save` → `study-lesson-weekly-save` → `study-lesson-weekly-cancel-save` | `POST /study/lesson/studylesson/saveLesson` |
| 新建作业式周课堂 | `study-lesson-weekly-assignment-prepare-create` → `study-lesson-weekly-assignment-create` → `study-lesson-weekly-assignment-cancel-create` | `POST /study/lesson/studylesson` |
| 编辑作业式周课堂 | `study-lesson-weekly-assignment-prepare-update` → `study-lesson-weekly-assignment-update` → `study-lesson-weekly-assignment-cancel-update` | `PUT /study/lesson/studylesson` |
| 删除课堂 | `study-lesson-weekly-prepare-delete` → `study-lesson-weekly-delete` → `study-lesson-weekly-cancel-delete` | `DELETE /study/lesson/studylesson`，body 为 `[id,...]` |
| 发布/取消/不推送发布 | `study-lesson-weekly-prepare-publish` → `study-lesson-weekly-publish` → `study-lesson-weekly-cancel-publish` | PUT `/publish` 或 `/publishAndNoPush`，body `{ id, status }` |
| 读取出勤/记录 | `study-lesson-weekly-attendance`、`study-lesson-weekly-record` | `GET /lessonrecord/selectAttendanceStatus`、`GET /lessonrecord/getLessonRecord` |
| 保存周课堂记录 | `study-lesson-weekly-record-prepare-save` → `study-lesson-weekly-record-save` → `study-lesson-weekly-record-cancel-save` | `POST /study/lesson/lessonrecord/saveLessonRecordV1` |
| 保存出勤 | `study-lesson-weekly-prepare-attendance` → `study-lesson-weekly-attendance-save` → `study-lesson-weekly-cancel-attendance` | `POST /study/lesson/lessonrecord/studentManage`，body 为数组 |
| 导出周课堂 | `study-lesson-weekly-export` / `sdk.studyLesson.exportWeekly` | `POST /study/lesson/studylesson/exportWeekLesson`，body `{ lessonIdList, lessonKind }`，返回 `{ fileName, contentType, base64, byteLength }` 文件描述 |
| 学生列表（隐藏页） | `study-lesson-weekly-student-list` | `GET /study/lesson/studylessonstudentrel/studyStudentList` |
| 学生行移入/移出 | `study-lesson-weekly-student-prepare-move-out` → `study-lesson-weekly-student-move-out` → `study-lesson-weekly-student-cancel-move-out` | PUT `/study/lesson/studylessonstudentrel/moveOut`，body `{ lessonId, staffCodeList, type }` |
| 学生页批量按钮 | `study-lesson-weekly-student-prepare-batch-delete` → `study-lesson-weekly-student-batch-delete` → `study-lesson-weekly-student-cancel-batch-delete` | DELETE 同一 `moveOut`，body 直接为学生行 `[id,...]`，无 query |

学生行操作按 `status === 1` 生成 `type: 2`，否则生成 `type: 1`。批量 DELETE 是
`common/libs/renren/list.js` 的 `deleteIsBatch` 原样行为，不是 Java `MoveOutLessonStudentDTO` 的
PUT 变体。

## 门禁与跨页依赖

- 保存会议式表单固定 `type=2`、`lessonKind=0`，保留 `gradeIds`、`gradeStaffCodeList`、
  `title`、`hostCode`、`lessonType`、`time`、`info` 等 Portal 字段；保存按钮由
  `!!status` 禁用。
- 作业式表单保留 Portal 的 `linkDTOS` 字段投影；页面的 `isDisabled` 是
  `isStart === 1 && status === 1`，prepare 同样拒绝该状态。
- 列表发布按钮只在 `isRelGrade === 1` 的分支中显示。周课堂的 `publishAndNoPush` 不把
  选择值放进 body，只改变 URL；body 仍是 `{ id, status }`。
- 删除 prepare 在已知 status=1 时拒绝，Java `deleteLesson` 仍是最终门禁。
- `saveLesson` 返回的课堂 ID 要继续传给 `studentManage` 和记录保存；Portal 页面把出勤与
  记录作为后续请求，并非把学生 DTO 塞进 `saveLesson` body。
- 导出至少选择一条课堂且 ID 不能重复；`lessonKind=0` 对应会议周课堂，`lessonKind=1`
  对应作业周课堂。SDK 固定返回 Portal 使用的文件名 `周课堂.xlsx`，只接受非空二进制文件；
  空响应或 JSON/text 错误体会报错。
- `cancel` 只取消本地 prepare 草稿，没有后端回滚。

## Java 对照证据

固定检出 `CodeReview_Mall_Platform_Java@test/test` 的 `0f1a557…`：

- `StudyLessonController` 提供 `lessonList`、详情、基类 POST/PUT/DELETE、`saveLesson`、
  `publish`、`publishAndNoPush`；基类 POST/PUT 是作业式 `AddLessonDTO`，`saveLesson` 是
  会议/晨/月使用的 `SaveLessonDTO`。
- `StudyLessonRecordController` 提供 `getLessonRecord`、`selectAttendanceStatus`、
  `studentManage(List<StudyLessonStudentRelDTO>)`、`saveLessonRecordV1`。
- `StudyLessonStudentRelController` 的 `PUT moveOut` 接受 `lessonId`、`staffCodeList`、
  `type`；其基类 DELETE 并不改变 Portal 把 DELETE 发到 `/moveOut` 的事实。
- 发布接口要求 id/status；删除服务拒绝已发布课堂。
- `StudyLessonController.exportWeekLesson` 接受 `lessonIdList` 与 `lessonKind`；会议周课堂
  (`lessonKind=0`) 会向响应流写出 Excel。当前固定 Java 检出中，作业周课堂
  (`lessonKind=1`) 只调用 `selectExportWeekLesson` 而控制器没有写出文件；SDK 对空响应报错，
  该分支仍是后端缺口。
