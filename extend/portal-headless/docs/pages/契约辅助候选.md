# 契约辅助候选（已有业务缺失候选的补齐）

新增11个只读候选能力和1个必要的法人开户详情能力，帮助已有绩效、知识权限、考勤排班、合同模板、学习统计和差旅链路取得真实ID。统一SDK门面为 `sdk.contractSupport`，每个方法只收一个query对象；统一调用可用 `sdk.capabilities.invoke(capabilityId, query)`。合成目录上下文 `/base-data/contract-support` 不是一个新开发菜单页面。AI权威说明在 `src/catalog/contracts-support.ts`，由 `catalog.describe()` / `describeMethod()` / `describePage()` 实际提供。

岗位参数为keyword、pageNo（默认1，1至1000000）、pageSize（默认20，1至100）。差旅预算额外必填orgId和budgetMonth（YYYY-MM），可选applyAmount为当前行trafficAmount+foodAmount+housingAmount+otherAmount+inputTaxAmount五项之和，单位元且非负；预算占用含进项税，不能只加四项费用。后端按输入orgId扩展自身和祖先orgIds，候选orgName可能属于上级组织，不是错误组织。budgetMonth来自预计付款日期，不是出差开始月份。

所有排班候选只提供新增范围的ID；排班保存是整体覆盖，必须先读现有排班保留其他类别，不能把本次未选类别清空。候选取得不代表业务已保存或预算已占用。

## 最终返回契约

公共候选返回 `{list,total,limit,truncated}`，没有后端ret/code/data包络。

| 字段 | 含义 |
| --- | --- |
| list[].id / name | 实体ID字符串与展示名；数字ID超过JavaScript安全整数时拒绝而不悄悄改号 |
| list[].code | 源节点code，未提供为null；不可用名称生成编码 |
| list[].parentId | 树上级ID；平面清单/根节点无上级为null |
| list[].path[].id / name | 当前响应树根到自身路径，帮助同名消歧；平面清单仅自己，不承诺完整公司组织链 |
| list[].hasChildren | 原始树有无子节点；课程有子节点仍可选，合同分类只保留叶子 |
| list[].selectable | 组织isSelected=1映射false；祖先不可选标记不能反读 |
| total | 本次完整源响应经过keyword匹配后的条数，不是全租户实体总量 |
| limit / truncated | 本地上限与是否仍有匹配未返回；截断后细化关键词或增大limit |

岗位返回 `{list,total,pageNo,pageSize,hasMore}`。list元素仅含id/name/postId/parentId/status/ancestors；postId为后端真实岗位派生ID，nullable；status为0未使用/1正在使用，nullable，不是权限枚举；ancestors元素为id、可空name、available。hasMore按pageNo*pageSize<total判断，继续下一页。响应混入dataType=1文件夹直接报错。

预算返回相同本地切片容器，但元素为：id（明细ID）、budgetDetailNo（detailCode）、budgetId（主单ID）、budgetNo、budgetType、budgetMonth、orgName、detail（业务内容分类ID）、detailType、amount、availableBalance、occupiedAmount、paymentDate、selectable、disabledReason。金额保留后端number或十进制string，单位元；缺失为null，不按0解释。余额优先availableAmount再availableBalance。SDK保留后端不可选原因，并按余额<=0及余额<applyAmount补足不可选判断；余额未知不宣称足够。查询不锁预算，准备/提交前按当前业务金额再次核实。

法人开户详情不需要keyword；corporationId必须来自用户所选法人候选。

接口原始扩展字段不向AI透传，避免将未核实字段包装成已理解的结构。结构不是数组、必需ID/名称缺失、金额格式错误时抛错；不把异常转换成空候选。

法人详情返回七字段：payeeType=2（公司）、companySubType=1（内部分公司）、receivingCorporationId（字符串且必须等于查询ID）、receivingCorporationName、receivingCompanyName（同法人名，兼容显示）、receivingBankName、receivingAccount（字符串保留前导零）。后端选该法人收款账户列表第一条，不是用户任选账户列表。更换法人必须清空旧receivingCompanyId、payeeId/payeeCode/payeeSourceType/sourceType及receivingBankDictValue和旧银行信息，再填入本次七字段。后端404无法人、400未配置账户时停止，不能沿用旧账号。
