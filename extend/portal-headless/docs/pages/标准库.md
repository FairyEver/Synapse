# 标准库（孵化预案）

## 能力定义

- 页面：`/dashboard/product/setting/hatchery-manage/lib/list`
- 菜单/路由权限：`/dashboard/frame/hatchery-plan/lib`
- 页面源码是 Portal 包装器 `hatchery-manage/lib/list.vue`，实际导入并复用 `hatch-manage/lib/list.vue`；因此实际接口和表单行为按复用组件记录。
- HTTP 实例：`product`；页面没有可推导的 `module-type`，不发送该请求头。
- 页面按钮权限：查询 `program:suite:query`，新建/编辑/查看标准 `program:suite:submit`，删除 `program:suite:delete`。

## 参数契约

筛选字段为品种 `variety`、代次 `gen`、舍内温度 `tempId`，列表请求固定带 `scope=1`、`order=''`、`orderField=''`，分页默认 `pageNo=1`、`pageSize=20`，页面支持 10/20/50/100。

舍内温度来自 `GET /programNew/baseSetting/temp/getTempInList`，Portal 将 `id` 映射为 value、`inTitle` 映射为 label。列表来自 `GET /programNew/standardLib/getPage`，编辑使用 `id、variety、gen、tempId、suiteCode、file:null`；当前 Java 列表 DTO 通常没有 id，编辑/删除不能从名称猜 ID，删除必须使用 `suiteCode`。

新建表单要求品种、代次、舍内温度和 `.xls/.xlsx` 文件。首次 `POST /programNew/standardLib/importStandardLib` 发送 `variety、gen、tempId、suiteCode、file`；响应冲突标记为 1 时，必须由用户明确选择 1 替换、2 增加或 3 覆盖，再对同一草稿发送第二次请求并带 `flag`。模板下载调用 `GET /programManage/exportFile?fileName=标准库模板`。

## 逐字段基准

列表行包含 variety、varietyName、gen、genName、ageStage、ageStageName、tempId、tempName、suiteCode、flag；页面展示品种、代次、舍内温度，编辑/删除使用 suiteCode，其他字段按原值保留。分页 `total` 是筛选条件下的总数，不是当前页长度。

导入文件在 SDK 中用文件名、MIME、Base64 和字节数表示；返回的模板也是 Base64，不把它解释成业务记录。空文件、坏 Base64、非 xls/xlsx、权限或 Java 业务错误均抛出。

## 操作步骤

1. 查询温度候选，再按筛选条件读取标准库分页。
2. 新建或编辑先 `prepareCreate`/`prepareUpdate`；取消只丢弃草稿。
3. 新建首次调用 `create` 时省略 flag；返回 conflict 后只接受用户明确的 1/2/3，再次调用同一 `create`。
4. 编辑调用 `update`，删除先 `prepareRemove` 再由用户确认调用 `remove`；写入成功或响应不确定时重新 list 回查。
5. “查看标准”会导航到 `/dashboard/product/setting/hatch-manage/lib/indicator/list`；该子页不是本页能力，需单独核对。

Portal/Java 固定检出锚点为 Portal `82651c98c5`、Java `998ce8223fa`。本页未启动浏览器、未执行真实测试环境 smoke；当前实现复用已逐页核对的养殖预案标准库能力，并将页面路径和权限重新绑定到孵化预案菜单。后端没有 requestId 幂等包装，写请求不确定时先回查，不自动重放。
