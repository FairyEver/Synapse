## 这一页是五页里最简单的一条：**表单是空的**

`useListPageModule({ …, form: {} })`（`list.vue:78-116`）—— 没有 `convertFetchForm`，
也没有任何筛选控件（表单区只有一个「创建月度双赢协议」按钮）。所以列表接口除分页外
**没有任何业务参数**：URL 上就是 `order=&orderField=&pageNo=&pageSize=`。

要按条件筛月度协议请用[所辖月度](./所辖月度.md)（`othersPage`），它才有那套筛选。

## 参数契约

顺序逐字推自 `list.js:473-483`，`convertFetchForm` 是恒等函数、`form` 是空对象 ⇒
order 表就是 `[order, orderField, pageNo, pageSize]`：

| 参数 | kind | 说明 |
| --- | --- | --- |
| `pageNo` / `pageSize` | number | 默认 `1` / `20`（`styleV2: true` → 20） |

`order` / `orderField` 两个键**照发**（空串），它们是列表模块自己加的（`list.js:474-475`），
页面没有这两个控件。

GET /admin-api/performance/protocol/kpimonthprotocol/page

  `DELETE /performance/protocol/kpimonthprotocol/{id}`，**没有 body**（不是批量删）。

- 页面上「时间节点及扣分标准」是个纯展示弹窗，没有接口。

## SDK AI 说明契约（2026-09-22）

本节由当前 SDK 描述结果整理；说明权威来源为 `src/catalog/contracts-business.ts`。调用 `catalog.describe(id)`（或 `id-llm`）可得到参数来源、返回字段/状态、数据消费与后续映射；`catalog.describePage(页面路径)` 用于选择页面功能。以下更新以本节为准；前文历史请求/实测记录仍保留其记录日期。

### `perf-month-agreement-list`

查询当前用户个人月度协议；仅分页，没有名称/年月筛选参数。

- 执行：`sdk.perfAgreement.listMonthAgreements`；通过 `capabilities.invoke('perf-month-agreement-list', args)` 调用时按 `params` 填参。性质：read。
- 参数：`pageNo` 可选 (number)；`pageSize` 可选 (number)。完整来源、枚举、条件必填与默认值由 SDK 同次返回。
- 返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。
- 字段：`list`、`total`、`list[].id`、`list[].name`、`list[].year`、`list[].month`、`list[].promoterName`、`list[].creatorName`、`list[].signatoryName`、`list[].createTime`、`list[].status`、`list[].actionButtons`。嵌套字段、可空性及业务含义见同次返回的 `returns.fields`。
- 消费：展示协议名、年月、创建人及签订人；按动态字典解释 status。actionButtons 仅用于解释页面可选动作，本组 SDK 没有签订、评分、撤销或状态变更写能力。
- 完成条件：在请求的数据范围交付协议列表；不要宣称签订/变更已完成。
- 后续：optional → `base-dict-get`：按 month_task_review_status 查询当前字典，将返回 value 与业务行状态/类型值转成同一字符串后匹配 label；没有匹配时显示原码并说明标签未配置（dictType ← literal:"month_task_review_status"）
- 失败/不确定：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。
