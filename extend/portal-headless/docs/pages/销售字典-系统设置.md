# 销售字典（系统设置）

页面：`/dashboard/setting/dict-platform/sale/list`
菜单权限：`/dashboard/setting/dict-platform/sale`
HTTP 实例：`platform`；页面路径不命中 `module-type`，不发送该请求头。

Portal 的销售 wrapper 固定 `SYSTEM_SALE_VALUE=6`，根类型分页由 SDK 固定发送 `useSystem=6`；数据子页沿用当前字典类型，不额外发送 `useSystem`。

能力包括类型分页、字典数据分页/详情、新建、编辑和单条删除。根页类型写入、批量删除、导入、导出及数据页批量删除未在活动页面中启用，不作为 SDK 能力。

## 参数与返回

类型请求为 `GET /admin-api/system/dict-type/page`，发送 `order=''`、`orderField=''`、`useSystem=6`、`name`、`type`、`pageNo`、`pageSize`；分页大小仅接受 `10/20/50/100`。数据请求为 `/admin-api/system/dict-data/{page,get,create,update,delete}`，`dictType` 必须来自类型行的 `type`，不能使用类型 `id`。

数据表单的 `label`、`value` 必填，`sort` 为非负整数（默认 0），`status` 为 `0=开启/1=关闭`；创建同时提交 `dictTypeId=dictType` 和 `dictType`。`platform=true` 的共享行不可编辑或删除。长整数 ID 保留字符串形态，列表/详情/写入错误原样抛出，不降级为空结果或成功。

返回字段保留类型行 `id/name/type/status/remark/createTime/useSystem/tenantEditable`，数据行 `id/sort/label/value/dictType/status/colorType/cssClass/remark/createTime/tenantId/platform`。写操作返回新 ID 或 `true` 后必须按原 `dictType` 分页回查确认终态；超时先回查，不盲目重试。
