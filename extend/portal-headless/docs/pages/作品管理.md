# 作品管理（`/dashboard/certificate/works/list`）

风险防控域的作品分页列表、作品表单和共享设置。Portal、Java 与 SDK 按本页逐项核对；页面没有可达导出按钮。

## 页面标识

| 项 | 值 |
| --- | --- |
| 菜单路径 | `/dashboard/certificate/works/list` |
| 菜单名 | 作品管理 |
| 菜单/路由权限 | `/dashboard/certificate/works` |
| 列表文件 | `app/portal/views/dashboard/hr/certificate/works/list.vue` |
| 表单文件 | `app/portal/views/dashboard/hr/certificate/works/[mode]/[id].vue` |
| 共享组件 | `app/portal/components/portal/hxr/modal-share-user/index.vue` |
| module-type | **15 风险防控**，按页面路径推导 |
| HTTP 实例 | `platform` |
| 页面形态 | 分页列表 + 新建/编辑表单 + 共享设置 |
| SDK 能力 | `piece-*` |

## Portal 页面行为

列表通过 `GET /admin-api/hr/piece/page` 查询。可见筛选只有 `name`、`softwareNumber`、`author`，初始值为空字符串；页面状态中还保留不可见的 `status=''`，请求带 `order=''`、`orderField=''`、`pageNo=1`、`pageSize=20`。可达操作是新建、编辑、共享设置和删除。

详情通过 `GET /admin-api/hr/piece/get?id=...` 读取。新建调用 `POST /admin-api/hr/piece/create`，编辑调用 `PUT /admin-api/hr/piece/update`，删除调用 `DELETE /admin-api/hr/piece/delete?id=...`。创建返回作品 ID，更新和删除返回 Boolean。列表/详情由后端补充作品类别名称、组织名称、提醒人员名称和到期状态。

## 表单、权限和数据规则

- `softwareNumber`、`name`、`type`、`author`、`copyrightOwner`、`completeDate`、`isPublish`、`publishDate`、`signDate`、`organizationId`、`endTime`、`remindTime`、`remindUser`、`pdfUrl` 按 Portal 校验为必填；`softwareNumber` 最多20字符，名称/作者/著作权人最多50字符。
- `isPublish` 为1发表或2未发表；Portal 的 `publishDate` 规则始终登记为必填，未发表时控件隐藏但 SDK 不擅自改变该校验语义。
- 日期按 `YYYY-MM-DD` 传输；`remindTime` 为1至99999的整数月数；提醒人员数组提交为逗号字符串。
- 附件只接受 `application/pdf`，上传控件最多保留5项；`pdfUrl` 与 `pdfName` 按下标成对，提交时分别逗号连接。
- `type` 是 `works_type` 字典值，必须使用已核实候选；共享资源 `type` 固定为 `7`。列表源码中的导出相关代码没有页面按钮，不注册导出能力。
- 列表、详情、写入和共享受当前会话、租户、页面权限及后端数据范围约束。Java `HrPieceDO` 继承 `TenantBaseDO`；SDK 不把 `true` 单独当作写入完成证据。

## 后端与 SDK 对齐

Java `HrPieceController` 提供分页、详情、创建、更新、删除和不可达导出端点；`HrPieceSaveReqVO` 使用 Long/LocalDate/Integer 和逗号字符串字段；`HrPieceServiceImpl` 补充提醒人员、组织和到期状态。共享枚举为 `PIECE(7, "作品")`。

实现文件：`src/capabilities/piece.ts`；AI 说明：`src/catalog/contracts-piece.ts`。写能力按 `prepare → submit → 回查`，用户取消只丢弃本地草稿，不虚构服务端取消接口。
