# 领导利润工资计提表

页面路径：`/dashboard/report/leadership-profit-salary/list`。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询列表 | `report-leadership-profit-salary-list` / `reportLeadershipProfitSalary.list` | `GET /admin-api/hr/leader-profit-salary-provision/page` |
| 准备新建 | `report-leadership-profit-salary-prepare-create` / `.prepareCreate` | 不发请求；按页面表单规则生成本地草稿 |
| 新建 | `report-leadership-profit-salary-create` / `.create` | `POST /admin-api/hr/leader-profit-salary-provision/create` |
| 准备编辑 | `report-leadership-profit-salary-prepare-update` / `.prepareUpdate` | 不发请求；只允许待月结记录 |
| 编辑 | `report-leadership-profit-salary-update` / `.update` | `PUT /admin-api/hr/leader-profit-salary-provision/update` |
| 准备删除 | `report-leadership-profit-salary-prepare-remove` / `.prepareRemove` | 不发请求；只允许待月结记录 |
| 删除 | `report-leadership-profit-salary-remove` / `.remove` | `DELETE /admin-api/hr/leader-profit-salary-provision/delete/{id}` |
| 下载模板 | `report-leadership-profit-salary-download-template` / `.downloadTemplate` | 平台鉴权 `GET /admin-api/sys/oss/download?fileName=领导利润工资计提模板` |
| 准备导入 | `report-leadership-profit-salary-prepare-import` / `.prepareImport` | 不发请求；本地校验文件 |
| 导入 | `report-leadership-profit-salary-import` / `.importExcel` | `POST /admin-api/hr/leader-profit-salary-provision/import`，multipart 字段 `file` |

页面菜单权限为 `/dashboard/report/leadership-profit-salary`，属于人力报表 `module-type=14`，请求使用 Portal 的 `platform` HTTP 实例。SDK 方法内部使用不带 `/admin-api` 的路径，由平台实例补齐前缀。

## 列表与权限范围

列表默认请求参数为：

```json
{
  "order": "",
  "orderField": "",
  "standardUnitId": null,
  "useYearMonth": null,
  "pageNo": 1,
  "pageSize": 20
}
```

页面只有月份和组织两个筛选。月份由 Portal 月选择器转换为 `YYYY-MM`；分页选项为 `10/20/50/100`。列表展示月份、组织名称、利润计提金额和状态，列表行同时保留编辑/删除所需的 `id`、`standardUnitId`、`useYearMonth`、`provisionAmount`、`status`。

Java 服务层先通过 `getOrgIdListByModuleType()` 取得当前用户在 `module-type=14` 下可见的组织范围，再写入 `roleOrganizationIdList` 交给 Mapper 过滤。调用方提供的 `standardUnitId` 只能在该范围内继续筛选，不能扩大可见数据。

状态值为 `0=待月结`、`1=已月结`。Portal 对 `status !== 1` 才显示编辑和删除；SDK 的 `prepareUpdate`、`update`、`prepareRemove`、`remove` 都要求当前状态为 `0`。Java 删除服务也会再次拒绝已月结记录。

## 表单提交规则

新建和编辑页面的必填字段为：

- `useYearMonth`：月份，格式 `YYYY-MM`。
- `standardUnitId`：角色组织树选中的组织 ID。
- `provisionAmount`：利润计提金额。

`provisionAmount` 对应 Portal `a-input-number` 的 `precision=2`、`min=0`、`max=9999999999.99`，SDK 提交两位小数数值。`standardUnitName` 是组织树名称快照，可随表单传入；Java 服务会按 `standardUnitId` 查询并优先补全组织全路径，名称不能代替 ID。

编辑草稿还要带当前列表行 `id` 和 `status=0`。`status` 只用于 SDK 复现页面状态门禁，不会放进 Java 的保存请求体；真正提交体为 `useYearMonth`、`standardUnitId`、可选的 `standardUnitName`、`provisionAmount`，编辑另外带 `id`。

页面表单通过列表行 bridge 回填，没有调用 `/get`；SDK 不把后端存在但页面未调用的 `get` 端点登记为本页能力。

## 模板下载与导入

模板按钮使用 `newPageWithPlatformAuth` 打开平台 OSS 下载地址，固定参数为 `fileName=领导利润工资计提模板`。SDK 用同一 `platform` 会话请求 `/sys/oss/download`，返回文件名、Content-Type、Base64 和字节数；响应没有文件名时使用 `领导利润工资计提模板.xlsx`。

导入文件选择器接受 `.xml`、`.xlsx`、`.xls`。SDK 的 `prepareImport` 校验扩展名、标准 Base64 和非空文件；确认后 `importExcel` 以 multipart 字段 `file` 提交。页面没有撤销或导入预览接口，用户取消时只丢弃本地预览；导入成功或响应不确定后，必须按文件中的月份和组织重新列表回查，不能只相信成功文案。

## 逐页操作步骤与证据边界

1. 用 `list()` 按月份/组织查询，确认记录 ID、组织、金额和状态。
2. 新建调用 `prepareCreate()`，编辑从当前列表行带上 `status` 调用 `prepareUpdate()`；只有状态 `0` 会生成草稿。
3. 用户明确确认后，把同一份 `draft` 交给 `create()` 或 `update()`；请求成功或响应不确定后按月份、组织和 ID 回查。
4. 删除用当前列表行的 `id` 与 `currentStatus=0` 调 `prepareRemove()`；确认后把同一草稿交给 `remove()`，再回查 ID 是否消失。
5. 导入先 `prepareImport()`，确认文件后调用 `importExcel()`，再按文件条件回查新增记录。

本轮逐页核对了 Portal 菜单、列表筛选/分页、列表行状态动作、bridge 表单、月份/组织/金额校验、提交字段、OSS 模板、导入文件规则、权限和 platform 请求，以及 Java Controller、Page/Save/Response/Import VO、Service、Mapper、DO 的字段和组织范围。尚未在真实测试环境使用浏览器会话执行列表、模板、导入及 `prepare → submit → 回查` 闭环；当前证据为 Portal/Java 源码和离线请求形状测试。
