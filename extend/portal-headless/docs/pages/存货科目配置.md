# 存货科目配置（`/dashboard/finance/setting/inventory-account/list`）

Portal「财务设置 → 存货科目配置」是行内编辑列表，提供筛选、物料候选、物料分类树、存货调整类型树、新增/编辑、启停、Excel导出、模板下载和Excel导入。本页按当前可达页面逐项核对 Portal 前端、Java 后端和 SDK；后端存在但页面不可达的端点不扩展为本页能力。

## Portal 页面行为

列表使用 `styleV2: true` 的自定义 `customLoad`，初始表单为：

```json
{
  "materialCategoryIds": [],
  "materialCode": null,
  "materialName": null,
  "inventoryAccountIds": [],
  "adjustmentTypeIds": null,
  "outboundUseType": null,
  "counterpartAccountIds": [],
  "useOrgAttribute": null,
  "status": null
}
```

默认页大小为 `20`，页面支持 `10/20/50/100`。列表请求逐字段为：

```json
{
  "pageNo": 1,
  "pageSize": 20,
  "materialCategoryIds": "",
  "materialCode": null,
  "materialName": null,
  "inventoryAccountIds": "",
  "adjustmentTypeIds": null,
  "outboundUseType": null,
  "counterpartAccountIds": "",
  "useOrgAttribute": null,
  "status": null
}
```

页面多选ID数组通过英文逗号拼接；调整类型既可能是单值，也可能是数组后再拼接。列表可见列为 `materialCategoryName`、`materialCode`、`materialName`、`inventoryAccountCode`、`inventoryAccountName`、`adjustmentTypeLabel`、`outboundUseType`、`counterpartAccountCode`、`counterpartAccountName`、`useOrgAttribute`、`statusName` 和操作列。状态是绝对数值 `0=停用`、`1=启用`。

物料弹窗只有选择了至少一个物料分类才打开，调用 `/admin-api/supply/materiel/page`，固定 `status=1`，默认页大小 `10`，支持 `10/50/100/500`，并携带 `categoryIds`、`matCode`、`matName`。物料分类树使用节点 `id/catName/children`；调整类型树使用节点 `id/label/value/children`。

## 表单提交规则

页面行内保存统一构造以下字段：

```json
{
  "id": "已有行ID或undefined",
  "materialCategoryIds": [],
  "materialId": "物料ID或null",
  "materialCode": "物料编码或null",
  "materialName": "物料名称或null",
  "inventoryUnitOrgId": "所属单元ID或null",
  "unitType": "normalizeSingleValue后的值或null",
  "inventoryAccountId": "存货科目ID",
  "inventoryAccountCode": "存货科目编码",
  "adjustmentTypeId": "normalizeSingleValue后的调整类型ID",
  "counterpartAccountId": "对方科目ID",
  "counterpartAccountCode": "对方科目编码",
  "counterpartAccountName": "对方科目名称",
  "outboundUseType": "字典值或null",
  "useOrgAttribute": 0,
  "status": 1,
  "remark": null
}
```

有 `id` 时发送 `PUT /update`，没有 `id` 时发送 `POST /create`。创建默认状态为启用；无 `materialId` 时至少选择一个物料分类。Java VO 还要求 `adjustmentTypeId` 非空且最多50字符，存货科目ID/编码必填，对方科目ID/编码/名称必填，备注最多500字符；物料、出库用途等动态组合由后端最终校验。`inventoryUnitOrgId` 和 `unitType` 是 Portal当前行内编辑会发送的兼容字段，但当前Java保存VO不落库，SDK仍保留它们以对齐浏览器请求。

启停使用当前状态的相反绝对值：`status=1` 的行发送 `0` 停用，`status=0` 的行发送 `1` 启用。Portal源码通过URL query发送 `id/status`；SDK请求配置使用等价的 `params: { id, status }`。启用时后端会再次检查重复配置和业务条件，不能把启停当作无条件toggle。

导出复用当前筛选条件但不携带分页字段，返回非空二进制文件；模板文件名为 `存货科目配置导入模板.xlsx`。导入文件控件接受 `.xml/.xlsx/.xls`，以 multipart 字段 `file` 上传，后端返回 `totalCount/successCount/failureCount/errorMessages`，SDK保留失败信息并要求导入后刷新列表核对。

## 权限与后端规则

- 页面权限为 `/dashboard/finance/setting/inventory-account`。
- 导出、模板、导入共用 `finance:setting:inventory-account:export`；编辑使用 `...:edit`；新增使用 `...:create`；启停使用 `...:status`。
- 当前列表没有删除按钮；Java服务的删除和详情接口不计入当前页面能力。不能因为后端有端点就绕过页面权限扩展SDK。
- 后端创建默认启用，并校验物料/分类维度、调整类型、会计科目、重复配置和租户数据范围；更新/删除还会保护已被业务使用的配置，启停允许服务端按业务状态处理。
- 页面和SDK使用 `platform` 实例，module-type无法由页面推导时不发送；凭据、租户和最终权限由会话绑定。
