列表默认值按 Portal 页面和公共分页组件：

- 配置项：pageNo=1、pageSize=20、code=null、name=null、projectDomain=null、itemType=null。

- 模板中心版本编辑器复用 `itemSimpleList({ projectDomain, status: 0 })` 获取启用的字段/业务组件候选；返回值只保证编辑器消费的 `id/itemCode/itemName/itemType/mustSelect`，后端扩展字段原样保留。

### 配置项提交映射

Portal 表单中的 domainValues 是多选数组，请求中的字段是 projectDomainCodes 字符串。SDK 先校验每个值属于
biology/information/engineering、拒绝重复值，再按代码排序并用逗号连接：

~~~text
domainValues: ["engineering", "biology"]
→ projectDomainCodes: "biology,engineering"
~~~

新增请求固定显式发送 id: null。编辑请求发送：

~~~text
id
itemCode
itemName
itemType
projectDomainCodes
mustSelect
status
remark
~~~

编辑时 itemCode 来自 current 行并保持不变；changes 只允许
itemName/itemType/domainValues/mustSelect/status/remark。恶意传入 changes.itemCode 或
changes.projectDomainCodes 会被忽略。

### 节点提交映射

Portal 节点新增表单默认：

~~~text
nodeCode: ""
nodeName: ""
projectDomain: 当前项目大类，首次为biology
parentId: null
sort: 0
status: 0
remark: ""
~~~

提交时严格复刻 form.parentId || 0：空值、null 和根节点都发送 0。节点编辑的 openForm 会展开整行，
保存时也会展开整个 form，因此 SDK 的 prepareNodeUpdate/nodeUpdate 保留 children/path/leaf/depth
以及响应中的其它行扩展字段；不可编辑的 nodeCode、projectDomain 仍从 current 行保留。

SDK 不增加 Portal 没有的树环检测，也不把当前节点的所有后代自动禁用。Portal 当前只在父节点树选择器中禁用正在编辑的节点本身。

## 表单规则

### 配置项库

| 字段 | Portal 行为与 SDK 规则 |
| --- | --- |
| itemCode | 必填、whitespace: true；编辑时禁用 |
| itemName | 必填、whitespace: true |
| itemType | 必填；field=字段、component=业务组件 |
| domainValues | 数组必填，至少一项；SDK还拒绝未知值和重复值 |
| mustSelect | switch，默认 false；页面没有额外 required 规则 |
| status | radio，默认 0；可提交 0=启用、1=停用 |
| remark | textarea，默认空字符串；没有额外规则，可保留 null |

### 节点库

| 字段 | Portal 行为与 SDK 规则 |
| --- | --- |
| nodeCode | 必填、whitespace: true；编辑时禁用 |
| nodeName | 必填、whitespace: true |
| projectDomain | 新增默认当前项目大类；编辑时禁用 |
| parentId | tree-select；清空表示根节点，提交转为 0 |
| sort | input-number，min=0，默认 0；未擅自限制为整数 |
| status | radio，默认 0=启用，1=停用 |
| remark | textarea，默认空字符串；没有额外规则 |

配置项和节点的 ID 均接受安全正整数或其十进制字符串；删除用记录 id，不能用业务编码、名称、路径或数组下标替代。

## 返回字段与消费

配置项列表返回 { list, total }。list[] 包含：

- id：记录主键，编辑和删除定位。
- itemCode、itemName：编码和名称。
- itemType：field 或 component；Portal 显示映射不应替换原编码。
- projectDomainCodes：逗号分隔编码；展示时按编码映射生物/信息/工程，未知编码保留原文。
- mustSelect：布尔值，决定“发布必选/普通”显示。
- status：页面仅将数值 0 显示为启用，其它读取值按 Portal 逻辑显示停用；写入只接受 0/1。
- remark：备注，可为 null。
- updateTime：页面原文显示，不做时区转换。

节点列表返回根节点数组，节点包含 id/nodeCode/nodeName/projectDomain/parentId/sort/status/remark，
以及页面响应中可能出现的 path/leaf/depth/children。leaf=true 显示末级，leaf=false 显示非末级；
depth 只作为页面层级展示，不重新计算路径。

所有坏响应都会抛错：分页响应缺少数组 list 或非法 total、节点树不是数组、行字段类型不符合约束，
均不会静默变成空结果。HTTP、Portal 业务错误、401/403、网络错误原样向调用方失败。

## 操作顺序和写入确认

推荐顺序：

1. itemList 或 nodeList 读取并保留用户选中的完整行。
2. 新增调用对应 prepare...Create；编辑调用对应 prepare...Update；删除调用对应 prepare...Remove。
3. 用户确认后调用对应 create/update/remove。
4. 写请求正常返回后，再调用同一页的 list/tree 回查，按 ID 和关键字段独立确认。

页面没有服务端取消或事务回滚接口。编辑恢复只能用 previous 重新形成一次 PUT，删除没有恢复动作。
写请求超时或断网时结果不确定，必须先回查，不能盲目重试新增或删除。
