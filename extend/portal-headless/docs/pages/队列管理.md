# 队列管理

## 能力定义与页面范围

平台设置 → 定时任务 → 队列管理，菜单 `/dashboard/platform/system/regular/queue/list`，权限为
`/dashboard/platform-v2/system/regular/queue`。页面使用 platform-mall-admin.js，列表和删除请求不发送 `module-type`。

页面只有分页列表和批量删除。Java Controller 还存在 get/save/update 等接口，但当前 Portal 页面没有对应入口，SDK 不把不可达后端接口发布为能力。

依据 Portal `test/portal/main @ 3622e02147` 的 `list.vue`、`mall.v2.js`，以及 Java `test/test @ c3348150f42` 的
`ManageSysQueueMysqlController` 和 `SysQueueMysqlDTO`。

## 能力和请求

| 能力 | SDK 方法 | 请求 | 页面行为 |
|---|---|---|---|
| `platform-system-queue-mysql-list` | `list(query?)` | GET `/mall-manage-api/sys/queueMysql/page` | styleV2 默认 pageSize=20 |
| `platform-system-queue-mysql-prepare-remove` / `…remove` | `prepareRemove({ids})` / `remove({ids})` | 不发请求 / DELETE `/mall-manage-api/sys/queueMysql/delete`，body 为 ID 数组 | 页面批量删除 |

列表请求固定发送 `{order:'', orderField:'', pageNo, pageSize}`，返回 `{list,total}`。行字段为 `id/queueName/worker/params/createTime/
lastConsumeTime/ownerThreadId/attempts`；页面将两个时间字段通过 `formatDate` 展示，SDK 保留 Java DTO 的整数原值，不擅自转换时区。

## 删除规则与操作步骤

页面多选值是行 `id`。SDK 要求 `ids` 非空，逐项校验正整数或十进制正整数字符串，不接受行号、空数组或不安全数字。
操作顺序：`list()` → 用户选中 ID → `prepareRemove` → 用户确认 → `remove` → 重新分页 list，确认所有 ID 消失。
取消确认不发请求；后端没有 requestId 或撤销接口，删除超时先回查，不盲目重试。
