## 参数契约

| 参数 | kind | 说明 |
| --- | --- | --- |
| `name` | text | 学员姓名（模糊） |
| `mobile` | text | 手机号（模糊） |
| `isRelatedClass` | text | 是否关联班级。**取值域未实测**（基准里是空串）→ 只透传、不给枚举 |
| `isRelatedLayer` | text | 是否关联层级。同上 |
| `createTimeStart` / `createTimeEnd` | date | 创建时间区间，**结束日 +1 天**（`buildStudyStudentTimeRange`） |
| `pageNo` / `pageSize` | number | 默认 1 / 20 |

实测 URL：`?order=&orderField=&name=&mobile=&isRelatedClass=&isRelatedLayer=&createTimeStart=&createTimeEnd=&pageNo=1&pageSize=20&_t=…`

⚠️ `isRelatedClass` / `isRelatedLayer` 的初值是**空字符串、不是 null**，所以**照样发**。
写成 null 会被 qs 的 `skipNulls` 丢掉，URL 就不与浏览器一致了。

## 那条「删除前置」单独做成了只读能力

页面删除学员前会先问一句：`GET /study/base/studystudent/isStudentInGrade?studentIds=…`，
命中就提示「XXX已在「YYY」中」而不发删除。这是一个对调用方有用的**只读**前置
（"这个学员能不能删"），所以单独做成 `study-student-check-in-grade`。

⚠️ **参数名不一样**：这里是 `studentIds`（复数、**逗号串**），而删除接口的 body 是 `ids`（数组）。
页面上就是 `ids.join(',')`。

## 真实验证（2026-09-21）

- `list()` → **5567 条**，URL 与基准逐字段一致（含键顺序）。
- `checkInGrade([327208])` → 1 条命中，打的是 `isStudentInGrade`。

## `/study/grade/student` 的归属边界

本页的菜单路径是 `/dashboard/base/student/list`，对应学员主表接口。用户本轮指定的
`DELETE /study/grade/student` 实际位于班级详情隐藏子页
`grade/[id]/student/[id]/item-list.vue`，语义是“从班级移出学员”，body 是班级学员关联记录
ID 的裸数组。因此它已归入 `study-grade.ts` 的 `study-grade-student-*` 能力，未误加到本页。

本页的 `DELETE /study/base/studystudent`（学员主表批量删除）仍未实现；已有列表和
`checkInGrade` 只读能力保持不变。

## 尚未覆盖

## SDK AI 说明契约（2026-09-22）

本节由当前 SDK 描述结果整理；说明权威来源为 `src/catalog/contracts-business.ts`。调用 `catalog.describe(id)`（或 `id-llm`）可得到参数来源、返回字段/状态、数据消费与后续映射；`catalog.describePage(页面路径)` 用于选择页面功能。以下更新以本节为准；前文历史请求/实测记录仍保留其记录日期。

### `study-student-list`

查学习系统学员基础信息及班级/层级关联情况。

- 执行：`sdk.studyStudent.list`；通过 `capabilities.invoke('study-student-list', args)` 调用时按 `params` 填参。性质：read。
- 参数：`name` 可选 (string)；`mobile` 可选 (string)；`isRelatedClass` 可选 (string)；`isRelatedLayer` 可选 (string)；`createTimeStart` 可选 (string)；`createTimeEnd` 可选 (string)；`pageNo` 可选 (number)；`pageSize` 可选 (number)。完整来源、枚举、条件必填与默认值由 SDK 同次返回。
- 返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。
- 字段：`list`、`total`、`list[].id`、`list[].name`、`list[].mobile`、`list[].isRelatedClass`、`list[].isRelatedLayer`、`list[].createTime`。嵌套字段、可空性及业务含义见同次返回的 `returns.fields`。
- 消费：按 name/mobile 区分同名学员；关联标记是关联情况，不是学习完成状态。
- 完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。
- 后续：optional → `study-student-check-in-grade`：需要知道具体所属班级时检查关联（studentIds ← list[].id）
- 失败/不确定：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。


### `study-student-check-in-grade`

只读检查指定学员与班级的关联，返回名称对；不会加入或移出班级。

- 执行：`sdk.studyStudent.checkInGrade`；通过 `capabilities.invoke('study-student-check-in-grade', args)` 调用时按 `params` 填参。性质：read。
- 参数：`studentIds` 必填 (string | number | (string | number)[])。完整来源、枚举、条件必填与默认值由 SDK 同次返回。
- 返回：`object[]`。[] 表示本次查询没有条目；这是数组，不读取 list/total。
- 字段：`[].studentName`、`[].gradeName`。嵌套字段、可空性及业务含义见同次返回的 `returns.fields`。
- 消费：以学员姓名—班级名称成对展示；结果没有班级 ID，不要把名称当 ID。
- 完成条件：展示各学员所属班级；空数组仅表示此次未查到关联。
- 失败/不确定：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。
