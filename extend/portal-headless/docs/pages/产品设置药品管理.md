# 产品设置药品管理

页面路径：`/dashboard/product/setting/base-setting/medicine/list`。

## 页面能力

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询列表 | `product-setting-medicine-list` / `productSettingMedicine.list` | `GET /config/medicine/page` |
| 本地准备新建/编辑 | `product-setting-medicine-prepare-save` / `productSettingMedicine.prepareSave` | 不发请求 |
| 保存 | `product-setting-medicine-save` / `productSettingMedicine.save` | `POST /config/medicine/save` |
| 删除 | `product-setting-medicine-remove` / `productSettingMedicine.remove` | `DELETE /config/medicine/delete` |

菜单权限为 `/dashboard/frame/base-setting/medicine`，请求使用 `product` HTTP 实例，不发送 `module-type`。页面内查询权限为 `base:medicine:query`，新建、编辑、删除按钮权限为 `base:medicine:submit`。SDK只复刻页面和服务端权限边界，不绕过权限。

## 参数契约与表单提交规则

列表是 `useListPageModule` 的 `customLoad`，初始表单和请求参数为：

```json
{
  "order": "",
  "orderField": "",
  "type": "1",
  "factory": "",
  "name": "",
  "pageNo": 1,
  "pageSize": 20
}
```

`type` 是筛选值：`1` 表示兽药，`2` 表示消毒药；Portal 列表单选控件按字符串发送。`factory` 和 `name` 是生产厂家、药物名称筛选。分页大小遵循页面支持的 `10/20/50/100`。Java 返回 `page` 包络，Portal `customLoad`消费其中的 `list` 和 `total`；SDK统一返回 `{ list, total }`。

新建和编辑共用弹窗。弹窗提交前只校验四项：类型、使用途径、生产厂家、药物名称；药物分组、成份、供应商可为空。`prepareSave` 和 `save` 始终发送八个字段：

```json
{
  "id": "",
  "type": 1,
  "purpose": "饮水",
  "medicineGroup": "抗菌药",
  "element": "有效成份",
  "factory": "厂家A",
  "supplier": "供应商A",
  "name": "药物A"
}
```

- `type` 只能是 `1` 或 `2`，SDK最终以数字提交；编辑弹窗中的类型单选框被 Portal 禁止修改。
- `purpose`、`factory`、`name` 必填；空白字符串在 SDK 发请求前拒绝。
- `medicineGroup`、`element`、`supplier`虽然可为空，也必须保留为 `''`，不能从 body 删除。
- 新建的 `id` 是空字符串；编辑保留当前列表行的 ID。
- 用户取消时只丢弃本地草稿，不调用保存接口。

删除只使用当前列表行 `record.id`，严格发送 `DELETE /config/medicine/delete` 和查询参数 `{ id }`；页面没有批量删除、启停或单独详情读取动作，SDK不扩展这些不可达接口。

## 逐字段基准

列表行保留 Portal 表格和编辑弹窗需要的字段：

| 字段 | 含义 |
| --- | --- |
| `id` | 药品记录 ID；编辑和删除目标。 |
| `type` | 数字类型，`1=兽药`、`2=消毒药`。 |
| `purpose` | 使用途径。 |
| `medicineGroup` | 药物分组。 |
| `element` | 成份。 |
| `factory` | 生产厂家。 |
| `supplier` | 供应商。 |
| `name` | 药物名称。 |
| `measureUnit`、`unit` | 后端 DTO/实体兼容字段；当前列表表格不直接展示。 |
| `total` | 当前筛选条件下的总记录数。 |

Java `MedicineController.page`把 `MedicineVO` 和 `pageNo/pageSize`交给服务层，返回 `page`；`save` 有 ID 时更新、无 ID 时新建并带防重复提交限制；`delete`是软删除。SDK不把“接口成功”当作最终业务证据。

## 操作步骤、权限和证据边界

1. 用 `list()`读取最新列表，确认 `type/factory/name`和目标行 ID。
2. 新建或编辑先调用 `prepareSave()`；用户取消则丢弃 `draft`。
3. 用户明确确认后，把同一 `draft`交给 `save()`；成功或超时用 `list()`按 ID和八个字段回查。
4. 用户确认删除后调用 `remove({ id })`；成功或超时重新查询并确认目标 ID已不再返回。
