# 纠纷信息（`/dashboard/certificate/legalDisputes/list`）

风险防控域的法律纠纷列表、完整表单、Excel 导出和共享设置。Portal、Java 与 SDK 按本页逐项核对；Java 中仅供 APP 的组织/列表接口不属于本页面能力。

## Portal 页面行为

列表通过 `GET /admin-api/hr/legal-dispute/page` 查询，筛选只有 `caseReason`、`caseNumber`、`prosecutor`、`defendant` 四个空字符串。列表模块补充 `order=''`、`orderField=''`、`pageNo=1`、`pageSize=20`。可达操作是导出、新建、编辑、共享设置和删除；导出通过 `/admin-api/hr/legal-dispute/export-excel` GET 当前四个筛选，页面固定下载 `法律纠纷.xlsx`。

表单详情通过 `GET /admin-api/hr/legal-dispute/get?id=...` 读取。新建调用 `POST /admin-api/hr/legal-dispute/create`，编辑调用 `PUT /admin-api/hr/legal-dispute/update`，删除调用 `DELETE /admin-api/hr/legal-dispute/delete?id=...`。提交前把 `pdfUrl`、`pdfName` 数组分别逗号连接，空数组转为 `null`；详情的年份和组织 ID按页面转换为表单字符串。

共享弹窗使用 `/admin-api/system/share-user/getShare` 和 `/admin-api/system/share-user/createShare`，法律纠纷资源的 `type` 固定为 `4`；读取保留 `name/managerType` 展示，保存时四类成员只发送 `{ id }`。

## 表单、权限和数据规则

- `organizationId`、`year`、`disputeType`、`litigationType`、`caseReason`、`caseNumber`、`prosecutor`、`defendant`、`requestItem`、`amount`、`solution`、`result`、`causeLoss`、`recoverLoss` 必填；`thirdPerson` 可选。
- `caseReason` 最多20字符，`caseNumber` 最多50字符，`prosecutor/defendant` 最多100字符，`thirdPerson` 最多500字符，`requestItem/result` 最多5000字符。
- `amount/causeLoss/recoverLoss` 必须非负，Portal 输入控件精度为2且自定义限制最多20字符；`solution` 只能是 `1=判决`、`2=调解`、`3=和解`。
- 年份以 `YYYY` 字符串提交，组织 ID、纠纷类型和诉讼类型使用已核实候选值。附件只允许 PDF，最多10项，URL 与名称必须逐下标对应；无附件时分别提交 `null`。
- 列表、详情、写入、导出和共享受当前会话、租户、页面权限及后端数据范围约束。Java `LegalDisputeDO` 继承 `TenantBaseDO`；SDK 不扩大权限，也不把空列表、非空文件或 `true` 回执单独当作业务完成证据。

## 后端与 SDK 对齐

Java `LegalDisputeController` 提供分页、详情、创建、更新、删除和 Excel 导出；`LegalDisputeSaveReqVO` 使用 Long ID、BigDecimal 金额、Integer 年份/类型和逗号字符串附件。`LegalDisputeServiceImpl` 按当前会话租户查询和写入；共享枚举为 `LEGALDISPUTE(4, "法律纠纷")`。`organization-list`、`getLegalDisputeListForApp`、`getLegalDisputeListForAppInfo`、`getLegalDisputeOrg` 是 APP/内部端点，不因存在于 Controller 就注册进本页面能力。

实现文件：`src/capabilities/legal-dispute.ts`；AI 说明：`src/catalog/contracts-legal-dispute.ts`。SDK 将页面可达动作接入 `legalDispute` 门面；写能力按 `prepare → submit → 回查`，取消只丢弃本地草稿，不虚构服务端取消接口。
