## ⚠️ 这是本模块里唯一**会把空值参数整个丢掉**的页

它的 `customLoad` 先过一遍：

```js
Object.fromEntries(Object.entries(params).filter(([, v]) => v !== null && v !== undefined && v !== ''))
```

实测：**无筛选时浏览器只发 `?pageNo=1&pageSize=20&_t=…`** —— 连 `order`/`orderField` 都不在。
**这与同域其它页（空值也照发）正相反**，是本模块最容易写错的一处。

`dropEmptyParams()` 就是复刻它。注意它只丢 `null`/`undefined`/空串 —— **`0` 与 `false` 要留着**。

## 时间字段是 `startTimeCondition` / `endTimeCondition`

同样与另外两页不同名。有值时它们**会**出现在 URL 上（不被丢掉）。

真值排除后，表单里 `gradeId` / `isGradeListJump` 的初值是 `undefined`（也是从 `route.query` 来）。

## 真实验证（2026-09-21）

- `listLessons()` → **76 条**；URL 是 `?pageNo=1&pageSize=3&_t=…`，**空值参数确实被丢掉**。
- 带区间时 `startTimeCondition` / `endTimeCondition` 正常出现。

## SDK AI 说明契约（2026-09-22）

本节由当前 SDK 描述结果整理；说明权威来源为 `src/catalog/contracts-business.ts`。调用 `catalog.describe(id)`（或 `id-llm`）可得到参数来源、返回字段/状态、数据消费与后续映射；`catalog.describePage(页面路径)` 用于选择页面功能。以下更新以本节为准；前文历史请求/实测记录仍保留其记录日期。

### `study-statistics-lesson-list`

按班课汇总应学人数、实学人数、完成率及平均自评/讲师成绩。

- 执行：`sdk.studyStatistics.listLessons`；通过 `capabilities.invoke('study-statistics-lesson-list', args)` 调用时按 `params` 填参。性质：read。
- 参数：`lessonTitle` 可选 (string)；`gradeId` 可选 (string)；`isGradeListJump` 可选 (string)；`type` 可选 (string)；`startTimeCondition` 可选 (string)；`endTimeCondition` 可选 (string)；`pageNo` 可选 (number)；`pageSize` 可选 (number)。完整来源、枚举、条件必填与默认值由 SDK 同次返回。
- 返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。
- 字段：`list`、`total`、`list[].lessonId`、`list[].lessonTitle`、`list[].gradeName`、`list[].startTime`、`list[].endTime`、`list[].type`、`list[].shouldStudyNum`、`list[].realStudyNum`、`list[].completionRate`、`list[].interactionsNum`、`list[].avgSelfScore`、`list[].avgTeacherScore`。嵌套字段、可空性及业务含义见同次返回的 `returns.fields`。
- 消费：用 lessonId 区分班课；人数是当前班课统计，不与学员数简单累加去重。
- 完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。
- 后续：optional → `study-record-list`：需要学员学习明细时按班课名继续查并核对班级（lessonTitle ← list[].lessonTitle）
- 失败/不确定：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。
