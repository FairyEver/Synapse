# 导出队列

## 能力定义与页面范围

平台设置 → 队列管理 → 导出队列，菜单 `/dashboard/platform/system/queue/export/list`，权限为
`/dashboard/platform-v2/system/queue/export`。页面使用 platform-mall-admin.js，列表和删除请求不发送 `module-type`。

页面只有分页列表和批量删除，没有新增、编辑、下载或单条详情动作；`type` 是页面固定的隐藏查询条件 `export`。

依据 Portal `test/portal/main @ 3622e02147` 的 `app/portal/views/dashboard/platform/system/queue/export/list.vue`、
`mall.v2.js`，以及 Java `test/test @ c3348150f42` 的 `ManageSysQueueInOutController` 和 `SysQueueInOutDTO`。

## 能力和请求

| 能力 | SDK 方法 | 请求 | 页面行为 |
|---|---|---|---|
| `platform-system-queue-export-list` | `list(query?)` | GET `/mall-manage-api/sys/queueInOut/out/page` | 固定 `type=export`，styleV2 默认 pageSize=20 |
| `platform-system-queue-export-prepare-remove` | `prepareRemove({ids})` | 不发请求 | 校验用户选中的 ID 数组 |
| `platform-system-queue-export-remove` | `remove({ids})` | DELETE `/mall-manage-api/sys/queueInOut/out/delete`，body 为 ID 数组 | 页面批量删除；没有恢复接口 |

列表请求参数为 `{order:'', orderField:'', type:'export', pageNo, pageSize}`。返回 `{list,total}`，不是数组；`list` 行保留
`id/name/message/fileType/createDateString/completeDateString/statusString/key` 以及 DTO 中的原始状态、时间和类型字段。
长 ID 保留字符串，时间整数保留原值，展示文本不擅自解析时区。

## 删除规则与操作步骤

页面多选框的选中值是行 `id`，点击删除时由公共列表模块发送 `DELETE`，body 是当前选择的 ID 数组。SDK 要求 `ids` 非空，
逐项校验为正整数或十进制正整数字符串，不接受行号、名称或空数组。

操作顺序：`list()` → 用户选择完整 ID → `prepareRemove({ids})` → 用户确认后 `remove({ids})` → 重新分页 `list()`，逐页核对所有 ID
都已消失。取消确认只是不调用 remove；后端没有 requestId 和撤销接口，删除超时不能盲目重试。
