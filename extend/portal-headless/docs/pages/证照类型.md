# 证照类型（`/dashboard/certificate/type/list`）

风险防控域的证照类型列表、提示词模板候选和类型表单。Portal、Java 与 SDK 按本页逐项核对。

## 页面标识

| 项 | 值 |
| --- | --- |
| 菜单路径 | `/dashboard/certificate/type/list` |
| 菜单名 | 证照类型 |
| 菜单/路由权限 | `/dashboard/certificate/type` |
| 列表文件 | `app/portal/views/dashboard/hr/certificate/type/list.vue` |
| 表单文件 | `app/portal/views/dashboard/hr/certificate/type/[mode]/[id].vue` |
| module-type | **15 风险防控**，按页面路径推导 |
| HTTP 实例 | `platform` |
| 页面形态 | 非分页列表 + 新建/编辑表单 |
| SDK 能力 | `certificate-type-*` |

## Portal 页面行为

列表通过 `GET /admin-api/system/license-category/page` 查询，唯一可见筛选是 `name`，初始值为空字符串；响应是证照类型数组。页面可达操作是新建、编辑和删除。

表单先调用 `GET /admin-api/sys/tip-template/list?useType=license` 加载提示词模板候选，编辑时调用 `GET /admin-api/system/license-category/get?id=...`。新建调用 `POST /admin-api/system/license-category/create`，编辑调用 `PUT /admin-api/system/license-category/update`，删除调用 `DELETE /admin-api/system/license-category/delete?id=...`。

## 表单、权限和数据规则

- `name` 必填，Portal 在失焦时去除首尾空格，最多15个字符。
- `remindTime` 必填，输入控件精度为整数且最小值为0，单位是月；0 不提前提醒。
- `tipTemplateId` 可清空；保存时按 `null` 发送。模板 ID 必须来自 `useType=license` 候选。
- 列表 `count` 是后端按当前租户证照使用情况补充的只读数量，不是表单字段。
- Java 服务校验名称重复；类型仍被证照使用时拒绝删除。列表、详情和写入受会话、租户、页面权限及后端数据范围约束。

## 后端与 SDK 对齐

Java `HrLicenseCategoryController` 提供数组列表、详情、创建、更新和删除；`HrLicenseCategorySaveReqVO` 使用 Long ID、String 名称、Integer 提醒月数和可选 Long 模板 ID；`HrLicenseCategoryDO` 继承 `TenantBaseDO`。SDK 不把 Boolean `true` 单独当作写入完成证据，写入后必须按名称/ID回查。

实现文件：`src/capabilities/certificate-type.ts`；AI 说明：`src/catalog/contracts-certificate-type.ts`。

读取当前用户在证照类型页面可见的类型列表。

- 边界：提示词模板只请求 useType=license；模板候选的 id/name 来自 Portal 下拉数据，不能用名称猜 ID。

| --- | --- |
| name | 类型名称筛选；省略时发送空字符串。；来源：用户明确输入 |
