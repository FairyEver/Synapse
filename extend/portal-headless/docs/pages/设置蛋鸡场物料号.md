# 设置蛋鸡场物料号

## 能力定义

- 页面：`/dashboard/product/setting/business-manage/setup-material-code/list`
- 路由权限：`/dashboard/frame/business/setup-material-code-farm`
- HTTP 实例：`product`；页面没有可推导的 `module-type`，不发送该请求头。
- 页面有两个 Tab：批量设置物料号、批次设置物料号。
- 批量列表：`GET /base/setupMaterialCode/farmMaterialList`，筛选 farm、variety、line、gen，分页默认 `pageNo=1`、`pageSize=20`。
- 批次列表：只有选中批次并得到 `flockGroupId` 后才调用 `GET /base/setupMaterialCode/batchMaterialList`，参数为 `flockGroupId`、`batch`；页面不显示分页。
- 联动查询：`GET /config/building/getByFarmId`、`GET /base/setupMaterialCode/getFlockBatch`。
- 弹窗候选：按页面固定的 14 个物料描述逐个调用 `GET /consumeMaterial/getMaterialList?description=...`。
- 弹窗回填：批量模式调用 `GET /base/setupMaterialCode/farmMaterial`；批次模式调用 `GET /base/setupMaterialCode/batchMaterial`。

## 参数契约

14 个物料类别及提交键为：

`eliminate`、`seedEgg`、`fecunditySeedEgg`、`combiningAbilitySeedEgg`、`parentalGenerationSeedEgg`、`commodityGenerationSeedEgg`、`male`、`female`、`growing`、`commodityEgg`、`soupEgg`、`friedEgg`、`moulting`、`moultingGrowing`。

每类都提交 `${prop}Name`、`${prop}RowId`、`${prop}MaterialId`。`Name` 是页面固定标签，`MaterialId` 是物料候选的 ID，`RowId` 是既有配置行 ID；不能用物料 ID 替代行 ID。空选择按 Portal 发送空字符串。

批量模式提交 `farmId`、`gen`、`variety`、`line`；批次模式提交 `flockGroupId`。两种模式都 POST 到 `/base/setupMaterialCode/farmMaterialSubmit`。

列表筛选按钮的页面权限分别为 `layer-farm:set-material-code-farm:query` 和 `layer-farm:setup-material-code-batch:query`。创建权限代码在 Portal 中被注释，页面实际显示创建/修改入口；SDK不添加不存在的创建权限判断。后端存在删除端点，但页面没有删除操作，因此 SDK 不提供删除能力。

## 逐字段基准

批量列表的页面列为代次、品种、品系和 14 类物料展示名称；编辑还依赖 farmId、variety、line、gen 以及每类的 MaterialId/RowId。批次列表列为 batch 和 14 类物料展示名称，并在页面内补回 farm、building、startDate、endDate、batch 作为编辑上下文。

栋号候选按 `shortName → label`、`id → value` 映射；批次候选按 `batch → label/value`、`groupId` 作为后续查询 ID；物料候选按 `materialDescription → label`、`id → value` 映射。原始扩展字段保留，但不是页面可操作契约。

## 操作步骤

1. 读取批量或批次列表；批次模式先按蛋鸡场、栋号、日期范围读取批次候选。
2. 打开弹窗时按 14 个固定 description 读取物料候选，并按当前配置回填 MaterialId 与 RowId。
3. `prepareFarmSubmit` 或 `prepareBatchSubmit` 只生成本地草稿；用户取消时丢弃草稿，不发请求。
4. 用户确认后调用对应的 `farmSubmit` 或 `batchSubmit`，成功或超时都按原筛选重新查询，逐项核对 14 类物料配置。
