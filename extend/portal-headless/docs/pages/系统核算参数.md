# 系统核算参数（`/dashboard/setting/system-accounting-parameters/list`）

## 页面范围与证据

Portal 菜单“系统设置 → 系统核算参数”，权限 `/dashboard/setting/system-accounting-parameters`，使用 `platform` HTTP 实例；页面路径不命中 module-type 规则，SDK 与 Portal 一样不发送 `module-type`。

当前页面是 `common-layout-dashboard-crud-container` 承载的只读分页。列表源码只定义了一个名为 `query1` 的输入框，调用 `/salary/parameter/page`，展示名称、来源和备注。当前页面没有新增、编辑、删除、详情或导出按钮，也没有调用对应 Java 端点，因此 SDK 不把后端存在的写接口扩成页面能力。

Portal 证据：`app/portal/menus/hr.js`、`app/portal/views/dashboard/hr/setting/system-accounting-parameters.vue`、`list.vue`，固定提交 `bbcfc35154`。

Java 证据：`SalarySysCalculateParameterController`、`SalarySysCalculateParameterSelectDTO`、`SalarySysCalculateParameterDTO`、`SalarySysCalculateParameterServiceImpl`，固定提交 `b7a359adc9e`。Controller 的分页 DTO 声明 `name`、`source`、`pageNo`、`pageSize`，但 Portal 当前页面实际发送的是 `query1`；SDK 保留 Web 的实际请求，不伪造一个页面没有的字段映射。

## 能力与权限边界

| 页面动作 | SDK 能力 / 方法 | 请求与副作用 |
| --- | --- | --- |
| 查询分页 | `setting-system-accounting-parameters-list` / `settingSystemAccountingParameters.list` | `GET /salary/parameter/page`；无写副作用，返回当前请求对应的 `list` 与 `total` |

页面权限是菜单权限 `/dashboard/setting/system-accounting-parameters`；接口鉴权、会话租户和数据范围由 `platform` 会话负责。SDK 不把空列表解释为权限通过。

## 参数与返回字段

- 默认请求参数为 `{ order: '', orderField: '', query1: '', pageNo: 1, pageSize: 20 }`；页面支持 `10/20/50/100` 条每页。
- `query1` 是 Portal 实际表单字段和实际发送字段。Java `SalarySysCalculateParameterSelectDTO` 没有 `query1`，也没有证据表明当前页面将它转换为 `name` 或 `source`；SDK 不擅自重命名或承诺按名称/来源过滤。
- 每条记录保留 Java DTO 返回的完整字段：`id`、`name`、`source`、`remark`、`tableName`、`columnName`、`staffCodeName`、`filterSql`、`isDel`、`creator`、`createTime`、`updater`、`updateTime`。Long ID 可能是字符串；时间保留原值，不做时区转换。
- `source` 的后端约定为 `1=组织系统、2=绩效系统、3=薪酬系统`；`isDel` 的约定为 `0=未删除、1=已删除`。页面当前用字典展示 source，不能把显示标签当成请求值。

## 操作步骤与失败处理

1. 用 `list` 获取当前页，按 `total` 继续翻页，并保存需要后续核对的 `id`。
2. 展示来源时按 `source` 数值解释；不要从 `tableName`、`columnName` 或 `filterSql` 推测页面未展示的业务含义。
3. 如果用户要求按名称或来源筛选，先说明当前 Portal 只发送 `query1`，不要把 `query1` 的回包说成已按 Java DTO 的 `name/source` 过滤。
4. 分页响应缺少 `list/total`、行字段类型错误、权限失败、网络错误或后端错误均原样报告，不能降级为空页。
