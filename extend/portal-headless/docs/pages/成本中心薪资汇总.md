## 能力定义

| 页面动作 | 能力 / 方法 | 请求 |
| --- | --- | --- |
| 筛选、分页 | `report-cost-center-salary-list` / `.list` | `GET /salary/report/costCenterSummaryPage` |
| 导出 | `report-cost-center-salary-export` / `.export` | `GET /admin-api/salary/report/exportCostCenterSummary` |

页面只有只读查询和导出，没有写入动作。

## 参数契约与逐字段基准

列表请求键序为 `order`、`orderField`、`organizationId`、`monthPay`、`costCenterId`、`ledgerIds`、`pageNo`、`pageSize`。组织和成本中心是单选 ID；账套是多选 ID 数组，按页面顺序连接为逗号字符串；月份格式为 `YYYY-MM`，默认当前月；默认分页为 1/20。

导出只发送 `organizationId`、`monthPay`、`costCenterId`、`ledgerIds`，不发送排序和分页字段，默认文件名为 `成本中心薪资汇总.xlsx`。

列表可见字段包括工资月份、成本中心、人数、基本工资、考核/加班/补贴/福利等金额。金额保持服务端 `BigDecimal` 原值；页面合计只针对当前页。

组织树、成本中心和账套候选由 Portal 自动加载，SDK不复制全量候选；调用方必须提供已核实的 ID。

## 操作步骤、失败处理与验证边界

1. 用已核实的组织/成本中心/账套 ID 和月份调用 `.list`，使用 `total` 翻页。
2. 需要文件时以同一筛选条件调用 `.export`，保存非空文件。
3. 非法 ID、月份、页码、页大小、坏分页或空文件会失败；权限、网络和后端错误原样抛出。
4. 当前完成静态源码、Java DTO 和离线请求核对；真实环境读/导出 smoke 与部署版本一致性仍待执行。
