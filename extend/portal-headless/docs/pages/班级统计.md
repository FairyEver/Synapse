## 一页三个端点，按课堂类型（晨/周/月）三选一

`kind: 'morning' | 'weekly' | 'monthly'` 决定打哪个端点，也决定 body 的**形状**：

- `morning` / `weekly`：`{..., startDate, endDate}`
- `monthly`：额外把区间拆成 `year` / `month` / `endYear` / `endMonth` **四个字段**

## ⚠️ 这一页的区间是**闭区间**，不是别处那个 +1 天

页面写的是 `dayjs(form.date[0]).format('YYYY-MM-DD')` 与 `dayjs(form.date[1]).format('YYYY-MM-DD')`
—— **原样取两端、不加一天**。默认区间是「今天~今天」，body 里 `startDate` 与 `endDate` **都是今天**（实测）。

## body 的键序（是 JSON 键序，不是 qs 顺序）

实测：

```json
{"order":"","orderField":"","managementCenterIdList":[],"gradeName":"","pageNo":1,"pageSize":20,
 "startDate":"2026-09-21","endDate":"2026-09-21"}
```

⚠️ 后两项是 `customLoad` 里**追加**上去的，所以**排在最后** —— 不是插进中间。

## 另外两个端点

页面挂载时还会打 `POST /study/statistics/countGradeMorningLesson`（一个**汇总**调用，不是分页查询），
以及 `GET /study/base/studymanagementcenter/getAllCenter?roleId=`（**全部**管理中心灌下拉）。
**两个都没有做**：前者不是这一页的列表契约，后者是长选项参数（D6 / H35 不照抄）。

## 真实验证（2026-09-21）

- `listGradeLessons('morning')` → **820 条**；是 POST；body 键序与基准逐项一致。

### `study-statistics-grade-list`

按晨/周/月课堂统计各班级开课数；kind 决定查询端点，日期为闭区间。

- 执行：`sdk.studyStatistics.listGradeLessons`；通过 `capabilities.invoke('study-statistics-grade-list', args)` 调用时按 `params` 填参。性质：read。
- 参数：`managementCenterIdList` 可选 ((string | number)[])；`gradeName` 可选 (string)；`startDate` 可选 (string)；`endDate` 可选 (string)；`pageNo` 可选 (number)；`pageSize` 可选 (number)；`kind` 必填 (string)；`year` 可选 (string)（含条件必填）；`month` 可选 (string)（含条件必填）；`endYear` 可选 (string)（含条件必填）；`endMonth` 可选 (string)（含条件必填）。完整来源、枚举、条件必填与默认值由 SDK 同次返回。
- 返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。
- 字段：`list`、`total`、`list[].gradeId`、`list[].serialNumber`、`list[].gradeName`、`list[].studentNum`、`list[].countNum`、`list[].lessonIds`。嵌套字段、可空性及业务含义见同次返回的 `returns.fields`。
- 消费：显示班级编号、名称、人数、开课数；不包含顶部已开课/未开课班级 count 接口。
- 完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。
- 后续：optional → `study-statistics-lesson-list`：查看某个班级各班课统计（gradeId ← list[].gradeId）
- 失败/不确定：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。

## 本轮补齐（2026-09-26）：行上的「课堂内容」弹窗（只读）

页面每一行（有 `lessonIds` 时）都有一个「课堂内容」入口，弹窗里打的是
`grade/components/record.vue:73` 的这条请求 —— 它不是列表模块发的，参数也和列表完全不同。

| 能力 id | 请求 | 入口 |
| --- | --- | --- |
| `study-statistics-grade-lesson-record` | `GET /study/statistics/getGradeLessonRecord` | 行「课堂内容」→ 弹窗 |

**参数契约**：**只有 `lessonIds` 一个参数**，而且它是**逗号分隔的字符串**（后端 `lessonIds.split(",")`），
不是数组也不是重复参数。SDK 收数组、在本地拼成逗号串；传空数组或空串**直接拒绝** ——
后端对空值是 `StringUtils.isBlank` 直接返回空列表（不是"查全部"），静默的空会让人以为"这个班没有课堂内容"。

**逐字段（`LessonRecordDTO`）**：`lessonId`、`name`（班课名）、`recordList[].recordType` / `.recordContent`
（页面按字典 `lesson_tag` 取标签再展示内容）、`imgUrl` / `pdfUrl` / `pdfName`
（三者都是**逗号分隔的多值**，页面自己 split；`pdfName` 与 `pdfUrl` 按下标一一对应）。

**⚠️ 返回顺序不等于传入顺序**：后端拿到 id 串后 `split(",")` → `sorted(Collections.reverseOrder())`
（**字符串倒序**）再逐个取，所以返回数组的次序与传入的 `lessonIds` 不一致 —— **按 `lessonId` 逐条对应，不要按下标对齐**。

**操作步骤**：从班级统计行拿 `lessonIds`（字符串，直接原样传给 SDK 的数组参数或字符串参数都可）→ 读取记录。只读。

**推断与缺口**：**没有浏览器基准**；参数形状来自固定检出源码；尚未在真实测试环境执行；
`lesson_tag` 字典取值未核实（页面取值句在 recordType 命中不到时会抛错，这也是照抄的行为）。
