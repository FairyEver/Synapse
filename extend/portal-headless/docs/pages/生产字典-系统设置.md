# 生产字典（系统设置）

页面：`/dashboard/setting/dict-platform/product/list`

业务键：`product`

页面权限：`/dashboard/setting/dict-platform/product`

HTTP 实例：`platform`

module-type：按当前规则表未命中，不发送。

## 能力定义

生产字典 wrapper 将共享字典根列表固定为 `useSystem=4`（`SYSTEM_PRODUCT_VALUE`）。根列表只查询生产字典类型；类型的新增、编辑、删除、批量删除、导入、导出不是活动页面能力。点击某个类型的“字典数据”进入数据子页。

数据子页提供标签/状态筛选、分页、读取详情、新建、编辑和单条删除。查询结果是平台共享数据与当前租户自有数据的合并视角；`platform=true` 的平台行在页面上禁用编辑和删除。

## 参数契约与请求

类型列表：`GET /admin-api/system/dict-type/page`，参数顺序和字段为 `order=''`、`orderField=''`、`useSystem=4`、`name`、`type`、`pageNo`、`pageSize`。`name`、`type` 缺省发送空字符串；页码默认 1，每页默认 20，仅支持 10/20/50/100。调用方不能用参数覆盖 `useSystem`。

数据列表：`GET /admin-api/system/dict-data/page`，发送 `order=''`、`orderField=''`、`dictType`、`label`、`status`、`pageNo`、`pageSize`；`dictType` 必须来自类型行的 `type`，不是类型 `id`。状态为 `0=开启`、`1=关闭`，清空时发送 `undefined`。

详情：`GET /admin-api/system/dict-data/get?id=<id>`。

新建：`POST /admin-api/system/dict-data/create`。页面表单字段为 `label`、`value`、`sort`、`remark`、`status`；SDK 序列化为 `id=''`、`dictTypeId=dictType`、`dictType`、`label`、`value`、`sort`、`status`、`remark`。`sort` 默认 0 且不能为负数，`status` 默认 0，`label`/`value`/`dictType` 不能为空且后端长度上限为 100。

编辑：`PUT /admin-api/system/dict-data/update`，提交 `id`、`dictType`、`label`、`value`、`sort`、`status`、`remark`。删除：`DELETE /admin-api/system/dict-data/delete?id=<id>`。两者都只允许当前租户自有数据；平台共享行不得提交。

## 返回字段与消费

分页返回 `{ list, total }`。类型行字段包括 `id`、`name`、`type`、`status`、`remark`、`createTime`、`useSystem`、`tenantEditable`；数据行字段包括 `id`、`sort`、`label`、`value`、`dictType`、`status`、`colorType`、`cssClass`、`remark`、`createTime`、`tenantId`、`platform`。长整型 ID 可能是字符串，应原样保留。

用类型行的 `type` 调用数据列表；用数据行的 `id` 读取详情、编辑或删除。`tenantEditable=1` 是租户写入该类型的前置条件；`tenantId=0` 对应平台共享，`platform=true` 表示只读。`list=[]` 是当前页为空，`total=0` 才表示筛选无记录；请求或业务错误抛出，不能降级为空页。

## 操作步骤与失败处理

读取：先调用类型列表，选择 `type` 后调用数据列表；编辑前调用详情并保留完整字段。新建、编辑、删除的 true/ID 回执不能单独证明业务已落库，成功或超时后应按原 `dictType` 分页回查：新建核对唯一的 `label/value` 及 `sort/status/remark`，编辑核对同一 `id`，删除核对目标 `id` 已消失。

参数校验、类型不存在或停用、`tenant_editable` 不满足、平台行只读、当前租户缺失、权限、网络和后端错误均应报告失败。没有后端 `requestId` 幂等包装；创建、更新或删除超时先回查，不要盲目重试。该页面没有通用 `prepare/cancel` 能力。
