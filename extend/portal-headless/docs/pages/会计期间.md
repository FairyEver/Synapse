## 页面条件与权限

页面目录和路由权限均为 `/dashboard/finance/setting/accounting-period`。Portal 当前启用 `financeListPermissionSwitch = true`：查询和重置没有独立按钮权限；新建按钮要求 `finance:setting:accounting-period:create`，启停按钮要求 `finance:setting:accounting-period:status`，详情按钮要求 `finance:setting:accounting-period:detail`。企业名称筛选仅在用户名严格为 `admin` 时渲染。启停按钮始终可见于有权限的列表行，按当前 `status` 发送相反的绝对目标值。

当前 Java `AccountingPeriodController` 没有类级或方法级 `@PreAuthorize`；上述按钮权限是 Portal 的显示条件，不是 SDK 本地的授权裁决。SDK 绑定页面权限、platform 实例和 `moduleType=null`，实际是否允许仍由当前会话、租户和后端认证/权限链路决定。Java 同时存在 `/update`、`/get`、`/export-excel`，但 Portal 本页没有到达这些端点的动作，因此不发布对应 SDK 能力。

## 参数契约

列表固定发送 `order=''`、`orderField=''`，默认 `year=''`、`tenantName=null`、`status=0`、`pageNo=1`、`pageSize=20`。`tenantName=null` 经 HTTP 序列化后不出现在 URL。`status` 只接受数值 `0`（启用）或 `1`（停用）；页面不提供“全部”。企业名称输入只向用户名严格等于 `admin` 的 PC 用户显示。

创建只接受 `startDate/endDate`（`YYYY-MM-DD`）：页面日期控件禁止早于浏览器当前年份，结束日期必须与开始日期同年且不早于开始日期；选择开始日期时页面会把结束日期预填为当年最后一天。SDK 按同一页面语义使用 Asia/Shanghai 当前年份校验，并生成固定 12 项 `accountingPeriodMonthList`，每项的 `month` 是数值 `1..12`，区间外月份的 `startDate/endDate` 保留空字符串。`createIdempotent` 另需 `requestId`，只在 SDK 进程内、短窗口、同一用户/租户/能力范围防重，不发送给后端。

启停参数为 `{ id, status }`，其中 `id` 是列表主记录 ID，`status` 是绝对目标值，不是“切换”命令。详情参数只需列表行的 `startDate/endDate`。

## 逐字段基准

真实浏览器列表请求：

```text
GET /admin-api/finance/accounting-period/page?order=&orderField=&year=&status=0&pageNo=1&pageSize=20&_t=...
```

使用 `platform` HTTP 实例，带当前会话 token、`tenant-id` 与语言头；本页没有匹配到 `module-type`，浏览器与 SDK 都不发送该头。

列表返回只公开 PC 六列及动作 ID：`id`、`tenantName`、`year`、`startDate`、`endDate`、`status`、`updateTime`，分页根字段为 `list/total`。`tenantName` 和 `updateTime` 可为 `null`；真实 SDK 已成功投影当前启用记录，仍保留字符串或数值时间原值，契约不猜时区，空值变体尚未实测。

详情固定返回 12 行 `{ month, start, end }`。首月从 `startDate` 开始，末月到 `endDate`，中间月取自然月首/月末，区间外月份日期为空字符串。

创建请求：

```text
POST /admin-api/finance/accounting-period/create
body = { startDate, endDate, accountingPeriodMonthList: [{ month: 1..12, startDate, endDate }] }
```

后端 `create` 返回根 Long ID；启停请求为 `GET /admin-api/finance/accounting-period/enableOrStop?id=<id>&status=<0|1>`，Controller 使用 `success(null)`，SDK 只接受解包后的 `null` 成功回执。

## 操作步骤与验证

1. 查询并分页到 `total`；用列表 ID 指向详情或启停。
2. 详情完全本地生成，不读取后端月度表；需要最新日期时先刷新列表。
3. 创建先 `prepareCreate` 核对 12 行，再用新 `requestId` 调 `createIdempotent`。返回 ID 后按开始年度、状态 0 分页定位同一 ID并核对日期，不能只凭 HTTP 成功声明创建完成。
4. 启停前保存最新 `status`，传相反的绝对目标值；请求后按目标状态分页定位同一 ID。需要恢复时再写回保存的原状态并再次回查。

离线测试覆盖 Portal/Java 静态动作与权限、默认及筛选请求、无 `module-type`、页面字段投影、闰年月末、区间外空值、当前年边界、完整 12 项数字月份创建 body、根 ID、绝对状态、`null` 回执、非法 ID/状态和 AI 映射。关键契约反证把状态回查映射由 `args.status` 故意改成 `args.id`，定向测试按预期失败；本轮没有修改共享 AI 合约文件。
