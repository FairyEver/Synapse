# 我的工资（`/dashboard/me/pay-roll/list`）

本页是 Portal「个人中心 → 我的工资」的只读能力。它包含两个年度图表和一个按月份筛选的个人工资表；页面没有新建、修改、删除、审批或导出动作，因此 SDK 不提供写能力。

## 页面标识

| 项 | 值 |
| --- | --- |
| 菜单路径 | `/dashboard/me/pay-roll/list` |
| 权限码 | `/dashboard/me/pay-roll` |
| 路由 | `app/portal/views/dashboard/hr/me/pay-roll/list.vue` |

## 能力定义与请求契约

实现位于 `src/capabilities/me-pay-roll.ts`，目录能力为：

| 能力 ID | 页面动作 | 请求 |
| --- | --- | --- |
| `me-pay-roll-list` | 查询我的工资明细 | `GET /salary/report/selectPersonPayrollPage` |
| `me-pay-roll-wages-chart` | 查询应发工资趋势 | `GET /hr/homepage/wagesLineData` |
| `me-pay-roll-five-insurances-chart` | 查询五险一金趋势 | `GET /hr/homepage/fiveInsurancesLinenData` |

工资列表的请求参数顺序和 Portal 一致：`order`、`orderField`、`startYearMonth`、`endYearMonth`、`pageNo`、`pageSize`。开始/结束月份省略时由 SDK 使用当前本地月份，显式传 `null` 才清空；月份格式必须是 `YYYY-MM`。分页默认为 `1/10`，每页条数只接受页面选项 `10/20/50/100`。

Portal 前端只提交日期和分页条件，后端在 `selectPersonPayrollPage` 内使用当前会话用户工号覆盖 `staffCode`。SDK 不开放 `staffCode` 或其他员工标识，避免把个人页面扩大成他人薪资查询。

## 返回字段与消费

`me-pay-roll-list` 返回 `{ list, total }`。`list[]` 的字段与页面可见列一一对应：姓名、月份、基本工资、出勤工资、病假工资、工伤工资、部门考核工资、利润考核工资、考核工资、应发工资、税前工资、应税工资、个税、实发工资、个人社保、个人公积金、专项扣款合计、扣税起征点、购房扣款、其他扣款、扣款合计、奖金、福利性补贴、租房补贴、学历补贴、专项税字段以及个人/单位养老、失业、基本医疗、大额医疗、公积金字段。金额保持服务端返回的数字或数字文本；`null` 表示该记录没有值，不自动转成 0，也不进行元分换算。

两个图表返回 `title`、`xAxis` 和 `series[]`。每个系列包含 `name` 与按 `xAxis` 对齐的 `data`；Portal 的“半年/一年”按钮只在前端截取最后六个或全年十二个点，不是后端查询参数。

## 操作步骤与验证状态

```text
1. 确认当前 SDK 会话用户具有 /dashboard/me/pay-roll 权限。
2. 读取 me-pay-roll-wages-chart 和 me-pay-roll-five-insurances-chart，按 xAxis 对齐数据。
3. 按月份调用 me-pay-roll-list；需要完整结果时继续翻页直到 list 条数覆盖 total。
4. 仅将结果解释为当前会话用户可见的个人工资数据，不用 staffCode 改查其他员工。
```

本节点的离线验证在 `test/me-pay-roll.test.ts`：锁定 Portal 路径、表单默认值、参数顺序、分页选项、图表接口、权限传播、坏响应和 AI 说明字段。Java DTO 与控制器源码已逐字段核对；真实测试环境的浏览器基准和在线只读冒烟尚未在本节点提交中声称完成，后续代码检查必须补充或明确记录外部环境阻塞。
