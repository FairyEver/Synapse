# 日龄分割

页面路径：`/dashboard/product/setting/business-manage/age-division/list`。

页面权限：`/dashboard/frame/business/age-division`。请求使用 `product` HTTP 实例；页面没有可推导的 `module-type`，SDK 不发送该请求头。Portal 页面同时声明两套 tab 权限：批量设置 `base:age-division:query` / `base:age-division:submit`，批次设置 `base:age-division-batch:query` / `base:age-division-batch:submit`。查询代码不单独调用 query 权限，新增、编辑、删除按钮由对应 submit 权限控制；SDK 不把按钮可见性当作后端授权结论。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 批量设置分页查询 | `product-business-age-division-list-bulk` / `productBusinessAgeDivision.listBulk` | `GET /base/ageDivision/page` |
| 批量设置按批次号查询 | `product-business-age-division-get-bulk-by-flock-info` / `productBusinessAgeDivision.getBulkByFlockInfo` | `GET /base/ageDivision/flock_info/{flockInfo}` |
| 批次设置分页查询 | `product-business-age-division-list-batch` / `productBusinessAgeDivision.listBatch` | `GET /base/ageDivision/flock/page` |

| 批量设置删除 | `removeBulk` | `GET /base/ageDivision/delete?id={id}` |

## 参数与表单提交规则

批量设置查询默认发送：

```json
{
  "order": "",
  "orderField": "",
  "line": "",
  "gen": "",
  "variety": "",
  "moult": 0,
  "flockInfo": "",
  "pageNo": 1,
  "pageSize": 20
}
```

`moult` 为 `0=正常蛋鸡、1=换羽蛋鸡`；分页条数沿用 Portal 的 `10/20/50/100`。批量设置的类型搜索调用 `/base/ageDivision/page`；批次搜索如果批次号为空，Portal 直接返回空列表，不发送请求，否则调用 `/base/ageDivision/flock_info/{flockInfo}`。SDK 对路径参数做 URL 编码。

批次设置列表发送 `order`、`orderField`、`flockInfo`、`ageDiv`、`pageNo`、`pageSize`；`ageDiv` 非空时必须是整数。列表返回的 `list` 是当前页，`total` 是筛选条件下总数。批量列表保留 `line`、`gen`、`variety`、`moult`、`ageDiv` 及页面展示的 `lineName`、`genName`、`varietyName`；批次列表保留 `batch`、`ageDiv`。后端扩展字段透传，但不作为页面契约字段。

批量设置弹窗：

- 品系和品种至少填写一项；代次、蛋鸡类型、日龄分割必填。
- 蛋鸡类型只能是 `0` 或 `1`；日龄分割是整数，Portal 输入框允许 `0` 及以上。
- 新建和编辑都发送同一个 `/base/ageDivision/save`，编辑额外发送当前行 `id`。

批次设置弹窗的批次号和日龄分割必填，Portal 输入框允许日龄分割为 `0`；Java `AgeDivisionFlockVO` 的 `@Min(1)` 会拒绝 `0`，SDK保留这个真实的前端/后端边界，不提前伪造为页面校验失败。新建和编辑分别调用 `/flock/save` 与 `/flock/edit`，编辑带当前行 `id`。

取消新建、编辑或删除确认时只丢弃本地草稿；页面没有取消已提交写操作的接口。写请求成功或响应不确定后，应重新调用相应列表能力确认记录状态，不能把 `true` 当作业务终态。

## 逐字段基准

| 字段 | 含义 |
| --- | --- |
| `id` | 日龄分割配置记录ID；编辑和删除目标。 |
| `line` / `lineName` | 品系编码 / 页面展示名称。 |
| `gen` / `genName` | 代次编码 / 页面展示名称。 |
| `variety` / `varietyName` | 品种编码 / 页面展示名称。 |
| `moult` | `0` 正常蛋鸡，`1` 换羽蛋鸡。 |
| `ageDiv` | 分割日龄，单位为天；不做换算。 |
| `batch` | 批次设置记录的批次号。 |
| `total` | 当前筛选条件下的总记录数，不是当前页长度。 |

## 操作步骤、失败处理与证据边界

1. 调用对应 tab 的列表能力，确认目标行及其 `id`。
2. 新建或编辑调用对应 `prepare`，向用户展示草稿；删除调用 `prepareRemove`，只准备当前行ID。
3. 用户确认后，将同一个 `draft` 或 `id` 交给 submit 能力；用户取消时不发请求。
4. 成功或超时后重新查询对应列表，确认保存或删除的业务状态。

ID、枚举、必填字段、整数、分页或响应结构不合法时，SDK 在发请求前失败。401/403、网络错误和 Java 业务错误原样失败；写入超时先回查再决定是否重试。页面没有 requestId 防重协议，不能宣称重复调用安全。

本轮逐页核对了 Portal 菜单、父页面、两个 tab、两个弹窗、product HTTP、权限声明，以及 Java `AgeDivisionController`、`AgeDivisionFlockVO`、DTO。离线测试覆盖了请求形状、表单规则、分页响应、嵌套查询、prepare 映射、取消语义和坏输入反证。尚未在真实测试环境使用浏览器会话执行两个 tab 的读写回查闭环，也未取得真实租户的字典候选和业务错误文案。
