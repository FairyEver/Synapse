## base-dept-search

按部门名称寻找组织候选，为人员筛选和业务表单取得真实部门 ID。

- 场景：用户知道部门名称但没有 ID 时；已知父节点则用 base-dept-children。
- 性质：read
- 边界：在当前基础部门索引中本地匹配 name，区分大小写；不会查询人员或修改组织。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

### 参数契约

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |
| keyword | 部门名称片段，按 name.includes 匹配；来源：先向用户取得名称片段；不要用空串请求长候选集 | 去首尾空白的非空字符串 |
| limit | 最多返回条数；本地裁剪，不是服务端分页。超过上限截断到上限。；来源：调用方按展示预算填写 | 正整数，上限 50；无效值回退默认值，非正数归为1，小数取整；默认 20 |

### 返回与消费

`{ list: DeptNode[], total, matched }`

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| list | array | 最多 limit 个候选 |
| list[].id | number | 部门标识，供部门详情/下级查询及人员 deptId 使用 |
| list[].name | string | 部门名称，用于候选展示 |
| list[].parentId | number | 上级部门标识，0 表示根 |
| total | number | 过滤前完整索引条数，不是本次返回条数 |
| matched | number | 过滤命中数，可能大于当前返回数组长度 |

空结果：list=[] 且 matched=0 是没有匹配；total 仍为部门索引规模。

- 展示 name；重名时取详情的 pathNames 让用户区分；list.length<matched 表示候选被截断。

### 操作步骤与验证

- optional：需区分同名组织或展示完整路径 → base-dept-get；选择候选的数字 id 原样传入。；字段映射 {"id":"list[].id"}
- optional：用户要找该部门人员 → base-user-search；将选定部门 id 作为 deptId。；字段映射 {"deptId":"list[].id"}

完成判据：交付用户确认的部门候选或明确无匹配；不自动选择同名部门。

错误：参数错误先修正；部门不存在时重新按名称取候选，不猜新 ID。；基础索引可能来自会话或实例缓存；基础数据变化后由接入方 invalidate 对应切片再查询。；401 不能单凭错误码区分会话过期、权限或范围问题；恢复会话后再读，不能把失败当空集合。

防重：只读/本地能力，无写入防重要求。

## base-dept-get

读取一个部门及从根到它的组织路径。

- 场景：核对部门归属或消除同名歧义。
- 性质：read
- 边界：路径遇到悬挂父节点或环即停止，不能据此虚构缺失层级。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

### 参数契约

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |
| id | 部门数字标识；来源：base-dept-search.list[].id 或 base-dept-children.list[].id | 可转换为有限数字 |

### 返回与消费

`{ id, name, parentId, path: {id,name}[], pathNames }`

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| $.id | number | 部门标识，供部门详情/下级查询及人员 deptId 使用 |
| $.name | string | 部门名称，用于候选展示 |
| $.parentId | number | 上级部门标识，0 表示根 |
| path[].id | number | 路径各级部门 ID |
| path[].name | string | 路径各级部门名 |
| pathNames | string | 根到当前部门名，用 / 拼接 |

空结果：ID 不存在会抛错，不返回 null。

- 用 pathNames 展示完整归属；仍以 id 作为后续输入，不用路径字符串代替 ID。

### 操作步骤与验证

- optional：需要查看下一层部门 → base-dept-children；仅查询直接下级。；字段映射 {"parentId":"id"}

完成判据：已交付部门名称和可取得的组织路径。

错误：参数错误先修正；部门不存在时重新按名称取候选，不猜新 ID。；基础索引可能来自会话或实例缓存；基础数据变化后由接入方 invalidate 对应切片再查询。；401 不能单凭错误码区分会话过期、权限或范围问题；恢复会话后再读，不能把失败当空集合。

防重：只读/本地能力，无写入防重要求。

## base-dept-children

按上级部门逐层列直接下级。

- 场景：组织树逐层选择；不知道名字时可以从 parentId=0 的根开始。
- 性质：read
- 边界：只给直接下级，total 不是全树部门数；父节点不存在与没有下级都可能是空列表。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

### 参数契约

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |
| parentId | 父部门 ID；0 表示根；来源：base-dept-search.list[].id、上次本能力 list[].id，或根常量 0 | 有限数字 |
| limit | 最多返回条数；本地裁剪，不是服务端分页。超过上限截断到上限。；来源：调用方按展示预算填写 | 正整数，上限 200；无效值回退默认值，非正数归为1，小数取整；默认 50 |

### 返回与消费

`{ list: DeptNode[], total }`

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| list | array | 最多 limit 个直接下级 |
| list[].id | number | 部门标识，供部门详情/下级查询及人员 deptId 使用 |
| list[].name | string | 部门名称，用于候选展示 |
| list[].parentId | number | 上级部门标识，0 表示根 |
| total | number | 该父节点直接下级总数 |

空结果：list=[] 不足以证明父部门不存在；可用 base-dept-get 核对非零 parentId。

- 用 name 展示、id 继续下钻；返回条数少于 total 时增加 limit 或按名称搜索。

### 操作步骤与验证

- optional：继续下一层 → base-dept-children；由用户选择当前候选后继续。；字段映射 {"parentId":"list[].id"}

完成判据：用户选定部门或到达无下级节点。

错误：参数错误先修正；部门不存在时重新按名称取候选，不猜新 ID。；基础索引可能来自会话或实例缓存；基础数据变化后由接入方 invalidate 对应切片再查询。；401 不能单凭错误码区分会话过期、权限或范围问题；恢复会话后再读，不能把失败当空集合。

防重：只读/本地能力，无写入防重要求。

- 性质：read
- 边界：按类型名而不是选项 label 搜索，忽略大小写；同名 status 字典不能跨业务套用。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |

| 字段 | 类型 | 语义 |

## base-dict-get

读取一个明确字典类型的所有选项。

- 场景：填写小枚举或给一批业务数据的值贴显示标签。
- 性质：read
- 边界：只解释给定 dictType；不能把全平台 status 的含义套到流程或租户状态。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

### 参数契约

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |
| dictType | 精确字典类型键；来源：base-dict-search.list[].dictType 或业务能力明确指定的类型 | 非空字符串 |

### 返回与消费

`{ dictType, entries: {label,value,id}[] }`

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| dictType | string | 所查询字典类型 |
| entries[].label | string | 展示文本 |
| entries[].value | string 或 number | 业务存储值，原 JSON 类型保留 |
| entries[].id | string 或 number | 字典条目自身 ID，不是表单枚举值 |

空结果：不存在的 dictType 抛错；存在但无选项时 entries 为空。

- 展示 label，填业务枚举使用 value；比对时 String(value) 归一，不能使用 entry.id 代替 value。

### 操作步骤与验证

- optional：只需翻译一个已有业务值 → base-dict-translate；传精确类型和要翻译的业务值。；字段映射 {"dictType":"dictType","value":"entries[].value"}

完成判据：交付选项或完成值到标签的映射。

错误：参数错误先修正；部门不存在时重新按名称取候选，不猜新 ID。；基础索引可能来自会话或实例缓存；基础数据变化后由接入方 invalidate 对应切片再查询。；401 不能单凭错误码区分会话过期、权限或范围问题；恢复会话后再读，不能把失败当空集合。

防重：只读/本地能力，无写入防重要求。

## base-dict-translate

将一个业务字典值翻译成显示标签。

- 场景：展示已有记录中的枚举值；大量值可先 get 一次后本地映射。
- 性质：read
- 边界：数字 1 与字符串 "1" 按 String() 等价匹配；不改变业务值。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

### 参数契约

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |
| dictType | 精确字典类型键；来源：业务说明指定的类型或 base-dict-search.list[].dictType | 非空字符串 |
| value | 要翻译的原始业务值；来源：业务响应字段或 base-dict-get.entries[].value | string | number |

### 返回与消费

`{ dictType, value, label: string|null, found }`

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| dictType | string | 输入字典类型 |
| value | string 或 number | 输入值原样保留 |
| label | string，可null | 匹配选项的显示名，未找到为 null |
| found | boolean | 是否成功匹配选项 |

空结果：值不存在返回 found=false、label=null；dictType 不存在则抛错。

- found=false 时展示原始值并说明无对应标签；null 不能读成空状态。

### 操作步骤与验证

- optional：查询已满足用户目的 → 交付结果；把 label 或未匹配的原值交付用户。

完成判据：已展示翻译或明确告知值无匹配。

错误：参数错误先修正；部门不存在时重新按名称取候选，不猜新 ID。；基础索引可能来自会话或实例缓存；基础数据变化后由接入方 invalidate 对应切片再查询。；401 不能单凭错误码区分会话过期、权限或范围问题；恢复会话后再读，不能把失败当空集合。

防重：只读/本地能力，无写入防重要求。

## base-permission-has

- 性质：read
- 边界：清单结果不是后端权限裁决；false 不等于调用必然 403，true 也不保证写入获准。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

### 参数契约

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |
| code | 页面路径或动作权限码，精确匹配；来源：能力 permission 或 base-permission-search.list[] | 非空字符串，去首尾空白 |

### 返回与消费

`boolean`

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| $ | boolean | 权限清单是否包含该码，不是请求成功保证 |

空结果：false 表示清单没有该精确值。

- 按清单事实说明；不要据此把已注册可调用能力隐藏成不存在。

### 操作步骤与验证

## base-permission-check

批量检查并区分已有和缺失的权限码。

- 场景：核对一组页面/动作声明。
- 性质：read
- 边界：会去重和去空；不做后端权限探测。
- 前置：使用已绑定当前用户和租户的 SDK 会话。

### 参数契约

| 参数 | 含义与来源 | 格式/默认 |
| --- | --- | --- |
| codes | 多个精确权限码；来源：多个能力 permission 或 base-permission-search.list[] | 字符串数组或英文逗号/换行分隔串；至少一项 |

### 返回与消费

`{ granted: string[], missing: string[], checked }`

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| granted[] | string | 权限清单包含的码 |
| missing[] | string | 清单缺少的码，不代表必然 403 |
| checked | number | 去重后实际检查数量，等于两数组长度之和 |

空结果：codes 全为空时抛错；granted 或 missing 可为空。

- 分别列出两组，不把 missing 宣称为不能调用的能力。

### 操作步骤与验证

- optional：查询已满足用户目的 → 交付结果；交付两组权限清单及 checked 去重计数。

完成判据：每个去重后的输入码已归入 granted 或 missing。

错误：参数错误先修正；部门不存在时重新按名称取候选，不猜新 ID。；基础索引可能来自会话或实例缓存；基础数据变化后由接入方 invalidate 对应切片再查询。；401 不能单凭错误码区分会话过期、权限或范围问题；恢复会话后再读，不能把失败当空集合。

防重：只读/本地能力，无写入防重要求。
