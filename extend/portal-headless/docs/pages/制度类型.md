# 制度类型（`/dashboard/institution/type/list`）

风险防控域的制度类型列表和类型表单。Portal、Java 与 SDK 按本页逐文件核对。

## Portal 页面行为

列表调用 `GET /admin-api/system/policy-category/page`，由 `useListPageModule` 发送 `order`、`orderField`、`name`、`pageNo`、`pageSize`；后端实际返回数组，页面将数组转换为 `{ list, total: list.length }`。可达操作是新建、编辑和删除。

编辑调用 `GET /admin-api/system/policy-category/get?id=...`。新建调用 `POST /admin-api/system/policy-category/create`，编辑调用 `PUT /admin-api/system/policy-category/update`，删除调用 `DELETE /admin-api/system/policy-category/delete?id=...`。

## 表单、权限和数据规则

- `name` 必填；Portal 失焦时去除首尾空格，最多15个字符。
- `sort` 使用精度为0、最小值为0的数字控件，并且必填；SDK 只接受非负安全整数。
- 新建只提交 `name`、`sort`；编辑只提交 `id`、`name`、`sort`，不把 `size`、租户或审计字段回传。
- Java 服务拒绝重复名称；仍被公司制度使用的制度类型不能删除。列表、详情和写入受当前会话、租户、页面权限与后端数据范围约束。

## 后端与 SDK 对齐

Java `HrPolicyCategoryController` 提供数组列表、详情、创建、更新和删除；`HrPolicyCategorySaveReqVO` 约束名称非空且最多15个字符；`HrPolicyCategoryServiceImpl` 负责名称重复和被制度使用时拒绝删除，DO 继承 `TenantBaseDO`。SDK 保留 Portal 的列表请求字段和数组转分页语义，写操作拆为 `prepare → submit`，取消只丢弃本地草稿，写入后必须按 ID 或名称回查。

实现文件：`src/capabilities/institution-type.ts`；AI 说明：`src/catalog/contracts-institution-type.ts`。
