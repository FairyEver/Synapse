# 物料管理（`/dashboard/setting/material/list`）

## 页面范围与证据

门户 → 系统设置 → 物料管理，权限 `/dashboard/setting/material`，使用 `platform` HTTP 实例；页面路径不命中 module-type 规则，因此 SDK 与 Portal 一样不发送 `module-type`。

列表页可到达物料新增、平台物料选择、物料视图详情和规格换算页。列表的“导出”目前只显示“导出功能开发中”，没有可调用的导出能力；注释掉的类型、采购方式字段也不纳入 SDK。

Portal 证据：`app/portal/menus/common.js`、`app/portal/views/dashboard/hr/setting/material/list.vue`、`[mode]/[id].vue`、`material-view/[id].vue`、`material-spec-conversion/[id].vue`，固定提交 `bbcfc35154`。

Java 证据：`SysMaterielController`、`SysMaterielServiceImpl`、`SysMaterielBaseVO`、`SysMaterielUnitConversionController`、`SysMaterielUnitConversionServiceImpl` 及相关 VO，固定提交 `b7a359adc9e`。租户边界、平台物料 useTenant、批量创建字段校验、删除限制和换算整组替换由 `test/setting-material.test.ts` 锁定；本页未把离线请求当作真实环境写入证据。

| --- | --- | --- |
| 当前租户物料分页 | `setting-material-list` / `settingMaterial.list` | 只读；返回当前会话租户可见物料 |

| 批量新增物料 | `setting-material-create` / `settingMaterial.create` | 写入当前租户；返回 ID 后必须回查 |

## 参数与表单规则

- 当前租户列表默认请求参数为 `{ order: '', orderField: '', matName: null, matDescribe: null, supplierId: null, categoryId: null, pageNo: 1, pageSize: 20 }`；分页大小沿用页面的 `10/20/50/100`。
- 平台物料选择列表使用 `/select-platform-page`，默认文本筛选为空字符串、ID筛选为空字符串，分页仍为 `pageNo: 1, pageSize: 20`。
- 新增前调用 `prepareCreate`。页面提交 `materials` 数组；每行的 `matName`、`matDescribe`、`categoryId`、`unit`、`supplierId` 必填，`specDes` 最多 20 个字符。当前页面还提交 `matCode`、`supplierCode`、`isEntry`、`entryTime`；空值按 Portal 形状分别归一为 `''`、`false` 或 `null`。
- 分类变化会带出分类名称作为描述，供应商变化会带出供应商编码和简称；SDK 不替调用方猜名称，调用方应先使用准备能力的选项构造表单。
- 新增返回 ID 数组不是最终证据；批量创建成功后按名称、分类、供应商和规格逐行调用 `list` 回查。请求失败不能解释成空数组或部分成功。
- 删除、添加平台物料和换算保存都必须保留请求超时后的核查步骤。添加平台物料时只提交选择结果中的 ID，并使用当前会话租户 ID；不能用请求体的 tenantId 伪造权限。
- `get` 的长整数 ID 可能是字符串。`viewSalesList` 可能包含 `status=false` 的未配置视图，不能当作已启用视图。
- 收货配置默认参数为 `{ order: '', orderField: '', orgId: undefined, materielId, pageNo: 1, pageSize: 20 }`；清空组织筛选保留 `undefined`。
- 换算保存必须提交完整 `groups`。每组可以有多个辅助单位，最多一组不填写规格；辅助单位数量必须为正数、不能选择基本单位、同组不能重复。空数组返回表示清空全部规则，不表示网络失败。

## 操作步骤与失败处理

1. 用 `list` 定位当前租户物料，保存返回的 `id`；需要平台物料时单独用 `platformList`，跳过 `selectable=false` 的行。
2. 新建先 `prepareCreate`，按页面联动规则准备每行，再调用 `create`；返回后逐行 `list` 回查。
3. 删除前确认目标 ID 和租户上下文；成功或超时后回查目标是否仍在当前租户列表中。`true` 只代表后端接受请求，不代表物理删除。
4. 详情页先调用 `get`，再用 `viewLookups` 将店铺、品牌、销售品类和规格组 ID 映射为展示信息；缺失名称时保留原始 ID。
5. 规格换算先读取 `conversionContext`，编辑完整分组后调用 `conversionSave`；成功后再次读取上下文，逐项核对基本单位、规格组、辅助单位和系数。
6. 参数校验、平台行不可选、租户不匹配、采购属性限制、权限、网络或后端业务错误均原样报告，不能降级为空列表或假成功。
