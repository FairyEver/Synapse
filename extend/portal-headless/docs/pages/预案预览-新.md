# 预案预览-新（`/dashboard/product/setting/plan-preview/list`）

Portal「系统设置 → 生产设置 → 养殖预案 → 预案预览-新」是只读预案查询页。页面先加载省/市/区地区树，再按代次、品种、地区和进鸡日期查询一次日龄预案；结果在本地切换饲养、营养、防疫页签和日龄。

## 页面标识

| 项 | 值 |
| --- | --- |
| 菜单路径 | `/dashboard/product/setting/plan-preview/list` |
| 菜单权限 | `/dashboard/frame/breeding-plan-new/preview` |
| Portal 页面文件 | `app/portal/views/dashboard/product/setting/plan-preview/list.vue` |
| HTTP 实例 | `platform` |
| `module-type` | `null`（不发送） |
| 页面形态 | 代次/品种 + 省市区 + 进鸡日期查询；三类预案页签；日龄切换 |
| 主接口 | `GET /flockSimu/rearingPlan/preview/get` |

地区树不在本页重复登记：复用既有 `product-setting-season-area-tree` / `productSettingSeason.areaTree` 能力，它调用同一个 `GET /system/area/tree`。Portal 本页使用的代次 `gen` 和品种 `variety` 字典值由调用方提供，本页不复制字典维护能力。

## 1. 能力定义

| 页面动作 | 能力 / 方法 | 请求或行为 |
| --- | --- | --- |
| 读取省市区 | 复用 `product-setting-season-area-tree` / `productSettingSeason.areaTree` | `GET /system/area/tree`；递归返回节点 `id/name/children` |
| 查询预案预览 | `product-plan-preview-preview` / `productPlanPreview.preview` | `GET /flockSimu/rearingPlan/preview/get`；只读，不保存预案 |

Java DTO 还声明了 `strain` 和 `previewDate`，但 Portal 本页没有对应表单控件；本页能力不额外暴露它们。

## 2. 参数契约与表单提交规则

### 省市区联动

Portal 的表单状态为 `provinceCode`、`cityCode`、`districtCode`。选择省时清空市和区，选择市时清空区；最终 `areaCode` 按“区县 → 市 → 省”取最深层非空值。页面的实际校验只要求最终 `areaCode` 为六位数字，因此可以按省级或市级查询，不强行要求三级都选满；SDK同时拒绝没有上级却传下级的状态，复刻控件的可达状态。

`region` 是地区树节点名称按 `省 / 市 / 区` 拼出的回显文本，不是编码。为空时不发送，不能用名称替代 `areaCode`。

### 查询参数

SDK 会把表单投影为以下请求参数，不发送省市区原字段、`previewDate` 或 Portal 未使用的 `strain`：

```json
{
  "generation": "商品代",
  "areaCode": "360102",
  "entryDate": "2026-05-01",
  "variety": "京红1号",
  "region": "江西 / 南昌 / 东湖",
  "dayAge": 133
}
```

规则如下：

- `generation`、`variety` 去首尾空白后必填，Java DTO限制最多64个字符；代次改变后必须重新选择品种。
- `entryDate` 必须是有效的 `YYYY-MM-DD` 日期；它用于选择指标版本和计算计划日期。
- `areaCode` 必须是六位数字；优先使用已选区县，其次市、省。
- `region` 最多64个字符，非空才发送。
- 首次查询或未指定日龄时省略 `dayAge`，由后端按当前日期计算；切换日龄时发送数字。

### 日龄切换

Portal `PlanPreviewDetail.vue` 的日龄按钮集合是 `-1` 加 `1..700`，没有 `0`。`-1` 显示为“空舍”，表示汇总进鸡前的负日龄内容；正日龄为1至700。SDK严格接受 `-1` 或 `1..700`，拒绝 `0`、其它负数、小数和超出700的值。

Java 接口 DTO 的通用范围是 `-365..700`，但 `-2..-365` 不在本页面控件可达范围内；SDK不把后端更宽协议扩成Portal页面能力。后端仍会拒绝日龄0，且会对指标库、版本和地区温度条件进行业务校验。

## 3. 返回字段基准

SDK去掉可能存在的Portal `data`包络，并按Portal `utils.js` 把缺失数组补成空数组；其它响应扩展字段保留。

### 根与日龄

| 路径 | 含义 |
| --- | --- |
| `list` | 按日龄返回的预案数组；本接口一次查询通常固定一项 |
| `list[].delFlag` | 删除标记，Java预览响应固定为0 |
| `list[].age` | 后端最终组装日龄；正常为1至700，空舍汇总为-1 |
| `list[].feed` | 饲养预案分类 |
| `list[].nutrition` | 营养预案分类 |
| `list[].prevention` | 防疫预案分类 |

### 三类预案分类

`feed`、`nutrition`、`prevention` 结构完全相同：

| 路径 | 含义 |
| --- | --- |
| `list[].<category>.programIndexList` | 当前分类命中的指标库条目；空数组表示没有命中 |
| `list[].<category>.programPointList` | 当前分类命中的程序库内容、普通方法和匹配到的程序方法；每项都有归一化后的 `videoList` |
| `list[].<category>.programKeyPointList` | 关键点列表；当前 Java 接口固定返回空数组 |

指标条目按Portal/Java兼容结构保留 `txt`、`min`、`max`、`value`、`age`、`classification`、`contentType`、`scale`、`name`、`unit`、`code`、`codeType`、`title`，以及温度关联的 `tempBandCode/tempBandName/temperatureRelated`、值类型等字段。调用方优先使用 `txt/name/unit/age` 和实际存在的上下限；缺失上下限不能推断为0。

程序/方法条目保留 `txt`、`age`、`classification`、`name`、`unit`、`code`、`codeType`、`title`、`editableType`、`methodName`、`methodDescription`、`programCode`、`programName`、频次和日龄字段，以及各程序库自己的原始业务字段。页面展示优先使用后端已拼装的 `txt` 和 `*Name` / `*Names` 文本，不解析历史频次文本。

`programPointList[].videoList[]` 保留 `id`、`fileUrl`、`videoId`、`videoName`、`videoImg`、`title`、`duration`、`type`、`tag` 等字段；有视频时使用 `fileUrl` 播放，无匹配或视频查询失败时 `videoList=[]` 是合法结果，不把它当成预案查询失败。

## 4. 操作步骤、权限与边界

1. 复用地区树能力，按节点 `id/name` 形成省市区选择和可选的 `region` 回显；保留字典选择得到的代次、品种值。
2. 按上述表单规则调用 `productPlanPreview.preview`；SDK只发送最终 `areaCode` 和Portal实际使用的查询字段。
3. 使用 `list[0].age` 判断实际日龄，按三个分类读取指标和程序；空数组显示为空状态。
4. 切换日龄时重新调用同一只读能力；失败时报告失败，不能用占位的旧结果宣称新日龄查询成功。

本页没有写操作，因此不存在 `prepare → submit → cancel` 链，也没有保存、删除、导出或撤销能力。权限由服务端页面权限和会话共同裁决，SDK不根据菜单树自行放宽权限。

## 5. 证据与验证边界

本节点逐文件核对了 Portal 菜单、`list.vue`、`utils.js`、`PlanPreviewDetail.vue`，以及 Java `预案预览-PC端接口对接文档.md`、`RearingPlanPreviewController`、`RearingPlanPreviewReqVO`、`RearingPlanPreviewRespVO` 和服务端日龄校验。`test/product-plan-preview.test.ts` 覆盖页面权限/实例、请求参数投影、响应归一化、表单联动、非法日龄/日期/地区反证和 AI 契约结构反证。

当前只完成源码、接口文档/DTO和离线请求桩核对，未在真实测试环境启动浏览器执行地区树、首次查询或日龄切换；因此不能把离线测试描述为真实环境验证。
