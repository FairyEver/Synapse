# 种摊数据重传

页面路径：`/dashboard/product/setting/business-manage/data-retransmit/list`。

页面权限：`/dashboard/frame/business/re-upload`。请求使用 `product` HTTP 实例；页面没有可推导的 `module-type`，SDK 不发送该请求头。页面没有 tab 内部 `permissionCheck`，最终是否允许执行仍由当前会话与后端授权/业务校验决定。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| SAP 重传准备/提交 | `prepareSapUpload` / `submitSapUpload` | 不发请求；`POST /base/dataRetransmit/submit` |
| SAP 查询 | `listSap` | `GET /base/dataRetransmit/list` |
| 财务单个同步准备/提交 | `prepareFinanceSync` / `submitFinanceSync` | 不发请求；`GET /base/financeRetransmit/uploadAllByDateAndType` |
| 财务全部同步准备/提交 | `prepareFinanceSyncAll` / `submitFinanceSyncAll` | 不发请求；按固定类型顺序重复调用上述 GET |

页面的三个 tab 是：种摊数据重传（SAP）、种摊数据查询（SAP）、种摊数据重传（财务）。后端还有其他上传、按公司上传等接口，但页面没有调用，SDK 不加入这些动作。

## 参数与表单提交规则

SAP 重传页面初始化月份为上月，场区为空；点击任一按钮前，月份和场区都必须通过表单校验。类型是页面固定的整数 `1..12`：

1. 育成鸡订单数据
2. 蛋鸡订单数据
3. 蛋鸡订单死亡及淘汰数据
4. 蛋鸡转群及并栋数据
5. 畜禽周转表供数
6. 公母鸡饲养日存栏
7. 青年鸡订单数据
8. 雏场育成鸡接口
9. 蛋场育成鸡接口
10. 蛋场蛋鸡接口
11. 换羽育成鸡接口
12. 换羽蛋鸡接口

提交体严格为 `{ type, yearMonth, farm }`，月份格式为 `YYYY-MM`，场区非空。用户取消 prepare 草稿时不发请求；页面没有提交后的撤销接口。Java 端使用 `@RepeatSubmitLimit`，SDK 不额外声称跨进程幂等。

SAP 查询初始化类型为字符串 `"1"`，请求固定带 `scope=1`，类型下拉值为 `1..9、101、102、11、121、122`。`farm`、`yearMonth` 为空时仍按 Portal 发送空字符串；分页默认 `pageNo=1、pageSize=20`，支持 `10/20/50/100`。Portal 将响应每行的 `amortizationData` 展开，并派生 `yearAndMonth=e.month`；SDK保持同样映射。

财务重传月份必填，场区可选；场区为空时完全省略 `farm` 参数。单个同步的类型为 `1..11`：蛋鸡批次报表、育成鸡批次报表、雏鸡批次报表、死亡冲摊销、换羽蛋鸡批次报表、换羽育成批次报表、蛋鸡转群、育成鸡转群、种畜分摊、销售冲摊销、蛋鸡（换羽蛋鸡）日龄分割转群数据。单个请求参数为 `{ yearMonth, type }`，有场区时追加 `farm`。

“全部同步”不是一个后端批量接口。Portal 按 `1` 到 `11` 顺序逐个调用 `/base/financeRetransmit/uploadAllByDateAndType`；任一请求失败立即停止，SDK返回已完成类型集合，已完成的外部副作用不会回滚。

## 逐字段基准

列表根结果为 `{ list, total }`。`list` 是当前页，`total` 是查询条件下总数。

| 字段 | 含义 |
| --- | --- |
| `list[].id` | 种摊数据记录ID，仅作行标识。 |
| `list[].farmName` | 养殖场名称。 |
| `list[].yearAndMonth` | 来源 Java DTO `month` 的年月原值，不做日期换算。 |
| `list[].sapOrder`、`sapGrowingOrder`、`sapLayingOrder` | 页面按类型展示的 SAP 订单字段。 |
| `list[].batch`、`factoryCode`、`workingCenterCode`、`costCenterCode` | 批次、工厂和成本中心等业务标识。 |
| `list[].age`、`weekAge`、`startAge`、`ageOfPurchase` | 页面展示的日龄/周龄，原值显示。 |
| `list[].closingQty`、`openingQty`、`startQty`、`outQty`、`intoQty` 等 | 存栏、转入、转出和其他数量，SDK不做单位换算。 |
| `list[].layerDeathsAndEliminateItemList[]` | 死亡/淘汰明细；`type` 页面说明 `01=群淘、02=零淘、03=死亡`，另有 `deathDate`、`total`。 |
| `list[].layerTransferList[]` / `transferList[]` | 转入转出明细；含 `type`、`total`、`batch`、`order`、`transferDate`。两个数组按响应实际存在的键保留，不能互相推断。 |

页面的其他类型列（年度、期间、饲养日、死亡/淘汰、换羽、转群、并栋、UUID等）均按 Portal 列名透传为 `number|string|null` 或原值日期字符串；缺席、`null` 和空数组分别保留语义。未知扩展字段不是页面消费契约。

## 操作步骤、失败处理与证据边界

1. SAP 或财务动作先调用对应 `prepare`，校验月份、场区和类型；用户确认后再 submit。
2. SAP 查询按类型解释返回列；存在明细数组时逐条展示，空数组不能当成有明细。
3. 财务全部同步按返回的已完成类型数组判断停止位置；任一失败后先核实目标系统，不要自动从失败类型盲重试。
4. SAP/财务接口成功只代表请求未抛错；页面没有后端撤销或结果查询动作，必须用目标系统或后端业务查询独立核实。

月份、类型、场区、分页或响应结构不合法时，SDK 在发请求前失败。401/403、网络错误、财务上传开关关闭和 Java 业务错误原样失败。全部同步是串行非事务流程，部分成功时前序类型已经产生外部副作用。

本轮逐页核对了 Portal 菜单、父页面、SAP重传、SAP查询、财务重传和明细弹窗，以及 Java `DataRetransmitController`、`FinanceRetransmitController`、`DataRetransmitVO`、`AmortizationDataDTO`。离线测试覆盖了三个 tab 的请求参数、响应展开、嵌套明细、全部同步顺序、失败即停、prepare/cancel 语义和坏输入反证。尚未在真实测试环境使用浏览器会话执行SAP/财务写入及目标系统独立核验；各类型真实租户的字段序列化仍以页面源码列定义为依据。
