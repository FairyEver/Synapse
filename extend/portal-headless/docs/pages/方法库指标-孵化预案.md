# 方法库指标（孵化预案）

## 能力定义

- 页面路径：`/dashboard/product/setting/hatchery-manage/method-lib/indicator/list`
- 到达方式：孵化预案方法库列表行的“查看方法”按钮；父页面把 `suiteCode`、品种/代次/舍内温度展示值和 `moduleType=hatchery` 放入路由 query。
- 页面来源：`hatchery-manage/method-lib/indicator/list.vue` 只是包装器，实际复用 `hatch-manage/method-lib/indicator/list.vue`。
- 父页面权限：`/dashboard/frame/hatchery-plan/method-lib`。
- 页面动作权限：查询 `program:method-lib-indicator:query`，新建/编辑 `program:method-lib-indicator:submit`，删除 `program:method-lib-indicator:delete`。
- HTTP 实例：`product`；页面路径没有命中 `module-type` 推导规则，不发送 `module-type`。Java 控制器的 `@RequestHeader(defaultValue = "43")` 是服务端缺省值，不是浏览器实际请求证据。

## 参数契约

### 查询和动态选项

列表固定发送 `scope=1`，默认 `age=1`、`pageNo=1`、`pageSize=20`，分页只接受 Portal 支持的 `10/20/50/100`。筛选字段为 `traitType`、`traitCode`、`age` 和父页面传入的 `suiteCode`。Portal 复用组件会丢弃 `order` 和 `orderField`，SDK不补发。

`traitCodeOptions({ traitType })` 在 `traitType` 为空时按页面行为本地返回 `[]`；有值时发送 `classification=String(traitType)` 和固定 `searchType=2`。返回候选保留后端字段，并补充：`label=name`、`value=code`，以及 `contentType/title1/title2/title3`。调用方必须使用字典 `hatch_method_class` 的实际 value，不把中文展示名当作 classification。

### 新建

`prepareCreate` 的表单字段为：

- `traitType`：方法归类，必填；
- `traitCode`：方法名称编码，必填，通常来自动态选项的 `value`；
- `contentType`、`title1`、`title2`、`title3`：由动态选项回填的元数据，可为空；
- `age`：页面日龄，正整数，默认1；
- `txt`：方法内容，去除首尾空白后不能为空，长度不超过3000；
- `suiteCode`：父方法库行的业务编码，新建请求发送；页面没有可见输入项，缺省按空字符串保留。

首次 `create` 固定发送 `flag=0`。Java 返回 `flag=1` 时，SDK只返回 `{ status: 'conflict', flag: 1 }`；必须由用户确认覆盖后，用同一份 draft 再调用 `create({ draft, flag: 1 })`。用户取消时丢弃 draft，不发送第二次请求。

### 编辑

编辑草稿包含当前行 `id`、方法归类、方法名称、内容类型、三级标题、日龄和方法内容。`suiteCode` 如果提供，只作为写后回查上下文；SDK不会把它追加进 `editTrait` 请求体。页面实际编辑请求固定带 `flag=1`，但页面不处理额外覆盖交互。

### 删除和导出

删除只使用当前列表行的非空 `id`，HTTP 方法是 GET，不是 DELETE。`suiteCode` 可随删除草稿保存，用于删除后重新查询确认目标行消失。

导出复用当前筛选的 `traitType`、`traitCode`、`age`、`suiteCode` 和固定 `scope=1`，不发送分页参数；返回 `{ fileName, contentType, base64, byteLength }`，缺少响应文件名时使用 `方法库方法.xlsx`。

## 返回字段

列表返回 `{ list, total }`。`list` 是当前页，`total` 是当前筛选条件的总数，不是当前页长度。页面使用的主要字段为：

| 字段 | 含义 |
| --- | --- |
| `id` | 方法指标记录 ID，编辑/删除目标；空值不可安全操作。 |
| `suiteCode` | 所属孵化方法库预案业务编码，用于查询和写后回查。 |
| `traitType` / `traitTypeName` | 方法归类值 / 展示名称。 |
| `traitCode` / `traitName` | 方法名称编码 / 展示名称。 |
| `title1`、`title2`、`title3` | 方法层级标题。 |
| `age` | Portal 页面使用的日龄字段。当前 Java DTO主要返回 `hour`，不能自动视为同一字段。 |
| `hour` / `stage` / `stageName` | Java 孵化方法指标 DTO 的时间/阶段字段及展示名称。 |
| `contentType` / `contentTypeName` | 内容类型值 / 展示名称。 |
| `unit`、`min`、`max`、`txt` | 单位、数值范围和方法内容；原值保留，不做单位换算。 |

空列表不是权限或网络失败的替代；响应结构错误、权限错误、Java业务错误和网络错误均抛出。写请求返回 `true` 或 `submitted` 只表示请求未抛错，必须重新 `list` 回查业务终态。

## 操作步骤

1. 从父方法库最新列表取得 `suiteCode`，调用 `traitCodeOptions` 获取方法名称候选，再调用 `list` 查询指标。
2. 新建调用 `prepareCreate`；用户确认后首次调用 `create`。若返回 `conflict`，询问是否覆盖；仅确认后用同一 draft 和 `flag=1` 二次调用。成功或响应不确定时按 `suiteCode + traitCode + age` 回查。
3. 编辑调用 `prepareUpdate`；用户取消只丢弃 draft，确认后调用 `update`。成功或响应不确定时按 `suiteCode + traitCode + age` 回查。
4. 删除调用 `prepareRemove` 并取得确认；确认后调用 `remove`，再按 `suiteCode` 回查并确认目标 `id` 不再出现。
5. 导出直接调用 `export`，将 `base64` 按 `fileName` 保存。

## Portal 与 Java 差异及证据边界

Portal 当前指标页新建表单和查询使用 `age`；Java `HatchProgramLibDTO` 使用 `hour`，`HatchMethodLibController.createTrait` 还会先检查 `dto.getHour()` 是否为空，孵化 Service 也按 `hour`/`stage`创建。这是当前固定源码显示的字段错位，SDK按浏览器实际 `age` 载荷复刻，不能据此宣称线上新建已成功。

父方法库页面另有 `tempId` 与 Java 方法库父表 `ageStage` 的字段差异；它不属于本隐藏指标页的请求体，但 `suiteCode` 来源仍必须是父列表真实记录，不能自行拼接。
