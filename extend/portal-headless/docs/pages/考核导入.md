## 参数契约

**POST，body 就是参数对象**（`customLoad: async (form) => http.post(url, form)`，
`salary/examine-result/list.vue:94-97`）。没有 `_t`。

顺序逐字取自页面 `form:` 初值（`list.vue:103-108`）：

```
order → orderField → name → year → month → organizationIdList → pageNo → pageSize
```

初值：`{ name: '', year: '', month: '', organizationIdList: [] }`（全空）

⚠️ **组织字段叫 `organizationIdList`** —— [奖励导入](./奖励导入.md) 与
[工资找齐](./工资找齐.md) 都叫 `orgIdList`。三页里只有这一页是这个名字，
照抄隔壁就会发一个后端不认的键（**静默查不出人**，不报错）。

## 逐字段基准

```
POST /admin-api/performance/examineresult/page
Content-Type: application/json
{"order":"","orderField":"","name":"","year":"","month":"","organizationIdList":[],"pageNo":1,"pageSize":20}
```

同页还抓到 `GET /admin-api/org/organization/getRoleOrganizationTree?_t=<ts>`
—— 组织下拉的候选，不是列表请求，**不提供**。

## ⚠️ 行字段最容易读错的一处：`name` 不是人名

页面第一列标题是「姓名」，但取的是 **`realName`**；而 **`name` 是"考核名称"**
（`list.vue:110-119` 的 `columns`）：

| dataIndex | 列标题 |
| --- | --- |
| `realName` | 姓名 |
| `staffCode` | 工号 |
| `year` / `month` | 年度 / 月份 |
| **`name`** | **考核名称** |
| `unit` | 单位 |
| `forecast` / `actual` | 预测值 / 实际值 |
| `score` | 分数 |
| `money` | 金额 |

**筛选参数里的 `name` 与返回行里的 `name` 是两个东西**：前者是"按姓名模糊查"
（页面 form 的 `name` 输入框 placeholder 是"姓名"），后者是考核名称。
本能力的 `listSalaryExamineResult({ name })` 传的是**筛选用的姓名**。

## 敏感字段

返回行里有**个人身份 + 考核金额**：

| 字段 | 含义 |
| --- | --- |
| `realName` / `staffCode` | 姓名 / 工号 |
| `money` | 金额（考核结果对应的钱） |
| `score` / `forecast` / `actual` | 分数与指标值 |

**这几项在类型定义里保留了具名**（列表定位与语义需要）。
这一页**没有身份证号、没有工资构成明细** —— 那些在[奖励导入](./奖励导入.md)，
处理方式与理由见那一页的「敏感字段」一节。

### 隐藏表单字段与校验

- `userId`、`year`、`month`、`name`、`unit`、`forecast`、`actual`、`score`、`money` 必填；`staffCode` 可随表单带出但不是页面必填项。
- `name` 去除首尾空白后不得为空，最长 50；`unit` 同样不得是纯空白，最长 10。
- `forecast`、`actual`、`score`、`money` 必须是 `0..999999999` 范围内的数值；页面控件对前两项保留 3 位小数、后两项保留 2 位小数。SDK 不应把 `score` 或 `money` 当作字符串金额说明之外的货币单位推断。

### 各写动作的 prepare → submit → cancel

导入、新建、编辑、删除都遵循同一边界：`prepare` 只校验/读取待操作数据并形成草稿；`submit` 才发对应请求；`cancel` 只放弃草稿，不发请求。导入、新建、编辑成功后分别用列表或详情复核；删除成功后重新查询列表确认缺失（后端软删除的具体展示仍需真实环境确认）。

### 证据边界

上述字段、数组 DELETE 形状、隐藏路由和状态规则来自 Portal 前端源码及 Java 控制器静态审计。当前没有真实浏览器导入、删除、新建、编辑或模板下载冒烟，也没有真实权限拒绝、文件响应和写后列表/详情复核证据；这些均不能表述为已实测。

### `perf-salary-examine-result-list`

查询已导入的考核结果，按员工和年月筛选；不重新评分或导入。

执行：`sdk.perfSalary.listSalaryExamineResult`；性质：read。查询已导入的考核结果，按员工和年月筛选；不重新评分或导入。

- 边界：使用当前 SDK 用户与租户的数据权限；页面上下文由 SDK 绑定，调用方不要另拼 module-type。

| 参数 | 意义与来源 |
| --- | --- |
| name | 姓名（模糊匹配，对应返回行的 `realName`）；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| year | 年度，`'YYYY'` **字符串**（年选择器 value-format）。默认空串。用 buildSalaryYearMonth 生成；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| month | 月份 1..12，**数字**（不是 '09' 这种补零字符串）。默认空串；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| organizationIdList | 角色组织树所选组织 ID 数组；只选择 selectable=true 的节点；来源：contract-support-role-organization-search 返回 list[].id；由用户选定，不能以名称、编码或其他实体 ID 替代；候选：contract-support-role-organization-search list[].id |
| pageNo | 页码，默认 1；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| pageSize | 每页条数，默认 20；来源：用户给出的业务条件；格式和必填性按参数契约。 |

返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。

- list[].money：导入考核结果金额，单位元；后端合计后直接加到考核工资金额，无元分转换；与 score 考核分数区分；单位：元

完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。

- 失败处理：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。
