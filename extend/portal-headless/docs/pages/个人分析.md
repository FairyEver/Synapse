> [`src/capabilities/perf-salary.ts`](../../src/capabilities/perf-salary.ts) 的文件头里，

## 参数契约

**不是列表页。** 没有 `useListPageModule`，所以**没有**
`order` / `orderField` / `pageNo` / `pageSize`（`page-catalog.json` 把它标成
「其他/自定义页面」是对的）。

两条 GET 的 params 都只有两项（`person/list.vue:149-154` 的 `formComputed`）：

```
year → month        （+ 实例补的 _t）
```

⚠️ **两个都是字符串**，且 `month` **不补零**（`format('M')` → 9 月发 `'9'`，不是 `'09'`）：

```js
year:  formState.yearMonth ? formState.yearMonth.format('YYYY') : '',
month: formState.yearMonth ? formState.yearMonth.format('M')    : ''
```

**没有 `Number(...)` 包着** —— 这与[管理分析](./管理分析.md)的
`Number(format('YYYY'|'MM'))`（数字）**类型相反**，是本组最容易照抄错的一处。
用 `buildPersonYearMonth('2026-09')` → `{ year: '2026', month: '9' }`。

⚠️ **默认值是"上月"**（`formState.yearMonth = dayjs().subtract(1, 'month')`，`list.vue:146`）。

| 端点 | 喂给 |
| --- | --- |
| `/performance/statistics/homepage/monthProtocolInfo` | 顶部三块指标（任务平均进度 / 未完成任务数量 / 当前协议状态） |
| `/performance/statistics/homepage/personalStatistics` | 两张折线图 + 一张工资表 |

## 逐字段基准

`baseline/perf-salary.browser.json`（2026-09-21 抓，测试环境）里本页有 **2 条**：

```
GET /admin-api/performance/statistics/homepage/monthProtocolInfo?year=2026&month=8&_t=<ts>
GET /admin-api/performance/statistics/homepage/personalStatistics?year=2026&month=8&_t=<ts>
```

它一次钉住了四件事（这几条原本都是静态推导）：

1. **URL 上只有 `year` / `month` / `_t` 三项** —— 没有 `order` / `orderField` /
   `pageNo` / `pageSize`。这与"它不是列表页"互为佐证。
2. **`_t` 收尾**，且 `/admin-api` 前缀确实被补上了（页面源码里没写）。
3. **`month=8` 不补零** —— 若实现补零，发出去的就是 `08`，与基准不符。
4. **默认值是"上月"**：抓取时间是 **2026-09-21**，抓到的是 `month=8`，
   与源码的 `dayjs().subtract(1, 'month')` 一致（**不是"当前月"** `9`）。

## ⚠️ 日期控件的默认值也是"上月"

页面上的「日期」是 `picker="month"` 且 `:allowClear="false"`（`list.vue:13`）——
**不允许清空**，所以 `yearMonth` 永远有值。
`buildPersonYearMonth` 的格式化结果与页面的 `format('YYYY')` / `format('M')` 逐字一致。

## 真实验证

### 与基准逐字段核对（2026-09-21）—— ✅ 两条 GET 已核准

- **URL**：两条 GET 的 URL 与基准**逐条相同**（`normalize()` 后逐字比较，含 `_t` 位次）。
- **params**：`queryPairs()` 与基准**逐项相同** —— `[['year','2026'],['month','8'],['_t','<ts>']]`。
  另有一条**否定断言**明确钉住 `order`/`orderField`/`pageNo`/`pageSize` 一个都没有。
- **不补零**：基准抓到的是 `month=8`（不是 `08`）；测试里喂 `'2026-08'` 确认发出的是 `8`。
- **默认值是上月**：不传参时发出的是"上月"，与基准抓于 2026-09-21 拿到的 `month=8` 互相印证。

### 本地回归测试

- `test/perf-salary.test.ts` 里本页共 **6** 例，**全绿**。
- 反证（逐条改坏实现，确认会红）：
  `buildPersonYearMonth` 把 month 补零 → **红 4**；
  让 params 多带上 `order`/`orderField`/`pageNo`/`pageSize` → **红 5**；
  默认值从"上月"改成"当前月" → **红 2**。

### 未测到

- **真实返回结构**：`{ avgProgress, unfinishedNumber, status }` 与
  `{ cooperateTaskNumberDTO, salaryScoreDetailDTO, scoreTrendDTO }` 是从
  `useAsyncState` 的初值 + 模板取值推的，**没有对真实响应验证过**。
- **真实条数**：没测过（这一页没有"分页条数"这种说法，但两接口真实返回了什么没验证）。
- **本波没有对真实环境发过任何请求**（不冒烟、不开浏览器）——
  以上"核准"全部是**基准与契约的逐字段比对**，不是我自己发请求测出来的。

## 敏感字段（⚠️ 这一页比想象的重）

顶部三块指标是**聚合值**（进度百分比、任务数量、协议状态），不敏感。
**但下半页是一张工资表** —— `list.vue:241-268` 的 `salaryColumns` / `salaryData`
逐列取 `salaryScoreDetailDTO`：

| 字段 | 含义 |
| --- | --- |
| `monthlyWage` / `monthlyWageLow` / `monthlyWageHigh` | **月薪**的标准值 / 底线 / 高线 |
| `realWage` | **实际工资**（页面用红色 `¥` 显示） |
| `score` / `lastMonthScore` | 当月得分 / 上月得分 |
| `completionRate` | 完成率 |
| `scoreComparison` | 环比得分 |
| `orgScoreSort` | 所在组织排名（含多个组织的名次） |

**「个人分析」是这一组里唯一一页直接展示"我拿多少钱"的。**

`salaryScoreDetailDTO` / `monthlyScores` / `lastYearMonthlyScores` 这些字段
**没有在能力里具名** —— `getAnalysisPersonSummary()` 的返回是 `unknown`（整包透传）。
理由与[奖励导入](./奖励导入.md)一致：具名字段会被渲染进规格与提示词，
而这个能力（"看协议进度与得分趋势"）**不需要工资数字**就能完成任务。

**不具名 ≠ 不返回。** 调用方拿到的 `personalStatistics` 里**确实带着月薪与实际工资**。
将来若要做"查我的工资"，应当**单独开一条能力**并在这里写明用途，
而不是把字段加回这个聚合能力。

## 尚未覆盖

**这一页没有写接口。** 整页只有「查询」与「重置」两个按钮，
两者都只是重发那两条 GET（`list.vue:270-279`）。
`orgScoreSort` 的「更多排名」是 `a-tooltip` 纯前端展开，**不发请求**。

## 未核实的推断

> 两条端点与参数**已经不是推断了**（已与基准逐字段核准，见「真实验证」）。
> 下面剩下的才是。

- 返回结构（`{ avgProgress, unfinishedNumber, status }` 与
  `{ cooperateTaskNumberDTO, salaryScoreDetailDTO, scoreTrendDTO }`）是从
  `useAsyncState` 的初值 + 模板取值推的，**没有对真实响应验证过**。
- `scoreTrendDTO.monthlyScores` 是"按索引对齐"的数组，`mergeTrendByIndex`
  是**按位置**配对两个数组（`list.vue:186-192`）—— 它假定后端两个数组同长同序，
  这一条**没测过**，也没有在能力里复刻（能力只透传原始返回）。
