# 资产字典（系统设置）

页面：`/dashboard/setting/dict-platform/material/list`
菜单权限：`/dashboard/setting/dict-platform/material`
业务键：`material`

## 1. 能力定义

本页由 Portal 的资产 wrapper 复用系统字典共享页面：

- Portal 固定 `SYSTEM_MATERIAL_VALUE = 3`。
- 根类型列表使用 `platform` HTTP 实例，请求 `/admin-api/system/dict-type/page`，固定发送 `useSystem=3`。
- 页面路径未命中 module-type 规则，SDK 不发送 `module-type`。
- 数据子页复用 `/admin-api/system/dict-data/*`，不额外发送 `useSystem`。

交付六项能力：

| 能力 ID | 方法 | 作用 | 写入 |
| --- | --- | --- | --- |
| `setting-dict-platform-material-type-list` | `list` | 查询资产字典类型分页 | 否 |
| `setting-dict-platform-material-data-list` | `dataList` | 查询指定 `dictType` 的字典数据分页 | 否 |
| `setting-dict-platform-material-data-get` | `dataGet` | 查询字典数据编辑详情 | 否 |
| `setting-dict-platform-material-data-create` | `dataCreate` | 创建当前租户的字典数据 | 是 |
| `setting-dict-platform-material-data-update` | `dataUpdate` | 修改当前租户的字典数据 | 是 |
| `setting-dict-platform-material-data-remove` | `dataRemove` | 删除当前租户的字典数据 | 是 |

根类型页的类型新建、编辑、删除按钮不在活动 UI 中；类型租户接口的写入/导出也由 Java Controller 拒绝。页面没有批量删除、导入或导出能力。

## 2. 参数契约

### 类型分页 `list`

调用参数为 `{ name?, type?, pageNo?, pageSize? }`。SDK 始终序列化为：

```text
order='', orderField='', useSystem=3,
name=<字符串或 ''>, type=<字符串或 ''>,
pageNo=<正整数，默认 1>, pageSize=<10|20|50|100，默认 20>
```

`useSystem` 不是调用参数，不能被调用方覆盖。`name` 和 `type` 是模糊筛选片段。

### 字典数据分页 `dataList`

`dictType` 必填，必须是类型列表 `list[].type` 或当前数据子页路由中的类型代码，不是类型 `id`。其余参数为 `label?`、`status?`、`pageNo?`、`pageSize?`。

```text
order='', orderField='', dictType=<非空字符串>,
label=<字符串或 ''>, status=<0|1 或 undefined>,
pageNo=<正整数，默认 1>, pageSize=<10|20|50|100，默认 20>
```

状态值 `0` 表示开启，`1` 表示关闭；省略或传 `null` 时发送 `undefined`，表示不筛选状态。

### 详情、新建、编辑、删除

- `dataGet({ id })`：GET `/admin-api/system/dict-data/get`，查询参数只有 `id`。
- `dataCreate({ dictType, label, value, sort?, status?, remark? })`：POST `/admin-api/system/dict-data/create`。发送 `id=''`、`dictTypeId=dictType`、`dictType`、`label`、`value`、`status`（默认 `0`）、`sort`（默认 `0`）、`remark`（省略/null 转为空字符串）。
- `dataUpdate({ id, dictType, label, value, sort?, status?, remark? })`：PUT `/admin-api/system/dict-data/update`，发送完整表单字段；`platform=true` 的记录在 SDK 请求前拒绝。
- `dataRemove({ id, platform? })`：DELETE `/admin-api/system/dict-data/delete`，查询参数只有 `id`；`platform=true` 的记录在 SDK 请求前拒绝。

Java DTO 约束：`label`、`value`、`dictType` 非空且最长 100 个字符；`sort` 必填且页面输入不允许负数；`status` 必须是 `0/1`。SDK 在请求前执行对应校验，并保留长整数 ID 的字符串形态。

## 3. 逐字段基准

类型分页最终返回 `{ list, total }`：

| 字段 | 含义 |
| --- | --- |
| `list[].id` | 字典类型主键；进入数据页使用 `list[].type`，不能用此 ID 代替 |
| `list[].name` | 字典名称，可为空 |
| `list[].type` | 字典类型代码，作为数据页 `dictType`，可为空；为空不能继续下钻 |
| `list[].status` | 类型状态：`0` 开启、`1` 关闭，可为空 |
| `list[].remark` | 类型备注，可为空 |
| `list[].createTime` | 创建时间原值，可为字符串/有限数字/null |
| `list[].useSystem` | 所属系统编号；本页期望为 `3`，原值返回 |
| `list[].tenantEditable` | 是否允许租户维护数据：`1` 才满足租户数据写入前提 |
| `total` | 符合筛选条件的总记录数，不是当前页条数 |

数据分页最终返回 `{ list, total }`：

| 字段 | 含义 |
| --- | --- |
| `list[].id` | 字典数据主键，用于详情、编辑、删除 |
| `list[].sort` | 显示排序，可为空 |
| `list[].label` | 字典标签，可为空 |
| `list[].value` | 业务实际保存的字典值，可为空 |
| `list[].dictType` | 所属字典类型代码，可为空 |
| `list[].status` | 数据状态：`0` 开启、`1` 关闭，可为空 |
| `list[].colorType` | 颜色类型；页面表单不展示，可为空 |
| `list[].cssClass` | CSS 类名；页面表单不展示，可为空 |
| `list[].remark` | 数据备注，可为空 |
| `list[].createTime` | 创建时间原值，可为字符串/有限数字/null |
| `list[].tenantId` | 数据归属租户；`0` 为平台共享，正数为租户私有，可为空 |
| `list[].platform` | 是否平台共享；`true` 时页面禁用编辑和删除，可为空 |
| `total` | 当前 `dictType`、标签、状态筛选下的总记录数 |

`dataGet` 返回一条详情对象或 `null`；`dataCreate` 返回新建数据 ID；`dataUpdate`/`dataRemove` 只有 `true` 才表示后端业务成功。Portal 请求层先按 `platform` 实例规则解包响应包络，本能力再校验最终业务值、分页结构和字段类型；包络失败、网络错误不会被转为空列表或 `true`。

## 4. 操作步骤与证据

1. 调 `type-list`，用返回的 `list[].type` 作为 `data-list` 的 `dictType`；不要把类型 `id` 当作 `dictType`。
2. 调 `data-list` 展示当前页；`platform=true` 的行只读。
3. 编辑先调 `data-get`，保留详情中的 `id/dictType/label/value/sort/status/remark`，再按用户修改调用 `data-update`。
4. 新建调用 `data-create` 后，用 `data-list` 按原 `dictType`、`label`、`value` 回查并核对字段；超时不得盲目重试。
5. 删除仅允许非平台共享记录；调用 `data-remove` 后，用 `data-list` 跨页确认目标 `id` 消失。

写操作没有 `requestId` 幂等包装，也没有页面对应的 `prepare/cancel` 接口。`true` 或新 ID 只代表请求业务回执，不代表未经回查的最终状态。
