## 参数契约与逐字段基准

### 列表默认请求

Portal页面的年月控件初值为当前月，`convertFetchForm`把它拆成两个字符串；岗位组件的节点值通过`update:select`写入`postId`。列表首次请求的形状为：

```json
{
  "order": "",
  "orderField": "",
  "name": "",
  "staffCode": "",
  "costCenterId": "",
  "legalPersonId": "",
  "payrollUnitId": "",
  "postId": "",
  "organizationId": "",
  "documentName": "",
  "ledgerId": "",
  "year": "2026",
  "month": "09",
  "pageNo": 1,
  "pageSize": 20
}
```

`yearMonth`省略时使用调用时当前月；显式`null`或空串时`year`、`month`都发送空串。年月字符串必须为`YYYY-MM`，月份保持两位补零。`name`和`documentName`是模糊查询；`staffCode`为页面文本输入，但Java DTO按`Long`接收，所以只能传数字员工号。

`legalPersonId`是纳税单位ID，`payrollUnitId`和`organizationId`是组织ID，`postId`是岗位ID，`ledgerId`是账套ID，均不能用显示名称替代。`costCenterId`保留在Portal的formState并随请求发送，但当前页面模板没有可见成本单位控件；SDK保留该字段以复现页面请求形状。

后端在`PayrollServiceImpl.selectPayrollPage`中先取得当前网页可见账套；省略`ledgerId`时会把这些账套拼入查询。指定`organizationId`时，服务端调用`getDescendantByAncestor`展开后代组织，并叠加`@DataScope`数据权限。空筛选不表示绕过权限或查询全租户数据。

### 返回字段

返回`{ list, total }`，`list`是当前页，`total`是符合筛选条件的总记录数。每行身份和关联字段为：

`name`姓名、`staffCode`员工号、`idCard`身份证号、`costCenterName`成本中心、`legalPersonName`纳税单位、`payrollUnit`发薪单位、`postName`岗位、`orgName`部门全路径、`documentName`单据名称、`ledgerName`所属账套、`salaryYearMonth`工资年月、`bankAccount`银行账号、`bankName`开户行、`shouldAttendanceDays`应出勤天数、`actualAttendanceDays`实际出勤天数，以及后端DTO附带的`month`。

工资和扣款字段保持Java `BigDecimal`返回的数字或十进制字符串，不把精度转换成浮点数：

`basicSalary`基本工资、`attendanceSalary`出勤工资、`sickLeaveSalary`病假工资、`injurySalary`工伤工资、`examineSalary`考核工资、`orgAssessmentSalary`部门考核工资、`orgProfitSalary`利润考核工资、`overWorkSalary`加班工资、`weekdayOvertime`工作日加班、`weekendOvertime`双休日加班、`statutoryHolidayOvertime`法定节假日加班、`closureFee`封场费、`laborFee`劳动费、`dutyFee`值班费、`welfareSalary`福利性补贴、`educationAllowance`学历补贴、`seniorityAllowance`工龄补贴、`communicationAllowance`通讯补贴、`heatstrokePreventionFee`防暑费、`heatingFee`取暖费、`tenancyPerk`租房补贴、`onlyChildrenPerk`独生子女补贴、`otherPerk`其他福利、`bonus`奖金、`fullAttendanceBonus`全勤奖、`benefitBonus`效益奖、`highProductivitySalary`高产奖金、`stableProductivitySalary`稳产奖金、`projectSalary`项目奖金、`trainingSalary`培训奖金、`contributionFeeSalary`稿费、`otherSalary`其他工资、`grossSalary`应发工资、`pensionInsuranceSalary`养老、`unemploymentInsuranceSalary`失业、`medicalInsuranceSalary`医疗、`bigMedicalSalary`大额医疗、`personalSocialSecuritySalary`个人社保、`personalProvidentFundSalary`个人公积金、`incomeTaxSalary`个税、`housePurchaseDeductionSalary`购房扣款、`otherDeductionsSalary`其他扣款、`healthInsuranceDeductionSalary`安康扣款、`totalDeductionsSalary`扣款合计、`totalAdditionalPriceSalary`累计专项附加扣除、`totalSupportOldPriceSalary`累计赡养老人扣除、`totalTaxSalary`累计应缴纳个税、`totalHouseInterestPriceSalary`累计住房贷款利息扣除、`totalHouseRentPriceSalary`累计住房租金扣除、`totalChildEducationPriceSalary`累计子女教育扣除、`totalInfantCarePriceSalary`累计婴幼儿照护扣除、`totalAdultEducationPriceSalary`累计继续教育扣除、`totalPaidTaxSalary`累计已缴纳个税、`realPaySalary`实发工资、`preTaxSalary`税前工资（Portal实际消费的JSON字段；Java源码字段名为`PreTaxSalary`）、`taxableSalary`应税工资、`totalAdditionalSalary`专项附加扣除、`adultEducationSalary`继续教育、`supportOldSalary`赡养老人、`houseInterestSalary`住房贷款利息、`houseRentSalary`住房租金、`childEducationSalary`子女教育、`infantCareSalary`婴幼儿照护、`seriousIllnessSalary`大病医疗、`totalSpecialDeductionSalary`往期专项扣款合计、`totalTaxPointSalary`累计起征点、`totalPreTaxSalary`往期税前工资合计。

页面底部合计对当前页`listData`的上述字段逐项使用`parseFloat(value) || 0`求和并固定两位小数，不是后端返回的全量统计。SDK不伪造一个`summary`字段；需要全量合计时必须逐页获取并明确说明计算范围。

### 导出

导出请求只发送以下字段，字段值和列表筛选相同：

```json
{
  "name": "",
  "staffCode": "",
  "costCenterId": "",
  "legalPersonId": "",
  "payrollUnitId": "",
  "postId": "",
  "organizationId": "",
  "documentName": "",
  "ledgerId": "",
  "year": "2026",
  "month": "09"
}
```

Java导出服务把`pageSize`改成批量导出大小，循环复用列表查询，并在Excel末尾写入服务端汇总行。返回文件名可能包含年月、组织和账套名称；SDK返回`fileName`、`contentType`、Base64内容和原始`byteLength`，空文件抛错。非空文件只证明下载完成，不能单独证明筛选条件全部生效。

## 操作步骤、失败处理与验证边界

1. 需要查询时先确认年月；再按当前会话可见候选提供组织、纳税单位、发薪单位、岗位和账套ID。
2. 调用`.list`并按`total`翻页；展示身份证号和银行账号时按敏感字段处理，不写日志。
3. 需要文件时把相同筛选传给`.export`，用`byteLength`和`fileName`确认下载结果；不要把导出成功当成业务写入。
4. 非法年月、非数字员工号、非法ID、页码或页大小会在请求前失败；401/403、网络错误和后端业务错误原样保留。
