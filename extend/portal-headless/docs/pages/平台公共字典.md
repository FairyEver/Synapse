# 公共字典（`/dashboard/platform/setting/dict-mall/common/list`）

## 能力定义

本页属于 Portal 保留范围中的「平台设置 → 平台字典 → 公共字典」，不是独立的生产、财务、资产、人力或其他业务系统菜单。Portal wrapper 为
`app/portal/views/dashboard/platform/setting/dict-mall/common/list.vue`，共享实现为
`app/portal/views/dashboard/common/setting/dict-platform-mall/all/**`，菜单权限为
`/dashboard/platform-v2/setting/dict-mall/common`。

本节点登记与共享页面相同的 11 个用户动作：类型分页、类型详情、类型新增、类型编辑、类型删除；字典数据分页、详情、新增、编辑、单条删除和批量删除。公共字典根列表固定传 `useSystem=0`，调用方不能借此页面改写所属系统。

对应 SDK 门面为 `platformDictMallCommon`，能力定义和 AI 说明分别见：

- [src/catalog/contracts-platform-dict-mall.ts](/Users/liyang/Documents/code/github/portal-headless/src/catalog/contracts-platform-dict-mall.ts)

## 参数契约

根列表请求使用 `platform` HTTP 实例和 `/adminmanage-api/system/dict-type/page`，请求参数顺序和空值与 Portal 一致：`order=''`、`orderField=''`、`useSystem=0`、`name=''`、`type=''`、`tenantEditable=undefined`、`pageNo=1`、`pageSize=20`。分页大小只允许 Portal 下拉的 `10/20/50/100`。

类型表单来自 Portal 的默认值：`useSystem=0`、`name=''`、`type=''`、`tenantEditable=0`、`remark=''`、`status=0`；`name`、`type` 必填。SDK 在本页自动注入 `useSystem=0`，若调用方显式传入其他系统值则在发请求前拒绝。

字典数据子页使用当前路由的 `dictType`，分页请求为 `/adminmanage-api/system/dict-data/page`；数据表单默认 `id=''`、`dictTypeId=dictType`、`label=''`、`value=''`、`status=0`、`sort=0`、`remark=''`，`label` 和 `value` 在 blur 时必填。保存请求按编辑/新增分别使用 `PUT/POST /adminmanage-api/system/dict-data/{update|create}`，并把 bridge 产生的 `dictType` 一并提交。

类型和数据 ID 保留长整数的字符串形态。所有写入只在收到有效后端回执并完成回查后才能报告成功；权限、平台归属、类型状态和后端校验错误原样抛出。Portal 数据子页批量删除发送 `{ ids }`，而当前 Java `ManageDictDataController` 的声明仍是单个 `Long id`，因此该差异在 SDK 中作为独立能力如实暴露，不能假报成功。

## 逐字段基准

已按 Portal 源码逐字段锁定：

- 类型返回保留 `id/name/type/status/remark/createTime/useSystem/tenantEditable`，进入“字典数据”必须使用同一行的 `type`，不能把类型 `id` 当作 `dictType`。
- 数据返回保留 `id/sort/label/value/dictType/status/colorType/cssClass/remark/createTime/tenantId/platform`；`platform` 表示平台共享标记，但当前平台字典公共页源码没有在数据子页按该字段做前端禁用，最终可写性由平台服务归属校验决定。
- 平台管理 `ManageDictTypeController` 提供类型 create/update/delete；类型服务校验记录存在、名称/类型唯一和子数据约束。`/admin-api` 的租户 Controller 是另一套接口，不适用于本页。
- 平台管理数据服务查询和写入固定使用平台共享 `tenant_id=0`，创建校验类型启用，更新/删除校验平台归属；本页没有把 `platform` 行预先改写为客户端拒绝。

## 操作步骤

1. 先调用 `platformDictMallCommon.typeList`，保留返回行的 `type`、`id` 和完整字段；页面自动固定 `useSystem=0`。
2. 点击“字典数据”时把该行 `type` 传给 `dataList`；不要猜测类型代码，也不要传类型主键。
3. 新增、编辑或删除前先读取当前详情/列表，写操作完成后按原 `dictType` 分页回查；超时先核实，不要盲目重试。
4. 若后端返回权限、平台归属或协议错误，报告失败及原始错误；批量删除尤其不能把 `ids` 请求当成单 ID 删除已经成功。
