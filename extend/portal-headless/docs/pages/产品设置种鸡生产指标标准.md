# 产品设置种鸡生产指标标准

页面路径：`/dashboard/product/setting/standard-manage/chicken-production/list`。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询列表 | `product-setting-chicken-production-list` / `productSettingChickenProduction.list` | `GET /base/chickenProduction/page` |
| 准备新建 | `product-setting-chicken-production-prepare-create` / `productSettingChickenProduction.prepareCreate` | 不发请求 |
| 新建 | `product-setting-chicken-production-create` / `productSettingChickenProduction.create` | `POST /base/chickenProduction/save` |
| 准备编辑 | `product-setting-chicken-production-prepare-update` / `productSettingChickenProduction.prepareUpdate` | 不发请求 |
| 编辑 | `product-setting-chicken-production-update` / `productSettingChickenProduction.update` | `POST /base/chickenProduction/save` |
| 准备删除 | `product-setting-chicken-production-prepare-remove` / `productSettingChickenProduction.prepareRemove` | 不发请求 |
| 删除 | `product-setting-chicken-production-remove` / `productSettingChickenProduction.remove` | `DELETE /base/chickenProduction/{id}` |

页面属于 `门户 → 系统设置 → 生产设置 → 标准库管理`，不是独立顶层生产系统。请求使用 `product` HTTP 实例，固定追加 `devicetype=PC`，不发送 `module-type`。菜单权限为 `/dashboard/frame/standard-library/chicken-production`。

Portal 页面声明了 `base:chicken-production:query` 和 `base:chicken-production:submit`，但源码只实际调用 `permissionCheck(permissions.submit)`，用它控制新建、编辑和删除；查询按钮没有调用 query 权限检查。SDK保留该权限事实，服务端仍执行当前会话的实际权限校验。

## 参数契约与表单提交规则

列表是 `useListPageModule({ styleV2: true, customLoad, getDataListIsPage: true })`，默认请求参数为：

```json
{
  "order": "",
  "orderField": "",
  "year": "",
  "weekAge": 0,
  "gen": "",
  "line": "",
  "variety": "",
  "moulting": 0,
  "pageNo": 1,
  "pageSize": 20
}
```

`moulting` 为 `0=非换羽、1=换羽`；分页支持 `10/20/50/100`。列表筛选字段由 Java Mapper 的 `weekAge`、`gen`、`variety`、`line`、`year`、`moulting` 条件组成。

新建和编辑弹窗中年度、是否换羽、周龄必填；其他数字字段可为空。数值输入范围按 Portal 控件复刻，通常为 `-10000000` 到 `10000000`；品系版本为 `1` 到 `10000000` 的整数。九个率字段在弹窗中按百分数填写，提交时严格除以 `100`：

```json
{
  "year": 2026,
  "moulting": 1,
  "weekAge": 12,
  "layingRate": 0.82,
  "passRate": 0.96,
  "fertilityRate": 0.94
}
```

`ChickenProductionController` 的分页和详情响应又会把产蛋率、合格率、受精率、公母鸡死亡率、公母鸡死淘率、公母鸡淘汰率共九个字段乘以 `100` 后返回，所以 SDK 的 `list()` 保留服务端返回值，例如 `82` 表示 `82` 个百分点，不再二次换算。Portal 编辑弹窗源码在回显时还会把列表值再次乘以 `100`；这是页面现有的二次换算路径。直接调用 `prepareUpdate()` 时应传入该弹窗实际的 `formState` 值，不能把 `list()` 行的率字段未经页面回显转换直接当作弹窗百分数。

编辑提交会先展开 `...props.raw`，因此 SDK 的 `prepareUpdate()` 保留列表行的扩展字段，并覆盖编辑后的已知字段和比例换算值。用户取消新建、编辑或删除确认时只丢弃本地草稿，不发送写请求。

## 逐字段基准

| 字段 | 含义 |
| --- | --- |
| `id` | 种鸡生产指标标准记录ID；编辑和删除目标。 |
| `year` / `weekAge` | 年度、周龄。 |
| `moulting` | `0` 非换羽、`1` 换羽。 |
| `gen` / `variety` / `line` / `lineVer` | 代次、品种、品系、品系版本。 |
| `layingRate` / `passRate` / `fertilityRate` | 产蛋率、合格率、受精率；列表响应值已被 Java Controller 乘以100。 |
| `maleDeathsRate` / `femaleDeathsRate` | 公鸡、母鸡死亡率；列表响应值已被 Java Controller 乘以100。 |
| `maleDeathEliminationRate` / `femaleDeathEliminationRate` | 公鸡、母鸡死淘率；列表响应值已被 Java Controller 乘以100。 |
| `maleEliminationRate` / `femaleEliminationRate` | 公鸡、母鸡淘汰率；列表响应值已被 Java Controller 乘以100。 |
| `femaleWeight` / `maleWeight` | 母鸡、公鸡体重，服务端原始数值。 |
| `femaleTibiaLength` / `maleTibiaLength` | 母鸡、公鸡体尺，服务端原始数值。 |
| `dailyConsumption` / `evennessDegree` / `eggWeight` | 日耗料、均匀度、蛋重，服务端原始数值。 |
| `total` | 当前筛选条件下的总记录数。 |

SDK保留后端返回的页面无关扩展字段，但不把它们当作页面业务字段；网络、权限、Java业务错误或响应结构错误会抛出，不降级为空列表。

## 逐页操作步骤、权限与证据边界

1. 用 `list()` 读取最新列表，确认目标行的 `id`；列表中的率字段按服务端已乘100的值解释。
2. 新建先调用 `prepareCreate()`；编辑先按Portal弹窗回显规则准备 `form`，再调用 `prepareUpdate()`，确认 `draft` 中的率字段已经是比例小数。
3. 用户明确确认后，把同一 `draft` 原样交给 `create()` 或 `update()`；成功或响应不确定后重新调用 `list()` 回查。
4. 删除先调用 `prepareRemove({ id })`，用户确认后调用 `remove({ id })`；成功或响应不确定后重新查询，确认目标ID不再出现。

本轮逐页核对了 Portal 菜单、列表、弹窗、product HTTP、权限声明与实际调用、Java `ChickenProductionController`/`ChickenProduction`/`ChickenProductionServiceImpl`/Mapper、SDK请求和离线反证测试。尚未在真实测试环境使用浏览器会话执行列表、`prepare → submit → 回查`及删除闭环；页面率字段存在列表响应与编辑回显的二次换算路径，真实租户终态仍需实测确认。
