# 商标管理（`/dashboard/certificate/trademark/list`）

风险防控域的商标分页列表、表单、Excel 导出、共享设置、批量续展和续展记录。Portal、Java 与 SDK 按本页逐项核对；页面可达的导出和续展动作均纳入能力。

## Portal 页面行为

列表通过 `GET /admin-api/hr/risk/trademark/page` 查询。当前页面可见筛选只有 `signNumber`、`name`、`category`、`type`、`organizationId`，初始值均为空字符串；请求还带 `order=''`、`orderField=''`、`pageNo=1`、`pageSize=20`。可达操作是导出、上传商标、编辑、共享设置、删除、续展记录和批量续展；批量续展只允许选择 `renewable` 不为 `false/0` 的记录。

详情通过 `GET /admin-api/hr/risk/trademark/get?id=...` 读取。新建调用 `POST /admin-api/hr/risk/trademark/create`，编辑调用 `PUT /admin-api/hr/risk/trademark/update`，删除调用 `DELETE /admin-api/hr/risk/trademark/delete?id=...`。导出调用 `GET /admin-api/hr/risk/trademark/export-excel`，返回 Excel 二进制。

表单包含有效状态、申请号/注册号、名称、图样、类别、商标类型、注册日期、截止日期、提醒月数、提醒人员、注册人、注册地址、PDF 附件和核定商品。有效状态、申请号/注册号、名称、类别、注册日期、截止日期、提醒月数、提醒人员、注册人、注册地址和 PDF 附件必填；申请号/注册号和名称最多10字符，核定商品最多500字符。图样最多3项；PDF 只接受 `application/pdf`，最多10项，提交时 `fileUrl`、`pdfUrl`、`pdfName` 和 `remindUser` 均按页面规则转换为逗号字符串，空值发送 `null`。注册日期必须早于截止日期。

批量续展使用 `POST /admin-api/hr/risk/trademark/renewal/batch`，内容去除首尾空格后最多500字符，附件至少1个、最多10个，每个不超过20MB，扩展名限 PDF/XLS/XLSX/DOC/DOCX/JPG/JPEG/PNG。续展记录使用 `GET /admin-api/hr/risk/trademark/renewal/records?trademarkId=...`。

共享弹窗使用 `/admin-api/system/share-user/getShare` 和 `/admin-api/system/share-user/createShare`，商标资源 `type` 固定为 `3`；读取保留 `name/managerType` 展示，保存组织、岗位、职务和人员时每项只提交 `{ id }`。

## 表单、权限和数据规则

- `validStatus` 为1有效或2无效；`type` 为1驰名商标或2著名商标；`category` 为 `trademark_category` 字典值。
- `remindTime` 是大于等于1的整数；`remindUser` 是人员 ID 数组；`loginTime`、`endTime` 按 `YYYY-MM-DD` 传输且注册日期必须早于截止日期。
- 图样最多3项；PDF 附件最多10项且 URL/名称按下标成对。列表 `status` 是后端根据截止日期和提醒月数计算的展示状态：1=已过期、2=即将过期、3=未过期，不是用户筛选或保存字段。
- 续展提交的商标 ID 不得重复；附件名称最多255字符、URL最多1000字符、大小必须大于0且不超过20MB；后端也会校验当前租户中商标是否存在。
- 列表、详情、写入、导出、续展和共享受当前会话、租户、页面权限及后端数据范围约束。Java `TrademarkDO` 继承 `TenantBaseDO`；SDK 不扩大权限，也不把 `true` 或导出成功单独当作业务完成证据。

## 后端与 SDK 对齐

Java `TrademarkController` 提供本页面所需的分页、详情、新建、更新、删除、导出、续展提交和续展记录；`TrademarkSaveReqVO` 使用 Long/LocalDate/Integer 和逗号字符串字段；`TrademarkServiceImpl` 补充组织/提醒人员名称并计算到期状态；`TrademarkRenewalServiceImpl` 写入续展记录、关联商标和附件并按租户校验。共享枚举为 `TRADEMARK(3, "商标")`。

实现文件：`src/capabilities/trademark.ts`；AI 说明：`src/catalog/contracts-trademark.ts`。写能力按 `prepare → submit → 回查`，用户取消只丢弃本地草稿，不虚构服务端取消接口。
