# 软著管理（`/dashboard/certificate/softwork/list`）

风险防控域的软著分页列表、完整表单和共享设置。Portal、Java 与 SDK 按本页逐项核对；后端导出端点没有页面可达按钮，因此不注册为 SDK 页面能力。

| 项 | 值 |

| SDK 能力 | `software-*` |

## Portal 页面行为

列表通过 `GET /admin-api/hr/software/page` 查询。当前页面可见筛选只有 `name`、`softwareNumber`、`inventor`，初始值为空字符串；请求还带 `order=''`、`orderField=''`、隐藏的 `status=''`、`pageNo=1`、`pageSize=20`。可达操作是新建、编辑、共享设置和删除；列表源码没有可达导出动作。

详情通过 `GET /admin-api/hr/software/get?id=...` 读取。新建调用 `POST /admin-api/hr/software/create`，编辑调用 `PUT /admin-api/hr/software/update`，删除调用 `DELETE /admin-api/hr/software/delete?id=...`。Portal 只将 `endTime` 用 `formatDay` 规整；提交时 `endTime` 按 `YYYY-MM-DD` 发送，`remindUser`、`pdfUrl`、`pdfName` 数组分别逗号连接，空附件转换为 `null`。

表单包含证书号、软件名称、著作权人、开发完成日期、首次发表日期、取得方式、权利范围、登记号、所属组织、到期日期、提醒月数、提醒人员和附件。必填与长度规则：证书号/登记号最多20字符，软件名称/著作权人最多50字符，权利范围最多100字符；取得方式为 1 原始取得或 2 继受取得；提醒月数为 1 至 99999 的整数。附件只接受 `application/pdf`，控件最多保留5项，`pdfUrl` 与 `pdfName` 必须按下标成对。

共享弹窗使用 `/admin-api/system/share-user/getShare` 和 `/admin-api/system/share-user/createShare`，软著资源 `type` 固定为 `8`；读取保留 `name/managerType` 展示，保存四类成员时每项只提交 `{ id }`。

## 表单、权限和数据规则

- `softwareNumber`、`name`、`inventor`、`way`、`radius`、`signNumber`、`organizationId`、`endTime`、`remindTime`、`remindUser`、`pdfUrl` 必填；`developDate` 和 `firstPublishDate` 可为空。
- 日期按 `YYYY-MM-DD` 传输；提醒人员是人员 ID 数组，提交时变为逗号字符串；附件 URL 与名称保持同下标顺序。
- 列表 `status` 是 Java 服务根据到期日期和提醒月数计算的展示字段：1=已过期、2=即将过期、3=未过期，不是用户筛选或保存字段。
- Java `HrSoftwareDO` 继承 `TenantBaseDO`。列表、详情、写入和共享受当前会话、租户、页面权限及后端数据范围约束，SDK 不扩大权限，也不把 `true` 回执单独当作业务完成证据。

## 后端与 SDK 对齐

Java `HrSoftwareController` 提供本页面的分页、详情、新建、更新、删除；`HrSoftwareSaveReqVO` 使用 Long ID、LocalDate 日期、Integer 提醒月数和逗号字符串字段；`HrSoftwareServiceImpl` 补充组织/提醒人员名称并计算到期状态；共享枚举为 `SOFTWARE(8, "软著")`。`export-excel` 虽存在于 Controller，但 Portal 页面无可达入口，不接入本页能力。

实现文件：`src/capabilities/software.ts`；AI 说明：`src/catalog/contracts-software.ts`。写能力按 `prepare → submit → 回查`，取消只丢弃本地草稿，不虚构服务端取消接口。
