## 能力定义

| 页面动作 | 能力 / 方法 | 请求或行为 |
| --- | --- | --- |
| 筛选、分页 | `insurance-archive-list` / `.archiveList` | `GET /salary/salaryinsurancecosts/page`，默认 `archiveStatus=2` |
| 组织树 | `insurance-archive-organization-tree` / `.organizationTree` | `GET /org/organization/getRoleOrganizationTree` |
| 取消归档 | `insurance-archive-prepare-unarchive` → `insurance-archive-unarchive` | `PUT /salary/salaryinsurancecosts/unarchive` |
| 导出 | `insurance-archive-export` / `.archiveExport` | `GET /salary/salaryinsurancecosts/export`，`type=2` |

本页不发布费用导入、删除、归档或调整能力；这些动作属于社保费用页。

## 参数契约与逐字段基准

列表默认发送 `order=''`、`orderField=''`、`archiveStatus=2`、`isSalaryUsed=null`、空组织、`name=null`、费用归属和发生月份空范围、`pageNo=1&pageSize=20`。月份分别转为 `costDateStart/costDateEnd` 和 `occurredDateStart/occurredDateEnd`；导出删除分页与排序键，发送 `type=2` 和可选 `ids`，文件名为 `社保归档查询.xlsx`。

列表行与社保费用页共用完整费用投影。`archiveStatus=2` 表示已归档；`isSalaryUsed` 的 `0/1` 语义按后端原值解释，金额、月份、空值和审计字段不被改写。

取消归档输入必须是当前页面选中的非空记录ID数组，SDK生成 `{id}` 数组，不用姓名、组织名称或行号代替ID。

## 操作步骤、失败处理与验证边界

1. 先读取组织树，再用 `archiveList` 获取当前筛选结果和记录ID。
2. 用户确认后执行 `prepareUnarchive` → `unarchive`；取消确认时只丢弃草稿。
3. 完成或超时后按同一批ID重新查询，确认记录已离开归档结果；请求无异常不等于状态已改变。
4. 非法月份、状态、ID、空批次、分页或响应形状在本地失败；权限、网络和后端业务错误原样抛出。
