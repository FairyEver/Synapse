# 防疫功能使用分析（`/dashboard/product/operation/veterinarians/usage-analysis/list`）

Portal「产品运营 → 使用分析 → 防疫功能使用分析」是只读统计页。页面先读取组织树，再按组织、日期和两个分组维度查询防疫功能使用情况；图表/表格切换是本地行为，没有导出、保存、删除或取消接口。

## 1. 能力定义

| 页面动作 | 能力 / 方法 | 请求或行为 |
| --- | --- | --- |
| 读取组织树 | `product-prevention-usage-analysis-tree` / `productPreventionUsageAnalysis.tree` | `GET /config/farm/getOfficeFarmBuildingTreeByTag`，固定 `types=1,2` |
| 查询防疫统计 | `product-prevention-usage-analysis-list` / `productPreventionUsageAnalysis.list` | `POST /use/statistics/preventionUseSituation` |

页面菜单、权限、组织树、统计接口和 Java Controller/VO/DTO/Service 均按本页逐项核对。Java 存在独立的 `preventionUseSituation/getExcel` 导出接口，但当前 Portal 页面没有调用或导出按钮，不纳入本页能力。

## 2. 参数契约与表单提交规则

页面默认表单为 `buildingList=[]`、`startDate=当天`、`endDate=当天`、`timeGroup='1'`、`orgGroup='1'`；五项均为必填。

### 组织树

请求为：

```json
{
  "types": "1,2"
}
```

Portal 兼容接口直接返回数组或 `{ tree: [] }`。SDK保留递归 `child`，只把 `type=4` 或无下级的叶节点视为可提交栋舍；页面选择为空或只回传父级节点时回退到全部末级组织。调用 SDK 时应先用 `tree()`取树，再把合法栋舍 ID 交给 `list()`。

### 统计查询

Portal `convertFetchForm` 的请求体为：

```json
{
  "buildingList": ["栋舍ID"],
  "startDate": "YYYY-MM-DD",
  "endDate": "YYYY-MM-DD",
  "timeGroup": "1",
  "orgGroup": "1",
  "scope": 1,
  "menuName": "用户使用情况报表"
}
```

`timeGroup` 为 `1=按天、2=按周、3=按月`；`orgGroup` 为 `1=按公司、2=按场区、3=按栋号`。SDK接受页面实际发送的字符串，也接受对应数字并规范为字符串。

SDK在发请求前复刻 Java `UseStatisticsServiceImpl.validateAndBuildTimeRanges` 的边界：

- 按天/周/月日期跨度最多分别为 366/1096/1827 天；结束日期不能早于开始日期。
- 按天/周/月最多分别选择 100/200/300 个栋舍。
- 预计统计数据量（栋舍数 × 时间段数）不能超过 10000 条。

统计结果字段与 `PreventionUseSituationDTO` 对齐：`officeName`、`farmName`、`buildingName`、`dateStr`、`whiteDysentery`、`necropsyRecord`、`necropsyImage`、`auscultation`、`other`、`microorganismSubmit`、`microorganismAssay`、`antibodySubmit`、`antibodyAssay`、`etiologySubmit`、`etiologyAssay`、`immunity`、`medication`、`disinfection`、`diagnosis`。SDK不添加 Portal 表格使用的随机行 `id`，也不把 Java 存在但 Web 未使用的导出端点伪装成页面能力。

`test/product-prevention-usage-analysis.test.ts` 固定了 Portal/Java 源码锚点、两条请求的逐字段请求体、product 请求头与 URL、完整结果字段、非法输入不发请求和错误响应反证。当前环境未启动浏览器，尚未执行测试环境的真实读请求或真实权限差异，因此不能将离线断言表述为真实环境已验证。

## 4. 操作步骤与未覆盖项

1. 调用 `tree()`，递归展示组织树并让用户选择 `type=4` 或叶节点。
2. 将所选合法栋舍 ID 与日期、`timeGroup`、`orgGroup` 交给 `list()`；SDK会在请求前重新检查页面和 Java 边界。
3. 用返回数组填充表格或图表；`[]`是合法的无数据结果，权限、网络或响应形状错误会抛出。
4. 本页全部是只读能力，不存在 `prepare → submit → cancel` 写链；取消筛选只是不调用 `list()`。Java 导出 Controller 未被 Web 页面使用，不提供 SDK 导出动作。
