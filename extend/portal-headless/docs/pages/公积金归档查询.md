## 参数契约与逐字段基准

默认列表请求为：

```text
archiveStatus=2&orgIds=&isSalaryUsed=null&name=null&costDateStart=null&costDateEnd=null&occurredDateStart=null&occurredDateEnd=null&pageNo=1&pageSize=20
```

`archiveStatus` 固定为 `2` 表示已归档；`isSalaryUsed` 只接受 `0=未被工资使用` 或 `1=已被工资使用`。`orgIds` 数组按Portal规则连接为逗号字符串；`belongMonth` 转换为 `costDateStart/costDateEnd`，`occurMonth` 转换为 `occurredDateStart/occurredDateEnd`，月份格式均为 `YYYY-MM`。导出删除分页键，保留筛选键并发送 `type=2` 与可选 `ids`。

列表行与费用页共用公积金费用数据投影，保留记录ID、人员/组织、费用月份与发生月份、金额、归档状态、工资单使用关联、缴存单位、成本中心及审计字段。`archiveStatus` 是状态原值，不把后端 `2` 改成布尔值；金额和空值原样保留。

取消归档必须传当前页面选中记录的非空ID数组，SDK不会用组织名称或行号代替ID。组织树节点的 `id` 用于提交筛选，`name` 只用于显示。

## 操作步骤、失败处理与验证边界

1. 先用 `archiveList` 按月份、组织和工资使用状态读取当前归档记录；需要组织筛选时先读取 `organizationTree`。
2. 用户明确选择记录后执行 `prepareUnarchive` → `unarchive`，成功或超时按同一批ID回查费用页/归档页，不能把无异常返回当成归档状态已改变。
3. 导出时保留与列表相同的筛选条件；返回文件的 `base64`、`byteLength` 和 `contentType` 是SDK最终交付字段。
4. 非法状态、月份、ID、空批次、分页或响应形状在本地失败；401/403、网络错误和后端业务错误原样抛出。
