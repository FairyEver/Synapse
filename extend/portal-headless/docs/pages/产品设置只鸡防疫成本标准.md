# 产品设置只鸡防疫成本标准

页面路径：`/dashboard/product/setting/standard-manage/epidemic-prevention-cost/list`。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询列表 | `product-setting-epidemic-prevention-cost-list` / `productSettingEpidemicPreventionCost.list` | `GET /base/epidemicPreventionCost/page` |
| 准备新建 | `product-setting-epidemic-prevention-cost-prepare-create` / `productSettingEpidemicPreventionCost.prepareCreate` | 不发请求 |
| 新建 | `product-setting-epidemic-prevention-cost-create` / `productSettingEpidemicPreventionCost.create` | `POST /base/epidemicPreventionCost/save` |
| 准备编辑 | `product-setting-epidemic-prevention-cost-prepare-update` / `productSettingEpidemicPreventionCost.prepareUpdate` | 不发请求 |
| 编辑 | `product-setting-epidemic-prevention-cost-update` / `productSettingEpidemicPreventionCost.update` | `POST /base/epidemicPreventionCost/save` |
| 准备删除 | `product-setting-epidemic-prevention-cost-prepare-remove` / `productSettingEpidemicPreventionCost.prepareRemove` | 不发请求 |
| 删除 | `product-setting-epidemic-prevention-cost-remove` / `productSettingEpidemicPreventionCost.remove` | `DELETE /base/epidemicPreventionCost/{id}` |

页面属于 `门户 → 系统设置 → 生产设置 → 标准库管理`，不是独立顶层生产系统。请求使用 `product` HTTP 实例，固定追加 `devicetype=PC`，本页不发送 `module-type`。菜单权限为 `/dashboard/frame/standard-library/epidemic-prevention-cost`。

Portal 页面声明了 `base:epidemic-prevention-cost:query` 和 `base:epidemic-prevention-cost:submit`；查询没有单独调用 query 权限，新增、编辑和删除由 `permissionCheck(permissions.submit)` 控制。SDK保留该权限事实，服务端仍执行当前会话的实际权限校验。

## 参数契约与表单提交规则

列表是 `useListPageModule({ styleV2: true, customLoad, getDataListIsPage: true })`，默认请求参数为：

```json
{
  "order": "",
  "orderField": "",
  "farm": "",
  "year": "",
  "moulting": 0,
  "gen": "",
  "pageNo": 1,
  "pageSize": 20
}
```

场区、年度、是否换羽、代次是查询表单字段；页面要求四项都填写后才执行筛选。`moulting` 为 `0=否、1=是`；分页支持 `10/20/50/100`。

新建和编辑弹窗的年度、周龄起止、代次、场区、疫苗成本、兽药成本、消毒药成本和是否换羽均必填。数值控件范围为 `-10000000` 到 `10000000`；提交时年度、周龄起止、三项成本、代次和是否换羽均按 Portal 使用 `Number()` 转换，场区值原样提交：

```json
{
  "year": 2026,
  "weekAgeBegin": 1,
  "weekAgeEnd": 4,
  "gen": 2,
  "farm": "farm-1",
  "vaccineUnitCost": 1.2,
  "veterinaryDrugUnitCost": 2.3,
  "disinfectantUnitCost": 0.8,
  "moulting": 1
}
```

Java Controller 会为列表行补充 `farmName` 和 `genName`。Portal 场区展示优先使用选项加载后的ID→名称映射，回退到 `record.farmName`；代次使用 Portal 字典组件展示。编辑提交先展开 `...props.raw`，所以 SDK 的 `prepareUpdate()` 保留当前列表行的扩展字段，再覆盖可编辑字段和ID。用户取消新建、编辑或删除确认时只丢弃本地草稿，不发送写请求。

## 逐字段基准

| 字段 | 含义 |
| --- | --- |
| `id` | 只鸡防疫成本标准记录ID；编辑和删除目标。 |
| `year` | 年度。 |
| `weekAgeBegin` / `weekAgeEnd` | 周龄起始、终止。 |
| `moulting` | 是否换羽：`0` 否、`1` 是。 |
| `farm` | 场区ID；保存和筛选使用。 |
| `farmName` | 场区名称；Java Controller通过HROrgService补充，页面优先使用场区选项映射。 |
| `gen` | 代次ID/字典值；保存和筛选使用。 |
| `genName` | 代次名称；Java Controller从本地字典缓存补充。 |
| `vaccineUnitCost` | 只鸡疫苗成本标准。 |
| `veterinaryDrugUnitCost` | 只鸡兽药成本标准。 |
| `disinfectantUnitCost` | 只鸡消毒药成本标准。 |
| `satisfaction` | Java实体中的满意度字段；页面不编辑该字段。 |
| `total` | 当前筛选条件下的记录总数。 |

SDK保留后端返回的页面无关扩展字段，但不把它们当作页面业务字段；网络、权限、Java业务错误或响应结构错误会抛出，不降级为空列表。

## 逐页操作步骤、权限与证据边界

1. 用 `list()` 读取最新列表，确认目标行的 `id`、场区、年度、代次和三项成本。
2. 新建先调用 `prepareCreate()`；编辑调用 `prepareUpdate()`，确认 `draft` 保留当前行ID和所需raw字段。
3. 用户明确确认后，把同一 `draft` 原样交给 `create()` 或 `update()`；成功或响应不确定后重新调用 `list()` 回查。
4. 删除先调用 `prepareRemove({ id })`，用户确认后调用 `remove({ id })`；成功或响应不确定后重新查询，确认目标ID不再出现。
