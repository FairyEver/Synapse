- 页面：`/dashboard/finance/setting/cat-map/list`
- 菜单权限：`/dashboard/finance/setting/cat-map`
- 目录元数据：`generated/page-catalog.json` 中 `kind=列表页(声明式 getDataListURL)`、`write=true`、`menuSource=app/portal/menus/finance.js`、`moduleType=null`。
- 页面按钮权限：新建 `finance:setting:cat-map:create`、编辑 `finance:setting:cat-map:edit`、废弃 `finance:setting:cat-map:delete`。
- 源码锚点：Portal `test/portal/main:d3cf56bdc7`，Java `test/test:dcb3f360194`。两份固定检出工作区干净；本轮未执行 `pull --ff-only`，因此不能声明它们已与远端最新版本同步。
- 证据状态：本文和SDK实现均为静态源码推导加离线替身测试；本轮未启动浏览器，没有页面网络基准，也没有向真实测试环境发送读/写冒烟。

## 能力定义

| 能力 ID | SDK 方法 | 页面动作 | 副作用 |
| --- | --- | --- | --- |
| `finance-setting-cat-map-finance-category-search` | `financeSettingCatMap.searchFinanceCategories({ keyword, limit? })` | 搜索财务类目树候选 | 无；SDK拉取页面树后本地匹配 |
| `finance-setting-cat-map-thing-category-search` | `financeSettingCatMap.searchThingCategories({ keyword, limit? })` | 搜索资产类目树候选 | 无；SDK拉取页面树后本地匹配 |
| `finance-setting-cat-map-list` | `financeSettingCatMap.list()` | 查询类目对照表 | 无 |
| `finance-setting-cat-map-prepare-create` | `financeSettingCatMap.prepareCreate({ financeCategoryId, thingCategoryIds })` | 预览新建表单提交 | 无网络、无写入 |
| `finance-setting-cat-map-create` | `financeSettingCatMap.create({ financeCategoryId, thingCategoryIds })` | 新建类目对照 | 新增财务类目与资产类目关系 |
| `finance-setting-cat-map-prepare-update` | `financeSettingCatMap.prepareUpdate({ current, changes? })` | 预览编辑提交并保留旧值 | 无网络、无写入 |
| `finance-setting-cat-map-update` | `financeSettingCatMap.update({ current, changes? })` | 编辑类目对照 | 删除旧关系并重建目标关系；目标财务类目可变化 |
| `finance-setting-cat-map-discard` | `financeSettingCatMap.discard({ id, financeCategoryId, thingCategoryIds })` | 废弃当前映射 | 清除关系并把财务类目标记为未绑定 |

没有发布页面没有入口的 `get`、导出、独立恢复或删除能力。两个候选能力对应编辑页实际挂载的树选择器；后端候选接口本身不接关键字，所以SDK要求关键字并在返回树上本地过滤，避免一次把整棵长树交给调用方。

## 参数契约

### 候选

`searchFinanceCategories` 请求：

```text
GET /admin-api/finance/income-category/page
```

`searchThingCategories` 请求：

```text
GET /admin-api/finance/thing-category/getThingTree
```

两条请求不发送查询参数；`keyword` 必填且去首尾空白后非空，`limit` 默认20、允许1至100。SDK返回 `{ list, matched }`，其中 `matched` 是本次返回条数，不是后端全量匹配总数。候选 `path` 是SDK按树祖先名称拼出的 `》》` 路径。

资产候选的 `isUse=1` 会被页面组件转成 `disabled=true`，SDK同时返回 `selectable=false`；只能把 `selectable=true` 的ID放进提交数组。候选空数组表示本次关键字在返回树中没有匹配，不表示权限或网络成功。

### 列表

Portal列表使用 `useListPageModule` 的 `getDataListIsPage=false`，所以请求只带renren默认空排序参数：

```text
GET /admin-api/finance/thing-category/page?order=&orderField=&_t=...
```

后端名称含 `page` 但返回的是 `ThingCategoryUnionRespVO[]` 全量数组，不是 `{ list, total }`，请求也不发送 `pageNo/pageSize`。SDK公开字段为：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | `string \| number` | 类目对照行ID；Java当前实现把它设为财务类目ID |
| `financeCategoryId` | `string \| number` | 当前绑定财务类目ID；正常列表行与 `id` 相同 |
| `financeCategoryName` | `string` | 财务类目完整路径；Java用 `》》` 拼接，取不到路径时可能为空字符串 |
| `thingCategoryIds` | `array` | 资产类目ID数组，属于资产类目命名空间 |
| `thingCategoryName` | `array` | 资产类目完整名称路径数组；后端取不到某个路径时会跳过该名称，长度可能小于ID数组 |
| `bindTime` | `string \| null` | 最近绑定时间原值；页面格式化展示，SDK不猜时区 |

空列表 `[]` 表示当前权限范围内没有已绑定映射；响应异常、401/403或网络错误会抛出，不改写为空数组。

### 新建

表单只把两个业务字段交给调用方：`financeCategoryId` 与至少一个 `thingCategoryIds`。Portal隐藏表单初值为 `status=true`、`id=''`，因此SDK生成的POST body键序固定为：

```json
{"thingCategoryIds":["资产ID"],"financeCategoryId":"财务ID","status":true,"id":""}
```

请求：

```text
POST /admin-api/finance/thing-category/create
```

后端返回根 `Long`，SDK以 `string | number` 返回安全正ID。该ID是财务类目主键，不是关系表自增ID。

### 编辑

`current` 必须是最新列表完整行或 `prepareUpdate` 的 `draft`；`changes` 只允许 `financeCategoryId`、`thingCategoryIds`。省略字段沿用 `current`，资产数组是整组替换而非增量操作。编辑body键序固定为：

```json
{"thingCategoryIds":["资产ID"],"financeCategoryId":"目标财务ID","status":true,"id":"编辑前财务ID"}
```

请求：

```text
PUT /admin-api/finance/thing-category/update
```

如果更换财务类目，`id` 仍保留编辑前的旧财务ID；Java服务会解绑旧ID、绑定 `financeCategoryId` 指向的新ID。后端成功业务值必须严格为 `true`。

### 废弃

`id`、`financeCategoryId`、`thingCategoryIds` 必须来自同一条最新列表行，其中前两者按字符串值相等；资产数组可以为空。请求body键序固定为：

```json
{"id":"财务ID","status":false,"thingCategoryIds":[],"financeCategoryId":"财务ID"}
```

请求：

```text
PUT /admin-api/finance/thing-category/discard
```

后端成功业务值必须严格为 `true`。这不是数值状态切换：`status=false` 是页面废弃请求的固定字段。

## 逐字段基准

本轮没有浏览器基准；以下请求/响应是固定Portal源码与固定Java源码的推断，并由离线测试替身锁定，不应描述为线上实测。

- 页面列表直接使用 `platform.js` 默认实例；SDK定义显式记录 `httpInstance=platform`。
- 页面路径无法推导 `module-type`；SDK定义显式记录 `moduleType=null`，platform请求带当前会话的 `tenant-id`、`token`、`Accept-Language`，不带 `module-type`。
- platform层会在GET中追加 `_t`，并把空排序参数保留在URL中；候选树组件请求本身没有业务查询参数。
- 列表行的 `id` 与 `financeCategoryId` 在Java列表服务中都来自 `IncomeCategoryDO.id`；编辑请求仍允许二者分离，不能在SDK中把目标ID覆盖到旧ID字段。
- `thingCategoryName` 是后端逐条调用资产类目路径后收集的名称数组；后端跳过空路径，因此不能用名称数组下标反推ID数组下标。
- `bindTime` 源自Java `LocalDateTime`；当前无浏览器响应样本，SDK只接受字符串或null，不做时区换算。
- Java `create` 返回财务类目根ID，`update`/`discard` 返回布尔 `true`；SDK拒绝缺失、错误类型或伪成功值。

## 操作步骤与验证

1. 先用财务/资产候选能力分别按非空关键字搜索，展示 `path`，由用户确认真实ID；资产候选只选 `selectable=true`。
2. 读取 `list()` 取得当前全量映射。编辑或废弃前重新读取，保存整行快照。
3. 新建先 `prepareCreate` 审阅固定 `status/id` 和业务ID，再 `create`。成功或超时后必须 `list`，按返回财务ID核对完整资产ID数组。
4. 编辑先 `prepareUpdate`，确认 `draft.id` 仍是旧ID，保存 `previous`；再 `update`，成功或超时后 `list` 核对目标关系。
5. 废弃成功或超时后 `list`，确认原ID不再出现；不能只凭后端 `true` 或页面成功提示报告完成。
6. 新建的清理路径是用户明确要求后用同一行数据调用 `discard`，再 `list`确认消失。编辑恢复是使用保存的旧快照再次 `update`；废弃没有后端restore接口，恢复只能用原值重新 `create`，这是补偿写入，不是事务回滚。
