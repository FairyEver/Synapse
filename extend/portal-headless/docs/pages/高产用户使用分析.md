# 高产用户使用分析（`/dashboard/product/operation/business/usage-chicken/list`）

Portal「产品运营 → 业务分析 → 高产用户使用分析」是只读统计页。页面先读取组织树，再按组织、日期和两个分组维度查询高产用户使用情况；图表/表格切换是本地行为，没有导出或写入动作。

## 1. 能力定义

| 页面动作 | 能力 / 方法 | 请求或行为 |
| --- | --- | --- |
| 读取组织树 | `product-high-production-usage-tree` / `productHighProductionUsage.tree` | `GET /config/farm/getOfficeFarmBuildingTreeByTag`，固定 `types=1` |
| 查询高产统计 | `product-high-production-usage-list` / `productHighProductionUsage.list` | `POST /use/statistics/highProductionRecordSituation` |

页面菜单、组织树、统计接口和 Java Controller/VO/DTO/Service 均按上述页面逐项核对。稳产用户使用分析是另一个菜单、权限和端点，不归入本页能力。

## 2. 参数契约与表单提交规则

页面默认表单为 `buildingList=[]`、`startDate=当天`、`endDate=当天`、`timeGroup='1'`、`orgGroup='1'`；五项均为必填。

### 组织树

请求为：

```json
{
  "types": "1"
}
```

Portal 兼容响应数组和 `{ tree: [] }` 两种形状。SDK保留递归 `child`，只把 `type=4` 或无下级的叶节点视为可提交栋舍；选择为空时页面回退到全部合法叶节点。父级公司/场区 ID 不能直接作为 `buildingList`。

### 统计查询

Portal `convertFetchForm` 的请求体为：

```json
{
  "buildingList": ["栋舍ID"],
  "startDate": "YYYY-MM-DD",
  "endDate": "YYYY-MM-DD",
  "timeGroup": "1",
  "orgGroup": "1",
  "scope": 1,
  "menuName": "用户使用情况报表"
}
```

`timeGroup` 为 `1=按天、2=按周、3=按月`；`orgGroup` 为 `1=按公司、2=按场区、3=按栋号`。SDK接受页面实际发送的字符串，也接受对应数字并规范为字符串。

SDK在发请求前复刻 Java `UseStatisticsServiceImpl` 的边界：

- 按天/周/月日期跨度最多分别为 366/1096/1827 天；结束日期不能早于开始日期。
- 按天/周/月最多分别选择 100/200/300 个栋舍。
- 预计统计数据量（栋舍数 × 时间段数）不能超过 10000 条。

统计结果字段与 `ProductionRecordSituationDTO` 对齐：`officeName`、`farmName`、`buildingName`、`dateStr`、`flockCount`、`openingQty`、`programCount`、`dailyRecord`、`weightRecord`、`tibiaRecord`、`inChickenCount`、`transferCount`。SDK不添加 Portal 表格使用的随机行 `id`，也不提供页面不存在的导出或写入能力。

`test/product-high-production-usage.test.ts` 固定了 Portal/Java 源码锚点、两条请求的逐字段请求体、product 请求头与 URL、结果字段、非法输入不发请求和错误响应不伪造空结果。当前环境未启动浏览器，尚未执行测试环境的真实读请求或真实权限差异，因此不能将离线断言表述为真实环境已验证。

## 4. 操作步骤与未覆盖项

1. 调用 `tree()`，递归展示组织树并让用户选择 `type=4` 或叶节点。
2. 将所选合法栋舍 ID 与日期、`timeGroup`、`orgGroup` 交给 `list()`；SDK会在请求前重新检查页面和 Java 边界。
3. 用返回数组填充表格或图表；`[]`是合法的无数据结果，权限、网络或响应形状错误会抛出。
4. 本页全部是只读能力，不存在 `prepare → submit → cancel` 写链；取消筛选只是不调用 `list()`。
