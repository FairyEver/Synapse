## 时间字段是 `startStudyTime` / `endStudyTime`

**学习时间**，不是 `startTime`（讲师统计那一页才是）。参数顺序：

`order → orderField → staffName → lessonTitle → status → lessonType → gradeId → startStudyTime → endStudyTime → pageNo → pageSize → _t`

实测 URL 与推导逐字一致；结束端 +1 天（`buildStudyRecordTimeRange`）。

## 两级弹窗：4 个请求（2026-09-26 补）

行内的「查看详情」**不是**页面路由，是**弹窗套弹窗**：`list.vue` → `components/link-view.vue`
（"请选择环节"）→ `components/assignment.vue`（"作业详情"/"评分"）。两个弹窗各自带着自己的
`http.get` / `http.post`，所以上一轮"扫列表页的声明"整块漏掉了它们。

### 两条语义最要紧（都是后端实现，不是推断）

1. **`info` 的名字叫 get，实际会写。** `StudyAssignmentSubmitRecordServiceImpl:229-234`：
   当 `班课讲师工号 == 当前登录人工号` 或 `环节评分人 == 当前登录人工号` 时执行
   `updateById({ id, isRead: 1 })`。所以讲师/评分人"看一次"就把这条提交记录标成已读 ——
   SDK 按 `write: true` 登记，并写明**不能当只读轮询**。返回体里的 `isRead` 是**写入前**的值。
2. **学员没提交时不报错，返回一个几乎全空的对象**（只有 `submitStatus/submitType/scoreSubmitType`）。
   判断"有没有提交"要看 `assignmentId` 是否有值，不能看 HTTP 成功与否。

### `checkPermission` 的判据与评分链路

`StudyAssignmentServiceImpl#checkPermission` 放行三种身份：**作业创建人**（用户 ID 比）、
**班课讲师**（工号比）、**班课关联班级的助教**（工号比）；都不匹配返回 0。页面用它当提交按钮的
禁用条件（`data === 0` 即禁用）。评分链路是 `checkPermission`（只读预检）→
`update`（真写）：页面里没有"提交前向后端登记"的接口，也没有可撤销的预留，
所以这两个能力**没有** `prepare` / `cancel` 那一对。

`update` 的两个评分类字段二选一（页面按作业的 `scoreType` 只发其中一个）；
后端收到 `teacherFlower` 时会先按 `assignment_score` 字典换成 `teacherScore` 再落库
（`StudyAssignmentSubmitRecordServiceImpl:279-286`），所以两个都给等于 flower 覆盖分数 ——
SDK 在发请求前就拒绝，与页面行为一致。

## SDK AI 说明契约（2026-09-22）

本节由当前 SDK 描述结果整理；说明权威来源为 `src/catalog/contracts-business.ts`。调用 `catalog.describe(id)`（或 `id-llm`）可得到参数来源、返回字段/状态、数据消费与后续映射；`catalog.describePage(页面路径)` 用于选择页面功能。以下更新以本节为准；前文历史请求/实测记录仍保留其记录日期。

### `study-record-list`

按学员、班课、班级和学习时间查看个人学习记录明细；不返回课程资源文件。

- 执行：`sdk.studyRecord.list`；通过 `capabilities.invoke('study-record-list', args)` 调用时按 `params` 填参。性质：read。
- 参数：`staffName` 可选 (string)；`lessonTitle` 可选 (string)；`status` 可选 (string)；`lessonType` 可选 (string)；`gradeId` 可选 (string)；`startStudyTime` 可选 (string)；`endStudyTime` 可选 (string)；`pageNo` 可选 (number)；`pageSize` 可选 (number)。完整来源、枚举、条件必填与默认值由 SDK 同次返回。
- 返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。
- 字段：`list`、`total`、`list[].id`、`list[].staffName`、`list[].lessonTitle`、`list[].gradeName`、`list[].lessonType`、`list[].status`、`list[].startStudyTime`、`list[].endStudyTime`。嵌套字段、可空性及业务含义见同次返回的 `returns.fields`。
- 消费：展示学员—班课—班级—学习时间；按学习记录状态判断，不能用课程发布状态替代。
- 完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。
- 后续：optional → `base-dict-get`：按 lesson_study_status 查询当前字典，将返回 value 与业务行状态/类型值转成同一字符串后匹配 label；没有匹配时显示原码并说明标签未配置（dictType ← literal:"lesson_study_status"）
- 失败/不确定：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。
