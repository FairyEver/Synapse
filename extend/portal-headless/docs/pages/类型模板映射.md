# 类型模板映射

## 能力定义

- 页面路径：`/dashboard/technology/setting/type-template-mapping/list`
- 菜单权限：`/dashboard/technology/setting/type-template-mapping`
- 页面归属：门户科技设置页面（页面依赖 `platform` HTTP 实例；不发送 `module-type`）
- 主要能力：分页查询映射、加载项目类型/模板/已发布版本候选、新增、编辑、启用、停用。
- 页面没有删除、导入、导出、详情接口，也没有服务端回滚接口。

## 参数契约

### 查询

`technologyTypeTemplateMapping.list({ pageNo?, pageSize?, projectTypeId? })` 对应：

```json
{
  "pageNo": 1,
  "pageSize": 20,
  "projectTypeId": null
}
```

`projectTypeId` 是项目类型记录主键，不是类型编码。`pageSize` 最大为 500；空页不等于筛选范围没有记录，需结合 `total` 判断。

### 候选

`technologyTypeTemplateMapping.references()` 一次复刻页面挂载时的候选加载：

1. `GET /admin-api/technology/setting/project-type/simple-list`，参数 `{ status: null }`；
2. `GET /admin-api/technology/setting/template/page`，参数 `{ pageNo: 1, pageSize: 500 }`；
3. 对每个模板调用 `GET /admin-api/technology/setting/template/version/page`，参数 `{ templateId, versionStatus: "published", pageNo: 1, pageSize: 500 }`。

页面只把与项目类型 `projectDomain` 相同的模板族下的已发布版本放入“已发布模板版本”下拉框。SDK返回原始候选关联，调用方必须按相同规则过滤；不能把不同项目大类的版本提交到表单。

### 新增

先调用 `prepareCreate`，再把返回的完整 `draft` 传给 `create`。字段规则：

- `projectTypeId`、`templateVersionId`、`effectiveStartTime` 必填；
- `effectiveStartTime` / `effectiveEndTime` 使用 `YYYY-MM-DD HH:mm:ss`，结束时间可为 `null`；不做时区转换；
- `status` 只能是 `enabled` 或 `disabled`，省略时按页面默认 `enabled`；
- `remark` 省略时按页面默认空字符串；
- create 请求显式发送 `id: null`。

### 编辑

`prepareUpdate({ current, changes? })` 要求 `current` 来自最新列表行或上一次准备结果。页面编辑时项目类型下拉框禁用，因此 `changes` 不能包含 `projectTypeId`；可修改字段为：

`templateVersionId`、`effectiveStartTime`、`effectiveEndTime`、`status`、`remark`。

页面列表时间可能是带 `T` 的 ISO 字符串，准备编辑时只将 `T` 换为空格，不进行时区解析。`update` 提交完整草稿，不依赖不存在的详情接口。

### 启停

先调用 `prepareChangeStatus({ id, enabled })`，其中 `enabled` 是用户确认后的目标状态，不是 `displayStatus`。`changeStatus` 根据目标状态调用：

- `enabled: true` → `PUT /admin-api/technology/setting/type-template-mapping/enable?id=...`；
- `enabled: false` → `PUT /admin-api/technology/setting/type-template-mapping/disable?id=...`。

## 逐字段基准

列表行保留页面展示和后续操作需要的字段：

| 字段 | 含义 | 空值/限制 |
| --- | --- | --- |
| `id` | 映射记录主键 | 用于编辑、启停；不能用行号替代 |
| `projectTypeId` / `projectTypeName` | 项目类型主键及名称 | ID 与项目类型候选关联 |
| `templateVersionId` / `templateName` / `versionNo` | 模板版本主键、模板族名称、版本号 | 版本必须是已发布版本 |
| `effectiveStartTime` | 生效开始，含该时刻 | SDK不转换时区 |
| `effectiveEndTime` | 生效结束，不含该时刻 | `null` 表示没有结束时间 |
| `status` | 数据库启停状态 | `enabled` / `disabled` |
| `displayStatus` | 当前展示状态 | 只读展示值，不作为提交字段 |
| `remark` | 变更原因 | 页面空值回填为空字符串 |

## 操作步骤

### 新增

1. 读取 `references`。
2. 选定项目类型，根据其 `projectDomain` 过滤出已发布模板版本。
3. `prepareCreate`，确认完整草稿。
4. 用户明确确认后 `create`。
5. 重新 `list`，按项目类型和模板版本定位并逐字段回查，不能只依据 Promise 正常完成报告已落库。

### 编辑

1. 取最新列表行作为 `current`。
2. 仅把用户明确修改的允许字段放进 `changes`。
3. `prepareUpdate` 后确认 `draft.id` 未改变、`projectTypeId` 未改变。
4. 用户明确确认后 `update`。
5. 按同一 `id` 回查；超时先回查，不盲目重复提交。

### 启停

1. 从用户选中的列表行保留 `id`。
2. 根据确认框确定目标 `enabled`。
3. `prepareChangeStatus` → `changeStatus`。
4. 重新加载列表，按同一 `id` 核对 `status`；`displayStatus` 还受当前时间影响。
