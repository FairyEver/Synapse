# 工资导入

页面路径：`/dashboard/salary/adjust-import/list`。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询工资列表 | `salary-adjust-import-list` / `salaryAdjustImport.list` | `GET /salary/salarysheet/page` |
| 查询角色组织树 | `salary-adjust-import-organization-tree` / `.organizationTree` | `GET /org/organization/getRoleOrganizationTree` |
| 准备导入 | `salary-adjust-import-prepare-import` / `.prepareImport` | 不发请求；按Portal上传规则生成文件预览 |
| 导入工资Excel | `salary-adjust-import-import` / `.importExcel` | `POST /salary/salarysheet/importExcel`，multipart字段`file` |
| 模板下载 | `salary-adjust-import-download-template` / `.downloadTemplate` | `GET /salary/salarysheet/downloadTemplate` |
| 准备批量删除 | `salary-adjust-import-prepare-remove` / `.prepareRemove` | 不发请求；校验当前列表行ID数组 |
| 批量删除 | `salary-adjust-import-remove` / `.remove` | `DELETE /salary/salarysheet`，请求体为ID数组 |

页面菜单权限为`/dashboard/salary/adjust-import`，属于薪酬管理`module-type=14`，请求使用Portal的`platform` HTTP实例。SDK方法内部使用不带`/admin-api`的路径，由platform实例补齐前缀。

## 列表、权限与返回字段

Portal页面实际只提供工资月份和组织筛选，默认请求参数为：

```json
{
  "order": "",
  "orderField": "",
  "salaryDate": "",
  "orgId": "",
  "pageNo": 1,
  "pageSize": 20
}
```

选择`2026-09`时，Portal先用dayjs取月初并发送`salaryDate=2026-09-01`。`orgId`必须来自角色组织树；Java服务在`@DataScope`角色范围内继续按选中组织的后代组织筛选，SDK不能用任意组织ID扩大可见范围。

列表行保留后端工资DTO字段：`id`、`name`、`salaryDate`、`staffCode`、`fullPath`、基本工资至实发工资的全部金额字段、`profitEvaluationSalary`以及审计字段`isDel`、`creator`、`createTime`、`updater`、`updateTime`、`updaterName`、`tenantId`。Portal当前列展示姓名、工资月份、员工号、部门路径、各工资/扣款金额、修改人和最后修改时间；SDK保留后端返回的隐藏字段但不自行计算或换算金额。BigDecimal金额保留数字或十进制字符串原值，空值为`null`。

`salaryDate`按Java DTO约定为`YYYY-MM`。分页`pageSize`只允许Portal选项`10、20、50、100`。空列表和`total=0`表示当前筛选无记录，不表示权限失败。

## 表单与写操作规则

### Excel导入

Portal上传控件的`accept`为`.xlsx`，运行时还要求文件MIME精确等于：

`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

SDK的`prepareImport`检查文件名扩展名、标准Base64、非空字节和固定MIME；省略`contentType`时按Portal唯一接受类型补齐。确认后`importExcel`严格发送：

```text
POST /salary/salarysheet/importExcel
Content-Type: multipart/form-data
file=<xlsx Blob，使用原文件名>
```

不把Excel内容解析后改写成JSON，也不发送额外的工资月份、组织或导入数量参数。Java接口返回`CommonResult.data=null`，所以SDK写能力返回空回执；服务端按`staffCode + salaryDate`找到已有工资记录时更新，否则插入。导入成功或响应不确定后，必须用Excel中的工资月份和员工号回查列表核对实际记录和金额。

### 模板下载

Portal打开模板下载地址时传入`fileName=考核结果导入模板`，但Java后端会忽略该参数并固定读取`工资导入模板.xlsx`。SDK仍按页面请求发送该参数，并从二进制响应解析真实文件名、MIME、Base64和字节数。

### 批量删除

Portal的`deleteIsBatch=true`，选择行时取的是列表行`id`；SDK的`prepareRemove`只接受非空且不重复的`ids`数组。确认后严格发送：

```json
DELETE /salary/salarysheet
[
  101,
  "9007199254740993"
]
```

不能用员工号`staffCode`、姓名或当前筛选条件代替记录主键。Java返回空业务回执，完成或响应不确定后必须回查列表确认目标记录终态。

当前页面没有可达的单条查询、保存、编辑、导出或个人工资统计入口；同一Java Controller中的这些端点不注册为本页SDK能力。

## 逐页操作步骤与证据边界

1. 先调用`organizationTree()`取得当前会话可见的角色组织树；用户选定节点后把节点`id`传给`list({ orgId })`。
2. 调用`list()`并用`list[].id`作为删除候选；用`total`翻页，金额按后端原值展示，不自行做元/分换算。
3. 导入时先调用`prepareImport({ fileName, base64, contentType })`；用户确认后把同一份文件参数交给`importExcel()`，取消只丢弃预览。
4. 导入成功或超时后，按Excel中的工资月份和员工号重新`list()`，核对新增或更新记录；不能用空回执推断导入数量。
5. 删除时先调用`prepareRemove({ ids })`向用户展示目标记录并确认；确认后调用`remove({ ids })`，再按原筛选条件回查。
