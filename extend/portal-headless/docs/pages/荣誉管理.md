风险防控域的荣誉列表、荣誉表单和共享设置。Portal、Java 和 SDK 按本页逐项核对，导出虽然存在后端端点，但 Portal 列表按钮已注释，不是当前用户可达动作。

## Portal 页面行为

列表通过 `GET /admin-api/hr/honor/page` 查询，初始筛选是 `name`、`organizationId`、`issuingAuthority`、`manageOrganizationId` 四个 `null` 值，并由列表模块补充 `order`、`orderField`、`pageNo=1`、`pageSize=20`。可达操作是新建、编辑、共享设置和删除。源码中的导出按钮及 `actionExport` 已被注释，SDK 不注册导出能力。

表单详情通过 `GET /admin-api/hr/honor/get?id=...` 读取。Portal 把 `pdfUrl`、`pdfName`、`remindUser` 的逗号字符串还原为数组，把日期规整为 `YYYY-MM-DD`；提交时将 PDF URL/文件名和提醒人员数组分别逗号连接，调用新建 `POST /admin-api/hr/honor/create` 或编辑 `PUT /admin-api/hr/honor/update`。列表删除调用 `DELETE /admin-api/hr/honor/delete?id=...`。

共享弹窗使用 `GET /admin-api/system/share-user/getShare` 和 `POST /admin-api/system/share-user/createShare`，荣誉资源的 `type` 固定为 `10`；读取时保留 `managerType` 展示，保存时四类成员只发送 `{ id }`。

## 表单与权限规则

- `organizationId`、`isForever`、`name`、`awardedDate`、`issuingAuthority`、`reportOrganizationId`、`manageOrganizationId`、`depositAddress`、`pdfUrl` 必填。
- `isForever=0` 时 `endTime`、`remindTime`、`remindUser` 必填；提醒月数是正整数且最多5位，即 `1..99999`。`isForever=1` 时这些到期字段在 Portal 中隐藏。
- 荣誉名称最多50字符；颁发机构和存放地点的文本控件最多1000字符；日期按 `YYYY-MM-DD` 传输。
- 附件控件只接受 `application/pdf`，最多保留5个；`pdfUrl` 与 `pdfName` 必须按下标成对，空附件按 Portal 提交转换发送 `null`。
- 日期选择器禁止选择今天之前的日期。SDK 不把该 UI 选取限制扩展为对已有历史记录的强制拒绝，编辑时保留详情中的原始日期。
- 列表、详情、写入和共享受当前会话、租户、页面权限和后端数据范围约束；SDK 不扩大权限，空列表也不是权限证明。组织、部门和提醒人员 ID 必须来自已核实的 Portal 候选，附件 URL 必须来自上传结果。

## 后端与 SDK 对齐

Java `HonorController` 提供荣誉分页、详情、新建、更新、删除和未达页面的导出/App 端点；`HonorSaveReqVO` 使用 Long ID、LocalDate 日期、Integer 提醒月数和逗号字符串字段，`HonorDO` 继承 `TenantBaseDO`。`HonorServiceImpl` 负责 CRUD 和分页后的组织名称补充，成功写操作返回 `true` 或新建 Long ID。共享枚举为 `HONOR(10, "荣誉")`。

实现文件：`src/capabilities/honor.ts`；AI 说明：`src/catalog/contracts-honor.ts`。SDK 将 Portal 当前可达的列表、详情、准备、保存、删除和共享动作接入同一个 `honor` 门面；写能力通过 `prepare → submit → 回查`，取消只丢弃本地草稿，不虚构服务端取消接口。
