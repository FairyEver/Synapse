# 会议室列表（`/dashboard/meeting-room/list`）

2026-09-25 根据 Portal 前端、Java controller/DTO/服务权限与本地定向测试完成动作审计；本次未启动浏览器或服务器。

## 能力定义

- `src/capabilities/meeting-room.ts`：列表、详情，以及会议室新建、编辑、删除、状态切换的 prepare/submit/cancel 动作。
- 前端：`app/portal/views/dashboard/hr/meeting-room/list.vue`。
- 表单：`app/portal/views/dashboard/hr/meeting-room/components/ModalForm.vue`。
- 页面权限：`/dashboard/meeting-room`；实例：`platform`；当前规则不发送 `module-type`。
- 请求：`GET /admin-api/hr/meeting-room/page`。

## 参数契约

目录参数为 `name`、`authorizedOrgId`、`pageNo`、`pageSize`、`order`、`orderField`；授权组织是树形长选项。
请求保留列表默认空字段 `order`、`orderField`、`name`。表单只提交 `name`、`authorizedOrgId`；
`name` 必填、去除首尾空白后不可为空、最多 50 个字符，提交时保留用户原始输入；
`authorizedOrgId` 必填。编辑额外提交 `id`。

## Portal 实际动作

以下路径省略 Portal 的 `/admin-api` 前缀；请求方法、query、body 与页面源码一致。

| 能力 | Portal 请求 | 请求数据 | 成功返回/门槛 |
| --- | --- | --- | --- |
| `meeting-room-get` | `GET /hr/meeting-room/get` | query `id`；无 body | 会议室详情 |
| `meeting-room-create` | `POST /hr/meeting-room/create` | body `{ name, authorizedOrgId }` | 返回新建会议室 `id` |
| `meeting-room-update` | `PUT /hr/meeting-room/update` | body `{ name, authorizedOrgId, id }` | body 为 `true` |
| `meeting-room-delete` | `DELETE /hr/meeting-room/delete/{id}` | 无 query、无 body | body 为 `true`；仅当前 `status=0`（禁用）可删除 |
| `meeting-room-update-status` | `PUT /hr/meeting-room/update-status/{id}` | query `status` 为 `0` 或 `1`；body 为 `null` | body 为 `true`；目标状态由当前状态 `1↔0` 切换 |

`meeting-room-list`、`meeting-room-get` 及上述写动作均已登记到能力目录；每个写动作都有对应的
`prepare-*`、`submit`、`cancel-*` 三段描述。`prepare` 只校验并生成草稿，`cancel` 不发请求。

写动作均按 `prepare → submit → cancel` 建模：prepare 只校验和生成草稿，submit 才发请求，
cancel 为本地取消且不发请求。删除的状态门槛在 prepare 阶段拒绝；状态切换只接受 `0/1`。

## 操作步骤与边界

进入会议室列表，按会议室名称或授权组织筛选，点击查询，再按需翻页；可新建或编辑会议室，
可将启用/禁用状态切换，删除前必须确认列表行当前为禁用状态。
预约流程及占用查询属于另一条能力链，见 [会议室预定](./会议室预定.md)。
