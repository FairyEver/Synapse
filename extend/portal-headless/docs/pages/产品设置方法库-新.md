# 产品设置方法库-新

页面路径：`/dashboard/product/setting/method-lib/list`。

菜单归属是 `系统设置 → 生产设置 → 养殖预案 → 方法库-新`。这里的“生产设置”是 Portal 保留的系统设置子菜单，不是范围外的独立生产业务菜单。本页与旧“方法库”能力严格区分：旧页面位于 `dashboard/product/setting/hatch-manage` 下的 `method-lib/list`，使用 `product` 实例和 `/programNew/methodLib` 接口；本页使用 `platform` 实例和 `/flockSimu/rearingPlan/method` 接口。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询方法库 | `product-setting-method-lib-list` / `productSettingMethodLib.list` | `GET /flockSimu/rearingPlan/method/page` |
| 准备新建 | `product-setting-method-lib-prepare-create` / `productSettingMethodLib.prepareCreate` | 本地表单和规则校验，不发请求 |
| 新建方法 | `product-setting-method-lib-create` / `productSettingMethodLib.create` | `POST /flockSimu/rearingPlan/method/create` |
| 准备编辑 | `product-setting-method-lib-prepare-update` / `productSettingMethodLib.prepareUpdate` | 本地表单和规则校验，不发请求 |
| 编辑方法 | `product-setting-method-lib-update` / `productSettingMethodLib.update` | `PUT /flockSimu/rearingPlan/method/update` |
| 查询详情 | `product-setting-method-lib-get` / `productSettingMethodLib.get` | `GET /flockSimu/rearingPlan/method/get?id=...` |
| 准备删除 | `product-setting-method-lib-prepare-remove` / `productSettingMethodLib.prepareRemove` | 本地确认前准备，不发请求 |
| 删除方法 | `product-setting-method-lib-remove` / `productSettingMethodLib.remove` | `DELETE /flockSimu/rearingPlan/method/delete?id=...` |
| 下载导入模板 | `product-setting-method-lib-download-template` / `productSettingMethodLib.downloadTemplate` | `GET /flockSimu/rearingPlan/method/import-template` |
| 导出方法库 | `product-setting-method-lib-export` / `productSettingMethodLib.exportExcel` | `GET /flockSimu/rearingPlan/method/export-excel` |
| 导入方法库 | `product-setting-method-lib-import` / `productSettingMethodLib.importExcel` | multipart `POST /flockSimu/rearingPlan/method/import-excel` |

页面共用权限 `/dashboard/frame/breeding-plan-new/method-lib`。请求使用 Portal `platform` HTTP 实例：路径按 `platform.js` 补 `/admin-api`，使用 `generateHttpHeaders`；本页不发送 `module-type`，也不额外补 `devicetype`。SDK不绕过页面或服务端权限。

## 参数契约与提交规则

列表筛选字段是 `generation`、`variety`、`strain`、`methodName`、`methodType`。分页默认 `pageNo=1`、`pageSize=10`，页面支持10、20、50。导出复用相同筛选字段，但不发送分页参数。

方法表单字段规则与 Portal 一致：`methodName` 必填且最多100个字符，`methodDescription` 必填且最多2000个字符，`methodCategory` 必填且最多32个字符，并且必须是当前租户 `rearing_plan_category` 字典 value；`methodType=1` 是普通方法，`methodType=2` 是程序方法；`keyPoint` 是布尔值。

普通方法必须至少有一条规则。规则的 `generation`、`variety`、`strain` 是字典 value；没有代次时不能指定品种或品系；`startDayAge` 是1至500的整数，`intervalDays` 是1至100的整数；相同代次/品种/品系和开始日龄不能重复。程序方法无论表单中是否残留规则，提交时都固定为 `rules: []`。

`prepareCreate()` / `prepareUpdate()` 只产生本地草稿，不改变服务端；确认后把同一份 `draft` 交给 `create()` / `update()`。删除先 `prepareRemove({ id })`，用户确认后再调用 `remove({ id })`。写请求成功或响应不确定后重新 `list()` 或 `get()` 回查，不把 `true`、新建ID或导入条数当作业务终态。

模板下载返回 `方法库导入模板.xlsx` 的文件描述。导入文件用 `{ fileName, base64, contentType? }` 描述，Portal控件只接受 `.xlsx`，SDK以 multipart 字段 `file` 上传；Java最多读取1000行并按方法名称分组，返回成功导入的方法数量。导出默认文件名是 `方法库.xls`，服务端最多导出1000个方法/规则行。

## 逐字段基准

| 字段 | 含义 |
| --- | --- |
| `list` | 当前筛选和分页下的方法记录。 |
| `total` | 筛选后的方法总数，不是当前页长度。 |
| `list[].id` | 方法ID；编辑、详情和删除目标。 |
| `list[].methodName` / `methodDescription` | 方法名称和描述。 |
| `list[].methodCategory` | `rearing_plan_category` 字典 value，不是展示名称。 |
| `list[].methodType` | `1=普通方法`，`2=程序方法`。 |
| `list[].keyPoint` | 是否为要点。 |
| `list[].ruleCount` / `list[].rules` | 规则数量和规则数组；程序方法规则为空。 |
| `list[].rules[].generation` / `variety` / `strain` | 规则适用范围的字典 value；空字符串表示全部范围。 |
| `list[].rules[].startDayAge` / `intervalDays` | 开始日龄和间隔天数。 |
| `list[].creatorName` / `updateTime` | 创建人和更新时间；服务端缺失时SDK返回空字符串。 |
| `prepare*().draft` | 已通过Portal规则、尚未改变服务端的草稿。 |
| `create()` 返回值 | 服务端新建方法ID；仍需 `list()` / `get()` 回查。 |
| `importExcel()` 返回值 | Java按方法名称分组后成功导入的方法数；仍需 `list()` 回查。 |

## 操作步骤、权限和证据边界

1. 用当前用户会话和租户上下文调用 `list()`，按返回的 `list[].id` 进入编辑、详情或删除流程。
2. 新建或编辑先调用 `prepareCreate()` / `prepareUpdate()`，把草稿交给用户确认；取消只丢弃本地草稿。
3. 用户确认后调用 `create()` / `update()`；删除则在 `prepareRemove()` 后取得明确确认，再调用 `remove()`。
4. 导入先取得 `.xlsx` 文件，导入成功或响应不确定后重新调用 `list()`；编辑、删除和创建也必须按目标ID或方法名称回查。
