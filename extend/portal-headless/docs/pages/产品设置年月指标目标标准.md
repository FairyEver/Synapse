# 产品设置年月指标目标标准

页面路径：`/dashboard/product/setting/standard-manage/hatch-annual-monthly/list`。

## 页面能力定义

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询列表 | `product-setting-hatch-annual-monthly-list` / `productSettingHatchAnnualMonthly.list` | `GET /base/hatchAnnualMonthly/page` |
| 准备新建 | `product-setting-hatch-annual-monthly-prepare-create` / `productSettingHatchAnnualMonthly.prepareCreate` | 不发请求 |
| 新建 | `product-setting-hatch-annual-monthly-create` / `productSettingHatchAnnualMonthly.create` | `POST /base/hatchAnnualMonthly/save` |
| 准备编辑 | `product-setting-hatch-annual-monthly-prepare-update` / `productSettingHatchAnnualMonthly.prepareUpdate` | 不发请求 |
| 编辑 | `product-setting-hatch-annual-monthly-update` / `productSettingHatchAnnualMonthly.update` | `POST /base/hatchAnnualMonthly/save` |
| 准备删除 | `product-setting-hatch-annual-monthly-prepare-remove` / `productSettingHatchAnnualMonthly.prepareRemove` | 不发请求 |
| 删除 | `product-setting-hatch-annual-monthly-remove` / `productSettingHatchAnnualMonthly.remove` | `DELETE /base/hatchAnnualMonthly/{id}` |

页面属于 `门户 → 系统设置 → 生产设置 → 标准库管理`，不是独立顶层生产系统。请求使用 `product` HTTP 实例，固定追加 `devicetype=PC`，本页不发送 `module-type`。菜单和路由权限为 `/dashboard/frame/standard-library/hatch-annual-monthly`。

Portal 页面声明了 `base:hatch-annual-monthly:query` 和 `base:hatch-annual-monthly:submit`；查询没有单独调用 query 权限，新增、编辑和删除由 `permissionCheck(permissions.submit)` 控制。SDK保留该权限事实，服务端仍执行当前会话的实际权限校验。

## 参数契约与表单提交规则

列表是 `useListPageModule({ styleV2: true, customLoad, getDataListIsPage: true })`，默认请求参数为：

```json
{
  "order": "",
  "orderField": "",
  "hall": "",
  "year": "",
  "month": 1,
  "pageNo": 1,
  "pageSize": 20
}
```

孵化厅是查询表单必填项；月份初始值为 `1`，清空月份后不按月份筛选。分页支持 `10/20/50/100`。列表的孵化厅名称优先使用场区选择组件加载后的ID→名称映射，不能只依赖后端 `hallName`。

新建和编辑弹窗的年度、月度、孵化厅、健母雏率、蛋雏比和年月类型均必填。年度范围为 `1970` 至 `10000000`，月度范围为 `1` 至 `12`，健母雏率和蛋雏比范围为 `-10000000` 至 `10000000`。年月类型实际按 Portal 单选值提交：`3=年度、1=月度`。

健母雏率按页面百分数输入，提交时严格除以 `100`；蛋雏比不做百分比换算：

```json
{
  "year": 2026,
  "month": 4,
  "hall": "hall-1",
  "healthyFemaleRate": 0.82,
  "eggChickRatio": 1.25,
  "type": 3
}
```

Java 分页接口会把数据库中的健母雏率比例小数乘以 `100` 后返回，例如数据库值 `0.82` 返回 `82`。Portal 编辑弹窗在回显时又执行 `列表值 * 100`，提交时再执行 `输入值 / 100`；这是页面当前源码的二次换算路径。SDK 的 `prepareUpdate()` 接收的是 Portal 编辑弹窗的 formState 值，并保留 `...props.raw` 中的扩展字段，再覆盖编辑字段和ID。用户取消新建、编辑或删除确认时只丢弃本地草稿，不发送写请求。

Java 实体注释将类型写成 `1=年度、2=月度`，但 Portal 实际发送的是 `3=年度、1=月度`；SDK以页面实际请求为准，并在契约中保留该差异。

## 逐字段基准

| 字段 | 含义 |
| --- | --- |
| `id` | 年月指标目标标准记录ID；编辑和删除目标。 |
| `type` | 年月类型；Portal实际为 `3` 年度、`1` 月度。 |
| `year` | 年度。 |
| `month` | 月份。 |
| `hall` | 孵化厅ID；保存和筛选使用。 |
| `hallName` | Java实体中的孵化厅名称扩展字段；页面实际优先使用孵化厅选项映射。Java服务当前按 `hallName` 查询组织名称，不能把该字段当作稳定显示依据。 |
| `healthyFemaleRate` | 健母雏率；列表响应是服务端乘 `100` 后的数值，保存草稿是页面输入除以 `100` 后的比例小数。 |
| `eggChickRatio` | 蛋雏比；服务端原始数值。 |
| `total` | 当前筛选条件下的记录总数。 |

SDK保留后端返回的页面无关扩展字段，但不把它们当作页面业务字段；网络、权限、Java业务错误或响应结构错误会抛出，不降级为空列表。

## 逐页操作步骤、权限与证据边界

1. 用 `list()` 读取最新列表，确认目标行的 `id`、孵化厅、年度、月份和指标值。
2. 新建先调用 `prepareCreate()`；编辑先按 Portal 回显规则把列表健母雏率转换为弹窗值，再调用 `prepareUpdate()`，确认 `draft` 保留当前行ID和raw字段。
3. 用户明确确认后，把同一 `draft` 原样交给 `create()` 或 `update()`；成功或响应不确定后重新调用 `list()` 回查。
4. 删除先调用 `prepareRemove({ id })`，用户确认后调用 `remove({ id })`；成功或响应不确定后重新查询，确认目标ID不再出现。
