本节由当前 SDK 描述结果整理；说明权威来源为 `src/catalog/contracts-business.ts`。调用 `catalog.describe(id)`（或 `id-llm`）可得到参数来源、返回字段/状态、数据消费与后续映射；`catalog.describePage(页面路径)` 用于选择页面功能。以下更新以本节为准；前文历史请求/实测记录仍保留其记录日期。

### `study-statistics-teacher-list`

按讲师汇总授课数量、班课数量及评价。

- 执行：`sdk.studyStatistics.listTeachers`；通过 `capabilities.invoke('study-statistics-teacher-list', args)` 调用时按 `params` 填参。性质：read。
- 参数：`staffCode` 可选 (string)；`name` 可选 (string)；`startTime` 可选 (string)；`endTime` 可选 (string)；`pageNo` 可选 (number)；`pageSize` 可选 (number)。完整来源、枚举、条件必填与默认值由 SDK 同次返回。
- 返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。
- 字段：`list`、`total`、`list[].staffCode`、`list[].name`、`list[].courseNum`、`list[].lessonNum`、`list[].appraiseNum`、`list[].appraiseScore`。嵌套字段、可空性及业务含义见同次返回的 `returns.fields`。
- 消费：展示课程数、班课数、评价人数及平均分；平均分不可在缺少权重时跨讲师直接平均。
- 完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。
- 失败/不确定：权限或会话错误要交由用户恢复权限/登录后再读；不要通过换租户、换页面上下文绕过。业务校验失败按原错误修正参数，网络失败的只读查询可重试。

## 本轮补齐（2026-09-26）：三个下钻子路由（只读）

列表页每列点进去都是一个**隐藏子路由**（`course/[staffCode]/item-list.vue` 这类，没有菜单项），
三条请求原来整块漏了。三条都打同一个页面上下文（`/dashboard/base/...` → module-type 12）。

| 能力 id | 请求 | 入口 |
| --- | --- | --- |
| `study-statistics-teacher-course-list` | `GET /study/statistics/teacherCourseList` | 「讲授课程数量」→ `course/[staffCode]/item-list` |
| `study-statistics-teacher-lesson-list` | `GET /study/statistics/teacherLessonList` | 「讲师班课数量」→ `lesson/[staffCode]/item-list` |
| `study-statistics-teacher-score-list` | `GET /study/statistics/teacherScoreList` | 「整体评价」→ `score/[staffCode]/item-list` |

**参数契约（键序即 qs 顺序；`staffCode` 都来自路由参数 `[staffCode]`）**

- 课程明细：`order → orderField → staffCode → type → startTime → pageNo → pageSize`。
  ⚠️ `startTime` 是**单选日期**（页面是 `a-date-picker` + `show-time`），**不是区间** ——
  没有本域其它页那个「结束日 +1 天」。
- 班课明细：`order → orderField → staffCode → title → appraiseNumMin → appraiseNumMax → avgScoreMin → avgScoreMax → pageNo → pageSize`（页面没有时间筛选）。
- 得分明细：`order → orderField → staffCode → allScoreMin → allScoreMax → startTimeFrom → startTimeEnd → pageNo → pageSize`。
  ⚠️ 第二个时间字段名是 **`startTimeEnd`**（不是 `endTime`），且由 `convertFetchForm` 追加、结束日是**开区间 +1 天**
  （与讲师统计列表同一套，用 `buildStudyStatisticsTeacherScoreTimeRange` 生成）。

**逐字段**

- 课程明细行：`name`（讲师姓名）/`courseName`/`type`/`gradeName`/`startTime`（+ 后端透传的 `resourceId`）。
  `courseName` 是后端按 `type` 去远端资源补齐的：课程被删或远端取不到时该列为空，**不能用它反推课程不存在**。
- 班课明细行：`name`/`title`/`lessonId`/`appraiseNum`/`avgScore`/`oneAvgScore`~`fiveAvgScore`。
  ⚠️ **1~5 题的题号含义由「评价设置」决定**：先读 `study-appraise-setting-list` 的题目顺序再解释，
  题目可能少于 5 条，缺失的题号不要编造含义。
- 得分明细行：`createTime`/`userName`/`appraiseNum`/`sumScore`/`oneScore`~`fiveScore`。
  一行 = 一次评分（评分人 + 时间），不是一次班课。

**操作步骤**：`study-statistics-teacher-list` 找到讲师 → 按要看的维度选一条下钻。
都是只读，没有 prepare/submit。

**推断与缺口**：三条**没有浏览器基准**；参数名与键序**从固定检出源码推出**；
尚未在真实测试环境执行；`course_type` 字典取值未核实。
