# 专利管理（`/dashboard/certificate/patent/list`）

风险防控域的专利分页列表、完整表单和共享设置。Portal、Java 与 SDK 按本页逐项核对；Java 中仅供 APP 的知识产权端点不属于本页面能力。

| 项 | 值 |
| --- | --- |
| 菜单路径 | `/dashboard/certificate/patent/list` |
| 菜单名 | 专利管理 |
| 菜单/路由权限 | `/dashboard/certificate/patent` |
| 列表文件 | `app/portal/views/dashboard/hr/certificate/patent/list.vue` |
| 表单文件 | `app/portal/views/dashboard/hr/certificate/patent/[mode]/[id].vue` |

| 页面形态 | 分页列表 + 新建/编辑表单 + 共享设置 |
| SDK 能力 | `patent-*` |

## Portal 页面行为

列表通过 `GET /admin-api/hr/patent/page` 查询，当前页面可见筛选只有 `name`、`patentNumber`、`inventor` 三个空字符串。请求还发送 `order=''`、`orderField=''`、`status=''`、`pageNo=1`、`pageSize=20`；源码中的 status 控件已注释，SDK 不把它暴露为用户筛选参数。页面可达操作是新建、编辑、共享和删除，没有可达导出按钮。

表单详情通过 `GET /admin-api/hr/patent/get?id=...` 读取。新建调用 `POST /admin-api/hr/patent/create`，编辑调用 `PUT /admin-api/hr/patent/update`，删除调用 `DELETE /admin-api/hr/patent/delete?id=...`。提交前日期字段保持 `YYYY-MM-DD`，`remindUser`、`pdfUrl`、`pdfName` 数组分别逗号连接；空附件 URL/名称按 Portal 规则提交 `null`。PDF 上传只接受 `application/pdf`，页面最多保留5项。

共享弹窗使用 `/admin-api/system/share-user/getShare` 和 `/admin-api/system/share-user/createShare`，专利资源的 `type` 固定为 `6`；读取保留 `name/managerType` 展示，保存时四类成员只发送 `{ id }`。

## 表单、权限和数据规则

- `certificateNumber`、`name`、`inventor`、`patentNumber`、`organizationId`、`endTime`、`remindTime`、`remindUser`、`pdfUrl` 必填；`applyDate`、`patentee`、`address`、`announcementDate`、`announcementNumber` 可选。
- 文本上限与 Portal 一致：证书号/专利号/公告号最多20字符；名称/发明人/专利权人/地址最多50字符。
- `endTime` 为有效的 `YYYY-MM-DD`；`remindTime` 是1至99999的整数月数；`remindUser` 是人员 ID 数组，不能用姓名或员工工号替代。
- 附件只允许 PDF，最多5项；`pdfUrl` 与 `pdfName` 必须按下标成对，提交时分别逗号连接。`status` 是后端按到期日期和提醒月数计算的展示状态：1=已过期、2=即将到期、3=未过期，不是保存参数。
- 列表、详情、写入和共享受当前会话、租户、页面权限及后端数据范围约束。Java `HrPatentDO` 继承 `TenantBaseDO`；SDK 不扩大权限，也不把空列表或 `true` 回执单独当作业务完成证据。

## 后端与 SDK 对齐

Java `HrPatentController` 提供本页面所需的分页、详情、创建、更新和删除；`HrPatentSaveReqVO` 使用 Long ID、LocalDate 日期、Integer 提醒月数和逗号字符串字段。`HrPatentServiceImpl` 补充提醒人员与组织名称，并按到期时间计算 status；共享枚举为 `PATENT(6, "专利")`。Controller 中的 APP 专用知识产权接口和未被页面调用的 `export-excel` 不注册为本页面能力。

实现文件：`src/capabilities/patent.ts`；AI 说明：`src/catalog/contracts-patent.ts`。SDK 将页面可达动作接入 `patent` 门面；写能力按 `prepare → submit → 回查`，用户取消只丢弃本地草稿，不虚构服务端取消接口。
