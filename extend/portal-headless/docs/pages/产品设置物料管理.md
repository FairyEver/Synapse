# 产品设置物料管理

页面路径：`/dashboard/product/setting/base-setting/material/list`。

## 页面能力

| 页面动作 | SDK 能力 / 方法 | Portal 请求 |
| --- | --- | --- |
| 查询列表 | `product-setting-material-list` / `productSettingMaterial.list` | `GET /base/material/page/external` |
| 本地准备新建/编辑 | `product-setting-material-prepare-save` / `productSettingMaterial.prepareSave` | 不发请求 |
| 保存 | `product-setting-material-save` / `productSettingMaterial.save` | `POST /base/material/userMaterialSave` |
| 批量删除 | `product-setting-material-remove-batch` / `productSettingMaterial.removeBatch` | `GET /base/material/userMaterialDelete` |
| 启用 | `product-setting-material-enable` / `productSettingMaterial.enable` | `GET /base/material/enable` |
| 停用 | `product-setting-material-deactivate` / `productSettingMaterial.deactivate` | `GET /base/material/deactivate` |

菜单权限为 `/dashboard/frame/base-setting/material`，请求使用 `product` HTTP 实例，不发送 `module-type`。页面内的查询按钮权限是 `management:material:query`，新建、编辑、批量删除和启停按钮权限是 `management:material:submit`，`management:material:back` 在当前列表源码中声明但没有单独动作。SDK不会绕过这些服务端权限。

## 参数契约与提交规则

列表是 `useListPageModule` 的 `customLoad`，Portal 默认把以下完整参数交给后端：

```json
{
  "order": "",
  "orderField": "",
  "materialDescription": "",
  "type": "",
  "pageNo": 1,
  "pageSize": 20
}
```

`materialDescription` 是物料名称筛选；`type` 是物料类型字典值，不是 `typeStr` 展示文本。分页大小遵循页面支持的 `10/20/50/100`。后端返回可能位于 `page` 包络中，Portal `customLoad` 消费其中的 `list`、`records` 或 `rows`，以及 `total` 或 `count`；SDK统一返回 `{ list, total }`。

弹窗新建和编辑使用同一份表单。`prepareSave` 和 `save` 的草稿只包含下面六个字段，字段顺序和空值形状按 Portal `modalEmit('submit', ...)` 对齐：

```json
{
  "id": "",
  "materialDescription": "复合维生素",
  "supplier": "供应商A",
  "type": "2",
  "image": "",
  "measureUnit": "50ml/瓶"
}
```

- `materialDescription`、`type`、`supplier`、`measureUnit` 必填；空白必填文本在 SDK 发请求前拒绝。
- `measureUnit` 最多 10 个字符；其它三个必填字段不由页面额外截断。
- `type` 是选择器表单值，SDK以字符串提交；数值输入会转换为字符串。不要提交 `typeStr`。
- `image` 可为空，创建时也保留 `image: ''`，不能因空值把这个键删掉。
- 新建的 `id` 固定为空字符串；编辑保留当前列表行的 ID。

批量删除严格按页面 `ids.join(',')` 发送：

```text
GET /base/material/userMaterialDelete?materialIdList=物料ID1,物料ID2
```

启用和停用都只发送当前列表行的 `materialId`。Java 服务会按当前会话租户处理删除和状态变更；停用前会检查物料是否已经被使用，失败时必须把后端错误报告给调用方，不能自动删除或假报成功。

## 逐字段基准

列表行保留 Portal 表格实际使用的字段：

| 字段 | 含义 |
| --- | --- |
| `id` | Java `Material` 的记录 ID；写操作目标。 |
| `materialDescription` | 物料名称。 |
| `type` | 物料类型字典值。 |
| `typeStr` | 物料类型展示文本。 |
| `supplier` | 供应商名称。 |
| `image` | 图片地址；空值时页面隐藏图片。 |
| `measureUnit` | 规格文本。 |
| `status` | `1` 为启用，其他值页面显示停用。 |
| `total` | 当前筛选条件下的总记录数。 |

Portal `list.vue` 使用 `id` 作为表格选择和操作依据；不会先调用详情接口，编辑直接把列表行传给弹窗。Java `userMaterialSave` 无 ID 时新建、有 ID 时更新，并按“物料名称 + 供应商 + 类型”执行重复检查。删除服务对系统物料可能只移除当前租户关系，不应把 `true` 解读成物理删除。

## 操作步骤、权限和证据边界

1. 用 `list()` 读取最新列表，确认筛选条件和目标行 ID。
2. 新建或编辑先调用 `prepareSave()`；用户取消时只丢弃 `draft`。
3. 用户明确确认后，把同一个 `draft` 交给 `save()`；成功或超时都必须用 `list()`按 ID 和关键字段回查。
4. 批量删除先确认用户勾选的非空 ID 数组，再调用 `removeBatch()`，随后回查这些 ID 是否仍在当前租户列表中。
5. 启用/停用只对最新列表行调用对应方法，随后回查 `status`。停用收到“已使用”等业务错误时不得重试成删除。
