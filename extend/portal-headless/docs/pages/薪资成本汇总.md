## 参数契约与逐字段基准

Portal表单状态为：`orgId: ''`、`monthPay: 当前月`、`level: ''`、`ledgerIds: []`。列表请求固定带`order: ''`和`orderField: ''`，再发送：

```json
{
  "order": "",
  "orderField": "",
  "orgId": "",
  "monthPay": "2026-09",
  "level": "",
  "ledgerIds": "",
  "pageNo": 1,
  "pageSize": 20
}
```

`monthPay`使用`YYYY-MM`；省略时使用调用时当前月，显式`null`或空串时发送空串。`level`来自正整数输入框，清空时发送空串，服务端只有非空时才使用`部门level <= level`条件。`orgId`是角色组织树节点ID，不是组织名称。`ledgerIds`是账套ID数组，请求前按页面顺序连接为逗号字符串；空数组发送空串。

Java服务先取得当前网页可见账套集合：调用方省略账套时，服务端用这组ID查询；可见账套集合为空时直接返回空页。指定`orgId`时，服务端调用`getDescendantByAncestor`展开后代组织，并通过`@DataScope`叠加当前用户数据权限。空筛选不表示绕过权限或查询全租户数据。

### 返回字段

返回`{ list, total }`，`list`是部门和工资月份的当前页汇总记录，`total`是记录总数。每行字段为：

`index`服务端DTO保留的序号字段（Portal表格序号实际使用当前页行下标）、`orgName`部门名称、`deptPath`部门全称、`monthPay`工资月份、`level`部门层级、`staffNum`去重员工数。

金额字段保持服务端`BigDecimal`返回的数字或十进制字符串，不擅自转换浮点精度：

`baseSalary`基本工资、`evaluateWages`考核工资、`overtimeWages`加班工资、`educationalSubsidy`学历补贴、`seniorityAllowance`工龄补贴、`communicationsSubsidy`通讯补贴、`closureFee`封场费、`laborCosts`劳动费、`dutyPay`值班费、`otherWages`其他工资、`heatFee`防暑费、`heat`取暖费、`rentalSubsidy`租房补贴、`oneChildAllowance`独生子女补贴、`otherBenefits`其他福利、`bonusSalary`奖金、`shouldPay`应发工资、`pension`养老个人、`jobLess`失业个人、`medical`医疗个人、`seriousIllness`大病医疗、`personalSocialSecurity`个人社保、`personalProvidentFund`个人公积金、`taxableWages`应税工资、`incomeTax`代扣税、`otherChargebacks`其他扣款、`healthDeduction`安康扣款、`totalDeductions`扣款合计、`netSalary`实发工资。

列表没有页面合计行；不要把当前页金额相加当成全量成本。

### 导出

导出请求只发送`orgId`、`monthPay`、`level`、`ledgerIds`，响应文件名由服务端设置为URL编码后的`薪资成本汇总表.xlsx`。服务端把分页大小改为批量大小，逐页读取并按层级追加汇总行；这些汇总行只存在于Excel，不会出现在`.list`返回的`list`中。SDK返回`fileName`、`contentType`、Base64内容和原始`byteLength`，空文件抛错。

## 操作步骤、失败处理与验证边界

1. 先使用当前会话可见候选确认组织ID和账套ID，再决定月份和层级上限。
2. 调用`.list`并按`total`翻页；金额按原值消费。
3. 需要文件时把相同筛选传给`.export`，用`byteLength`和`fileName`确认下载结果；把Excel层级汇总行与列表分页记录区分。
4. 非法月份、层级、ID、页码或页大小会在请求前失败；401/403、网络错误和后端业务错误原样保留。
