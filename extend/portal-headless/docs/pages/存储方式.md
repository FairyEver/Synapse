# 存储方式

## 能力定义与页面范围

平台设置 → 队列管理 → 存储方式，菜单路径 `/dashboard/platform/system/queue/storage/list`，页面权限为
`/dashboard/platform-v2/system/queue/storage`。Portal 页面是 FTP 配置表单，使用
`platform-mall-admin.js`，请求不发送 `module-type`。

页面只读取和保存一份 FTP 配置，不是队列列表 CRUD。页面没有分页、查询、详情、FTP 连通性测试、文件上传、
新增、编辑、删除或服务端取消动作；SDK 不发布这些未发生的能力。

依据 Portal `test/portal/main @ acab69acc7` 的
`app/portal/views/dashboard/platform/system/queue/storage/list.vue`、`storage.vue`、`mall.v2.js`，以及 Java
`test/test @ 0f1a55718eb` 的 `ManageSysQueueInOutController`、`FTPSettingDTO` 和 `Constants`。

## 能力和请求

| 能力 | SDK 方法 | 请求 | 页面行为 |
|---|---|---|---|
| `platform-system-queue-storage-get` | `get()` | GET `/sys/queueInOut/getFTPSetting` | 页面加载时读取配置 |
| `platform-system-queue-storage-prepare-save` | `prepareSave({form})` | 不发请求 | 保存前复制并校验表单 |
| `platform-system-queue-storage-save` | `save({form})` | POST `/sys/queueInOut/saveFTPSetting`，body 为完整 form | 点击“保存”后提交 |

`platform-mall-admin` 的 baseURL 已包含 `/mall-manage-api`；SDK 请求路径因此保持 Portal 源码中的 `/sys/...`，不能再
拼接 `/mall-manage-api`。Java Controller 的 `sysPath=/sys`，后端实际使用 `importexport / ftp_server_setting` 基础设置键。

表单字段与 Java `FTPSettingDTO` 对齐：

| 字段 | 页面含义 | 规则 |
|---|---|---|
| `host` | FTP 地址 | 字符串；页面没有必填或格式校验 |
| `port` | FTP 端口 | 字符串；不转换为 number |
| `name` | FTP 用户名 | 字符串；页面没有必填校验 |
| `pass` | FTP 密码 | 字符串；页面以密码控件展示，SDK不脱敏或改写 |
| `dir` | FTP 路径 | 字符串；页面提示目录需已存在且具备读写权限 |

读取返回对象时保留字段原值，允许字段缺席或 `null`；兼容对象中的扩展字段也保留。Portal 的提交代码是
`data: {...formState.value}`，因此 SDK 提交整份 form：不删除空字段，不把 `port` 转成数字，不重命名 `pass`。
页面没有 Form.Item required、长度或格式规则，空字符串可提交；后端 `FTPSettingDTO` 也没有字段校验注解。

## 保存步骤、取消和失败边界

正常顺序为：`get()`（或已有当前表单）→ `prepareSave({form})` → 用户确认 → `save({form: result.payload})` →
再次 `get()` 逐字段核对。`prepareSave` 不产生网络副作用；用户取消时只丢弃 payload，不调用保存接口。

保存成功只表示后端接受并写入基础设置请求；Java 返回的“保存成功”文本不是 SDK 的业务返回值，SDK `save()` 返回
`undefined`。只有重新读取字段一致，才能报告配置已保存；不能据此报告 FTP 已连通、目录可写或队列导入导出已成功。

保存没有 `requestId`、撤销或恢复接口。请求超时先 `get()` 核对，未核实前不要重复覆盖保存；若用户需要恢复，调用方必须
保留旧表单并再次保存旧值，这是一次新的覆盖写入，不是事务回滚。

权限以 Portal 路由权限 `/dashboard/platform-v2/system/queue/storage` 为准；当前 Java Controller 源码未看到方法级
`@PreAuthorize`。权限、会话、网络和后端错误不能被解释为空配置或 FTP 不可用。
