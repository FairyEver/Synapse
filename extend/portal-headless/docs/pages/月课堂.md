## Portal 可达来源

`monthly-lesson/list.vue` 的创建按钮确认后进入 `voting/[mode]/[id].vue` 或
`nonvoting/[mode]/[id].vue`；编辑按 `monthKind` 进入对应路由。列表还绑定单删/批删、
发布/取消发布、会议记录弹窗、决议和评分记录入口。当前月课堂的创建/编辑表单不是旧的
`monthly-lesson/[mode]/[id].vue`，因此两组 `saveMonthLesson` 与旧记录接口必须区分。

Portal 固定检出 `CodeReview_Projects_Js@test/portal/main` 的 `acab69a…` 中：

- `list.vue`：`GET /study/lesson/studylesson/lessonList`，固定 `type: '3'`；状态按钮在
  列表行上调用 `PUT /study/lesson/studylesson/publish`；“会议记录”弹窗使用
  `components/month-course-record.vue`。
- `voting/[mode]/[id].vue`、`nonvoting/[mode]/[id].vue`：详情均为
  `GET /study/lesson/studylesson/getMonthLessonInfo?lessonId=...`，提交均为
  `POST /study/lesson/studylesson/saveMonthLesson`；按班级变化先查上一次月课堂，查不到再查
  班级主持人信息。
- `voting` 页面把避让人员数组转成逗号字符串；参会人与嘉宾 DTO 作为同一
  `saveMonthLesson` body 的数组提交，不走 `studentManage`。
- `components/month-course-record.vue`：当前列表“会议记录”弹窗提交
  `POST /study/lesson/studylesson/monthLessonRecord`。
- 旧 `monthly-lesson/[mode]/[id].vue` 仍存在，使用 `saveLesson` + `studentManage` +
  `saveLessonRecord`；它不是当前列表 `actionEdit` 的目标，但其真实端点已单独标记为 legacy，
  不与当前月课堂保存混淆。
- `student/[id]/item-list.vue` 是学生管理源文件；当前月课堂列表没有 student 跳转按钮，
  但本次按用户指定保留该隐藏页的 PUT/DELETE 形状；该页的出勤按钮另发
  `GET /study/lesson/studylessonstudentrel/updateAttendanceStatus?id=...`。任何注释或未绑定入口
  均不作为可达证据。

## 端点与能力

列表参数顺序为
`order → orderField → type=3 → title → gradeNames → status → createTimeStart/End →
startTimeStart/End → pageNo → pageSize`。月课堂使用 `YYYY-MM-DD HH:mm:ss`，结束日为 +1 天开区间。

动作实现位于 `src/capabilities/study-lesson.ts`，月课堂使用独立 `requestMonthly`：

| Portal 动作 | 能力 ID | 实际请求 |
| --- | --- | --- |
| 读取月课堂详情 | `study-lesson-monthly-detail` / `study-lesson-monthly-info` | `GET /study/lesson/studylesson/getMonthLessonInfo?lessonId=...` |
| 保存表决/非表决月课堂 | `study-lesson-monthly-prepare-save` → `study-lesson-monthly-save` → `study-lesson-monthly-cancel-save` | `POST /study/lesson/studylesson/saveMonthLesson` |
| 旧详情表单保存（legacy） | `study-lesson-monthly-generic-prepare-save` → `study-lesson-monthly-generic-save` → `study-lesson-monthly-generic-cancel-save` | `POST /study/lesson/studylesson/saveLesson` |
| 读取上一次月课堂 | `study-lesson-monthly-last-lesson` | `POST /study/lesson/studylesson/getLastMonthLessonByGradeId`，body 为 gradeId 数组 |
| 读取班级主持人信息 | `study-lesson-monthly-grade-info` | `POST /study/grade/studygrade/getGradeInfo`，body 为 gradeId 数组 |
| 删除课堂 | `study-lesson-monthly-prepare-delete` → `study-lesson-monthly-delete` → `study-lesson-monthly-cancel-delete` | `DELETE /study/lesson/studylesson`，body 为 `[id,...]` |
| 发布/取消发布 | `study-lesson-monthly-prepare-publish` → `study-lesson-monthly-publish` → `study-lesson-monthly-cancel-publish` | `PUT /study/lesson/studylesson/publish`，body `{ id, status }` |
| 当前会议记录弹窗 | `study-lesson-month-record-prepare-save` → `study-lesson-month-record-save` → `study-lesson-month-record-cancel-save` | `POST /study/lesson/studylesson/monthLessonRecord` |
| 旧课堂记录（legacy） | `study-lesson-monthly-record-prepare-save` → `study-lesson-monthly-record-save` → `study-lesson-monthly-record-cancel-save` | `POST /study/lesson/lessonrecord/saveLessonRecord` |
| 旧课堂出勤（legacy） | `study-lesson-monthly-prepare-attendance` → `study-lesson-monthly-attendance-save` → `study-lesson-monthly-cancel-attendance` | `POST /study/lesson/lessonrecord/studentManage`，body 为数组 |
| 学生列表（隐藏页） | `study-lesson-monthly-student-list` | `GET /study/lesson/studylessonstudentrel/studyStudentList` |
| 学生行移入/移出 | `study-lesson-monthly-student-prepare-move-out` → `study-lesson-monthly-student-move-out` → `study-lesson-monthly-student-cancel-move-out` | PUT `/study/lesson/studylessonstudentrel/moveOut`，body `{ lessonId, staffCodeList, type }` |
| 学生页批量按钮 | `study-lesson-monthly-student-prepare-batch-delete` → `study-lesson-monthly-student-batch-delete` → `study-lesson-monthly-student-cancel-batch-delete` | DELETE 同一 `moveOut`，body 直接为学生行 `[id,...]`，无 query |
| 学生出勤切换（隐藏页） | `study-lesson-monthly-student-attendance-toggle` | `GET /study/lesson/studylessonstudentrel/updateAttendanceStatus?id=...` |

`saveMonthLesson` 的月课堂表单会把 `time` 拆为 `startTime/endTime`，并将 voting 的
`avoidStaffCode/avoidName` 数组转为逗号字符串；参会/嘉宾 DTO 使用页面最终数组。班级 helper
的 body 是数组本身，不是 `{ gradeIdList: [...] }`。

## 门禁与跨页依赖

- 列表和所有动作保持 `/dashboard/lesson/monthly-lesson` 权限及页面 module-type 推导。
- 表决类表单固定 `type=3, monthKind=1`，非表决固定 `type=3, monthKind=2`；保留
  `gradeIdList`、`title`、`hostCode`、`time`、参会人/嘉宾、议案字段。保存按钮由
  `!!rrForm.formState.status` 禁用，prepare 在 status truthy 时拒绝。
- `handleGradeChange` 的依赖顺序是 `getLastMonthLessonByGradeId`，无结果才调用
  `getGradeInfo`；不要把两个 helper 合并成一个未在 Portal 出现的接口。
- 发布按钮只在关联班级条件满足时可见；删除的 Java 服务仍拒绝已发布课堂，prepare 在已知
  status=1 时拒绝。
- `monthLessonRecord` 需要当前详情中的参会人、嘉宾、议案和 `studyLessonRecordDTO`；
  它不是 `saveMonthLesson` 的隐式后续，也没有回滚接口。
- `cancel` 只取消本地草稿；月课堂已提交的后端状态不能由 cancel 撤回。

## Java 对照证据

固定检出 `CodeReview_Mall_Platform_Java@test/test` 的 `0f1a557…`：

- `StudyLessonController`：`lessonList`、详情、`saveMonthLesson`、`getMonthLessonInfo`、
  `getLastMonthLessonByGradeId`、`monthLessonRecord`、基类 DELETE、`publish`。
- `StudyGradeController`：`POST /study/grade/studygrade/getGradeInfo`，请求体为
  `List<Long> gradeIdList`。
- `StudyLessonStudentRelController`：学生分页、`PUT moveOut` 及其
  `MoveOutLessonStudentDTO`（type 1/2）；Portal 学生页批量删除仍是 DELETE `/moveOut` 的
  数组 body，不添加 query。
- `StudyLessonServiceImpl.saveMonthLesson` 保存月课堂、班级关系、参会人/嘉宾和议案；
  `getMonthLessonInfo` 决定详情和可编辑/投票数据；删除与发布分别有服务端状态校验。
- 旧 `saveLessonRecord` 与 `studentManage` 来自 `StudyLessonRecordController`，只对应旧
  generic 月课堂表单，不替换当前 voting/nonvoting 的 `saveMonthLesson`。
