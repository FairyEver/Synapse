## 与图文课程的差异

**只有一处**：`getDataListURL` 上的 `type` 是 2 而不是 1，`convertFetchForm` 与筛选框
（`keyword` + `date` 区间）**逐字相同**。所以能力实现共用同一个 `listOf(type)`。

## 真实请求（浏览器实测，2026-09-21）

```
GET …/admin-api/study/course/studycourse/courseList
    ?order=&orderField=&keyword=&startTime=&endTime=&pageNo=1&pageSize=20&_t=<ts>&type=2
```

与图文课程逐字段同形，只差末尾的 `type`。基准见 `baseline/study-course.browser.json` 第 2 条。

## 真实验证记录（2026-09-21）

`smoke/with-portal-token.sh node smoke/read-study-course.mjs`：

- `listVideo()` → **`total=42`**，本页 5 条；URL 与基准逐字段一致（含键顺序）。
- 首行：`id=1668 / resourceId=4068 / 徐曼 / 2026-05-08 10:47:15`，
  资源字段 **`news`/`videos`/`live`/`imGroupDTO` 四个全是 `null`**。

### 那四个 `null` 是一条值得记住的观测

`StudyCourseListDTO` 按 `type` 把资源本体塞进四个字段里的一个。这一行的四个都是 `null`，
说明**资源本体没取到**（`matchResourceByType` 是按 `resourceId` 去远端结果里找，
找不到就 `CollectionUtils.isNotEmpty(...)` 为假、跳过赋值），而不是"类型不对"。

**这类失联不报错**：课程行还在（本地 `hr_study_course` 有这一行），只是资源列空着。
所以调用方**不能**用「`videos` 是不是 null」来判断"这一行的 type 对不对" —— 那是两回事。

## 弹窗与隐藏子路由（本轮补的 4 条）

这一页的列表请求早在 SDK 里（`study-course-video-list`）。本轮补的是列表之外的隐藏面：
行操作里的「查看评论」「查看讲师」，以及**编辑页**（隐藏路由 `[mode]/[id]`）里的类别下拉与标签。

| 能力 id | 入口（页面动作） | 请求 | 实例 | write |
| --- | --- | --- | --- | --- |
| `study-course-video-comment-list` | 行操作「查看评论」→ 隐藏路由 `comment/[id]/item-list` | `GET /manage/getCommentList.lay` | `smart-layer-admin` | 否 |
| `study-course-video-professor-list` | 行操作「查看讲师」弹窗 | `GET /manage/professorsByMediaId.lay` | `smart-layer-admin` | 否 |
| `study-course-video-type-tree` | 编辑页「类别」下拉 | `GET /manage/getVideoTypeTreeList.lay` | `smart-layer-admin` | 否 |
| `study-course-video-tag-list` | 编辑页「标签」按钮组 | `GET /manage/lableList2.lay` | `smart-layer-admin` | 否 |

四条都在 `.lay` 网关上（host 与主站不同），`httpInstance` 必须由调用方在
`httpBaseUrls['smart-layer-admin']` 里配 baseURL，没配就**拒绝发请求**。

### 三个必须记住的点

**1. 评论页与图文课程共用同一个接口，靠 `type=2` 分片，但两个筛选字段名不同。**
视频页发的是 `userName` / `userPhone`（`comment/[id]/item-list.vue:73-74, :85-86`），
而后端 `CommentLayController#getCommentList` 的形参叫 `username` / `phone` ——
**这两个筛选在视频评论页实际不生效**（Spring 忽略多余的 query 参数，请求照样 200）。
SDK 照抄页面的线上形状（改名就不与页面逐字段一致了），并把"不生效"写进了能力说明。
`newsId` 要取 `videos.id`（远端资源 id），不是课程行 `id`。

**2. 「查看讲师」的 `type` 页面写死 0。** `video-course/list.vue:147` 传的是 `type: 0`，
紧挨着的 `// type: record.videos.type` 那行是**注释掉的** —— 按项目规则注释掉的东西不算数，
SDK 只发页面真的会发的那一个值，也不开放给调用方改写（`mp.type = 0` 就是"视频"这一路）。

**3. 标签候选返回的是字符串数组，而且图文课程编辑页用的不是这个接口。**
`/manage/lableList2.lay` 的 `data` 是 `select content from zhdj_label …` 的标签名数组，
页面把它们直接渲染成按钮、选中后 `join(',')` 存进 `tagNames`。
⚠️ 图文课程编辑页 import 的是**另一个同名组件** `text-course/components/tag.vue`，
打 `/tag/list.lay?typeList=1`，返回 `{id,name}` 对象数组、选中值存 `tagIds` ——
**不在本轮派单范围内**，没有做成能力。

另注：`getVideoTypeTreeList.lay` 只发 `type=1`（"新建或修改时的下拉，需要去掉有子分类的"），
后端另有一个 `videoHotTopicFlag` 入参（默认 0）页面没传，SDK 也不传 —— 传了会拿到与页面
不同的分类集合。

## SDK AI 说明契约（2026-09-22）

以下由真实 SDK 描述生成；权威数据为 src/catalog/contracts-*.ts。前文浏览器/冒烟记录是历史证据，本节不将源码和离线验证称作新的部署实测。

### `study-course-video-list`

查询 Portal 视频课程列表及该页可见的资源信息；与课堂/学员学习记录区分。

执行：`sdk.studyCourse.listVideo`；性质：read。查询 Portal 视频课程列表及该页可见的资源信息；与课堂/学员学习记录区分。

- 边界：仅说明当前已实现列表能力对应的 Portal 页面可见字段和操作标识；不要求解释外部内容管理端或后端完整 DTO。原始兼容扩展不是新增业务功能。

| 参数 | 意义与来源 |
| --- | --- |
| keyword | 远端资源名称关键字；当前租户历史实测命中资源时后端用户映射超过 500 条会报错，收窄名称不能保证修复；空结果也不能证明该路径可正常读取命中资源。；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| startTime | 创建时间起 `YYYY-MM-DD HH:mm:ss`；与 endTime 成对，用 buildStudyCourseTimeRange 生成；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| endTime | 创建时间止，**开区间**（结束日 +1 天）。用 buildStudyCourseTimeRange 生成，自己拼会少一天；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| pageNo | 页码，默认 1；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| pageSize | 每页条数，默认 20；来源：用户给出的业务条件；格式和必填性按参数契约。 |

返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。

- list[].videos.duration：视频时长；列表明确“时长（秒）”；单位：秒
- list[].videos.diversionMark：导流开关，Portal 按 yes_or_no 字典显示；{"0":"否","1":"是"}
- list[].videos.maySee：导流为 1 时编辑页显示的可播放秒数，控件 0..180；不是视频总时长；单位：秒

- 消费：按页面列展示 videos.title 和本契约字段；videos 为空时保留课程行并标明资源不可用，不能判定课程未创建。
- 消费：creator 与当前用户 userId 相同是页面显示行操作的条件，不据此替代服务端鉴权。当前 SDK 只提供列表查询，页面新建/编辑、同步、评论、语音和禁言等动作没有因此成为可调用 SDK 能力。
- 消费：既有请求仍透传原始行以保持兼容；未列出的资源元数据、其他类型资源和扩展对象不属于本 Portal 页消费契约，不展示、不解释、不据此执行动作。
- 消费：分享时效按 Portal 编辑页原值展示，不补单位，不进行时间换算；视频 duration 和 maySee 有明确秒单位，不能混为 sharingLimitation 的单位。

完成条件：按用户要求交付本次筛选范围的结果；需要完整清单时继续翻页至覆盖 total，不能把当前页当全集。

- 失败处理：已知命中资源时后端可能报 500（用户映射拉取超过 500 条），即时通讯查询在既有租户实测同样失败；不要循环重试或宣称更精确关键字必能修复，空列表也不能证明命中资源路径正常。

逐字段嵌套结构、可空性、格式及证据由同一 describe 返回；完整生成参考见 ai-contract-reference.generated.md。
