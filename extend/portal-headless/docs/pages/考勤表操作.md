# 考勤表操作补齐

范围：考勤统计与考勤档案页面。源码前端 test/portal/main@d3cf56bdc7，后端 test/test@dcb3f360194。

## 能力与调用

均可用 `capabilities.invoke(id,args)`；SDK 组为 `attendanceSheet`。

| 能力 | 方法 | 参数 / 最终返回 |
| --- | --- | --- |
| attendance-sheet-get | get | `{id}` → 编辑资料id/departmentId/organizationId/yearMonth/isArchived/users |
| attendance-sheet-department | department | 无参数 → `{id,fullPath}`；没有部门均为null |
| attendance-sheet-group-search | searchGroups | `{departmentId,keyword}` → `{list:[{id,fullPath}],total}`，最多50条 |
| attendance-sheet-user-search | searchUsers | `{keyword,organizationId?,pageNo?,pageSize?}` → `{list:[{id,name,staffCode,organizationName}],total}` |
| attendance-sheet-save | saveIdempotent | `{id?,isArchived?,departmentId,organizationId?,yearMonth,userIdList,requestId}` → undefined |
| attendance-sheet-archive | archive | `{id,isArchived}` → undefined，GET写入 |
| attendance-sheet-unarchive | unarchive | `{id}` → undefined，GET写入 |
| attendance-sheet-remove | remove | `{id,isArchived}` → undefined，DELETE |
| attendance-sheet-statistics | statistics | `{id,isArchived}` → 每人统计行数组 |

AI说明权威定义在 `src/catalog/contracts-attendance-sheet.ts`，通过实际describe/-llm返回；测试验证整组人员覆盖、用户ID不能用工号、取消归档删除快照、GET写标记与下游字段映射。直接 `attendanceSheet.save(draft)` 不防重，AI入口使用saveIdempotent；公共直接方法有独立说明。

## 参数与操作规则

- 当前用户部门从getUserDepartment取；班组只在该部门范围搜。人员使用页面getUserByRole，keyword必填，默认每页5、最大100。人员ID来自id，绝不是username工号。
- 新建id省略发null，年月拆为year四位字符串/month两位字符串；班组未选发null。至少一名人员，后端仍会校验所有人员已关联考勤组。
- 编辑必须先取得完整已选人员并保留未删除成员。传同一行的isArchived；不是0则禁止编辑。userIdList整组替换；保存不自动归档，后端不返回新ID，按部门/班组刷新列表核对新行。
- 归档、删除及统计簿按刷新后列表同一行的isArchived执行；SDK不额外调用详情。原因：真实Java详情getInfo对organizationId=null会空指针，而PC列表动作直接使用行快照；额外详情前检会阻断本来可操作的无班组记录。
- 删除只能未归档；归档后编辑/删除/再归档禁用。取消归档删除现有归档快照，不是历史恢复，且不是成功后的必做动作。取消新建测试数据需要定位本次创建ID并删除。
- 统计簿根据isArchived===1选择归档端点，否则未归档端点。请求只含order/orderField/id，不分页。只返回页面可见的姓名、日勤、公差、周六日、工伤、事假、病假、旷工、年休、探亲、婚假、产假、迟到、早退、小计，单位天；空值显示0，小计保持服务端原值，不累加重叠列。
