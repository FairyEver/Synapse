## ⚠️ `gradeName` 默认**不发**

这一页的表单里有 `gradeName: route.query.gradeName` —— 它是从**别的页面带 query 跳过来**的。
取不到就是 `undefined`，`qs` 的 `skipNulls` 把它丢掉。实测 URL 里**确实没有这一项**：
`?order=&orderField=&staffCode=&name=&allLesson=&startLesson=&completeLessonMin=&completeLessonMax=&pageNo=1&pageSize=20&_t=…`

所以能力侧这一项的默认值是 **`undefined` 而不是空串** —— 与同域其它页"初值空串、照样发"**相反**。

## 另一处：`order`/`orderField` 表单里也有

页面表单里同时写了 `order: ''` 与 `orderField: ''`，而列表模块也在最前面放这两个。
对象展开时**值被覆盖、键的位置留在第一次出现的地方** —— 最终仍是 `order` 打头。实测印证。

### `study-statistics-student-list`

按学员汇总应学/实学课次、完成率、互动和评分。

执行：`sdk.studyStatistics.listStudents`；性质：read。按学员汇总应学/实学课次、完成率、互动和评分。

- 边界：使用当前 SDK 用户与租户的数据权限；页面上下文由 SDK 绑定，调用方不要另拼 module-type。

| 参数 | 意义与来源 |
| --- | --- |
| staffCode | 学员工号；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| name | 学员姓名；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| allLesson | 总课次（取值语义未实测）；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| startLesson | 已开始课次（未实测）；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| completeLessonMin | 班课完成率下限，包含边界；来源：用户筛选范围，0..100 的百分数；不是完成课次数；单位：% |
| completeLessonMax | 班课完成率上限，包含边界；来源：用户筛选范围，0..100 的百分数；不是完成课次数；单位：% |
| gradeName | 班级**名称**。页面是从别的页带 query 跳过来的；不传就不发这一项（与其它页不同）；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| pageNo | 页码，默认 1；来源：用户给出的业务条件；格式和必填性按参数契约。 |
| pageSize | 每页条数，默认 20；来源：用户给出的业务条件；格式和必填性按参数契约。 |

返回：`{ list: object[], total: number }`。list=[] 为当前页无记录；total=0 表示该筛选无结果。保留筛选条件检查页码，不将空结果解释成权限判定。

- list[].completeLesson：班课完成率，非完成课次数；后端完成课数/应学课数×100，保留两位小数；分母为 0 时为 0；单位：%

- 消费：按 staffCode 区分学员；完成率 completeLesson 不是完成数量，不应求和。平均分应展示原统计值，不能直接对分页平均值二次平均。
- 消费：听课时长 studyTime 与 Portal 表格一致展示原始数值；页面未标单位且未换算，SDK 不添加秒/分钟/小时，不据此跨单位汇总。
