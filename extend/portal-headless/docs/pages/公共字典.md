# 公共字典（`/dashboard/setting/dict-platform/common/list`）

## 能力定义

本页属于 Portal「系统设置 → 公共字典」。菜单权限为 `/dashboard/setting/dict-platform/common`，wrapper 为
`app/portal/views/dashboard/common/setting/dict-platform/common/list.vue`，共享实现为
`app/portal/views/dashboard/common/setting/dict-platform/all/**`。

本页实际交付六项能力：公共字典类型分页查询；字典数据分页查询、详情、新增、编辑、单条删除。
根页固定传 `useSystem=0`（公共），只提供名称/类型筛选和“字典数据”入口。类型新增、编辑、删除按钮在 Portal 中被注释，Java 租户 `DictTypeController` 的对应写接口和导出接口也明确拒绝，因此不登记类型写入、类型导出或批量类型操作。

数据子页提供标签/状态筛选、分页、新增、编辑和单条删除；没有批量删除、导入或导出按钮。平台共享数据行 `platform=true` 时，Portal 禁用编辑和删除。

## 参数契约

所有请求使用 `platform` HTTP 实例和 `/admin-api/system/...` 路径；该页面没有可推导的 `module-type`，不发送此请求头。

类型列表：

- `GET /admin-api/system/dict-type/page`
- 参数按 Portal 列表默认值发送：`order=''`、`orderField=''`、`useSystem=0`、`name=''`、`type=''`、`pageNo=1`、`pageSize=20`
- `pageSize` 只接受页面选项 `10/20/50/100`；`name`、`type` 是模糊筛选，均可省略
- Java 租户 Controller 会强制 `tenantEditable=1`，调用方不能用本页查询到不可维护的类型

字典数据列表：

- `GET /admin-api/system/dict-data/page`
- `dictType` 必填，必须使用类型列表行的 `type`，不能使用类型行的 `id`
- 参数默认包含 `order=''`、`orderField=''`、`label=''`、`status=undefined`、`pageNo=1`、`pageSize=20`
- `label` 模糊筛选；`status` 为 `0=开启`、`1=关闭`，省略或 `null` 表示不筛选

字典数据表单和写入：

- 详情：`GET /admin-api/system/dict-data/get?id=<id>`
- 新增：`POST /admin-api/system/dict-data/create`。Portal 默认 `id=''`、`dictTypeId=dictType`、`label=''`、`value=''`、`status=0`、`sort=0`、`remark=''`，提交时再由 bridge 写入 `dictType`
- 编辑：`PUT /admin-api/system/dict-data/update`。提交详情中的字段并以当前子页 bridge 覆盖 `dictType`
- 删除：`DELETE /admin-api/system/dict-data/delete?id=<id>`，只支持单条 `id`
- `label`、`value` 在 blur 时必填；Java 还要求 `sort` 非空且非负、`status` 为 `0/1`、文本长度最多 100；`(dictType,value)` 全局唯一
- 查询返回平台共享数据和当前租户私有数据；写入要求当前租户上下文、类型存在且启用、`tenant_editable=1`，且编辑/删除目标必须属于当前租户。平台共享数据 `tenantId=0` 只读

## 逐字段基准

类型分页最终返回 `{ list, total }`：

| 字段 | 语义 |
| --- | --- |
| `list[].id` | 字典类型主键；长整数保留字符串形态 |
| `list[].name` | 字典名称，可能为 `null` |
| `list[].type` | 字典类型代码；进入数据子页和所有数据操作使用它，可能为 `null` |
| `list[].status` | 类型状态，`0=开启`、`1=关闭`，可能为 `null` |
| `list[].remark` | 类型备注，可能为 `null` |
| `list[].createTime` | 创建时间原值，可能为 `null` |
| `list[].useSystem` | 所属系统；本页请求固定筛选 `0=公共`，可能为 `null` |
| `list[].tenantEditable` | 是否允许租户维护该类型数据，`1` 才满足租户写入前提，可能为 `null` |
| `total` | 符合当前名称/类型筛选且 `useSystem=0` 的总数，不是当前页条数 |

数据分页最终返回 `{ list, total }`；详情返回一条同结构记录或 `null`：

| 字段 | 语义 |
| --- | --- |
| `id` | 字典数据主键，用于编辑/删除；长整数保留字符串形态 |
| `sort` | 显示排序，可能为 `null`；新增默认 `0` |
| `label` | 字典标签，可能为 `null` |
| `value` | 字典值，可能为 `null`；同一 `dictType` 下唯一 |
| `dictType` | 所属字典类型代码，应与当前子页路由一致，可能为 `null` |
| `status` | 数据状态，`0=开启`、`1=关闭`，可能为 `null` |
| `colorType` | 颜色类型；页面不展示但详情回显可能携带，可能为 `null` |
| `cssClass` | CSS 样式类；页面不展示，可能为 `null` |
| `remark` | 数据备注，可能为 `null` |
| `createTime` | 创建时间原值，可能为 `null` |
| `tenantId` | 数据归属租户；`0` 为平台共享，正数为租户私有，可能为 `null` |
| `platform` | Java `tenantId == 0` 的计算标记；`true` 表示平台共享只读，可能为 `null` |
| `total` | 数据分页中为当前 `dictType`、标签和状态条件的总数，不是当前页条数 |

空值口径：`list=[]` 只表示当前页没有记录，`total=0` 才表示条件下无记录；请求、权限和后端业务错误抛出，不能解释为空列表。详情 `null` 表示没有可用详情。

## 操作步骤

1. 调用类型列表，向用户展示 `name/type/status`，保留选中行的 `type`；不要把 `id` 当作 `dictType`。
2. 用户点击“字典数据”时，以该 `type` 调用数据列表；筛选只使用 `label` 和 `status`，按 `total` 跨页查找目标。
3. 新增时提交 `dictType、label、value、sort、status、remark`；`dictType` 必须来自当前公共类型，后端会检查类型启用和 `tenant_editable`。
4. 编辑前读取详情，保留完整字段并确认 `platform !== true`；编辑成功后按原 `dictType` 回查同一 `id`，逐字段核对。
5. 删除前确认列表行 `platform !== true`；删除成功或超时后按原 `dictType` 跨页确认目标 `id` 消失。回执超时不得盲目重试：后端没有 requestId 幂等包装。
6. 权限、租户上下文、类型状态、平台归属、唯一性或 Java 校验失败时原样报告；不要把失败当成空结果或成功。

## 同名页面边界：平台设置公共字典

以下页面是另一个已存在的 Portal 节点，不属于本次新增能力：`/dashboard/platform/setting/dict-mall/common/list`，权限为 `/dashboard/platform-v2/setting/dict-mall/common`，使用 `/adminmanage-api/system/...` 和平台管理 Java `ManageDictTypeController`/`ManageDictDataController`。它的类型与数据写入归属平台共享 `tenant_id=0`，与本页的租户视角、`/admin-api` 前缀和 `useSystem=0` 固定筛选不可混用。
