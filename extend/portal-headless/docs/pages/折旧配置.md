## 参数契约与逐字段基准

列表默认发送 `order=''`、`orderField=''`、`depreciationLifeMonth=null`、`materialCategory=null`、`pageNo=1&pageSize=20`。详情/保存字段为 `assetCategory`、`depreciationMethod`、`depreciationYear`、`depreciationDate`、`netSalvageValueRate`、`materialCategory`、`isCurrMonthDep`、`isDepreciationReduction`。

`assetCategory`、`depreciationMethod`、`depreciationYear`、`depreciationDate`、`netSalvageValueRate` 必填；折旧年限为非负整数（单位年），折旧日为 1 至 25，净残值率为 0 至 100。`isCurrMonthDep` 为 `1当月/0下月`，`isDepreciationReduction` 为 `1折旧/0不折旧`，默认均为 0。`materialCategory` 空值按 `null` 提交。详情读取会按Portal把 `depreciationMethod` 转成字符串用于表单，SDK返回值据此保持可消费的字符串。

## 操作步骤、失败处理与验证边界

1. 新增/编辑先读取资产类别和物料分类候选；候选的 `id` 用于提交，名称和路径只用于展示。
2. 调用对应 `prepare` 进行本地边界校验，用户确认后调用 `create` 或 `update`；取消只丢弃草稿，不发写请求。
3. 写请求完成或超时后按同一 `id`/完整字段回读核对；删除先准备并确认，再按ID回查消失。没有 requestId 时不能盲目重试。
4. 缺字段、范围越界、缺少更新ID、坏树/分页、权限、网络和后端错误均抛出；不保留页面源码中吞掉的错误。
