# 下载与安装

<!-- Sources: website/.vitepress/config.mts; package.json; desktop/package.json -->

## 下载

安装包在 GitHub Releases 发布：

- [Synapse Releases](https://github.com/FairyEver/SynapseAppRelease/releases)

选择最新版本，根据操作系统下载对应安装包：

| 操作系统 | 安装包 |
| --- | --- |
| macOS | `.dmg` |
| Windows | `.exe` |

## macOS

1. 双击 `.dmg` 文件。
2. 将 Synapse 拖入 Applications 文件夹。
3. 从 Launchpad 或 Applications 启动。

如遇“无法打开，因为来自身份不明的开发者”提示，前往 **系统设置 → 隐私与安全性** 选择“仍要打开”。

## Windows

1. 运行安装程序。
2. 按向导完成安装。
3. 从开始菜单或桌面快捷方式启动。

如遇 SmartScreen 警告，选择“更多信息 → 仍要运行”。
