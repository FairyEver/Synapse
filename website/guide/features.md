# 功能特性

## 1. 浏览与搜索

左侧导航提供 Rules 和 Skills 两个主入口，每个模块包含：

- **分类筛选** — 侧边栏按分类组织，显示各分类下的内容数量
- **全文搜索** — 实时关键字过滤
- **仓库同步** — 从远端仓库拉取最新内容

## 2. 内容详情

点击任意 Rule 或 Skill 进入详情视图：

- 元信息：标题、简介、作者、创建时间、分类
- 正文预览（只读）
- Skill 附件支持 Tab 切换查看
- 下载与安装操作入口

## 3. 下载

- Rule 导出为 `.md` 文件
- Skill 导出为 `.zip` 压缩包，保留完整目录结构

## 4. 一键安装到编辑器

核心功能。支持将 Rule / Skill 直接安装到目标编辑器：

- 支持 **Claude Code**、**Cursor**、**Codex**
- 安装范围可选 **全局**（当前用户所有项目生效）或 **项目级**（仅指定目录生效）
- 自动写入各编辑器官方推荐的规则目录，无需手动配置

::: tip 全局安装的限制
部分编辑器的全局规则仅支持通过其自身设置界面管理，此类组合会显示为不可用。
:::

## 5. 创建与分享

在 Rules 或 Skills 页面通过 `+` 按钮创建新内容：

- **Rule** — 填写标题、简介、分类、图标、正文
- **Skill** — 在 Rule 基础上添加附件（拖拽上传，保留目录结构）

提交流程：
1. Synapse 在仓库目录中生成标准化文件
2. 通过 Git 创建待审核提交
3. 团队管理员在代码托管平台完成合并
4. 其他成员同步后即可使用

::: tip 无需 Git 操作经验
仓库配置完成后，Synapse 自动处理分支创建、提交和推送，使用者只需填写内容。
:::

## 6. 多仓库管理

支持配置多个仓库目录，在设置中切换当前激活的仓库。同一时刻仅展示一个仓库的内容。

## 7. 设置

设置界面提供以下配置项：

- 仓库目录与子目录路径
- 本地项目列表与别名
- 用户显示名称（用于内容署名）
- 软件更新选项

## 8. 自动更新

内置版本检测，新版本发布后应用内提示更新，确认后自动下载安装。
