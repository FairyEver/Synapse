# 下载与安装

## 下载

所有版本统一在 GitHub Releases 发布：

<div class="download-actions">

**[前往下载（GitHub Releases）](https://github.com/FairyEver/SynapseAppRelease/releases)**

</div>

选择最新版本，根据操作系统下载对应安装包：

| 操作系统 | 安装包 |
| --- | --- |
| macOS | `.dmg` |
| Windows | `.exe` |
| Linux | 暂未提供，可关注后续版本 |

## 安装

### macOS

1. 双击 `.dmg` 文件
2. 将 Synapse 拖入 Applications 文件夹
3. 从 Launchpad 或 Applications 启动

如遇"无法打开，因为来自身份不明的开发者"提示，前往 **系统设置 → 隐私与安全性** 选择"仍要打开"。

### Windows

1. 运行安装程序
2. 按向导完成安装
3. 从开始菜单或桌面快捷方式启动

如遇 SmartScreen 警告，点击"更多信息 → 仍要运行"。

## 快速上手

### 第一步 · 配置仓库

打开 **Settings**，配置一个本地目录作为仓库：

- 已有团队仓库：将其 `git clone` 到本地，填入该目录路径
- 暂无团队仓库：先创建一个本地目录试用，后续再接入 Git

### 第二步 · 浏览内容

切换到 **Rules** 或 **Skills** 标签，查看仓库中的内容。支持分类筛选和全文搜索。

如果仓库为空，可以从创建第一个 Rule 开始。

### 第三步 · 安装到编辑器

找到目标 Rule 或 Skill，通过安装按钮选择编辑器（Claude Code / Cursor / Codex）和安装范围（全局 / 项目），完成安装。

重新打开编辑器后，安装的规则或能力包即生效。
