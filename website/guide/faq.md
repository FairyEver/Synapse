# 常见问题

## 使用门槛

### 我需要懂 Git 才能用吗？

**日常使用不需要。**

如果你只是想看看别人沉淀的 Rules / Skills、装到自己的编辑器里，完全不需要懂 Git——点几下按钮就行。

只有当你**创建并分享**自己的内容时，Synapse 会在后台用 Git 创建一条待审核的提交。这一步也是软件代劳的，你不需要自己敲命令。

团队里至少要有一个人熟悉 Git，负责初始化仓库和审核合并提交即可。

### 我需要懂 AI 或编程吗？

不需要。Synapse 是一个"整理和分发"的工具。

你只需要会：

- 用一段文字描述一个你觉得好用的提示词或规则；
- 或者把几个现成文件打包成一个能力包；

就可以把它分享给队友。真正跑 AI 的是你平常用的那个编辑器，不是 Synapse。

## 支持范围

### 支持哪些 AI 编辑器？

当前版本支持三个主流编辑器的 Rule / Skill 安装：

- **Claude Code**
- **Cursor**
- **Codex**

更多编辑器会陆续加入。如果你用的编辑器暂未支持，你仍然可以使用 Synapse 的**下载**功能，把文件下到本地，自己放到编辑器需要的位置。

### 支持哪些操作系统？

- **macOS**：支持（提供 `.dmg`）
- **Windows**：支持（提供 `.exe`）
- **Linux**：源码可以运行，暂未提供官方安装包

### 一定要用 Git 仓库吗？

不一定。仓库可以是：

- **Git 仓库**：推荐，方便团队协作、版本追踪；
- **本地普通目录**：也可以，适合个人试用或先独立整理。

差别在于：非 Git 目录下，「创建并分享」这一步会禁用，因为没有 Git 就没法提交到团队。浏览和安装不受影响。

## 数据与隐私

### 我创建的内容存在哪里？

存在**你自己选择的那个本地目录**里。Synapse 不上传你的内容，不在云端保存任何副本。

如果那个目录是一个 Git 仓库，你的内容会随着 Git 的 push 同步到团队的代码托管平台（比如 GitHub / GitLab / 私有 Git 服务），由你们自己的平台权限控制。

### Synapse 会看到我的内容吗？

不会。软件只是读取你本地的文件并展示。我们不收集你的 Rule / Skill 内容，也不做使用行为追踪。

### 会存我的 Git 账号密码吗？

不会。Synapse 依赖你系统上已有的 Git 凭证能力，不会在自己内部明文保存用户名密码。

## 离线与同步

### 可以离线使用吗？

- **浏览、搜索、安装**：可以，只要本地仓库目录存在即可。
- **刷新、创建并分享**：需要网络访问团队的 Git 服务。

### 为什么我看不到队友刚提交的新内容？

通常有两个原因：

1. **还没合并**：队友的提交可能还在等待审核，只有合并到主分支后才会出现在列表里；
2. **还没刷新**：Synapse 当前不自动同步，记得点右上角的刷新按钮。

### 我提交之后为什么列表里看不到自己的内容？

一样的原因：你的提交需要团队管理员合并到主分支，才会出现在所有人的 Synapse 里。提交成功后稍等审核即可。

## 内容与使用

### Rule 和 Skill 什么时候用哪个？

- 只是一段文字就能说清楚的 → **Rule**；
- 需要带附件、带示例、带模板的 → **Skill**。

更详细的区别见 [核心概念](/guide/concepts)。

### Skill 附件有大小或数量限制吗？

- 文件类型不限制；
- **单个文件不超过 10MB**；
- 数量没有硬性上限，但建议控制在合理范围，方便团队克隆和分发。

### 装过的 Rule / Skill 可以卸载吗？

可以。你只需要手动删除编辑器目录里对应的那个文件或子目录即可。因为 Synapse 是标准的写入到编辑器官方规则位置，删除方式和你平时管理编辑器规则一样。

### 我把一个 Rule / Skill 装到了项目里，换一个项目还会生效吗？

不会。项目安装只影响你选中的那一个项目目录。如果你想所有项目都生效，请选「全局」安装。

## 版本与更新

### 软件会自动更新吗？

有新版本时，软件内会提示更新。你确认后，Synapse 会下载新版本并安装，重启即完成。

### 在哪里看版本更新记录？

所有版本记录都在 [GitHub Releases](https://github.com/FairyEver/SynapseAppRelease/releases)。
