# 常见问题

## 使用门槛

### 需要 Git 经验吗？

日常浏览和安装不需要。Synapse 的界面操作不涉及任何 Git 命令。

创建并分享内容时，Synapse 会在后台自动完成 Git 提交流程。团队中需要至少一人负责仓库初始化和提交审核。

### 需要 AI 或编程基础吗？

不需要。Synapse 是内容管理与分发工具，不直接运行 AI 模型。使用者只需编写或整理提示词内容，实际的 AI 交互由目标编辑器完成。

## 支持范围

### 支持哪些编辑器？

当前版本支持：
- **Claude Code**
- **Cursor**
- **Codex**

更多编辑器将在后续版本中支持。未适配的编辑器可通过下载功能获取文件后手动放置。

### 支持哪些操作系统？

| 系统 | 状态 |
| --- | --- |
| macOS | 支持（`.dmg`） |
| Windows | 支持（`.exe`） |
| Linux | 源码可运行，暂无官方安装包 |

### 必须使用 Git 仓库吗？

不是必须的。仓库可以是 Git 仓库（推荐，支持协作与版本追踪）或普通本地目录（适合个人试用）。

非 Git 目录下，"创建并分享"功能不可用，浏览和安装不受影响。

## 数据与隐私

### 内容存储在哪里？

存储在用户指定的本地目录中。Synapse 不上传内容，不在云端保存任何副本。

如果该目录是 Git 仓库，内容随 Git push 同步到团队的代码托管平台，权限由平台自身控制。

### Synapse 会访问用户内容吗？

不会。软件仅读取本地文件并在界面中展示，不收集内容数据，不进行使用行为追踪。

### 会存储 Git 凭证吗？

不会。Synapse 依赖系统已有的 Git 凭证管理机制，不在应用内部存储任何账号信息。

## 离线与同步

### 支持离线使用吗？

- **浏览、搜索、安装** — 支持，只要本地仓库目录存在
- **同步、创建并分享** — 需要网络访问 Git 服务

### 看不到队友新提交的内容？

常见原因：
1. 提交尚未合并到主分支，需等待审核通过
2. 本地未同步，点击刷新按钮拉取最新内容

### 提交后列表中看不到自己的内容？

提交需经团队管理员合并到主分支后才会出现在所有人的列表中。

## 内容相关

### Rule 和 Skill 如何选择？

- 纯文本指令 → **Rule**
- 需要附带参考文件或示例 → **Skill**

详见 [核心概念](/guide/concepts)。

### Skill 附件有限制吗？

- 文件类型不限
- 单个文件不超过 10 MB
- 数量无硬性上限，建议控制在合理范围以便团队同步

### 已安装的内容可以卸载吗？

可以。删除编辑器规则目录中对应的文件或子目录即可。Synapse 写入的位置遵循各编辑器的官方规范，管理方式与手动维护一致。

### 项目级安装会影响其他项目吗？

不会。项目级安装仅作用于选定的目录。如需所有项目生效，请选择全局安装。

## 版本与更新

### 支持自动更新吗？

支持。新版本发布后应用内会提示更新，确认后自动下载安装。
