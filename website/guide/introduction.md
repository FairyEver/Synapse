# 产品介绍

## Synapse 是什么

**Synapse 是一个面向团队的桌面应用，帮你在团队内整理和分享 AI 提示词与能力包。**

团队里每个人都在积累自己的 AI 使用经验——

- 一段调教得很顺手的角色设定；
- 一份写代码、写文案、做分析的提示模板；
- 一个带着若干示例文件的完整工作流；
- 一套自己总结出的输出规范……

这些东西分散在每个人的聊天记录、备忘录、文件夹里，复用起来成本很高。Synapse 做的事情很简单：

> 把它们沉淀到同一个地方，让队友一键拿去用。

## 为什么叫 Synapse

Synapse 是"突触"——神经元之间传递信号的连接点。我们希望这个产品扮演同样的角色：

- 连接 **知识** 与 **使用者**
- 连接 **个人沉淀** 与 **团队复用**
- 连接 **AI 能力** 与 **真实工作环境**

好的想法不应该只留在一个人脑子里，也不应该被一堆私有文件夹埋起来。

## 适合谁使用

Synapse 适合任何已经在日常工作中使用 AI 编辑器的团队，典型场景包括：

- **工程团队**：统一项目的代码风格、审查标准、命名规则，让 AI 写出的代码符合团队约定。
- **产品/设计团队**：沉淀"写 PRD"、"写用户故事"、"生成文案"的提示模板。
- **运营/市场团队**：共享成熟的写作风格、营销文案模板、分析框架。
- **AI 爱好者社群**：把玩出来的好 prompt 有组织地分享，而不是丢在聊天群里被翻页淹没。

## 它不是什么

为了让定位更清晰，这里也说明 Synapse **不做**什么：

- 不是聊天机器人，它不直接和 AI 对话。
- 不是知识库问答工具，不做文档上传和 RAG。
- 不是笔记软件，不替代你已有的文档系统。
- 不托管你的内容，所有内容都保存在你自己的本地目录和 Git 仓库里。

> **把团队里好用的 AI 提示词和能力包，用最轻的方式整理、分享、安装。**
