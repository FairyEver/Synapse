# Apple Design 其他官方入口

这些入口与 [HIG 官方目录](hig-directory.md) 共同构成 Apple Design 的资料地图。资源与视频会更新，实际任务要进入当前页面读取相关内容。

| 内容 | 官方入口 | 使用时机 |
|---|---|---|
| Design 首页 | [Apple Design](https://developer.apple.com/design/) | 查看最新入口、专题与 Apple 设计内容 |
| 学习路线 | [Design Pathway](https://developer.apple.com/design/get-started/) | 需要基础概念与入口串联时 |
| 设计资源 | [Apple Design Resources](https://developer.apple.com/design/resources/) | 查 iOS/iPadOS UI Kit、图标模板、字体、素材与工具 |
| 设计视频 | [Design Videos](https://developer.apple.com/videos/design/) | 查对应主题的 Apple 讲座与示例；按当前目录选相关视频 |
| 图标与符号 | [SF Symbols](https://developer.apple.com/sf-symbols/)、[Icon Composer](https://developer.apple.com/icon-composer/) | 查符号、应用图标制作与当前工具要求 |

设计资源可能展示高于项目最低部署版本的系统外观。选用前核对 Apple 对应平台和版本的文档；视频、故事与模板不能替代 HIG 正文或 SwiftUI/UIKit API 可用性说明。
