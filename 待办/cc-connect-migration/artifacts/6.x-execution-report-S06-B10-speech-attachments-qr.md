## 原源码对照

已读取 CC Connect 源码和测试：

- `core/message.go`：复用 image/file/audio attachment 字段、`.cc-connect/attachments` 文件引用和 `AppendFileRefs` prompt 追加语义。
- `config/config.go`：复用 `attachment_send` 默认 `on`、合法值 `on/off`，以及 `[speech]`、`[tts]` provider、language、voice、model、base_url、tts_mode、max_text_len 配置。
- `cmd/cc-connect/main.go`：复用 speech provider 默认模型和 base URL、TTS provider 默认 voice/model/base URL、`tts_mode` fallback 和缺 API key warning 语义。
- `core/speech.go`、`core/speech_test.go`：复用 OpenAI/Groq/Qwen/Gemini STT 默认值、格式转换判断、API error、empty response 和 invalid JSON 错误分类。
- `core/tts.go`、`core/tts_test.go`：复用 Qwen/OpenAI/MiniMax/local TTS 默认值、`voice_only` 默认模式、`max_text_len` 跳过和 local provider constructor 默认值。
- `platform/wecom/websocket_media.go`、`platform/wecom/websocket_media_test.go`、`platform/wecom/inbound_file_test.go`：复用 media 最大 20MB、Content-Disposition 文件名解析、AES key URL-safe/hex 归一化、MIME magic/extension fallback。
- `platform/weixin/media_inbound.go`、`platform/weixin/media_outbound.go`、`platform/weixin/media_outbound_test.go`、`platform/weixin/weixin_test.go`：复用 CDN image/file/audio metadata、empty audio/reply context 错误和 AES key API 格式。
- `cmd/cc-connect/feishu.go`、`cmd/cc-connect/feishu_test.go`：复用 `setup/new/bind` 输入解析、`app_id:app_secret` 冒号 secret、QR begin/poll、slow_down、lark tenant switch、access denied 和 expired token 状态。
- `cmd/cc-connect/weixin.go`：复用 `setup/new/bind` token 模式、QR wait/scaned/expired/confirmed、缺 bot token/ilink bot id 错误和 cancel 状态。

迁移时保留的行为：

- 语音/TTS 只生成 provider plan 和 secret drafts，不真实调用 STT/TTS 服务，不运行 ffmpeg、espeak、pico 或 edge-tts。
- 附件服务只生成 metadata、hash、MIME、`.cc-connect/attachments` 引用和 prompt refs，不写业务附件文件。
- QR onboarding 只实现状态机和 mock poll 输入，不真实扫码、不发网络请求。
- Connector descriptor 补齐 Feishu/Lark/Weixin 的 media/audio/QR capabilities。
