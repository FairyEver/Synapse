# 8.4 CC Connect Admin -> 3S Gap List

## 当前 3S 入口状态

结论：当前 3S 不是完全入口缺失；`会话`、`连接`、`自动化` 已进入 App Shell，但仍接近最小骨架，和 CC Connect Admin 的可操作产品入口存在明显差距。

3S 源码证据：

| 能力 | 3S 文件 | 状态 |
| --- | --- | --- |
| 顶层入口 | `desktop/src/app-shell/tabs.ts` | 已注册 `agent-sessions`、`connectors`、`automation`，标签为 `会话`、`连接`、`自动化` |
| 顶层渲染 | `desktop/src/App.tsx` | 已根据 active tab 渲染 `AgentSessionsModule`、`ConnectorsModule`、`AutomationModule` |
| 会话模块 | `desktop/src/modules/agent-sessions/index.tsx` | 有 skeleton、空态、状态卡、消息区，但没有真实 Admin 会话列表/命令面板/会话抽屉/发送链路 |
| 连接模块 | `desktop/src/modules/connectors/index.tsx` | 有 skeleton、空态、能力卡，但没有项目平台列表、平台新增向导、QR/手动配置表单 |
| 自动化模块 | `desktop/src/modules/automation/index.tsx` | 有 Cron/Heartbeat/Hooks tabs 和空态，但没有 Admin 任务创建表单、任务列表、执行/权限/会话键配置 |

## 与 2.2 产品设计的入口对照

| 2.2 目标入口 | Admin 实测 | 当前 3S | 结论 |
| --- | --- | --- | --- |
| 会话 | `/chat`、`/chat/:name`，可进入真实历史和命令面板 | `desktop/src/modules/agent-sessions/index.tsx` 有入口但无真实数据/命令/详情 | 入口存在，产品能力不足 |
| 连接 | `/projects`、项目详情添加平台、`/providers` | `desktop/src/modules/connectors/index.tsx` 有入口但仅 skeleton | 入口存在，平台/provider 配置未承接 |
| 自动化 | `/cron`、项目 Heartbeat、命令面板 `/cron` | `desktop/src/modules/automation/index.tsx` 有入口但仅空态 tabs | 入口存在，任务配置未承接 |

## 是否应视为阻塞

是。阻塞不是视觉美化，而是迁移后用户无法在 3S 中完成 Admin 已具备的核心路径：

- 查看项目和连接状态。
- 新增/配置平台连接。
- 管理 provider。
- 打开真实会话、查看历史、使用命令面板。
- 创建定时任务和管理 Heartbeat。
- 管理 CC Connect 专属系统设置。
