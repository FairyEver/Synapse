## 重点观察风险

- Chat 发送：当前代码路径可能返回 `agent runtime is not connected`；这不是空壳，但不应被验收成真实 agent runtime 已接通。
- Provider / Connector secret：检查 API key/token 是否不明文泄漏；同时记录 secret value 是否能在真实运行时被取回。
- QR 平台：当前是 draft/onboarding 入口，不等同于真实扫码登录闭环。
- Heartbeat / Hooks / 高危命令：确认权限提示存在；不要把未接 runtime 的保护性错误判定为真实执行成功。
- Bridge / Webhook / Local API / Management / daemon：当前以设置/诊断体系承接，不能验收成独立 server、daemon 管理器或自更新器。

- A-E 人工验收全部完成。
