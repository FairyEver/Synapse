## 原源码对照

已读取 CC Connect 源码和测试：

- `README.md`：复用平台能力快照和“聊天平台连接本机 agent”的主流程定位。
- `core/interfaces.go`：复用 `MessageHandler`、`TypingIndicator`、`MessageUpdater`、`InlineButtonSender`、`CardSender`、`CardNavigable`、`CardRefresher` 等 optional capability 语义。
- `core/card.go`、`core/card_test.go`：复用 card header、markdown、divider、actions、list item、select、note、fallback text、HasButtons 和 CollectButtons 行为。
- `core/markdown_html.go`：确认 Markdown 到平台受限渲染的降级思路；本批 renderer 不引入自定义 Markdown 风格。
- `platform/feishu/card.go`、`platform/feishu/card_test.go`：复用 Feishu card action row/equal columns/list item/select、session key 注入和 fallback intent 语义。
- `tests/integration/engine_platform_test.go`：复用平台 handler 接收消息、agent session 独立性、平台 reply 和 card rendering integration 的主路径。
- `core/bridge.go`：复用 card/buttons/typing capability 降级和 card action 转 message/navigation 的分发语义。

迁移时保留的行为：

- connector 入站消息先归一化，再用 `sessionKey` 找到或创建 active session，写入 user/chat meta，并交给 engine turn。
- agent result 通过 reply context 回到 connector；permission request 保持 pending，不猜测用户决定。
- 富交互 renderer 保存 action intent；renderer 只上报交互，不执行敏感动作。
- 平台不支持 card/buttons 时使用与 CC `Card.RenderText()` 等价的 fallback。
- UI 仅使用现有 shadcn/Radix 组件和 token class，不新增自定义颜色、内联样式或旧 Web Admin 视觉。

## 实现摘要

- 新增 `desktop/src/types/agent-session.ts`，定义 session message、rich card、interaction 和 connector session turn 的 renderer-safe 类型。
- 新增 `desktop/src/modules/agent-sessions/message-interactions.ts`，实现 card fallback、button/select intent collection、capability fallback 和 action dispatch intent。
- 新增 `desktop/src/modules/agent-sessions/components/message-renderer.tsx`，用现有 shadcn/Radix primitive 渲染 card、button、select 和 fallback text。
- 新增 `desktop/electron/services/agent-session-connect-service.ts`，实现 normalized inbound message 到 session repository + engine service + outbound reply context 的主流程。
- 新增 `desktop/tests/unit/agent-session-connect.test.ts`、`desktop/tests/unit/message-interactions.test.ts`，覆盖 connector-to-session flow、permission pending、prompt assembly、card fallback、interaction intent 和平台降级。
