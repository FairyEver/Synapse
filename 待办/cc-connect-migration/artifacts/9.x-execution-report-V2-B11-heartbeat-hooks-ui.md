## 实现内容

- 新增 `AutomationRuntimeStoreService`：
  - 使用 DataRepository JSON namespace `automation.runtime` 持久化 Heartbeat 和 Hooks。
  - Heartbeat 复用既有 `AutomationHeartbeatService`，保留 enabled、paused、interval、onlyWhenIdle、sessionKey、prompt、silent、timeout、run/error/skipped/last state。
  - 从项目配置中的 `heartbeat` 种子数据初始化自动化 Heartbeat 列表。
  - Hooks 复用既有 `AutomationHookManager`，保留 event、type、command/url、timeout、async、lastRun、lastError、lastResult。
  - Command Hook 测试只返回 permission-required plan，不直接执行 shell。
- `automation` IPC / preload / bridge 新增：
  - `listHeartbeat`
  - `upsertHeartbeat`
  - `pauseHeartbeat`
  - `resumeHeartbeat`
  - `setHeartbeatInterval`
  - `triggerHeartbeat`
  - `listHooks`
  - `createHook`
  - `updateHook`
  - `deleteHook`
  - `testHook`
- 自动化页 Heartbeat tab 从空态接入真实数据：
  - 表格展示项目、状态、session key、interval、run/error/skipped、last run、last error。
  - 支持新建/编辑、暂停/恢复、立即触发。
- 自动化页 Hooks tab 从空态接入真实数据：
  - 表格展示事件、项目、目标、timeout、async、最近结果。
  - 支持 command/http 新建、编辑、删除、测试。
- 扩展 Heartbeat/Hook 单测，覆盖持久化、默认值、状态更新、permission gate 和校验错误。

## 手工验收脚本

1. 进入 `自动化 > Heartbeat`。
2. 点击 `新建`，选择项目，填写 Session Key、间隔和超时，保存。
3. 确认 Heartbeat 出现在列表，状态、间隔、运行计数可见。
4. 点击 Power 图标暂停，再恢复。
5. 点击运行图标触发一次，确认最近运行或错误更新。
6. 进入 `自动化 > Hooks`。
7. 新建 command hook，填写事件和命令，保存。
8. 点击测试，确认最近结果显示 `permission_required`，且没有直接执行 shell。
9. 新建或编辑 HTTP hook，填写 `http://` 或 `https://` URL，确认校验生效。
10. 删除 Hook，确认从列表移除。
