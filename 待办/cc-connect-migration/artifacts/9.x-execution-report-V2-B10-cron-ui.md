## 实现内容

- 新增 `AutomationCronStoreService`：
  - 使用 DataRepository JSON namespace `automation.cron` 持久化 jobs。
  - 复用 `AutomationCronScheduler`、`validateCronExpression`、`cronExprToHuman`、session mode 和 timeout 语义。

  - `listCron`
  - `createCron`

  - `toggleCron`
  - `deleteCron`
- 更新 IPC codegen source，生成 `automation` channels。
- 自动化页 Cron tab 从空态接入真实任务：
  - 表格展示任务、项目、计划、下次运行、最近结果。
  - 支持新建 Prompt Cron。
  - 支持新建 Exec Cron，并在保存前确认。

## 手工验收脚本

1. 进入 `自动化 > 定时任务`。
2. 点击 `新建`。
3. 选择项目、schedule，填写 Prompt 并保存。
4. 确认任务出现在列表，且展示下次运行。
5. 点击 Power 图标停用，再启用。
6. 点击编辑，修改 schedule 或描述并保存。
7. 新建 Exec 任务，确认出现权限确认。
8. 点击拒绝，确认不创建；再次保存并点击继续，确认创建。
9. 点击删除并确认，任务从列表移除。
