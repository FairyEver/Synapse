## 实现内容

- `AgentSessionsStoreService` 新增 `sendMessage`：
  - main 侧校验 `message is required`。
  - session 缺失返回 `session not found`。
  - 调用 `AgentEngineService.processTurn`，沿用先写 user history、再处理 success/error/timeout 的旧 engine 边界。
  - 成功时写 assistant history 并保存 `agentSessionId`。
  - error/timeout 保留 user history，并把错误返回给 renderer。
- `agent-sessions` IPC / preload / bridge 增加 `send`。
- 会话 UI 增加输入区：
  - Enter 发送，Shift+Enter 换行。
  - 发送时显示乐观 user 消息和发送中按钮。
  - 成功后刷新 detail history 和列表摘要。
  - 失败时恢复输入内容，显示可恢复错误。
- 单元测试覆盖：
  - send success：user + assistant history、agent session id 保存。
  - send error：状态为 `error`，保留 user history。
  - send timeout：状态为 `timed_out`，错误为 `agent session timed out (no response)`。
  - 空输入拒绝。
