## 3S 侧迁移决策

- 复用 3S 已有 `desktop/electron/services/automation-heartbeat-service.ts` 和 `desktop/electron/services/automation-hooks-service.ts`，不重写核心逻辑。
- Heartbeat 和 Hooks 的持久化通过 DataRepository JSON namespace 落在 Electron main service，renderer 只走 `window.synapse.automation.*` typed bridge。
- 命令 hook 在 UI 的测试入口只返回 permission-required plan，不直接执行 shell；HTTP hook 测试沿用服务注入 transport，未配置时返回明确错误。
- Heartbeat UI 还原旧 Web 的状态字段和操作；Hooks UI 还原事件、类型、command/url、timeout、async 字段和校验。
- UI 使用现有 shadcn 组件和 Tailwind token，不移植旧 Web 自定义样式。
