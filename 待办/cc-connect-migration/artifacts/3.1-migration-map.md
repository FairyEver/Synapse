# 3.1 Migration Map

## 映射原则

本映射承接 `2.2-product-design.md` 的产品归属，不改变菜单、入口和用户流程。renderer 只负责会话、连接、自动化、设置、IDE 和内容资产界面；agent、connector、automation、provider、webhook、bridge、daemon、secret、network bind、shell/process 均落在 Electron main process，并通过 typed preload 暴露到 `window.synapse.*`。

新增 renderer 业务模块建议仍限制在：

- `desktop/src/modules/agent-sessions/`
- `desktop/src/modules/connectors/`
- `desktop/src/modules/automation/`

新增 Electron 业务模块建议使用：

- `desktop/electron/modules/agent-sessions/ipc.ts`
- `desktop/electron/modules/connectors/ipc.ts`
- `desktop/electron/modules/automation/ipc.ts`
- `desktop/electron/modules/providers/ipc.ts`

新增 service 通过 `ServiceRegistry` 注入；新增 IPC 通过 `IpcRegistry` 注册；新增持久化通过 `DataRepository.namespace(name)`；新增网络服务通过 `NetworkServiceRegistry`；敏感操作通过 `PermissionGuard` 和 `AuditSink`。
