# 3.3 Permission And Security Map

## 安全边界原则

所有 shell、文件、网络、端口、git、token、进程、插件、下载、安装能力只能在 Electron main process 中执行。renderer 不直接接触 `ipcRenderer`、文件系统、进程、网络监听或 secret 明文；preload 只暴露窄 typed API。敏感操作必须通过 `PermissionGuard.check()`，并记录到 `AuditSink`。日志输出必须使用结构化 logger 并做 secret/token/path 级别脱敏。
