# 14.0 Feishu/Lark Runtime State

更新时间：2026-04-26 CST

## 当前结论

Synapse Stage 13 已完成 Feishu/Lark QR registration 的 main 侧 begin/poll/save 和 secretRef 保存，但没有完整迁移 CC Connect 的 Feishu/Lark 平台运行时。扫码保存后只会写入项目 `platformConnections`，不会启动或重载 WebSocket 长连接，也不会接收 Feishu/Lark 事件、调用 Synapse session/agent 链路、再把回复发回 Feishu/Lark。

## 已确认现状

| 能力 | 当前 Synapse 状态 | 证据 |
| --- | --- | --- |
| 平台 descriptor | 内置 Feishu/Lark 以及 DingTalk/Telegram/Slack/Discord/LINE/WeCom/Weibo/Weixin/QQ/QQBot 等 | `desktop/electron/services/connector-registry-service.ts` |
| QR registration | Feishu/Lark 已有 begin/poll/save；poll 可识别 `tenant_brand=lark` 并切到 Lark accounts domain | `desktop/electron/services/connector-qr-onboarding-service.ts` |
| secret 安全 | QR 成功后的 `app_secret` 不返回 renderer，保存时写 secret store，config 只留 `secretRefs.app_secret` | `desktop/tests/unit/connector-qr.test.ts` |
| UI | 添加平台弹窗仍暴露多个手动平台和 Weixin QR；二维码状态缺少“启动/重载连接中” | `desktop/src/modules/connectors/index.tsx` |
| runtime service | 未发现 Feishu/Lark runtime descriptor 或服务；`connectors.qr-onboarding` 保存后未触发 runtime | `desktop/electron/bootstrap/descriptors.ts`、`desktop/electron/bootstrap/registry.ts` |
| session 链路 | 已有 `AgentSessionConnectService` 可把 `SynapseInboundMessage` 转为 session turn，并生成 outbound reply/pending/error | `desktop/electron/services/agent-session-connect-service.ts` |
| outbound sender | 无 Feishu/Lark outbound sender；`BridgeService` 只处理桥接 adapter 的抽象 reply context | `desktop/electron/services/bridge-service.ts` |

## Stage 14 目标

- 当前内置平台入口只保留 `feishu` 和 `lark`，保留 registry 可扩展能力。
- 非 Feishu/Lark 历史配置不自动删除，读取展示为 legacy/unsupported，不允许继续新增。
- QR 保存成功后启动或重载对应项目的 Feishu/Lark runtime。
- runtime 使用 Feishu/Lark 长连接接收事件，转换为 `SynapseInboundMessage`。
- inbound 进入 Synapse session/agent 链路，agent 回复通过 Feishu/Lark API 发回。
- `app_secret` 仍只在 main 侧 secret store 中读取和使用，不进入 renderer、日志或报告。

## 当前阻塞风险

- 真实 Feishu/Lark 长连接验收需要可用账号、扫码手机、开放平台权限、应用发布与事件订阅；如权限缺失，应暂停并写明需要用户在飞书/Lark 后台补的步骤。
- Synapse 当前 agent runtime 仍是 Stage 6/9 的本地 event 模拟/未完全连接状态；Stage 14 会接入现有 `AgentSessionConnectService` 和 `AgentSessionsStoreService`，真实 agent 后端能力以当前项目已有实现为边界。
