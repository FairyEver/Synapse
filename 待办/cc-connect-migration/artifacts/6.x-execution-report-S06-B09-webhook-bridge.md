- `core/bridge_test.go`：复用 adapter 替换、认证失败、消息路由、image payload、reply ctx、session create/list/detail/delete/switch、card fallback/native 和 ping 样本。

- `config.example.toml`：复用 `[webhook]` 和 `[bridge]` 默认配置、token/path/port 字段。

迁移时保留的行为：

- 所有网络入口只生成 `NetworkServiceRegistry` descriptor，不裸用 `http.createServer`，不启动真实 listener。
- token 使用 bearer secretRef 或 in-memory token 校验，delivery/session 记录不保存 raw token。
- webhook `exec` 只记录 permission-gated delivery，不在本批执行 shell。
- bridge adapter/session 状态保留在服务层模型，覆盖 register、replace、capabilities snapshot、message normalization、reply ctx 重建、progress hints、card action 和 session create/switch/delete。
- bridge wire payload 兼容 CC 的 `mime_type` / `file_name` 附件字段。
