## 手工验收脚本

1. 进入 `设置 > 服务商`。
2. 点击 `添加服务商`。
3. 填写名称、API Key、Base URL、默认模型、Agent，保存。
4. 确认列表显示 provider，密钥列显示 secretRef 状态，不显示 API Key。
5. 编辑 provider，留空 API Key 保存，确认原密钥引用保留。
6. 打开 `导入 CC-Switch`，粘贴 providers JSON，确认成功、重复和错误状态可见。
7. 切换 `预设`，点击 `预填`，确认表单带入 preset 字段。
8. 删除 provider，确认弹窗出现；确认删除后，项目同名 `providerRefs` 被移除。
