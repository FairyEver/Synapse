# 4.3 Manual Acceptance Script

## 人工验收原则

人工验收只覆盖无法稳定自动化或需要确认用户入口、状态反馈、权限确认、错误态、空状态的流程。执行时不得启动未授权的外部服务或真实系统服务；涉及 daemon、Management API、QR、平台连接时优先使用 mock、测试账号或隔离环境。所有截图、日志和审计记录在执行阶段补充到本脚本的证据列。
