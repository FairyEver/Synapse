# 8.5 CC Connect Admin Layout And Flow Map

## 总体信息架构

```text
App Shell
├─ 概览
│  ├─ 运行指标
│  ├─ 项目摘要 -> 项目列表 / 项目详情
│  └─ 最近会话 -> 对话列表 / 对话详情
├─ 项目
│  ├─ 项目列表
│  ├─ 新增项目 -> 平台选择 -> QR 或手动配置
│  └─ 项目详情
│     ├─ 概览 -> 添加平台
│     ├─ 服务商 -> 关联全局 / 自定义添加
│     ├─ 心跳
│     └─ 设置 -> 项目级配置 / 平台访问控制 / 删除确认
├─ 服务商
│  ├─ 我的服务商 -> 添加 / 编辑 / 删除
│  ├─ CC-Switch 导入
│  └─ 推荐预设 -> 预填添加表单
├─ 技能
│  ├─ 本地技能 -> 项目切换
│  └─ 推荐 -> 刷新 / 外部来源
├─ 对话
│  ├─ 对话列表 -> 项目对话详情
│  └─ 对话详情
│     ├─ 会话抽屉
│     ├─ 命令面板
│     ├─ 消息历史
│     └─ 输入发送
├─ 定时任务
│  ├─ 任务列表
│  └─ 添加任务 -> Prompt / Exec -> schedule / session / permission
└─ 系统
   ├─ 全局设置
   ├─ Raw TOML
   ├─ 重载配置
   └─ 重启服务
```

## 核心功能连接关系

| 功能链路 | Admin 实测路径 | 数据/动作关系 | 当前 3S 承接 |
| --- | --- | --- | --- |
| 项目 -> 平台 -> 会话 | `/projects` -> `/projects/:name` -> 添加平台 -> `/chat/:name` | project 是平台连接和会话的共同父对象 | 入口分散在 `connectors` 与 `agent-sessions` skeleton，缺少 project 维度 |
| 项目 -> Provider | `/projects/:name` -> 服务商 Tab -> 关联全局/自定义 | 项目可以绑定全局 provider 或自定义 provider | 3S 尚无完整 provider UI |
| Provider -> Preset/Import | `/providers` -> 推荐预设/CC-Switch 导入 | provider 可从 preset 或外部配置导入 | 3S 尚无等价入口 |
| 项目 -> Heartbeat | `/projects/:name` -> 心跳 Tab | heartbeat 是项目级自动化状态 | 3S Automation 有 Heartbeat Tab，但无项目配置 |
| Chat -> 命令 -> Automation/Settings | `/chat/:name` -> 命令面板 -> `/cron`、`/model`、`/provider` 等 | 命令面板连接会话、provider、自动化、系统信息 | 3S 会话模块无命令面板 |
| Cron -> Project/Session/Permission | `/cron` -> 添加任务 | 任务必须绑定项目，可选会话键和权限模式 | 3S Automation 无真实表单 |
| System -> Global Config | `/system` | 全局配置影响平台、会话、流式预览、速率限制和日志 | 3S 设置未显式承接 CC Connect 专属项 |

## CC ID 相关映射

| 能力 | Admin 入口 | 相关 CC ID | 3S 下一步 |
| --- | --- | --- | --- |
| App Shell / Web Admin | Sidebar + Header + routes | CC-036 | 已有入口，但需把 Admin 功能落到 3S 模块 |
| Project / workspace | `/projects`、`/projects/:name` | CC-001、CC-002 | 需要项目列表和详情 |
| Provider | `/providers`、项目服务商 Tab | CC-004、CC-005、CC-006 | 需要 provider 管理 UI |
| Connectors / platform setup | 新增项目平台流、添加平台 | CC-007 至 CC-014 | 需要平台向导和表单 |
| Sessions / Chat | `/chat`、`/chat/:name` | CC-015、CC-016、CC-017 | 需要真实会话和命令面板 |
| Automation | `/cron`、Heartbeat | CC-018、CC-019、CC-020 | 需要任务与 Heartbeat UI |
| Skills | `/skills` | CC-024、CC-025 | 需要确认与 3S Skills 的承接方式 |
| Locale | Header language、System language、项目 language | CC-029 | 3S 已有底层闭合后仍需项目级用户入口 |
| System settings | `/system` | CC-030、CC-031、CC-032 | 需要 CC Connect 专属设置页 |

## 产品入口优先级

| 优先级 | 入口 | 原因 |
| --- | --- | --- |
| P0 | 项目列表/详情 | 其他能力都依赖 project 维度 |
| P0 | 会话列表/详情 | Admin 最核心日常入口 |
| P0 | 平台连接向导 | 迁移后的 connector 必须可配置 |
| P1 | Provider 管理 | 影响 agent 能否使用模型服务 |
| P1 | Cron/Heartbeat | 自动化能力已有底层迁移，缺少入口 |
| P1 | 系统设置 | 全局参数和语言偏好需要用户可见 |
| P2 | Skills 推荐/扫描对照 | 3S 已有 Skills，需要等价性审计 |

## 布局复用建议

| Admin 模式 | 3S 可承接位置 | 备注 |
| --- | --- | --- |
| Sidebar 一级导航 | 已有 App Shell top tabs | 不建议复制 Admin 左侧导航；应融入 3S 当前导航 |
| Project 卡片 + Detail tabs | 新建 CC Connect project 视图或 Connectors 内项目分栏 | 避免把所有连接做成无项目的平铺卡片 |
| Provider Tab 页面 | Settings 或 Connectors 的 provider 子页 | 需要保留 import/preset/per-agent 配置 |
| Chat detail + session drawer | AgentSessionsModule | 需要承接历史、命令、会话切换 |
| Cron modal | AutomationModule | 保留 Prompt/Exec、schedule、session、permission |
| System form | SettingsModule 下 CC Connect 分组 | Raw config 必须做 secret redaction |
