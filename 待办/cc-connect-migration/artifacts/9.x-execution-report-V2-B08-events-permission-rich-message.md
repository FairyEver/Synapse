## 实现内容

- `AgentSessionsStoreService.sendMessage` 返回本轮有序 event records 和 `pendingPermission`。
- main 侧新增 pending permission 记录和 `respondPermission`：
  - 校验 project/session/request/decision。
  - allow/deny 写入 `permission_response` event，保持 seq 顺序。
  - request 已处理后再次响应返回 `permission request not found`。
- `SessionEventLog` 增加 `permission_response` 映射。
- `agent-sessions` IPC / preload / bridge 新增 `respondPermission`。
- 会话 UI 增加事件流：
  - thinking/text/result 使用轻量 Markdown + code fence 展示。
  - tool_use/tool_result 展示工具名、输入/输出、状态、exit code、success。
  - code block 支持复制。
  - permission_request 使用富消息 renderer 展示 allow/deny 操作。
  - permission_response 展示最终决策。
  - error 以可见错误状态展示。
- `MessageRenderer` 从 shadcn Card 改为普通边框容器，避免会话详情中出现卡片套卡片。

3. 发送可触发 thinking/tool/result/error 的消息。
