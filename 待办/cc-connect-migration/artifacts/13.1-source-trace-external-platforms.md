## 目标落点

- Feishu/Lark：`beginQr(feishu|lark)` 在 main 调 Feishu registration `init/begin`，renderer 只收到 `qrContent/sessionId/status`；`pollQr` 成功时 app_secret 只留在 main session；`saveQr` 写 encrypted `secrets`，config 保存 `app_id/owner_open_id/secretRefs.app_secret`。
- Weixin：`beginQr(weixin)` 在 main 调 ilink QR API；`pollQr` 识别 `wait/scaned/expired/confirmed`；`confirmed` token 只留在 main session；`saveQr` 写 encrypted `secrets`，config 保存 `base_url/account_id/ilink_user_id/secretRefs.token`。
- 手动平台：renderer 动态读取 connector descriptors；secret 字段用 password input；`saveManualPlatform` 在 main 写 secret store 后更新项目平台连接。
- UI：只使用 shadcn/ui 和 Tailwind token，不新增自定义颜色，不写内联样式，不做草稿扫码假象。
