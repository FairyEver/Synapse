## 实现内容

- 在项目详情中新增 `添加平台` 入口。
- 平台向导支持：
  - 手动 Token 平台：`Telegram`
  - QR 平台草稿：`Feishu`、`Lark`、`Weixin`
- Telegram 表单包含：
  - `Token`
  - `允许用户`
  - `群聊全部回复`
  - `频道共享会话`
- Telegram 保存路径复用 `window.synapse.connectors.createDraft`，只持久化 connector metadata 与 `secretRefs`，不写入 `draft.secrets[].value`。
- QR 平台显示 `idle/waiting/expired/error/success` 状态；当前 Synapse 缺少旧 Web Admin 的 QR begin/poll/save 后端能力，因此本批保存为 disabled draft，不伪造扫码成功。
- 项目平台列表从项目配置渲染，减少内层卡片嵌套。

## 手工验收脚本

1. 进入 `连接`。
2. 新建或选择一个项目。
3. 进入项目详情。
4. 点击 `添加平台`。
5. 选择 `Telegram`，确认看到 `Token`、`允许用户`、`群聊全部回复`、`频道共享会话`。
6. 填写 Token 后保存，确认项目平台列表出现 Telegram，配置中只存在 `secretRefs.token`。
7. 再次打开 `添加平台`。
8. 选择 `Feishu`、`Lark` 或 `Weixin`。
9. 点击 `开始设置`，确认状态进入 `等待扫码`。
10. 点击 `标记过期` 或 `标记错误` 后可重试；点击 `保存草稿` 后进入 `草稿已保存`。
