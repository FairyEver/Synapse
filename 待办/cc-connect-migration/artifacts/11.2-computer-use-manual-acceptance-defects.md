# 11.2 Computer Use 人工验收缺陷清单

ID: CUA-001
验收段落: A. 项目和连接
步骤: A-8 QR 平台保存草稿
状态: fail
期望: 点击 `保存草稿` 后，平台页应出现对应 Feishu/QR 平台记录，或给出明确的未保存/仅草稿位置说明。
实际: UI 显示 `草稿已保存`，但返回平台页仍显示 `暂无平台`，项目平台数仍为 0。
证据: Computer Use 操作 Feishu 平台进入 `等待扫码` 后点击 `保存草稿`；完成弹窗后平台列表为空。
是否属于已确认裁剪点: 否。QR 只做 draft 可以接受，但保存成功后不可见不属于裁剪点。
是否阻塞发布候选: 是。
建议下一步: 修复平台草稿持久化或改为明确的未保存反馈；补充测试覆盖列表刷新和计数更新。
