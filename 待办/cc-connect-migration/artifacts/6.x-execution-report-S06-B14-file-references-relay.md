迁移时保留的行为：

- 文件引用只解析 workspace 内路径；workspace 外路径拒绝，不做越权读取。
- 文件展示支持 head/context/range/directory，目录不能携带 line/location。
- 本批服务层实现读取文件和目录；renderer 不直接读文件。
- Relay service 只用注入 handler 模拟目标 agent，不启动真实多 agent 进程。
- Relay 保留 exact project name、binding、timeout/partial、permission auto approve 和 group visibility message。
