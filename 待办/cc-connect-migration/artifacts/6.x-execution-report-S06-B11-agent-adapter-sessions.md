迁移时保留的行为：

- Adapter service 只构建 launch spec 和 injected availability，不调用 `exec.LookPath`，不启动真实 CLI，不从 renderer 启动进程。
- `__continue__` 只作为继续当前会话的 sentinel，不写入 agent session ID，也不传给 `--resume`。
- Codex resume argv 不包含 `--cd`，fresh argv 包含 `--json --cd <workDir> -`。
- Session repository 只做内存模型和 snapshot 转换，不用 `fs.writeFile` 持久化业务数据。
