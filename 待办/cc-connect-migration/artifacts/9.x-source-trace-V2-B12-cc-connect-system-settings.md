## 3S 侧迁移决策

- 3S 不直接读写旧 `config.toml`，而是在 DataRepository `core.config` 中增加 typed `global.ccConnect` 设置，保留旧 Web 字段、默认值和命名。
- Raw TOML 使用 3S 当前配置生成只读预览，并对 `token`、`secret`、`api_key`、`password` 等敏感键做脱敏。
- reload/restart 不直接执行进程重启；通过 main IPC 返回受保护结果并记录时间，UI 需要确认后才调用。
- 设置 UI 放入 `设置 > CC Connect`，使用现有 shadcn/Radix 组件和 Tailwind token。
