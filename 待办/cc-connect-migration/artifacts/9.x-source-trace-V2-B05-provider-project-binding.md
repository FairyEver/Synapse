## 要还原到 Synapse 的逻辑

- 项目详情 `服务商` Tab 不能只显示 badge，必须支持：
  - 显示已绑定的全局 Provider refs。
  - 显示项目级自定义 Provider。
  - 过滤可绑定全局 Provider：已绑定跳过，`agentTypes` 不匹配跳过。
  - 绑定全局 Provider：写入 `project.providerRefs`。
  - 解绑全局 Provider：从 `project.providerRefs` 移除。
  - 添加自定义 Provider：写入项目级 inline provider。
  - 删除自定义 Provider：从项目级 inline provider 移除。
- 自定义 Provider 必须使用 secretRef：
  - 表单可输入 API Key。
  - project config 只保存 provider metadata + `secretRef`。
  - 不把 API Key 明文保存进 project JSON、日志、报告或通知。
- 会话/后续执行读取项目 Provider 的数据入口：
  - 使用 `resolveProjectProviders(global.providers, project.providers, project.providerRefs, project.agentType)`。
  - inline provider 同名覆盖 global ref。
  - per-agent endpoint/model/models 覆盖沿用 V2-B04 纯函数。
