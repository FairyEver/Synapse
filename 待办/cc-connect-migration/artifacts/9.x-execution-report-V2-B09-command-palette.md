## 手工验收脚本

1. 进入 `会话`。
2. 新建或选择一个会话。
3. 点击输入区命令按钮，或在空输入框按 `/`。
4. 搜索 `status`。
5. 执行 `/status`，确认结果面板展示当前项目和会话状态。
6. 搜索并执行 `/new`，确认会话列表和详情切换到新会话。
7. 搜索 `/shell`，确认出现权限确认。
8. 点击拒绝，确认结果显示已拒绝。
