## 实现内容

- 新增 main 侧 `AgentSessionsStoreService`：
  - 通过 DataRepository JSON namespace `agent.sessions` 持久化项目 session snapshot。
  - 沿用旧 SessionManager 字段和边界：`sessionKey`、`active`、`historyCount`、`lastMessage`、`agentSessionId`、`userName`、`chatName`。
  - 支持列表、详情、新建 session、切换 active session。
  - 列表按 `updatedAt || createdAt` 倒序，`lastMessage.content` 截断到 200 字符。
  - detail 默认读取最近 200 条历史。
- 新增 `agent-sessions` IPC 模块和 preload bridge：
  - `list`
  - `getDetail`
  - `create`
  - `switchSession`
- 会话 UI 从空壳改为真实数据页：
  - 左侧读取 main 侧真实 session 列表。
  - 右侧读取选中 session 的 detail history。
  - 支持新建项目默认 Web 管理会话：`bridge:web-admin:${projectName}`。
  - 空列表、空消息、错误、加载状态均来自真实状态，不注入假数据。
- 更新 IPC codegen manifest 和生成文件。

## 手工验收脚本

1. 进入 `会话`。
2. 点击 `新会话`。
3. 确认左侧出现项目 session，平台为 `bridge`，消息数为 `0`。
4. 点击该 session，确认右侧显示空消息状态。
5. 点击刷新，确认 session 仍存在。
6. 有历史消息后再次进入该页，确认左侧显示最后一条消息摘要，右侧显示 detail history。
