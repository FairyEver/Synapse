# 4.2 Golden Test Cases

## Golden 样本原则

Golden cases 用于比较 CC Connect Go 原实现和 3S TypeScript/Electron 实现的输入输出等价性。这里不写测试代码，只定义执行迁移后必须落地的样本、边界样本、错误样本和等价判断规则。证据来源优先使用 `/Users/liyang/Desktop/code-guide/cc-connect-main` 的 Go tests、core、agent、platform、config、daemon 和 cmd 资产。
