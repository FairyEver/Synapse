## 人工验收脚本

1. 打开 3S。
2. 进入 `Skills`。
3. 确认默认仍显示 `内容库`。
4. 切换 `项目扫描`。
5. 选择已有 IDE / agent，查看项目维度的 Skill 列表。
6. 点开 Skill，确认可看到内容预览、路径和附件文件列表。
7. 点击路径按钮，确认能在系统文件管理器定位到该 Skill。

- Skills 中能找到项目扫描入口。
- 项目扫描数据来自本机配置项目和 editor-scan IPC，不是硬编码。
- 未配置项目、项目路径不存在、扫描失败时有空态或错误反馈。
