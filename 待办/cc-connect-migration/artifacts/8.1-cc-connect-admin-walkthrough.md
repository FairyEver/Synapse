## 安全跳过清单

| 操作 | 跳过原因 |
| --- | --- |
| 退出登录 | 会破坏当前登录态 |
| 保存项目/服务商/系统设置 | 会真实修改配置 |
| 删除项目/服务商 | 破坏性操作 |
| CC-Switch 导入 | 会真实写入 provider |
| 重载配置/重启 | 会影响正在运行的 Admin 服务 |
| 开始 QR 设置 | 会启动真实平台绑定流程 |
| 发送聊天消息 | 会真实发送消息到 Agent/平台 |
| 选择命令面板命令 | 源码显示会通过 bridge 发送命令 |
| 新建会话 | 源码显示会发送 `/new` |
| 复制消息/密钥显示 | 会触发剪贴板或暴露敏感数据 |
| 外部注册/下载链接 | 会离开当前 Admin 页面 |
| 原始 TOML 截图 | 面板含 token、secret、API key 等敏感字段 |
