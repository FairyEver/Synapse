|---|---|---|
| 输入 API 令牌并登录 | 否 | API 令牌是敏感凭据，当前未提供、未授权读取 |

| 保存/创建/删除/重启/发送消息/执行命令/触发 cron | 否 | 登录未完成；即使登录后也需要按提示词只观察，不执行最终动作 |
