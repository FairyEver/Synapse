迁移时保留的行为：

- connector 草稿不保存 raw secret；平台 token/app secret 转成 `secretRefs` + secret draft。
- 未启用真实平台连接，状态只根据配置得到 `configured`、`disabled`、`invalid`。
- connector type 通过 registry 注册，不新增硬编码 enum。
- inbound normalizer 以 CC `core.Message` 为输入形状，覆盖文本、图片、文件、音频、位置、reply context、voice、mode override、诊断摘要和 allow_from。
- session key builder 覆盖 Telegram topic、shared channel、WeCom 单聊 fallback、Lark/Feishu root thread key。

## 实现摘要

- 新增 `desktop/src/types/connector.ts`，定义 connector descriptor、connector draft、secret draft、inbound message、attachment、location、diagnostic 和错误分类。
- 新增 `desktop/electron/services/connector-registry-service.ts`，注册 Feishu/Lark/DingTalk/Telegram/Slack/Discord/LINE/WeCom/Weibo/Weixin/QQ/QQ Bot descriptors、capability map、必填配置和 secretRef 草稿。
- 新增 `desktop/electron/services/inbound-message-normalizer.ts`，实现统一入站消息归一化、allow_from 检查、空消息错误、附件/语音/位置归一化和 session key 构造。

- 新增 `desktop/tests/unit/connectors.test.ts` 和 `desktop/tests/unit/inbound-normalizer.test.ts`。
