## 还原到 Synapse 的逻辑

- 在 `设置` 中新增 `服务商` 分类和全局 provider 面板。
- 全局 provider CRUD 使用 3S `global.providers` 配置持久化。
- Provider 表单覆盖旧源码中的核心字段：
  - `name`
  - `API Key`
  - `agentTypes`
  - `baseUrl`
  - `model`
  - `models`
  - `thinking`
  - `codex.wireApi`
- API key 保存前先生成 `secretRef`，配置中只保存 provider metadata，不保存 API key 明文。
- 删除 provider 前确认；删除时同步移除项目 `providerRefs`。
- CC-Switch 导入首轮支持粘贴 cc-switch rows JSON 并预览冲突/可导入/错误；转换规则复用旧 CLI 中 claude/codex 的 `settings_config` 解析。
- Preset 助手首轮提供本地 preset，作为预填表单，不做 provider 商店。

## 未还原项

- 旧 Admin 的自动读取 cc-switch SQLite 需要 SQLite 运行时或系统 DB 读取能力；当前项目没有预授权新增依赖。本批用 JSON rows 导入预览承接转换和冲突提示，不自动扫描本机数据库。
- 远端 preset 拉取与 fallback URL 暂不在本批引入网络请求；本批使用内置首轮 preset 数据作为预填助手。
