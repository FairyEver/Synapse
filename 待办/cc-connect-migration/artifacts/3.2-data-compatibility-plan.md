# 3.2 Data Compatibility Plan

## 数据兼容原则

旧 CC Connect 数据与配置以 `/Users/liyang/Desktop/code-guide/cc-connect-main` 中的 Go、config、web、daemon、npm 资产为来源证据。进入 3S 后，业务数据通过 `DataRepository.namespace(name)` 或既有 content/config repository 保存；secret/token 只保存引用，不在普通 JSON、日志或 renderer state 中落明文。

| CC ID | 旧数据或配置来源 | 3S 目标数据模型或配置位置 | 字段映射 | 默认值 | 兼容读取策略 | 一次性迁移策略 | 失败回滚策略 | 导入导出影响 | 测试样例建议 |
