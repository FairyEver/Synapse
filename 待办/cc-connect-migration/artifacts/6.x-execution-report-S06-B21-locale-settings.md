## 原源码对照

- CC Connect `core/i18n.go` 支持 `auto`、`en`、`zh`、`zh-TW`、`ja`、`es`，并在 `/lang` 中接受 english/cn/zh_tw/jp/spanish 等别名；3S 在 `desktop/src/lib/locale.ts` 中实现相同支持集合和别名归一。
- CC Connect `DetectLanguage` 先检测日文假名，再检测中文 CJK 区间，再以西班牙语提示字符判定 `es`，否则回退 `en`；3S `detectSynapseLocale` 保留该顺序和边界。
- CC Connect `T` 对 `zh-TW` 先 fallback 到 `zh`，再 fallback 到 `en`，缺失 key 返回 key；3S `getLocaleFallbackChain` 和 `InMemoryI18nProvider.t` 保留该规则。
- CC Connect `config.Config.Language` 和 `SaveLanguage` 持久化全局语言偏好；3S 合并为 `SynapseGlobalConfig.locale`，设置 > 通用提供 select，配置 sanitize 支持旧 `global.language` 到 `global.locale` 的兼容映射。
- CC Connect Web `i18next` 使用 `cc_lang` 和 `fallbackLng: "en"`；3S 不引入新依赖，使用现有 runtime i18n provider 实现同等 fallback 和语言偏好入口。

## 实现

- 新增 `desktop/src/lib/locale.ts`，封装 locale 归一化、语言检测、fallback chain 和显示名。
- 扩展 `desktop/src/types/config.ts`、`desktop/src/constants/defaults.ts`、`desktop/src/lib/config.ts` 和 `desktop/electron/services/config-backup-service.ts`，支持 `global.locale` 默认值、校验、备份和 legacy `language` 兼容。

- 更新 `desktop/src/app-shell/config.tsx`，在全局配置 locale 变化时同步 runtime i18n provider。

- 新增 `desktop/tests/unit/locale-settings.test.ts`，覆盖 CC Connect 语言别名、检测边界、fallback chain、settings patch 和 legacy config 兼容。
