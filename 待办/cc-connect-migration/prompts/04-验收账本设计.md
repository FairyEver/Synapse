# 提示词 04：验收账本设计

把下面提示词完整发送给 Codex。

```text
目标：基于功能全集、产品设计和迁移映射，生成可执行、可闭合的验收账本。本阶段只设计验收，不写业务代码。

角色与职责：
你是 QA 与验收负责人。你的职责是为每个正式 CC ID 设计可判断通过或失败的验收项，覆盖核心逻辑、产品流程、Electron 边界、数据兼容和人工验收场景。你不能新增功能，不能放宽验收标准，不能写实现代码。你的输出必须让执行阶段知道完成后如何证明 done。

请直接在当前仓库中读取和写入下面列出的路径，不要要求用户手动粘贴文件内容。

请读取：

1. 待办/cc-connect-migration/整体标准.md
2. 待办/cc-connect-migration/artifacts/1.2-feature-manifest.md
3. 待办/cc-connect-migration/artifacts/2.1-synapse-product-baseline.md
4. 待办/cc-connect-migration/artifacts/2.2-product-design.md
5. 待办/cc-connect-migration/artifacts/3.1-migration-map.md
6. 待办/cc-connect-migration/artifacts/3.2-data-compatibility-plan.md
7. 待办/cc-connect-migration/artifacts/3.3-permission-and-security-map.md
8. 待办/cc-connect-migration/artifacts/1.4-glossary-and-concept-map.md
9. 待办/cc-connect-migration/artifacts/1.3-open-questions.md
10. 当前仓库 AGENTS.md

请生成：

待办/cc-connect-migration/artifacts/4.1-verification-ledger.md
待办/cc-connect-migration/artifacts/4.2-golden-test-cases.md
待办/cc-connect-migration/artifacts/4.3-manual-acceptance-script.md

如果 `待办/cc-connect-migration/artifacts/` 不存在，先创建该目录。

要求：

1. 每个正式 CC ID 都必须有验收项。
2. 每个验收项都必须能判断通过或失败，不能是模糊描述。
3. 核心逻辑优先使用 golden tests。
4. UI 流程使用人工验收步骤或组件行为测试。
5. Electron main process 能力使用 service/repository/IPC 边界测试。
6. 数据迁移和配置兼容必须有输入样例、预期输出和副作用检查。
7. 对无法自动化的验收项，写清楚人工验收步骤。
8. 涉及 Go 核心逻辑、解析、校验、配置生成、协议、状态机、数据转换的功能，必须进入 golden test 样本库。
9. 涉及菜单、页面、设置、弹窗、错误状态、加载状态、空状态的功能，必须进入人工验收脚本。
10. 不要写业务代码。
11. 不生成最终开发计划。

待办/cc-connect-migration/artifacts/4.1-verification-ledger.md 的表格字段至少包含：

CC ID
验收类型
输入或前置条件
操作步骤
预期结果
验证方式
证据文件或命令
状态
备注

待办/cc-connect-migration/artifacts/4.2-golden-test-cases.md 的表格字段至少包含：

CC ID
逻辑类型
输入样本
Go 原实现输出
3S 预期输出
边界样本
错误样本
等价判断规则
证据来源

待办/cc-connect-migration/artifacts/4.3-manual-acceptance-script.md 的表格字段至少包含：

场景
关联 CC ID
前置条件
操作步骤
预期结果
通过或失败记录
证据截图或日志位置
备注

验收类型只能使用：

unit
golden
integration
renderer
manual
static-audit

本阶段完成标准：

1. 每个正式 CC ID 都有验收方式。
2. 每个验收方式都有明确通过条件。
3. 无法自动化的部分有人工验收步骤。
4. 核心逻辑样本进入 待办/cc-connect-migration/artifacts/4.2-golden-test-cases.md。
5. UI 和人工流程进入 待办/cc-connect-migration/artifacts/4.3-manual-acceptance-script.md。
6. 没有进行任何迁移实现。
```
