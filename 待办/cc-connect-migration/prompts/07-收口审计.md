# 提示词 07：收口审计

把下面提示词完整发送给 Codex。

```text
目标：对 CC Connect 迁移到 3S 做最终收口审计。审计只能判断迁移闭环是否完成，不能重新发散成开放式建议。

角色与职责：
你是发布前收口审计负责人。你的职责是只判断迁移闭环是否完成，检查正式 CC ID、产品设计、工程映射、验收账本、开发计划和最终状态是否闭合。你不能重新发散需求，不能提出新架构设想，不能输出 UI 美化建议。你的输出必须明确 complete 或 incomplete。

请直接在当前仓库中读取和写入下面列出的路径，不要要求用户手动粘贴文件内容。

请读取：

1. 待办/cc-connect-migration/整体标准.md
2. 待办/cc-connect-migration/artifacts/1.1-source-inventory.md
3. 待办/cc-connect-migration/artifacts/1.2-feature-manifest.md
4. 待办/cc-connect-migration/artifacts/2.1-synapse-product-baseline.md
5. 待办/cc-connect-migration/artifacts/2.2-product-design.md
6. 待办/cc-connect-migration/artifacts/3.1-migration-map.md
7. 待办/cc-connect-migration/artifacts/4.1-verification-ledger.md
8. 待办/cc-connect-migration/artifacts/5.1-development-plan.md
9. 待办/cc-connect-migration/artifacts/1.3-open-questions.md
10. 当前仓库 AGENTS.md

审计规则：

只允许输出两类问题：

A. manifest 中已有正式 ID 未闭合。
B. 有来源证据的新候选项，需要用户确认是否纳入正式范围。

禁止输出：

1. 泛泛优化建议。
2. 没有证据的可能遗漏。
3. 新架构设想。
4. UI 美化建议。
5. 与 CC Connect 功能全集无关的重构建议。

请生成或更新：

待办/cc-connect-migration/artifacts/7.1-final-audit.md

如果 `待办/cc-connect-migration/artifacts/` 不存在，先创建该目录。

待办/cc-connect-migration/artifacts/7.1-final-audit.md 必须包含：

1. 审计结论：complete / incomplete
2. 未闭合正式 ID 列表
3. 产品设计未覆盖 ID 列表
4. 新发现候选项列表
5. 验收账本未通过项
6. 需要用户确认的 dropped / replaced / merged 项
7. 最终是否满足完成定义

完成定义：

当 待办/cc-connect-migration/artifacts/1.2-feature-manifest.md 中所有正式 CC ID 都处于 done / merged / replaced / dropped，且 待办/cc-connect-migration/artifacts/4.1-verification-ledger.md 中对应验收项全部通过或有用户确认的豁免，则 CC Connect 迁移到 3S 完成。

如果满足完成定义，请明确写：

CC Connect 迁移闭环完成。

如果不满足完成定义，请只列出阻塞完成的具体 ID 和证据，不要扩展讨论。
```
